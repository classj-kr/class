# 수 모형

홈의 **교과 탐구 → 수학 교구 → 수 모형**에서 여는 자릿값 교구입니다.
주소는 `/learning/inquiry/math/number-models/`입니다.

- 자연수는 일·십·백·천(0~9999), 소수는 1·0.1·0.01·0.001(0~9.999)을 다룹니다.
- 자연수에서는 작은 정육면체가 1, 소수에서는 큰 정육면체가 1입니다. 기준을 항상 표시합니다.
- 모형마다 작은 정육면체의 변 길이를 같게 그립니다. 자연수와 소수의 장면은 각각 보관합니다.
- 모형 10개를 바로 왼쪽 자리의 1개로 묶거나, 1개를 바로 오른쪽 자리의 10개로 풉니다.
  교환 전후 전체 값은 보존합니다. 소수는 0.001 단위 정수로 계산하여 부동소수점 오차를 피합니다.
- 28+7, 42−17, 0.8+0.5, 1.2−0.5 예시가 있습니다. 뺄셈은 필요한 모형으로 풀어 놓은 뒤 실행합니다.
- 표시할 자리는 2~4개, 한 자리의 모형은 30개까지입니다. 모형이 있는 자리를 숨길 수 없습니다.
- 값 가리기, 되돌리기/다시 하기, 설정 접기, 키보드 조작을 지원합니다.
- 제목 줄과 전체 화면 버튼 없이 바로 조작 도구와 모형을 표시합니다. 사용 설명은 접힌 도움말에 모으고, 저장 상태와 조작 메시지는 오류가 있을 때만 표시합니다.
- 계정의 `SiteStorage` 공간 `number-models/board`에 저장합니다. 게스트는 탭 메모리만 사용합니다.
- SVG로 모형을 그립니다. 외부 이미지·런타임 CDN·브라우저 로컬 저장소를 사용하지 않습니다.

`npm run test:number-models`로 수량 보존, 입력 범위, 예시를 검증합니다.
`npm run test:number-models:ui`로 홈 연결, 교환, 소수, 모바일, 계정 저장을 검증합니다.
검증 캡처는 `outputs/number-models/`에 무손실 WebP로 저장합니다.
