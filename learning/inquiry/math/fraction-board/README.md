# 분수 그림판

홈의 **교과 탐구 → 수학 → 분수 그림판**에서 여는 정적 수학 교구입니다.
주소는 `/learning/inquiry/math/fraction-board/`입니다.

- 사각막대·사각형 격자·수직선·원판에서 등분 수와 색칠할 칸 수를 정합니다.
- 칸을 누르면 색칠하거나 지웁니다. 수직선은 눈금을 눌러 0에서 해당 위치까지 표시합니다.
- 1~24등분, 그림마다 전체 1~4개, 비교 그림 최대 6개를 지원합니다.
- 분자가 분모보다 크면 전체가 자동으로 늘어나며 대분수도 표시합니다.
- 분자·분모 입력으로 바꾸면 색칠은 처음 칸부터 채웁니다. **양 유지**를 켠 분모 변경은
  정확한 동치분수만 허용하며 온전한 칸으로 표현할 수 없는 값을 반올림하지 않습니다.
- 같은 모양의 전체 크기는 모든 비교 그림에서 같습니다. 등분선·색칠·분수 이름을
  각각 숨기거나 보일 수 있습니다. 설정 접기와 전체 화면으로 그림을 크게 봅니다.
- 복제·삭제·색칠 지우기·되돌리기·다시 하기를 지원합니다. 방향키로 칸을 고르고
  Enter/Space로 색칠합니다. Ctrl/⌘+Z, Ctrl/⌘+Shift+Z로 되돌리고 다시 합니다.
- 로그인하면 기존 `SiteStorage`의 `fraction-board/board`에 자동 저장합니다.
  게스트와 서버 저장을 사용할 수 없는 경우에는 현재 탭 메모리만 사용합니다.
  저장 실패를 표시하며 브라우저 로컬 저장소에 기록하지 않습니다.
- 전체/선택 그림을 투명 또는 흰 배경의 **무손실 WebP**로 내보냅니다.
  로컬 WebP 인코더는 내보낼 때만 별도 Worker에서 실행합니다.
  SVG 도형은 코드로 유지합니다. 외부 이미지나 런타임 CDN은 사용하지 않습니다.

`core.js`는 분수 모델·입력 검증·공통 SVG 기하, `app.js`는 조작·기록·저장,
`export-worker.js`는 무손실 WebP 인코딩을 담당합니다.
인코더의 버전과 출처는 `vendor/webp/SOURCE.md`에 있습니다.

검증은 저장소 루트에서 실행합니다.

```sh
npm run test:fraction-board
npm run test:fraction-board:ui
```

브라우저 검증은 임시 PGlite와 Edge(Windows)를 사용합니다. 검증 캡처와 내보낸
그림은 Git에서 제외된 `outputs/fraction-board/`에 무손실 WebP로 저장하며,
디코딩 결과·투명도·크기·샘플 RGBA 값의 일치를 확인합니다.
