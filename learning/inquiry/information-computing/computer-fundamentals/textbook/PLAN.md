## 확정 조건
- 대상: 초등 고학년 컴퓨터 입문자.
- 기존 A01–J03, 36차시의 순서와 학습 범위 유지. 제목은 2026-09-26 요청에 따라 간결한 명사구로 통일.
- 설명·문제·선지·해설: KoPubWorld 바탕체.
- 필수 용어: 첫 정의와 개념 표시에 한국어·영어 병기. 약어는 풀네임 함께 표시.
- 광고 문구, 자찬, 반복 격려, 별도 상단 띠 금지.
- 목차와 실제 차시 주소에서 개편된 교재 사용. 검토용 별도 주소만 남기고 끝내지 않음.
- 기존 실습·원본 자료는 보존하며 실제 동작을 확인해 활용.

## 작업 순서
1. 아래 차시별 학습 범위에 따라 본문·용어·적용 과제를 집필한다.
2. 본문 / 실습 / 적용 / 확인으로 학습 화면을 나눈다. 본문의 부품 설명과 시뮬레이터를 한 화면에 몰아넣지 않는다.
3. 관찰한 증거와 결과 예측을 요구하는 적용 과제를 작성한다.
4. 확인 문항과 오답 설명을 검토한다. 오답 선택지 제거로 정답을 강제하지 않는다.
5. 실제 목차 및 lessons 경로에 연결하고 진도 저장을 통합한다.
6. 전 차시를 브라우저에서 읽고 조작하며 검증한다. 소스 존재 여부만으로 완료 판정하지 않는다.

2026-09-21 후속: 전체 36차시를 대상으로 생활 사례·비유 필요성을 다시 검수했다. 기존 세 그림을 유지하고 33차시에 비교 그림을 추가했다. A04는 시계·피아노·온도계로 본문과 확인 문항까지 수정했다. [차시별 검수표](../../../../../docs/computer-analogies/AUDIT.md)에 대응 개념과 한계를 남겼다. 새 그림 312개 상태·너비 조합, 기존 그림 52개 조합, 기존 35차시 전체 회귀 검사와 효과음 38개 시나리오를 통과했다.

2026-09-26: 차시 제목을 질문형 문장에서 짧은 개념명으로 통일했다. 목차, 본문 상단, 브라우저 제목, 앞뒤 이동용 데이터, 영어 제목, 진도표를 함께 수정했다. Chrome에서 36차시의 목차·본문 상단·브라우저 제목 일치와 기존 순서 유지, 1440px·390px 목차 표시를 확인했다.
