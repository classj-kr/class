# 컴퓨터 교재 1차시 검토본

대상: 초등 고학년 컴퓨터 입문자.

기존 36차시의 제목과 순서를 유지한다. 차시 안의 분량, 설명의 깊이, 실습과 평가를 조정한다. 기존 lessons 디렉터리는 보존한다.

## 작성 원칙

학생 화면에는 학습에 필요한 제목·상황·설명·조작·결과만 쓴다. 홍보 문구, 학습 효과를 자찬하는 문장, 반복적인 격려는 쓰지 않는다.

필수 개념은 처음 정의할 때 한국어와 영어 원어를 함께 쓴다. 개념도에도 영어 원어를 병기한다. 약어는 처음 소개할 때 영어 풀네임도 함께 쓴다.

설명·문제·선지·해설은 사용자가 선택한 KoPubWorld 바탕체로 표시한다. 제목 위에 별도 상단 바나 반복되는 영역명을 두지 않는다. 차시 이동과 진도는 제목 옆에 배치해 본문 시작 위치를 높인다.

## 1차시: 컴퓨터는 무슨 일을 할까?

진입점: a01.html

이번 차시의 범위는 입력·처리·출력·저장의 역할과 관계다. CPU·GPU·RAM·SoC, 픽셀, 파일 형식의 세부 설명은 뒤의 해당 차시에 남긴다.

1. 읽기: 고양이 그림의 색을 바꾸는 사례로 네 역할을 설명한다.
2. 그림 실습: 같은 입력에 다른 규칙을 적용한다. 저장하지 않은 출력을 닫고, 저장한 결과를 다시 연다. 흑백과 밝기 변환은 실제 이미지 데이터에 적용한다.
3. 다른 상황: 숫자를 입력하고 처리 규칙을 정해 결과를 저장한다. 결과를 다시 열어 제출한다. 화면 출력이 정답이어도 저장본이 다르면 통과하지 않는다.
4. 확인 문제: 날씨 앱, 카메라, 계산, 터치 화면에서 역할을 판단한다. 오답별 설명을 제공하며 틀린 선택지를 제거하지 않는다. 첫 응답과 재시도 결과를 구분한다.

완료 조건은 그림 실습의 관찰 세 가지, 숫자 독립 과제, 확인 문제 4개 해결이다. 각 항목은 자유롭게 다시 열 수 있으며 단순 방문으로 완료하지 않는다.

학습 기록은 classj:textbook:a01:v1 키에만 저장한다. 기존 교재의 진도는 변경하지 않는다. 모형의 저장본은 작업 닫기 이후에도 유지되지만, 페이지 새로고침 시 작업 상태는 초기화된다. 완료한 항목과 문항 응답 기록은 재방문 시 유지된다. 이 차이를 학생 화면에 명시한다.
