# 컴퓨터 교재

대상은 초등 고학년 컴퓨터 입문자다. 기존 A01–J03의 36차시 순서와 범위를 유지하고, 본문·용어·적용 과제·평가 문항을 새로 작성했다. 차시 제목은 2026-09-26 요청에 따라 짧은 개념명으로 통일했다.

## 사용 경로

- 차시 목록: `../index.html`
- 실제 차시 주소: `../lessons/?lesson=a01`부터 `?lesson=j03`
- A01은 `a01.html`로 연결된다. A02–J03은 실제 lessons 주소에서 새 본문과 검증한 기존 실습을 함께 사용한다.
- 범위와 완료 기준: [PLAN.md](PLAN.md)

## 작성 기준

필수 개념은 첫 정의에 한국어와 영어를 병기한다. 약어에는 영어 풀네임을 함께 적는다. 설명·문제·선지·해설에는 KoPubWorld 바탕체를 사용한다. 차시 제목 위에 별도 안내 띠나 반복되는 영역명을 두지 않는다. 학생 화면에는 홍보 문구나 학습 효과를 자찬하는 문장을 넣지 않는다.

본문과 실습을 나누고, 실제 조작으로 관찰할 것과 새 상황에서 판단할 것을 구별한다. A03은 기기·운영체제·앱의 역할과 지원 조건을 다루고, C01은 요청·권한·장치 제어에서 멈춘 위치를 판단한다. G01은 0·1 조합을 직접 만들며 A04·A05의 측정 설명을 반복하지 않는다. 내용이 많은 H05·I02에는 소주제를 표시한다.

## 파일 구성

- `a01.html / a01.css / a01.js / a01-model.js`: 그림 변환과 저장, 숫자 독립 과제, 확인 4문항.
- `edition-abc.js / edition-de.js / edition-fg.js / edition-h.js / edition-ij.js`: 나머지 35차시의 집필 자료.
- `edition.js / edition.css`: 본문·실습·적용·확인 화면, 용어 병기, 오답별 해설, 답 기록.
- `../lessons/boot.js`: 실제 주소에서 차시에 맞는 자료를 읽고 새 화면 연결.
- 기존 실습은 원본 파일을 유지해 활용한다. 3차시의 과도한 전문 용어를 덜었고, 14차시의 메뉴 클릭 충돌을 수정했다. 24차시는 새 이진 조합 실습을 사용한다.

## 문항과 기록

A01을 제외한 차시는 실습 확인 1문항, 새로운 적용 상황 2문항, 확인 문제 2문항이다. 총 175문항에 선택지별 설명을 작성했다. A01 확인 4문항을 포함하면 179문항이다.

답을 고르는 것만으로 완료하지 않는다. 답 확인을 눌러야 판정하며, 오답도 계속 선택할 수 있다. 표시 순서는 차시·문항별로 섞고 새로고침 뒤에도 유지한다. 재시도 끝에 해결한 문항과 첫 답부터 맞힌 문항은 별도로 기록한다. 실습 확인에는 실습 조작 기록도 필요하다.

새 기록은 `classj:textbook:{id}:v1`에 저장한다. 기존 `computer-literacy:{id}` 기록을 지우지 않는다. 목차는 새 완료 기록과 기존 완료 기록을 함께 표시한다. 잘못된 저장 데이터나 저장 불가 환경에서도 본문과 답 확인을 사용할 수 있다.

실습 모형의 조작 상태는 새로고침하면 초기화된다. 완료 기록은 같은 브라우저에 남는다. 이 차이를 실습 화면에 표시한다.

## 검증

```text

node tests/computer-a01-browser.cjs
```

A01 검사는 실제 그림 데이터 변환, 저장본의 독립성, 독립 과제의 판정, 재시도, 기록 복원, 5가지 너비를 확인한다. 전체 개편 검사는 35차시의 대표 실습 조작, 모든 새 문항의 오답·정답 처리, 완료 기록 복원, 실제 웹폰트 사용, 4가지 화면 너비, A01 실제 경로와 목차 연결을 확인한다.

결과: [검증 기록](../../../../../docs/computer-edition/VERIFICATION.md). 검사 코드가 확인하는 범위와 학생 대상 수업 검증은 다르다. 차시별 수업 시간과 실제 독해 난도는 아직 학생 수업으로 검증하지 않았다.

## 2026-09-21 정오 효과음 수정

기존 공통 효과음은 화면 문구에서 정오를 추측했다. H05 적용 2에서 오답을 제출하면 해설은 오답인데, 학습 기록의 ‘첫 답 정답 0/0’이 정답으로 감지되어 success.ogg가 재생되는 것을 실제 브라우저에서 재현했다.

새 교재의 공통 채점기와 A01은 이번 제출의 판정으로 ClassGameSfx의 success/error를 직접 호출한다. 문항 해설과 누적 기록의 자동 문구 감지를 제외하고, 답 확인 단추의 일반 클릭음도 제외해 결과음이 겹치지 않게 했다. 음소거·음량 설정은 공통 효과음 설정을 따른다. 두 진입 HTML에서 공통 효과음 스크립트를 직접 읽어 정적 미리보기에서도 재생하며, 서버는 같은 스크립트를 중복 삽입하지 않는다.

검사: `node tests/computer-sounds-browser.cjs`. H05와 A01에서 38개 시나리오를 통과했다. 정답→오답 재시도, 같은 오답 반복, 저장 기록 복원, 인접 문항, 미선택·실습 미조작, 키보드 제출, 음량·음소거를 확인했다. 실제 OGG 재생 Promise가 성공하는 것까지 검사했으며 사람이 직접 청취한 검사는 아니다. 기록: `docs/computer-edition/verification-sounds.json`.

추가로 A01 전체 브라우저 검사와 H05 실습·문항·진도·레이아웃 회귀 검사를 통과했다.

## 2026-09-21 전체 생활 사례·비유 검수

A01·B01·E04만 보완했던 범위를 전체 36차시로 넓혔다. 나머지 33차시 본문에 생활 사례 또는 실제 동작 그림을 추가했다. 각 그림은 비교 단추로 상태와 설명이 함께 바뀌며, 실제 개념에 대응되는 관계와 비유의 한계를 적었다. 조작 자체가 개념인 차시에는 물건 비유를 강요하지 않고 실제 동작을 그렸다.

A04는 매끄러운 초침과 초 단위 숫자 시계, 어쿠스틱·디지털 피아노, 액체 기둥과 숫자 온도계를 함께 비교한다. 같은 입력을 움직이는 조절 막대로 연속적인 변화와 구별된 기록 단계를 관찰한다. 네 단계 피아노는 교육용 모형임을 명시하고 실제 건반/해머 감지와 음량·음색, 스피커의 공기 진동을 구별했다. 본문과 확인 두 문항도 이 사례로 바꿨다.

구현: `life-figures.js`, 공통 `analogies.css`. 검수표: [36차시 검수표](../../../../../docs/computer-analogies/AUDIT.md).

검증:

- `node tests/computer-life-figures-browser.cjs`: 새 33차시, 312개 상태·너비 조합(1440·768·390·320px), 실제 KoPubWorld 폰트, 키보드 전환, SVG 글자 잘림, 시계·피아노·온도계의 수치 대응 검사 통과.
- `node tests/computer-analogies-browser.cjs`: 기존 3차시의 52개 보기·너비 조합 통과.
- `node tests/computer-edition-browser.cjs`: 기존 35차시 실습·175문항·560개 배치·140개 폰트·진도·저장 복구 검사 통과.
- `node tests/computer-sounds-browser.cjs`: 정오 효과음 38개 시나리오 통과.
- 새 33차시의 기본 그림, 대표 비교 상태와 모바일 화면을 직접 보고 겹침·표시 오류를 수정했다. 학생 대상 수업 검증은 별도다.

## 2026-09-21 본문 소제목과 H04 설명 순서 수정

‘답을 눌렀는데 제출 기록이 없다’는 선택과 제출을 구별하지 못하는 모호한 소제목이므로 ‘답 선택부터 채점 결과 확인까지’로 바꿨다. H04 본문은 정상적인 선택·제출·서버 채점·결과 저장·응답·화면 표시부터 설명한다. 실습 지시도 실제 제출 뒤 각 단계의 변화를 비교하도록 정리했다. 오류 상황은 처리 기록이 명시된 기존 적용 과제에서 다룬다.

전체 본문 소제목을 점검하고 B02·C03·C04·F01·G02·H03·H05의 모호한 표현도 수정했다. 차시 제목과 순서는 유지했다. 8개 소제목의 390px 실제 화면과 H04 기존 실습·문항·진도·저장 복구 검사를 확인했다.
