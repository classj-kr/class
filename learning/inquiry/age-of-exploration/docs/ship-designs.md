# 경쟁전 출발 항구별 선박

경쟁전에서 학생이 고른 출발 항구로 배의 외형을 정한다. 현재 위치, 방문 도시, 정박 항구, 접속 기기와 무관하게 저장된 출발 선택을 사용한다. 자유 항해와 출발 선택 전에는 기존 원작 선박을 사용한다. 출발 선택 화면에 배 미리보기는 추가하지 않는다.

## 배정

`data/catalog/ship-origins.json`의 `ports`가 현재 입항 가능한 122개 도시의 배정표다. `shipType`은 외형, `shipScale`은 화면상 크기이며 이동 물리·속도·충돌·피로·바람 보정에는 사용하지 않는다.

- 리스본·세비야: 갤리온. 대표 원양항의 높은 선미와 다중 돛.
- 포르투·카디스: 카라벨. 말라가·팔마: 작은 연안 범선.
- 런던 등 큰 북유럽 교역항: 카락. 비스뷔·베르겐: 코그.
- 이탈리아·발칸: 갤리선. 이슬람권·인도양: 다우.
- 중국·베트남: 정크선. 한국: 한선. 일본: 일본 연안선. 동남아시아: 종선.
- 서아프리카: 연안 돛배.
- 아바나·베라크루스·파나마: 카라벨. 아카풀코 등 현지 해안 도시: 대형 카누. 툼베스: 발사 뗏목선.

도시의 조선소 유무와 항해 전통을 참고한 게임용 배정이다. 실제 도시에서 특정 선종만 사용했다는 주장이 아니며, 개별 역사 선박의 정밀 복원도 아니다. 원작 성능 차이는 경쟁전에 도입하지 않았다.

## 참고자료

사용자가 제공한 `해설지.xls`를 읽기 전용으로 참고했다.

- `선박,기술!A2:J9`: 코그·카라벨·다우·카락·갤리온의 원작 분류와 등장 지역. 갤리온은 원작 표에서 1515년 이베리아로 기재되어 있다.
- `도시(자세)!H2:J227`: 항구와 조선소 여부. 각 배정에 `sourceRow`, `sourceCityName`, `sourceShipyard`를 기록했다.
- 해설지에는 순번 159의 페구가 있고 현재 카탈로그에는 없다. 따라서 말라카 이후에는 원작 순번에 1을 더해 연결했다. 말라카·오문(마카오)·한양(서울)·나가사키·아바나·툼베스 등을 이름으로 교차 확인했다.
- 도시의 현재 입항 가능 여부는 해설지 대신 서버의 검증된 카탈로그를 따른다. 해설지에 항구가 표시되어 있어도 현재 입항할 수 없는 도시는 배정 대상에서 제외했다.
- 비유럽 선종 추가와 개별 항구의 최종 배정은 이 작업의 디자인 결정이다. 아메리카 배정은 기존 도시 데이터의 `in1520` 설명도 참고했다.

조형 참고: [Royal Museums Greenwich의 다우 모형](https://www.rmg.co.uk/collections/objects/rmgc-object-7039), [15세기 말 카락 그림](https://www.rmg.co.uk/collections/objects/rmgc-object-111321), [Junk Rig Association의 돛살 구조 설명](https://www.junkrigassociation.org/Common-terms). 모형의 선체와 돛 구조만 참고했으며 웹 이미지를 자산으로 복제하지 않았다.

## 구현과 검증

`public/js/ship-designs.js`는 서버와 브라우저가 공유하는 배정/외형 모듈이다. 저장된 출발 도시에서 매번 선종을 도출하므로 별도의 선박 저장 데이터가 필요 없다. 선체를 8방향으로 투영하되 돛대는 수직으로 유지하고, 선종과 방향별 이미지를 캐시한다.

`npm run test:ship-designs`는 122개 배정과 자료 연결·모드별 선택·방문 항구 독립성을 검사한다. `npm run test:ship-designs:smoke`는 임시 서버에서 출발 선택, 주변 참가자 동기화, 새 경기 초기화, 재접속과 서버 재시작 복원을 검사한다. 테스트가 만든 데이터는 저장소의 `.tmp/ship-design-review`에만 둔다.
