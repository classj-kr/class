# 발견 장소의 사진 선정

2026-11-21 사용자 지적에 따라 대표사진과 보조사진에 위성·궤도·합성 영상을 사용하지 않는다. 자료가 존재하거나 이용 조건이 허용된다는 이유만으로 넣지 않고, 학생이 장소의 특징을 바로 이해하는 데 도움이 되는 이미지만 제시한다. 적절한 사진이 없는 곳은 사진 없이 설명을 제공한다.

`photo-credits.json`에 연결된 WebP 370장을 축소 모음으로 시각 검토했다. 아마존강 하구를 포함한 위성·궤도·합성 영상 39장과 발트해 호박 해안의 광역 지도 1장을 발견 팝업·학습 설명에서 제외했다. 이 검토는 모든 사진의 세부 촬영 장소와 연대를 재검증했다는 뜻은 아니다. 사진의 출처 메타데이터는 보존하며, `representative: false`인 이미지는 서버가 내려주지 않는다.

저장된 미션의 설명 자료도 서버 시작 때 사진 선정 결과를 갱신한다. 문제와 답변 진행 상태를 다시 생성하거나 초기화하지 않는다. 사진이 없는 설명에서는 기존 공통 스타일로 사진틀과 출처 버튼을 숨긴다.

검증:

- `node tests/discovery-photo-policy-unit.js`: 제외된 40개 항목, 현장 사진 유지, 저장된 미션 갱신과 반복 실행 확인.
- `node tests/discovery-photo-policy-browser.cjs`: 실제 서버에 입장하여 아마존강 하구의 사진·빈 틀·출처 버튼이 사라지고 메테오라 풍경 사진은 정상 표시되는지 확인.
- `VOYAGE_PHOTO_CAPTURE`를 지정하면 검증 화면을 무손실 WebP로 저장한다.
