# 발견 장소의 사진 선정

2026-11-21 수정. 장소의 특징을 알아보기 어려운 위성·궤도·합성 영상과 광역 지도는 실제 장소의 풍경 사진으로 교체한다. 이미지를 숨기는 것으로 교체를 대신하지 않는다. 사진의 대상과 촬영 장소를 원본 설명에서 대조하고, 이용 조건과 저작자를 기록하며, 실제 이미지를 시각 검수한다.

앞서 숨겼던 40곳 모두 대체 사진을 확보해 다시 표시한다. 아마존강 하구의 바이리키 제도, 나미브 사막과 대서양이 맞닿는 해안, 발트해에서 호박을 찾는 사람 등 본문과 연결되는 사진을 선정했다. 40장의 이전·새 출처, 원본 설명, 이용 조건, 캡션, 파일 해시와 크기는 `discovery-photo-replacements.json`에 기록한다. `photo-credits.json`은 새 사진의 출처를 제공한다.

원본 종횡비와 구도를 유지한 WebP를 사용한다. 임의의 위성사진·지도를 사진의 빈자리 채우기로 사용하지 않는다. 사진이 장소 전체 대신 일부를 보여줄 때는 캡션에 구체적인 지명을 적고, 오늘날의 운하나 환경 변화가 나타나는 사진은 시점을 설명한다. 저장된 미션도 사진 경로·캡션·출처를 갱신하며 문제와 답변 진행 상태는 유지한다.

검증:

- `node tests/discovery-photo-policy-unit.js`: 40곳의 새 출처·이미지 해시와 표시 여부, 저장된 미션 갱신과 반복 실행 확인.
- `node tests/discovery-photo-policy-browser.cjs`: 실제 서버에 입장해 아마존 하구 사진과 캡션을 확인하고, 40장 전체 디코딩과 모바일 표시, 기존 메테오라 사진 유지를 확인.
- `VOYAGE_PHOTO_CAPTURE`를 지정하면 검증 화면을 무손실 WebP로 저장한다.
