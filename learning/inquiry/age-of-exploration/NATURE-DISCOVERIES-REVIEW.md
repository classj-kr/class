# 자연 발견물 보강

선정 기준: 관광 인지도만으로 추가하지 않고 지형 형성 과정과 눈에 띄는 경관을 설명할 수 있는 곳을 선정했다. 도시나 휴식 항구를 신설하지 않는다.

- 바투르 칼데라: 이중 칼데라와 호수. UNESCO Batur Global Geopark.
- 밀퍼드사운드: 빙하가 깎은 골짜기에 바닷물이 들어온 피오르. New Zealand Department of Conservation.
- 초콜릿 힐스: 석회암의 용식·침식으로 형성된 원뿔형 언덕. UNESCO Bohol Island Global Geopark.
- 팔라완 지하강: 석회암 동굴 속 강이 바다로 연결되는 경관. UNESCO World Heritage 652.
- 테이블산: 기존 도시 명소를 독립 발견물로 전환. 기존 ID와 사진 출처를 유지하여 발견 기록을 보존한다. SANParks의 지질 설명 참고.

각 항목의 원문 링크는 discoveries.json의 sources에 기록했다. 보라카이는 추가하지 않았고, 노르웨이 송네피오르는 기존 항목을 유지했다.

네 곳 모두 위키미디어 공용의 실제 사진을 사용한다. 바투르: TropicaLiving (CC BY-SA 3.0), 밀퍼드사운드: Wikikiwiman (Public domain), 초콜릿 힐스: Mmlibranda (CC BY-SA 4.0), 팔라완 지하강: Mike Gonzalez (CC BY-SA 3.0). 원본 및 이용조건 링크는 data/catalog/photo-credits.json에 기록하고 발견 화면에 표시한다. 크기 축소와 WebP 변환만 적용했으며 오늘날 모습으로 표시한다.

검증: nature-discoveries-smoke.js에서 실제 서버와 지형 데이터로 접근 가능한 육상·해상 위치, 최초/중복 발견, 원거리 및 육상 경관의 선박 접근 거부, 이미지 응답을 확인했다. Chrome에서 다섯 발견 버튼과 데스크톱·모바일 표시를 확인했다. npm run check, v79-city-landmark-unit.js, caspian-discovery-unit.js 통과.

기존 전체 이미지 검사(v78)는 티르 영녕사 항목의 기존 이미지 누락으로 285/286에서 실패한다. 이번에 추가한 네 사진와 테이블산 사진은 모두 제공된다.
