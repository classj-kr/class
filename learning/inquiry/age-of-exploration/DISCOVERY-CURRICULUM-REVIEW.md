# 대항해시대 발견물 교육과정 검토

검토·반영일은 2026년 10월 21일이며, 범위는 2022 개정 교육과정의 초등학교부터 고등학교까지다. **발견물·명소 346개를 전수 분류하고, 교과 핵심 109곳과 문화·과학적 가치가 큰 보조 24곳을 합쳐 133곳을 기본 추천으로 반영했다.** 교육과정에 지명이 없더라도 배울 가치가 큰 장소는 유지한다.

이 수치는 교육과정이 정한 필수 지명 수가 아니라, 현재 설명의 학습 가치·대표성·중복·항해 맥락을 함께 고려한 편집 판단이다. 이름이 교육과정 원문에 없다는 이유만으로 불필요하다고 판정하지 않았다. 반대로 ‘세계 문화’나 ‘여행’에 연결할 수 있다는 사실만으로 모든 관광지를 기본 학습 대상으로 유지하지도 않았다.

## 실제 반영 결과

| 구분 | 반영한 동작 |
| --- | --- |
| 기본 추천 | 핵심 109곳 + 가치가 큰 보조 24곳 = 133곳. 스톤헨지·카호키아·울루루·소코트라·팔라완 지하강 등 교과 밖의 가치도 포함한다. |
| 주제별 탐구 | 핵심 109곳과 보조 150곳을 합친 259곳을 현장 발견 대상으로 센다. 추천 밖의 보조 126곳은 비교·심화 목적에 맞춰 선택한다. |
| 추가 자료 | 축소 후보 82개 중 같은 장소의 접근 경로 2개는 대표 기록에 통합한다. 나머지 80곳은 기본 지도·추천에서 제외하고 ‘전체 자료’에서 선택하게 한다. |
| 후대 문화 | 5곳을 별도 자료 범위와 도시의 ‘후대 문화’ 버튼으로 구분한다. 타지마할은 교사가 지정한 후대 문화 미션으로 방문할 수 있다. 학습 기록은 남고 현장 발견 수에는 더하지 않는다. |
| 선택 화면 | 자료 범위·학교급·주제·종류 필터, 문화·과학 가치 표시, 학습 목표와 연계 가능 성취기준을 제공한다. 학교급은 사례 활용 가능 범위이며 문항 난도가 학년별로 달라지는 기능은 아니다. |
| 문항 | 추천 133곳 모두 이해 중심 문항 3개씩을 적용했다. 후대 문화 5곳과 티르·페리토모레노 등도 직접 구성했다. 원인·자료·교류·환경과 생활의 관계를 묻는다. |
| 중복 기록 | 기자 피라미드와 하롱베이는 지도·도시 접근을 하나의 발견 기록으로 센다. 두 접근 경로에서 같은 미션을 진행할 수 있다. |
| 이전 기록 | 원본 발견 ID 배열을 삭제하지 않는다. 완료·순위·맞힌 문제 수를 유지하면서 오래된 미션의 본문과 문항을 갱신한다. 진행 중인 문제는 설명 화면에서 이어 간다. |

현장 발견 총수는 **346 → 259곳**으로 바뀌었지만, 옛 발견과 추가 자료·후대 문화의 학습 기록은 도서관의 ‘내가 살펴본 곳’에 보관한다. 도시 설명 229곳은 발견물 등급과 별개로 유지하며, 학교급 필터를 적용하면 등급이 있는 발견물·명소만 보인다. 바다 동물 8종은 별도 활동으로 유지했다.

문구도 고쳤다. 드레이크 해협의 ‘이듬해’를 같은 해인 1520년으로 바로잡았다. 과나아니의 ‘유럽 배 최초’와 근거가 불명확한 잔존 인구 11명, 페리토모레노의 1520년 빙하 크기 단정을 제거했다. 과나아니는 콜럼버스 일행의 상륙 및 루카요 주민 피해를 설명하고, 정확한 섬 위치에는 견해 차이가 있음을 표시했다. 티르의 제작 사정은 학생 본문에서 뺐다. 타오스·아코마는 ‘옛 도시터’에서 ‘생활 유산’으로 바꿨고, 확인하기 어려운 ‘아무도 몰랐다·오른 적 없다’ 같은 단정도 해당 설명에서 덜어냈다. 그랜드캐니언·갈라파고스의 ‘몇 해 뒤’는 절대 연도로 고쳤다.

후대 건물 설명은 오늘날 시점으로 다시 쓰고, 1520년 설명과 제목으로 분리했다. 블루 모스크의 완공 연도는 1617년으로 바로잡았으며, 베르사유의 사냥용 숙소·증축·왕실과 정부 이전을 구분했다. 근거: [콜럼버스와 타이노](https://www.loc.gov/exhibits/exploring-the-early-americas/columbus-and-the-taino), [상륙지 위치에 관한 해양연구소 논문](https://www2.whoi.edu/staff/prichardson/wp-content/uploads/sites/75/2018/11/Richardson-Goldsmith-1987-Oceanus-Columbus.pdf), [루카요 강제 동원을 다룬 연구](https://doi.org/10.1073/pnas.2015764118), [포탈라궁](https://whc.unesco.org/en/list/707/), [모스크바의 성당](https://whc.unesco.org/en/list/545/), [블루 모스크의 튀르키예 종무청 자료](https://www.diyanet.gov.tr/kurumsal/Detay/10373), [베르사유 공식 연혁](https://en.chateauversailles.fr/press/evenements/1623-2023-400-years-palace-versailles).

검증 결과:

- 도시를 포함한 575개 장소에서 세 문항씩 생성되며 선택지·본문 근거·정답 누출 검사를 통과했다. 직접 구성한 문항 묶음은 기존 자료를 포함해 153곳이다.
- 발견물·명소 346개, 1,038문항 기준 ‘만들다 → 만’ 오류는 **20곳 → 0곳**, 수치 빈칸 문항은 **37개 → 26개**다. 추천 133곳과 후대 문화 5곳에는 수치 빈칸 문항이 없다. 나머지 선택 자료의 자동 문항까지 모두 이해 문항으로 바꾼 것은 아니다.
- 학교급·주제 필터, 모바일 선택·읽기 화면, 중복 장소의 두 접근 경로, 후대 문화의 기록과 집계 분리를 실제 Edge에서 확인했다.
- 서버 재시작 시 이전 ID·발견 기록·완료 시각·순위·연속 정답 2개를 유지하면서 문항이 갱신됐다.
- 전체 단위 검사 70개 중 64개가 통과했다. 실패 6개는 수정 전 HEAD 코드에서도 같은 지점에서 실패했다. 교사 안내 문구 2건, 이전 입장·최종 문제 UI 검사 3건, `grand-banks-cod` 사진·위치도 분류 검사 1건이다. 이번 장소 학습 전용 단위·복구·통합 검사와 새 브라우저·이전 기록 검사는 통과했다.

실행 명령은 `npm run check`, `npm run test:place-study`, `node tests/discovery-learning-browser.cjs --capture`, `node tests/discovery-learning-migration-smoke.cjs`다. 화면 캡처는 [검증 폴더](E:/webprojects/class/output/discovery-learning-browser)에 무손실 WebP로 저장하고 크기·디코딩 결과를 확인했다.

아래 판정표와 오류 사례는 **수정 전 검토의 근거 기록**이다. 모든 세부 사실·사진·좌표의 검증, 학교급별 문항 분기, 모든 비교 자료의 수동 출제를 완료했다는 뜻은 아니다.

## 수정 전 검토 범위와 판정 기준

지도 발견물 286개와 도시 명소 60개의 설명·1520년 설명을 읽고 판정했다. 주된 비교 대상은 사회·역사·지리·과학이며 여행지리 등 선택 과목의 활용 가능성도 포함했다. `mission-catalog.js`가 `discoveries.json`에 `regional-sites.json`의 발견물 1개를 추가하므로, 원본 JSON 하나만 세면 전체 목록을 놓친다. 발견 총수는 서버의 `FOUND_TOTAL`에 따라 도시 명소까지 포함한 346개다. 동물 만나기 8종은 별도 활동이므로 이번 발견물 346개 판정에는 넣지 않았다. 도시 자체의 설명 전체와 모든 사진·좌표의 사실성은 별도 검토 범위다.

| 판정 | 지도 발견물 | 도시 명소 | 합계 | 권장 처리 |
| --- | ---: | ---: | ---: | --- |
| 핵심 | 85 | 24 | 109 | 교육과정과 항해의 개념을 연결하는 기본 추천 후보 |
| 보조 | 128 | 22 | 150 | 교사가 주제·학교급·비교 목적에 맞춰 선택 |
| 축소 | 72 | 10 | 82 | 기본 추천과 필수 완료 목표에서 제외하거나 대표 항목 안으로 통합 |
| 시대분리 | 1 | 4 | 5 | 후대의 역사·문화 학습으로 분리 |
| 전체 | 286 | 60 | 346 | 학생 기록을 보존하는 방식으로 정리 |

‘축소’는 자료 자체가 무가치하다는 뜻이나 파일 삭제 지시가 아니다. 같은 성취기준을 더 잘 설명하는 대표 사례가 있고, 현재 설명으로 얻는 추가 학습 효과가 작다는 뜻이다. ‘핵심’도 현재 자동 문항을 그대로 사용해도 된다는 뜻은 아니다. 그랜드캐니언과 마젤란 해협처럼 좋은 소재인데 문항을 다시 써야 하는 항목이 있다.

2022 개정 교육과정은 2026년에 초등 5·6학년과 중·고 2학년까지 순차 적용되고, 중·고 3학년은 2027년부터 적용된다. 이 검토는 2022 개정의 전 학교급을 설계 기준으로 삼았으며, 2015 개정 교육과정이나 출판사별 모든 교과서의 지명 수록 여부를 전수 대조한 결과는 아니다. [교육부 고시 안내](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0), [저장소의 교육과정 자료](E:/webprojects/class/references/moe/2022-revised-curriculum/README.md).

## 교육과정에서 실제로 요구하는 학습

초등 사회의 세계지리 학습은 생소한 지명의 나열·암기보다 지구본과 지도 활용, 위치·기후·생활의 관계에 초점을 둔다. 중학교도 지역의 특성을 단순 암기하기보다 추론하는 데 지식을 활용하도록 한다. 고등 세계시민과 지리에서도 지나치게 세부적인 기후 구분이나 미지형 형성 원인을 평가에 반영하지 않도록 한다. 따라서 ‘장소를 많이 찾고 짧은 설명 속 단어·수치를 맞힌다’는 방식만으로는 교육과정 연계가 충분하지 않다. [사회과 원문 1901행](E:/webprojects/class/references/moe/2022-revised-curriculum/extracted/07-social-studies.txt:1901), [중학교 적용 방향 1999행](E:/webprojects/class/references/moe/2022-revised-curriculum/extracted/07-social-studies.txt:1999), [고등학교 평가 유의점 4557행](E:/webprojects/class/references/moe/2022-revised-curriculum/extracted/07-social-studies.txt:4557).

## 수정 전 확인한 문제

### 신규 문항에서 단어 일부가 지형 용어로 오인된다

실제 서버의 읽기 구성과 동일하게 본문 뒤에 ‘1520년에는 …’을 붙여 346곳의 신규 문항 1,038개를 생성했다. **20곳에서 ‘만들다’의 ‘만’이 바다 지형인 ‘만’으로 잘려 정답이 되는 오류**가 재현됐다. 지도 발견물 18곳, 도시 명소 2곳이다. 저장된 과거 미션의 문항까지 조사한 수치는 아니다.

예를 들어 발라암섬 수도원은 ‘밭을 (          )들었습니다’를 묻고 정답을 ‘만’으로, 오답을 ‘해협·곶·군도’ 중 일부로 제시한다. 발라암섬 수도원뿐 아니라 스톤헨지·산토리니섬·초콜릿 힐스·피렌체 두오모·파르테논 신전에서도 나온다. [단어 경계 판정](E:/webprojects/class/learning/inquiry/age-of-exploration/lib/study-question-builder.js:8), [지형 용어 묶음](E:/webprojects/class/learning/inquiry/age-of-exploration/lib/study-concepts.js:17).

기존 문항 품질 검사는 설명에 정답이 있는지·선택지가 네 개인지·다른 장소 문장이 섞이지 않았는지 등을 확인한다. 이 오류는 그 조건을 만족하기 때문에 별도 의미 검사가 필요하다. [현재 검사](E:/webprojects/class/learning/inquiry/age-of-exploration/tests/study-question-quality-unit.js:12).

### 학년과 학습 목표가 선택 화면에 나타나지 않는다

지도 발견물 286개에는 학교급·성취기준·학습 목표를 구분하는 필드가 없다. 교사 선택 목록은 도시·발견물·명소와 이름·지역을 기준으로 구성된다. 초등의 세계 위치 학습, 중학교 세계사, 고등 지질 심화를 한 목록에서 골라야 하는 구조다. [선택 목록](E:/webprojects/class/learning/inquiry/age-of-exploration/public/teacher.html:41).

‘핵심·보조’와 함께 학교급·주제·학습 목표를 표시하고, 초등에서는 위치·대표 경관·생활, 중학교에서는 지역 비교·문명·교역, 고등에서는 선택 과목별 심화를 고를 수 있게 하는 편이 좋다. 핵심 109개를 모든 학생에게 한꺼번에 제시하거나 완료하도록 요구할 필요는 없다.

### 후대 문화와 당시 경관을 구분해야 한다

타지마할·포탈라궁·성 바실리 대성당·블루 모스크·베르사유는 모두 ‘설 자리’로 표시한 예고 항목이다. 이미 없는 건물을 있다고 잘못 표시한 경우로 단정할 수는 없다. 다만 현장 발견 수집과 동일하게 집계하면 1520년의 공간 이해를 흐릴 수 있다. 타지마할은 무굴 문화, 베르사유는 절대왕정에 의미가 있으므로 후대 문화 학습으로 옮기는 편이 낫다. [타지마할의 건립 시기와 문화적 의미](https://whc.unesco.org/en/list/252/), [베르사유의 초기 사냥용 건물](https://en.chateauversailles.fr/discover/history/great-characters/louis-xiii).

드레이크 해협의 1520년 설명에는 ‘마젤란 일행이 이듬해 북쪽 해협으로 지나간다’고 되어 있다. 같은 목록의 마젤란 해협 설명은 1520년 통과를 명시한다. 마젤란 항해의 동시대 기록도 1520년 10~11월을 제시하므로 연도 관계를 바로잡아야 한다. ‘아직 아무도 몰랐다’ 같은 표현도 누구의 지식인지 구분해야 한다. [현재 문구](E:/webprojects/class/learning/inquiry/age-of-exploration/data/catalog/discoveries.json:3160), [동시대 항해 기록의 전사본](https://sourcebooks.web.fordham.edu/mod/1519magellan.asp).

티르의 영녕사 설명에는 ‘지도에는 근대에 생긴 러시아 도시 대신 이 유적의 위치를 표시했다’는 제작 사정이 들어 있으며 실제로 그 문장에서도 문제가 만들어진다. 제작 사정을 학생용 본문에서 분리해야 한다. ‘600년쯤 전’처럼 기준 연도가 없는 표현과 오늘날 사진·1520년 설명의 관계도 일관되게 정리해야 한다.

과나아니의 ‘유럽 배의 첫 도착’과 정확한 인구 수치, 페리토모레노 빙하의 1520년 크기, 일부 사찰·궁전의 오늘날 건축 요소가 당시 설명에 섞이는 문제는 사실 근거를 추가 점검할 항목이다. 이번 판정표의 학습 적합성 등급이 모든 연대·높이·최상급 표현의 사실 검증을 대신하지 않는다.

## 정리하면서 보존할 가치

바투르 칼데라·초콜릿 힐스·팔라완 지하강·밀퍼드사운드는 모두 자연 형성 과정을 설명하므로 ‘교과서에 낯선 이름’이라는 이유만으로 불필요하다고 볼 수 없다. 기존 칼데라·카르스트·피오르 사례와 무엇을 비교할지 정하고 보조 자료로 쓰면 된다.

유럽 중심으로 장소를 줄이는 것도 피해야 한다. 그레이트짐바브웨·반다 제도·슈리성·폴리네시아의 타푸타푸아테아는 교역과 항해의 다양한 주체를 보여 준다. 카호키아·카카두·마오리 취락도 주제에 따라 의미가 있다. 중학교 `[9역04-03]`의 해설은 신항로와 세계 교역망의 결과를 유럽 이외 지역의 관점에서도 이해하도록 한다. [성취기준 해설](E:/webprojects/class/references/moe/2022-revised-curriculum/extracted/07-social-studies.txt:3015).

## 권장 적용 순서

1. ‘만들다’를 잘라 내는 신규 문항 오류와 드레이크 해협 연도 모순을 먼저 고친다. 핵심 항목의 문항부터 학습 목표와 연결해 다시 쓴다.
2. 교사 선택 화면에 핵심·보조·학교급·주제·학습 목표를 표시한다. 수업에서 필요한 비교 사례를 쉽게 선택하게 한다.
3. 축소 후보 82개를 기본 추천과 필수 완료 목표에서 제외한다. 같은 유적 2쌍은 대표 기록을 정하되 기존 접근 경로를 연결한다.
4. 미래 건축물 5개는 후대 문화 학습으로 분리한다. 150개 보조 사례는 비교·심화 선택에서 사용할 수 있게 한다.
5. 기존 발견·완료 기록은 ID 대응표로 보존한다. 수집 총수의 변경은 학생별 과거 진행도와 함께 처리한다.

아래는 수정 전 346개 전수 판정표다. 표의 ID는 같은 이름이나 접근 경로를 혼동하지 않도록 남겼다. 이 판정을 바탕으로 적용한 실행 데이터·화면·기록 처리 결과는 위 ‘실제 반영 결과’에 정리했다.

## 검토의 재현과 자료 범위

수량과 신규 문항은 검토 시점의 `mission-catalog.js`, `study-question-builder.js`를 기준으로 재현했다. 항목별 판정은 자동 키워드 일치 점수가 아니라 본문·당시 설명·대표성·중복을 읽고 내린 추천안이다. 코드의 문항 입력을 재현할 때는 아래처럼 당시 설명까지 포함해야 한다. 본문만 넣으면 실제 신규 출제와 다른 통계가 나온다.

```javascript
const Catalog = require('./lib/mission-catalog.js');
const { createQuestions } = require('./lib/study-question-builder.js');
const items = [...Catalog.DISCOVERIES, ...Catalog.CITY_LANDMARKS];
let questions = 0, numericQuestions = 0, brokenItems = 0;
for (const source of items) {
  const item = { ...source, text: [source.text,
    source.in1520 ? '1520년에는 ' + source.in1520 : ''
  ].filter(Boolean).join('\n\n') };
  const set = createQuestions(item, []);
  questions += set.length;
  numericQuestions += set.filter(q => q.prompt.includes('값')).length;
  brokenItems += Number(set.some(q => q.answer === '만' && q.passage.includes('(          )들')));
}
console.log({ items: items.length, questions, numericQuestions, brokenItems });
// 수정 전: items: 346, questions: 1038, numericQuestions: 37, brokenItems: 20
// 반영 후: items: 346, questions: 1038, numericQuestions: 26, brokenItems: 0
```
