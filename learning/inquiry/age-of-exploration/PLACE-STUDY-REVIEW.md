# 학급 장소 학습

교사 현황판의 기본 미션은 ‘장소 탐험 · 설명 읽고 두 문제’다. 도시, 지도 발견물, 입장 가능한 도시의 명소를 검색하여 중복 없이 1~5곳 선택한다. 방문 순서는 자유이며 기존 항구 4곳 중 출발지를 고르는 절차를 유지한다.

도시는 실제 입장, 발견물은 기존 육상·해상 접근 판정, 도시 명소는 해당 도시 입장을 확인한다. 장소 설명을 연 다음 문제를 시작한다. 설명 본문에서 서로 다른 두 문장을 골라 4지선다 빈칸 또는 문장 완성 문제를 만든다. 두 문제 연속 정답이면 장소 완료다. 오답은 연속 정답을 0으로 초기화하고 설명을 다시 표시한다. 지정 장소 전부를 완료한 시각으로 완주 순위를 정한다.

판정과 정답, 제출 토큰은 서버에서 관리한다. 학생에게는 현재 문제의 선택지만 전송한다. 미도착·출발 전·일시정지·이전 미션·중복 제출을 거부하며 완료 장소와 진행 중 문제를 저장한다. 자유 항해는 기존 즉시 발견 방식을 유지한다. 기존 진행 중 경주와 동물 만나기 미션의 호환 경로는 유지한다.

검증: npm run test:place-study에서 575개 설명의 두 문제 구성, 정답 비공개, 연속 정답/오답 초기화, 저장 복원, 교사 권한, 1~5개 제한, 순서 없는 다섯 곳 방문, 도시 입장, 원거리 거부, 재접속, 중복 제출, 완료 집계를 검사한다. 실제 Chrome에서 교사 다섯 곳 선택, 학생 설명 열기, 두 번째 문제 오답 후 재시도, 발견 성공, 도시 설명 연계, 모바일 문제 표시를 확인했다.
