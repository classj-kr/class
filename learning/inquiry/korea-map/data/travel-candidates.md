# 국내 체험학습 관광지 후보 132곳

목적: 학교 현장체험학습과 가족 교외체험학습에 활용할 수 있는 장소를 전국 17개 시·도에서 고르게 선정한다.

선정 기준:
- 공식 운영기관 홈페이지가 있거나 지방자치단체가 관리하는 장소
- 역사·문화, 과학·산업, 자연·생태, 민주·평화 학습으로 연결 가능한 장소
- 학생 단체 또는 가족 방문이 가능하고 관찰·체험 활동을 만들 수 있는 장소
- 아이들이 실제로 가고 싶어 하는 놀이·동물·대형 체험시설
- 대표사진의 이용조건과 출처를 확인할 수 있는 장소

실제 지도 등록 전 필수 확인 항목:
공식 명칭 / 공식 홈페이지 / 위도·경도 / 대표사진 1장과 이용조건 / 관람시간 / 요금 / 예약 / 권장 체류시간 / 단체 방문 가능 여부 / 구체적 설명 / 관찰 활동

## 제작 순서

1. 기존 7곳의 화면 품질과 데이터 구조를 완성한다.
2. 시·도별 대표 2곳씩 34곳을 1 공개한다.
3. 나머지 후보의 공식 홈페이지와 사진 이용조건을 검증한다.
4. 60곳, 100곳, 132곳 순서로 확장한다.
5. 모든 장소에 학교 출발 경로, 대표사진 1장, 구체적 설명, 관찰 활동, 공식 홈페이지를 적용한다.
