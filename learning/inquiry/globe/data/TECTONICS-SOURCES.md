# 판 구조론 표시 기록 — 2026-10-12

저장소 안의 작업 기록이다. 학습 화면에는 출처 글자를 넣지 않고 사이트의 「자료 출처」 쪽(`/credits`)에만 적는다.

지도 표시의 「판 구조와 지진·화산」 묶음(판 경계·판 이름 / 지진 분포 / 화산 분포)이 쓰는 자료다. 수능(지구과학Ⅰ·통합과학·세계지리)에서 이름으로 묻는 것만 싣는다.

| 파일 | 원자료 | 가공 |
|---|---|---|
| `tectonics-points.json`의 `quakes` | 미국 지질조사국(USGS) 지진 목록, 규모 6 이상, 1970-01-01~2025-12-31, 7,823건. https://earthquake.usgs.gov/fdsnws/event/1/query?format=csv&starttime=1970-01-01&endtime=2025-12-31&minmagnitude=6&orderby=time-asc (2026-10-12 받음, 퍼블릭 도메인) | 경도·위도를 소수 둘째 자리로, 진원 깊이를 세 단계로(0 천발 70km 미만 · 1 중발 70~300km · 2 심발 300km 이상). 규모·날짜는 버렸다. |
| `tectonics-points.json`의 `volcanoes` | 미국 해양대기청(NOAA NCEI) 화산 위치 자료 1,609곳. https://www.ngdc.noaa.gov/hazel/hazard-service/api/v1/volcanolocs (2026-10-12 받음, 퍼블릭 도메인) | 경도·위도만. 홀로세에 활동한 화산 목록이라 지금 분화 중인 화산만 뜻하지 않는다. |
| `tectonics-labels.js`의 선 모양 | 이미 있는 `atlas-plates.json`(USGS 판 경계, `ATLAS-SOURCES.md` 참고) | 해령·해구·변환 단층·조산대마다 판 이름 짝과 범위로 선을 골라 이었다. 경도 180도에서 끊었다. |
| 이름표 자리 | 판·열점은 표에 직접 적은 좌표, 해령·해구·단층은 고른 선 위의 점 | 해구 이름표 자리의 깊이를 ETOPO1로 확인했다(6,500~9,000m). |

판 경계선의 종류(수렴·발산·보존)는 USGS 자료의 구분을 그대로 쓴다. 이 자료는 일본 동북부를 북아메리카판에 넣는다. 설명 글에서는 일본 해구에서 "태평양판이 일본 열도 아래로 섭입한다"고만 적어 판 이름 다툼을 피했다.

## 설명 글에 적은 수치의 근거

- 해구의 가장 깊은 곳: 마리아나 약 11,000m, 통가 약 10,800m, 필리핀 약 10,500m, 일본 8,000m 넘음, 페루·칠레 약 8,000m, 알류샨 약 7,700m, 순다 약 7,300m. ETOPO1(1분 격자)에서 잰 값은 차례로 10,898 / 10,750 / 9,848 / 8,374 / 8,094 / 7,649 / 7,239m다. 필리핀 해구만 격자가 성겨 얕게 나와 널리 쓰이는 값(10,540m)을 따랐다.
- 지진: 1960 칠레 규모 9.5, 1964 알래스카 9.2, 2004 수마트라 9를 넘음, 2011 동일본 9.0, 1906 샌프란시스코, 2010 아이티.
- 화산: 1980 세인트헬렌스산, 1991 피나투보.

## 다시 만들기

```powershell
node learning/inquiry/globe/tools/build_tectonics.mjs
```

`references/geography/tectonics/`에 `usgs-m6-1970-2025.csv`와 `noaa-volcanolocs.json`(여러 쪽을 하나로 합친 것)이 있어야 한다. 이름표를 더하면 `data/info.json`에 설명도 함께 넣는다(검사가 이름표마다 설명을 요구한다). 점 자료를 바꾸면 `app.js`의 `TECTONICS_VERSION`을, 이름표·선을 바꾸면 두 진입 화면의 `tectonics-labels.js?v=`를 올린다.
