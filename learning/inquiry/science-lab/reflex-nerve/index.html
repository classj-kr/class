자극의 전달과 반사

중학교 3학년과학
  1. 반응의 종류를 고릅니다.
  2. 판단에 대뇌가 관여하는지 예상합니다.
  3. 자극이 전달되는 경로를 차례로 확인합니다.
  4. 반응의 중추와 결과를 비교합니다.

실험 조건

반응의 종류
이 반응을 일으킬 때 대뇌의 판단이 필요한가요?

관찰 결과

조건을 정하고 확인해 보세요.

관찰

    전달 순서를 살펴보는 모형입니다. 단계 수나 화면 진행 속도는 실제 신경 수·반응 시간을 나타내지 않습니다.

    실험 결과의 의미

    의식적 반응 대뇌가 자극을 판단한 뒤 명령을 내립니다.

    무조건 반사 대뇌의 의식적인 판단 없이 일어납니다. 무릎 반사의 중추는 척수, 동공 반사의 중추는 중간뇌입니다.

    대뇌의 판단 없이 반응한다고 해서 자극에 관한 정보가 대뇌에 전혀 전달되지 않는 것은 아닙니다.

    확인 문제

    4문제

    무조건 반사의 특징은?

    무조건 반사는 대뇌의 의식적인 판단 없이 일어나며, 반응에 따라 척수나 뇌의 다른 부분이 중추가 됩니다.

    자극이 전달되는 순서로 알맞은 것은?

    감각 신경은 자극을 중추로, 운동 신경은 중추의 명령을 반응 기관으로 전달합니다.

    무릎 반사의 중추는?

    무릎 반사의 중추는 척수입니다. 동공 반사의 중추인 중간뇌와 구별합니다.

    의식적 반응의 예는?

    신호를 보고 판단하여 손을 드는 것은 대뇌가 관여하는 의식적 반응입니다.
