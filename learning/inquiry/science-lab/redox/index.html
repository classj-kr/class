전자는 산화되는 쪽에서 환원되는 쪽으로 흐릅니다.

실험 결과의 의미

이온화 경향 표준 환원 전위가 낮을수록 전자를 잃기 쉽습니다. 두 금속을 이으면 낮은 쪽이 산화되어 (−)극이 됩니다.

기전력 표준 상태에서 두 반쪽 반응의 표준 환원 전위 차이로 표준 전지 전위를 구합니다. 이 모형은 같은 금속의 두 전극에 같은 조건을 적용하므로 전위 차가 0입니다. 농도 등이 다르면 같은 금속이어도 전위 차가 생길 수 있습니다.

패러데이 법칙 흐른 전기량이 전자의 몰수를 정합니다. 전자 1몰마다 석출되는 물질의 양은 이온의 전하수로 나눈 만큼입니다.

확인 문제

4문제

아연과 구리로 만든 전지에서 산화되는 것은?

아연의 표준 환원 전위는 −0.76 V, 구리는 +0.34 V입니다. 낮은 쪽인 아연이 전자를 내놓고 산화되어 (−)극이 됩니다.

아연−구리 전지의 기전력은?

E°전지 = E°(환원되는 쪽) − E°(산화되는 쪽) = 0.34 − (−0.76) = 1.10 V입니다.

같은 전기량을 흘렸을 때 은이 구리보다 많은 몰수가 석출되는 까닭은?

Ag⁺ + e⁻ → Ag 는 전자 1개, Cu²⁺ + 2e⁻ → Cu 는 전자 2개가 필요합니다. 같은 전자 몰수라면 은이 두 배 많은 몰수로 석출됩니다.

물을 전기 분해하면 수소와 산소의 부피비는?

2H₂O → 2H₂ + O₂ 이므로 부피비는 2 : 1입니다. 전자 4몰마다 수소 2몰, 산소 1몰이 나옵니다.
