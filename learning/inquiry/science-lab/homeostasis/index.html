항상성 — 혈당·체온·물의 조절

고등학교 2~3학년생명과학
  1. 혈당 조절, 체온 조절, 물(삼투압) 조절 가운데 하나를 고릅니다.
  2. 먹은 것과 몸 상태, 날씨와 몸 상태, 마신 것을 정합니다.
  3. 2시간 뒤 혈당, 1시간 뒤 체온, 1시간 뒤 오줌이 어떻게 될지 예상합니다.
  4. 시작해서 호르몬과 몸의 반응이 값을 어떻게 되돌리는지 확인합니다.

혈관 속 노란 점이 포도당입니다. 이자가 인슐린과 글루카곤을 내어 간·근육이 포도당을 넣고 꺼냅니다.

실험 결과의 의미

되먹임 조절 몸속 값이 정해진 범위를 벗어나면 그것을 감지한 곳이 반대 방향으로 되돌리는 반응을 일으킵니다(음성 되먹임). 혈당이 오르면 인슐린이, 내리면 글루카곤이 나오고, 체온이 오르면 땀과 넓어진 혈관이, 내리면 떨림과 좁아진 혈관이 맞섭니다. 값이 돌아오면 반응도 멎습니다. 이렇게 안팎이 바뀌어도 속을 일정하게 지키는 것이 항상성입니다.

혈당 조절 혈당이 오르면 이자의 β세포에서 분비된 인슐린이 혈당을 낮추는 작용에 관여합니다. 혈당이 내려가면 α세포의 글루카곤이 간에서 포도당을 혈액으로 내보내는 작용에 관여합니다. 화면은 분비·작용 조건에 따른 차이를 비교하는 가상 모형이며 질병의 진단·유형 판별·치료 결정을 위한 자료가 아닙니다.

체온 조절 몸은 열의 생성과 방출을 조절하여 체온을 일정한 범위로 유지합니다. 더울 때 땀의 증발과 피부 혈관 확장이 열 방출에 기여하고, 추울 때 떨림과 피부 혈관 수축 등이 작용합니다. 화면의 열량·체온·시간은 가상 조건이며 사람의 체온 변화를 예측하지 않습니다.

물의 양 조절 체내 수분이 부족해 삼투압이 높아지면 시상 하부가 관여하는 조절로 갈증이 생기고, 뇌하수체 후엽에서 방출되는 항이뇨 호르몬이 콩팥의 물 재흡수를 늘립니다. 물이 충분할 때와 비교하여 오줌 양의 변화를 살핍니다. 표시량은 가상 값입니다.

확인 문제

4문제

식사 뒤 혈당이 오르자 이자에서 어떤 호르몬이 나와 무엇을 할까요?

혈당이 오르면 β세포의 인슐린이 근육·지방 세포에 포도당을 들이고 간이 글리코젠으로 저장하게 해 혈당을 내립니다. 글루카곤은 혈당이 내렸을 때 나옵니다.

인슐린의 분비나 작용이 감소했을 때를 비교하는 목적은?

같은 조건에서 인슐린의 분비·작용을 달리하여 혈당 변화의 경향을 비교합니다. 가상 모형으로 진단하거나 치료를 결정하지 않습니다.

땀이 증발할 때 체온 조절에 기여하는 방식은?

땀의 증발은 열을 빼앗아 몸의 열 방출에 기여합니다. 실제 효과는 습도 등 여러 조건에 따라 달라집니다.

짠 음식을 많이 먹은 뒤 몸에서 일어나는 일은?

몸속 물이 진해지면 뇌하수체가 항이뇨 호르몬을 내어 콩팥이 물을 다시 빨아들이고, 갈증 중추가 물을 마시게 합니다. 오줌은 적고 진해집니다.
