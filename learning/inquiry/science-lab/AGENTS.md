# 과학실험실 작업 기준

## 교육과정 범위

- 사용자의 지정에 따라 구현·검증 대상은 2022 개정 교육과정으로 한정한다. 2015 개정 자료의 대조나 구현을 추가 요구하지 않는다.
- 기존 앱 개수를 필요한 실험의 총수·목표·상한으로 사용하지 않는다. 104는 기존 앱 102개에 2개를 추가한 구현 현황이며 교과서 전수 대조로 확정한 실험 수가 아니다.
- 수집된 2022 교과서의 활동 절차와 평가자료를 개별 실험 단위로 대조하고 출판사별 중복을 판정한 뒤 실험 목록을 정한다. 교육과정의 명시된 탐구 활동 261개도 전체 교과서의 독립 실험 총수로 대체하지 않는다. 목록 확정 전 전체 필수실험 수는 미확정으로 기록한다.

## 이미지 형식

- 사용자가 별도로 말하지 않아도 신규·수정 래스터 이미지는 WebP를 기본으로 저장하고 참조한다.
- 과학실험실 관련 검증 보고서와 화면 캡처도 WebP로 저장한다. 브라우저가 PNG 캡처만 제공하면 메모리에서 받아 WebP로 인코딩한다.
- PNG가 생성되면 WebP의 크기·투명도·디코딩 결과를 확인한 뒤 불필요한 PNG 사본을 제거하고 참조를 갱신한다. 글자와 도표가 있는 검증 캡처는 무손실 WebP를 사용한다.
- SVG·HTML·CSS로 구현된 실험 그림은 해당 형식을 유지한다.

## 공유 파일과 검증

- 앱 코드·공유 탐구·문제은행·스타일 수정 후 `node scripts/sync-science-assets.cjs --write`로 하위 파일부터 로더·HTML까지 콘텐츠 해시를 갱신한다. `--check`는 읽기 전용 검사다.
- 실행·채점 통과, 화면 검토, 원문 대조, 교육과정 활동 포함 여부를 구분해 기록한다. 관련 단원 앱이 있다는 이유로 실제 실험 수행이나 전체 활동 충족으로 판정하지 않는다.
