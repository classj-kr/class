트랜지스터로 소리 증폭하기

고2~3전자기와 양자

같은 작은 신호를 스피커에 직접 연결한 경우와 증폭 회로를 거친 경우로 비교해 보세요.

입력과 출력 비교

전압 이득 10을 가정한 기능 모형입니다. 실제 부품의 바이어스·주파수 응답을 계산한 회로도는 아닙니다. 파형의 시간 축은 느리게 재생하며, 세로 축은 입력과 출력에 같은 눈금을 씁니다.

결과 해석 문제 4문제

작은 입력 신호로 큰 출력이 나올 때 추가 에너지를 공급하는 것은?

입력 신호가 전지에서 공급되는 에너지의 흐름을 제어합니다. 트랜지스터가 에너지를 만들어 내지는 않습니다.

증폭 회로에 입력 신호를 그대로 두고 전지만 분리했습니다. 이 모형의 출력은?

증폭 작용에는 적절한 전원이 필요합니다. 입력 신호만으로 같은 출력 전력을 공급할 수는 없습니다.

입력 진폭을 지나치게 키웠더니 출력 파형의 꼭대기가 평평해졌습니다. 이는?

출력은 전원과 회로의 동작 범위를 벗어날 수 없습니다. 제한에 걸리면 파형이 잘리는 왜곡이 나타납니다.

증폭 전후의 소리를 비교할 때 적절한 조건은?

입력과 스피커를 유지해야 회로를 바꾼 영향을 비교할 수 있습니다.
