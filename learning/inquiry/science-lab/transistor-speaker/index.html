트랜지스터로 소리 증폭하기

고(선택)전자기와 양자

같은 작은 신호를 스피커에 직접 연결한 경우와 증폭 회로를 거친 경우로 비교해 보세요.

입력과 출력 비교

전압 이득 10을 가정한 기능 모형입니다. 실제 부품의 바이어스·주파수 응답을 계산한 회로도는 아닙니다. 파형의 시간 축은 느리게 재생하며, 세로 축은 입력과 출력에 같은 눈금을 씁니다.

결과 해석 문제 4문제

증폭 회로의 출력 에너지가 입력 신호의 에너지보다 크다. 차이에 해당하는 에너지를 공급하는 부품은?

전지가 공급하는 에너지의 흐름을 입력 신호와 트랜지스터가 제어합니다. 증폭 소자가 에너지를 만들어 내는 것은 아닙니다.

출력 진폭이 입력의 10배인 증폭기에서 입력 진폭이 0.1 V이다. 출력 한계에 닿지 않는다면 출력 진폭은?

출력 진폭은 0.1×10=1 V입니다. 증폭률은 두 진폭의 비이며 출력 주파수를 10배로 만든다는 뜻은 아닙니다.

입력은 매끈한 사인파인데 출력 꼭대기가 평평하다. 같은 회로에서 파형 잘림을 줄일 조작은?

출력 요구 진폭이 동작 한계를 넘으면 파형이 잘립니다. 입력을 줄이면 요구 출력이 낮아져 한계 안으로 들어올 수 있습니다.

직접 연결과 증폭 연결의 소리 크기를 비교한다. 연결 방식 외에 같게 유지할 조합은?

입력과 스피커, 관찰 거리를 같게 해야 연결 방식에 따른 출력을 비교할 수 있습니다. 출력 진폭은 이 실험에서 비교하려는 결과입니다.
