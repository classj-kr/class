실험 결과의 의미

우열의 원리 순종 둥근 완두(RR)와 순종 주름진 완두(rr)를 교배하면 잡종 1대는 모두 Rr인데 전부 둥글게 나타납니다. 둘이 함께 있을 때 겉으로 드러나는 R이 우성, 숨는 r이 열성입니다.

분리의 법칙 잡종 1대(Rr)가 생식세포를 만들 때 R과 r은 갈라져 하나씩 들어갑니다. 이 생식세포들이 무작위로 만나 RR : Rr : rr = 1 : 2 : 1이 되고, 겉모습은 둥근 : 주름진 = 3 : 1이 됩니다.

독립의 법칙 씨 모양과 씨 색처럼 이 모형에서 다루는 두 유전자 쌍은 서로 독립적으로 분리됩니다. 모든 유전자 쌍에 예외 없이 적용되는 것은 아닙니다. 그래서 RrYy끼리 교배하면 둥근 노란 : 둥근 초록 : 주름진 노란 : 주름진 초록 = 9 : 3 : 3 : 1이 됩니다.

비는 많이 뿌려야 보인다 3 : 1은 확률이어서, 씨앗 몇 알로는 5 : 3이나 2 : 2도 나옵니다. 멘델이 완두 수천 알을 세어 법칙을 찾은 까닭입니다. 씨앗 수를 바꿔 뿌리면서 비가 어떻게 달라지는지 보세요.

확인 문제

4문제

순종 둥근 완두(RR)와 순종 주름진 완두(rr)를 교배하면 잡종 1대의 씨 모양은?

잡종 1대는 모두 Rr입니다. R과 r이 함께 있으면 우성인 R만 겉으로 드러나므로 전부 둥글게 나타납니다. 이것이 우열의 원리입니다.

잡종 1대(Rr)끼리 교배해 얻은 잡종 2대에서 둥근 완두와 주름진 완두의 비는?

생식세포 R, r이 무작위로 만나 RR : Rr : rr = 1 : 2 : 1이 됩니다. RR과 Rr은 모두 둥글게 보이므로 겉모습의 비는 둥근 : 주름진 = 3 : 1입니다.

잡종 2대에서 둥근 완두가 600알 나왔습니다. 이 가운데 순종(RR)은 약 몇 알일까요?

둥근 완두는 RR : Rr = 1 : 2입니다. 600알의 3분의 1인 약 200알이 순종 RR이고, 나머지 약 400알은 겉은 둥글지만 r을 숨긴 잡종 Rr입니다.

잡종 1대끼리 교배한 씨앗 8알을 뿌렸더니 둥근 것 5알, 주름진 것 3알이 나왔습니다. 3 : 1이 아닌 까닭은?

3 : 1은 씨앗 한 알 한 알이 둥글 확률이 4분의 3이라는 뜻입니다. 8알처럼 적게 뿌리면 우연 때문에 5 : 3, 7 : 1도 흔히 나오고, 수백 알을 뿌릴수록 3 : 1에 가까워집니다.
