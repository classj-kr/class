사슬 끝에 연결할 단위체를 고르세요. 한 사슬의 결합 수와 부산물을 비교합니다.

결과 해석 문제 4문제

다이아민 수용액 위층과 산 염화물 유기 용액 아래층에서 나일론 막이 처음 생길 위치는?

서로 다른 층의 두 단위체가 만나는 계면에서 반응합니다. 막을 꺼내면 새로 드러난 계면에서 반응이 이어집니다.

다이아민의 –NH₂와 산 염화물의 –COCl이 연결된다. 생성 결합과 작은 부산물은?

–CO–NH– 아마이드 결합을 만들면서 N 쪽의 H와 산 염화물의 Cl이 HCl로 빠져나갑니다.

단위체 6개가 하나의 가지 없는 사슬로 연결되었다. 연결할 때마다 HCl 하나가 생기면 결합 수와 HCl 수는?

6개를 한 줄로 연결하려면 5번 연결합니다. 각 연결에서 HCl 하나가 나옵니다. 끝의 미반응 작용기는 남습니다.

나일론 합성에서 수산화 나트륨을 넣는 주된 목적은?

반응에서 생기는 HCl을 중화하여 반응 환경을 유지하는 역할입니다. 고분자의 탄소·질소 골격을 공급하는 단위체와 구별합니다.
