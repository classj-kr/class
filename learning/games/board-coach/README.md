# 리버시·오목·체스·장기 학습 대국

각 게임 대기실의 방 만들기·참가 버튼 옆에 있는 **AI와 배우기**에서 진입한다. 이름이 없으면 이름 안내 안의 같은 버튼을 사용할 수 있다. 로컬 Web Worker에서 계산한다. 기존 온라인 게임의 차례 제한 시간과 규칙은 수정하지 않는다.

## 수준의 차이

모든 수준에 같은 공격·방어 기준을 적용하며, 일부러 무작위 악수를 선택하지 않는다. 반복 심화 알파베타 탐색의 최대 깊이와 계산 예산만 달라진다. 제한에 도달하면 마지막으로 완전히 계산한 깊이의 수를 사용한다.

| 수준 | 리버시 최대 깊이 | 오목 최대 깊이 | 노드 예산 | 시간 예산 |
| --- | ---: | ---: | ---: | ---: |
| 초급 | 2 | 2 | 2,500 | 300ms |
| 중급 | 4 | 3 | 18,000 | 800ms |
| 상급 | 6 | 4 | 90,000 | 1,800ms |

- 오목: 즉시 승리, 상대의 즉시 승리 방어, 한 수로 두 승리 지점을 만드는 공격, 상대가 그런 공격을 만들지 못하게 하는 방어 순서로 후보를 제한한다. 나머지는 연결·위협·중앙을 평가한다. 탐색 후보 폭은 8/10/12이다.
- 리버시: 초중반에는 확보 가능한 모서리를 우선하고, 안전한 대안이 있으면 즉시 상대에게 모서리를 주는 수를 피한다. 모서리 주변 위험, 합법 수의 수, 빈칸에 노출된 돌, 종반 돌 수를 평가한다. 빈칸 12개 이하에서는 탐색이 최종 돌 수를 위해 모서리와 다른 이익을 비교할 수 있다.
- 리버시 복기도 마지막 12칸에서는 단순히 모서리를 내줬다는 이유로 지적하지 않는다. 마지막 8칸에서는 끝까지 완전 탐색한 돌 수로 실제 더 나은 대안만 제시한다. 이길 수 있는 모서리 희생을 잘못 고치도록 가르치지 않는다.
- 리버시 기본 전개 `E6 F4 E3 → D6`와 대칭 위치를 자료에 근거한 작은 개국 표로 포함한다. 프로 정석 전체, 렌주 정석, 최선 수를 보장하는 엔진은 아니다.
- 실제 계산 깊이는 기기 속도와 판의 복잡도에 따라 달라진다. 레벨 이름은 이 학습 모드 안에서의 상대적 구분이다.

## 체스

체스에서도 같은 `coach.html?game=chess` 화면을 사용한다. `chess-coach.js`가 기물 선택·승격·흑 시점 회전·기보·무승부 선언을 담당한다. 제목과 수준은 **AI와 배우기 / 초급 AI·중급 AI·상급 AI**로 통일한다.

- `chess/chess-rules.js`의 `standard` 모드: 자기 킹 노출 금지, 체크 해소, 체크메이트, 스테일메이트, 캐슬링의 안전 조건, 앙파상, 네 종류 승격. 온라인 대국의 기존 간소화 규칙은 기본 모드로 유지한다.
- 반복 판정은 실제 합법적인 앙파상 권리까지 포함한다. 3회 반복·50수 규칙은 현재 판 또는 예정 수로 선언할 수 있고, 5회 반복·75수 규칙은 자동 적용한다. 체크메이트가 우선한다. 킹만 남거나 킹과 단일 비숍/나이트, 같은 색 칸 비숍만 남는 기본 기물 부족을 판정한다. 모든 특수한 봉쇄 위치의 데드 포지션을 해결하는 테이블베이스는 포함하지 않는다.
- `chess-ai.js`: 모든 수준이 즉시 메이트를 찾고, 피할 수 있는 상대의 한 수 메이트를 막는다. 작은 초반 전개 표와 중앙·기물 전개·킹 보호 평가, 반복 심화 알파베타 탐색, 잡기·체크에 대한 추가 탐색을 사용한다. 무작위 실수로 수준을 낮추지 않는다. 무승부 선언 조건에서도 즉시 승리가 우선한다.
- 체스 탐색 예산은 초급 2수 깊이/9,000노드/450ms, 중급 3/35,000/1,100ms, 상급 4/120,000/2,400ms다. 깊이의 단위는 한쪽이 두는 한 수다. 한 수 메이트 안전 검사와 추가 탐색은 모든 수준에 공통이다. 전체 프로 정석집이나 공인 레이팅을 의미하지 않는다.
- 체스도 깊이 2를 끝내지 못하면 전체 후보의 즉시 포획 손실 평가를 사용한다. 움직인 말뿐 아니라 그대로 남긴 퀸·룩 등 모든 말의 위협과 합법적인 되잡기를 확인한다.
- 기본 퀸·룩 종반에서는 왕 접근·상대 왕을 가장자리로 몰기·상대 왕의 이동 범위 줄이기를 평가한다. 왕+룩 대 왕에서는 룩이 가두는 공간도 평가하여 무의미한 장군 반복을 줄인다.
- 힌트와 설명, 놓친 메이트·메이트 허용·되잡기 어려운 기물 손실 복기, 내 수 물리기, 승격 선택, 기권 확인을 제공한다. 작업 토큰으로 취소된 계산 결과를 무시한다.

체스 참고: [FIDE 체스 규칙](https://rcc.fide.com/wp-content/uploads/2022/11/Laws_of_Chess-2023.pdf), [ChessKid 초반 원칙](https://www.chesskid.com/learn/terms/chess-opening).

## 장기

`coach.html?game=janggi`에서 시작한다. 장기 대기실에도 기존 탭 옆의 작은 **AI와 배우기** 링크를 제공한다. 설정에는 수준·초/한 선택·양쪽 마·상 차림만 표시하고, 규칙은 접힌 규칙 메뉴에 둔다. 한글 말 이름, 좌표, 한 시점 회전, 힌트·수 물리기·복기·대국 기록을 제공한다.

- `janggi-rules.js`: 별도 순수 규칙 모듈이다. 9×10 교차점과 네 가지 차림(각자 자기 쪽에서 왼쪽부터 읽는 순서), 장군을 남기는 수 금지, 왕 잡기 금지, 외통수 종료, 포의 발판과 포끼리 잡기 금지, 마·상의 길막, 궁성 대각선 이동을 처리한다. 기존 온라인 장기 규칙은 수정하지 않는다.
- 빅장은 장군과 별개다. 응수자는 마주봄을 풀거나 받아들여 비긴다. 동시에 장군이 걸렸어도 빅장 수락이 가능하다. 장군이 아닐 때 한 수 쉴 수 있고 두 사람이 연속으로 쉬면 비긴다.
- 학습 대국의 종료 정책: 같은 판·차례가 세 번 나타나면 무승부, 한쪽이 반복 구간 내내 장군을 부른 경우에는 그쪽 패배. 잡기 없이 100수(양쪽 50수씩)도 무승부다. 대한장기연맹 대회의 점수제·한의 1.5점 덤·4회 반복 실격·묵장/자장 후 왕 포획을 모두 재현하는 대회 모드는 아니다. 이 차이는 규칙 메뉴에 표시한다.
- `janggi-ai.js`: 모든 수준이 한 수 외통수와 그 방어를 우선하고, 포획 뒤 되잡기를 확인한다. 마·상 전개, 차·포 이동 가능 자리, 연결된 졸, 궁성의 사를 평가한다. 모든 수준은 같은 평가와 안전 검사를 사용하며 의도적인 무작위 악수는 없다. 프로 정석집이나 공인 레이팅을 뜻하지 않는다.
- 초급은 2수 깊이/9,000노드/500ms, 중급은 4/65,000/1,200ms, 상급은 6/200,000/2,500ms의 반복 심화 탐색을 사용한다. 외통수 안전 검사와 전체 후보의 즉시 포획 손실 평가는 공통이며 이 예산 밖이다. 깊이 2를 끝내지 못하면 이 안전 평가의 결과를 사용한다. 깊이는 양쪽이 번갈아 두는 한 수 단위이며 잡기 추가 탐색은 별도다.
- 장군 판정은 왕의 자리에서 차·포의 경로와 마·상의 길막을 역으로 확인한다. 상대 말의 모든 목적지를 반복 생성하는 비용을 줄여 중급이 상대의 두 번째 응수까지 읽을 여유를 늘렸다. 공격·방어 평가, 초급의 계산 예산과 각 수준의 기존 시간 한도를 유지한다.
- 같은 계산 예산에서 더 깊이 읽도록 앞선 깊이에서 좋았던 수, 가지치기를 일으킨 조용한 수와 그 이력을 먼저 탐색한다. 반복 이력에 따른 무승부 판정이 섞이지 않도록 수의 순서만 재사용하고 평가 점수는 저장하지 않는다. 빅장 수락으로 큰 기물 손실을 피할 수 있으면 초급도 무승부를 선택한다.
- `janggi-worker.js`에서 탐색한다. `janggi-coach.js`는 작업 토큰·worker 종료로 수 물리기/새 대국/기권 뒤 늦은 결과를 차단한다. 학습 모드의 점수는 수수 표시이고 온라인 순위나 승률을 기록하지 않는다.

장기 참고: [PyChess의 행마·빅장·초반 원칙](https://www.pychess.org/variants/janggi), [대한장기연맹의 대회 규정](https://www.kojf.net/theme/sample30/html/content03.php). 반복과 무승부 처리는 위 학습 정책으로 명시한다.

## 규칙과 학습 기능

- `rules.js`: 기존 온라인판과 같은 8×8 리버시 및 15×15 자유 오목. 오목은 금수 없이 5개 이상이면 승리한다. 렌주의 금수·개국 규칙을 가르치는 모드가 아니다.
- `ai.js`: 후보 생성, 탐색, 판에서 확인할 수 있는 사실에 근거한 설명, 놓친 승리·필수 방어·모서리 양보 복기.
- `ai-worker.js`: 계산을 화면과 분리한다. `coach.js`의 작업 토큰과 worker 종료로 수 물리기·새 대국 후 늦게 온 응답을 차단한다.
- `coach-ui.js`: 체스·장기의 힌트와 복기 후보에 출발→도착 화살표를 그린다. 현재 보이는 판의 좌표를 사용하므로 흑·한 시점에서도 방향이 맞고, 말 선택을 가로막지 않는다. 힌트와 복기를 요청했을 때 설명을 화면 안으로 가져온다.
- 힌트는 돌을 놓지 않고 후보와 이유를 표시한다. 수 물리기는 내 마지막 수를 두기 직전으로 돌아가며 그 이후 AI 수들도 취소한다. 대국 종료 후 주요 장면을 최대 세 개 다시 볼 수 있다.
- 시간 제한과 순위 기록이 없다. 작은 터치 화면에는 판 확대와 스크롤을 제공한다.
- 작은 화면에서는 힌트 설명이 원칙 안내보다 먼저 나온다. 체스의 여섯 말 이동 방법은 접힌 규칙 메뉴에 둔다. 힌트 계산을 취소하면 취소 상태를 표시하며, 계산 중 문구가 남지 않는다.

## 검증

```sh
npm run test:board-coach
npm run test:board-coach:ui
npm run test:chess-coach
npm run test:chess-coach:ui
npm run test:janggi-coach
npm run test:janggi-coach:ui
npm run test:coach-quality
npm run test:coach-usability
npm run test:coach-arena
```

UI 검사는 `http://127.0.0.1:8936`의 개발 서버와 프로젝트 Playwright/Edge를 사용한다. 다른 서버는 `BOARD_COACH_TEST_URL`로 지정한다. 결과 화면은 `tmp/board-coach/`에 저장한다.

`test:coach-usability`는 네 게임의 힌트가 말을 놓지 않는지, 작은 화면 안에서 설명을 읽을 수 있는지, 힌트 계산 중 설정을 열어 취소한 뒤 늦은 결과가 도착하지 않는지 확인한다. Worker 파일 로딩 실패 후 재시도해도 판이 유지되는지, 체스·장기의 양쪽 시점에서 화살표 끝이 실제 출발·도착 칸을 가리키는지도 검사한다. 실제 학생 참여 검사가 아닌 브라우저로 재현한 사용 흐름 검사이며, 결과 화면은 `tmp/board-coach-usability/`에 저장한다.

규칙 검사는 기존 리버시 엔진과 20판의 합법 수·뒤집기를 비교한다. 모든 수준의 전술·개국 표·안전 기준, 자동 패스·승패·입력 불변성, 두 게임 AI 완주를 검사한다. 브라우저 검사는 진입·수준 선택·힌트·수 물리기·작업 취소·완주·복기와 Chromebook/iPad/휴대전화 크기의 화면을 검사한다. 실제 iPad 하드웨어에서의 검증은 별도이다.

체스는 초기 판 perft 20/400/8,902 및 Kiwipete 48/2,039, 핀·앙파상으로 인한 킹 노출, 캐슬링, 메이트, 승격, 반복·무승부 조건과 모든 수준 AI의 필수 전술을 검사한다. 브라우저에서 실제 초기 판 대국과 특수 위치의 승격·체크메이트·무승부·복기를 검증하며, 화면 결과는 `tmp/chess-coach/`에 저장한다. 기존 온라인 체스 규칙·서버·화면 계약 검사도 함께 실행한다.

장기는 양쪽 16개 차림 조합, 말별 이동과 길막, 장군·외통수·빅장·연속 쉼·반복 장군, 모든 수준의 전술과 저예산 안전 선택, 입력 불변성과 4개 차림의 160수 무작위 합법 진행을 검사한다. 실제 브라우저에서 진입·회전·차림·힌트·되돌리기·계산 취소·기권·특수 상황·복기 및 네 가지 화면 크기를 확인한다. 화면 결과는 `tmp/janggi-coach/`에 저장한다. 화면 크기 검증은 데스크톱 Edge의 뷰포트를 사용하며 실제 iPad 하드웨어 검증은 별도다.

`test:coach-quality`는 별도 완전 탐색으로 리버시 종반 16판과 복기를 검증하고, 오목 240개 공격·방어 선택 및 위협 설명, 체스 저예산 퀸 보호, 양쪽 색·세 수준의 퀸/룩 종반 12판, 체스·장기의 장군/체크 방어와 설명을 검사한다. `test:coach-arena`는 실제 수준별 예산을 사용하여 초급/중급·중급/상급·초급/상급을 각각 선후공을 바꾸어 대국시킨다. 게임별 6판이며 원시 결과·수순·실제 탐색 깊이·응답 시간·코드 해시를 `tmp/board-coach-quality/`에 저장한다. 중단된 판은 무승부에 합산하지 않는다. 소수의 자체 엔진 대국이므로 공인 레이팅이나 모든 판에서의 수준 우위를 뜻하지 않는다.
