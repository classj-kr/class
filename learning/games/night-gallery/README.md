# 밤의 미술관 — 로컬 카드 게임 시제품

Art Robbery의 4라운드 진행을 직접 작성한 코드와 SVG/CSS 화면으로 구현한 비공식 시제품입니다. 원작의 삽화, 로고, 카드 이미지, 규칙서 PDF, 번역 문구를 앱 자산에 포함하지 않았습니다. 이용허락을 받은 공식 디지털판이 아니며 권리 검토가 끝난 배포본도 아닙니다. 사이트 메인 보드게임 목록의 77 폭탄 다음에 연결했습니다. 공개 배포는 진행하지 않았습니다.

## 실행

저장소 루트에서:

```powershell
node learning/games/night-gallery/preview.mjs
```

<http://127.0.0.1:4317>에서 실행됩니다. 미리보기 서버는 127.0.0.1에만 바인딩하고 게임 실행 파일 다섯 개와 기존 공통 대기실 CSS만 제공합니다. 별도 패키지 설치가 필요하지 않습니다. 기존 정적 서버로 실행한다면 `/learning/games/night-gallery/`를 사용합니다.

## 구현 범위

- 2~5명, 4라운드. 컴퓨터 상대 또는 한 기기에서 돌아가며 플레이.
- 최근 미술관 방문자를 첫 차례로 선택. 컴퓨터 대전도 첫 차례 선택 가능.
- 숫자 카드 36장(0~5 각 6장), 보스 6장, 경비견 6장, 도둑 7장.
- 손패 5장 유지, 숫자 카드의 가운데 우선 획득, 도둑은 가운데에서만 획득.
- 보스는 숫자 5와 별도 종류. 보스 카드로 보스를 가져오거나 빼앗고, 도둑 카드로 가운데의 보스 획득 가능.
- 경비견 소유자가 전리품을 내줄지 경비견을 넘겨 막을지 선택. 방어가 끝난 뒤 공격자가 카드를 보충.
- 가운데 마지막 전리품 획득 즉시 라운드 종료. 같은 라운드의 숫자 4/5가 없으면 보스 반납. 보스끼리 조건을 충족하지 않음.
- 보관한 전리품은 비공개로 전환되고 다시 뺏을 수 없음. 손패와 경비견은 이어짐.
- 경비견 소유자가 다음 라운드 선. 경비견이 아직 가운데면 원래 다음 사람부터.
- 3~5명은 알리바이 최저자 모두 탈락. 2명은 유일한 최저자에게 10점 감점. 알리바이 동점이면 감점 없음.
- 점수 동점은 알리바이로 판정하고 둘 다 같으면 공동 승리. 전원 알리바이 동점으로 탈락하면 승자 없음.
- 자동 저장/이어하기, 저장 불가 시 안내, 손상된 저장 내용 방어. 로컬 모드는 매 차례 및 복귀 때 손패 가림.
- 상대 손패를 조회하지 않는 간단한 컴퓨터 전략, 두 가지 진행 속도, 규칙 창을 열면 컴퓨터 일시 정지.

## 구성품 확인 상태 — 완전 일치 판정 전

동작 규칙은 출판사 영문 규칙서 및 한국어판 상품 안내와 대조했습니다. 초판 사진에는 3라운드 보스 2개와 숫자 4 두 개가 보입니다. 이후 판본의 구성 차이가 언급되어 있어 초판 기준임을 명시했습니다.

**2·4라운드의 중복 숫자 개수는 공개 사진에서 일부가 가려져 아직 확정하지 못했습니다.** 해당 라운드는 현재 `0,1,2,3,3,3,4,5,보스`의 임시 배치입니다. `engine.mjs`의 `TILE_LAYOUTS`에 분리했으며, 실물의 각 라운드 앞면 9개가 모두 보이는 사진과 대조해 확정해야 합니다. 따라서 원작 구성까지 완전히 일치한다고 표현하면 안 됩니다. 자동 테스트는 입력한 데이터와 구현의 일관성을 검증하며 이 미확인 실물 데이터를 검증한 것은 아닙니다.

2인 규칙은 영문판의 '10점어치 전리품 반납'을 프랑스어판에 명시된 10점 감점으로 계산합니다. 실물 전리품을 선택해 반납하는 별도 UI는 없습니다. 첫 선과 보스가 여러 개일 때의 처리 등 명확화가 필요한 부분은 별도 데이터/엔진에서 수정 가능합니다.

## 검증

```powershell
node --test tests/night-gallery.test.mjs
node --test tests/night-gallery-ui.test.mjs
```

엔진 검증은 잘못된 행동 거부, 전리품 이동, 경비견 방어 양쪽 선택, 보스 조건, 카드 재순환, 동점과 탈락, 2인 감점, 2~5인 400판 완주 및 매 단계 카드/전리품 보존을 검사합니다.

브라우저 검증은 기존 `game-hub-server`의 Playwright를 사용합니다. Windows에서는 설치된 Edge를 사용하며, 4라운드 실제 클릭 완주, 컴퓨터 진행/일시 정지, 방어 중 새로고침, 재경기, 360/390/768px 화면, 저장소 차단·손상·이름 입력을 확인합니다. 화면 기록은 git에서 제외되는 `outputs/night-gallery/`에 저장합니다.

## 권리 관련 남은 작업

공개·배포 허락은 확보하지 않았습니다. 원작 규칙을 그대로 유지한 디지털판을 공개하려면 구체적인 결과물의 법률 검토 또는 권한 있는 상대의 이용허락을 확인해야 합니다. 자체 코드와 미술만으로 모든 권리 문제가 해소되었다고 보장하지 않습니다.

[Knizia Games의 출판 문의](https://www.knizia.de/publisher-info/)는 온라인·모바일 게임도 안내합니다. 이곳 또는 Helvetiq에 Art Robbery 디지털 권리 담당자를 먼저 확인하고, 브라우저 제작·한국어 사용·대상 이용자·공개 범위·수익화 여부·원작 명칭 사용·기간을 명시한 허락을 받아야 합니다. 현재 디지털 권리 보유자는 확인하지 않았고 연락도 보내지 않았습니다.

온라인 방 생성, 여러 기기 동시 접속, 사이트 목록 등록, 외부 배포는 이 시제품 범위에 포함하지 않습니다. 로컬 저장 데이터는 개발자 도구로 볼 수 있으므로 경쟁용 보안 경계가 아닙니다.
