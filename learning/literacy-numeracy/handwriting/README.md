# 글씨 쓰기

문해·수리의 읽기 다음에서 여는 한글 연습장. 자음·모음·현대 한글 낱말과 문장을 공책처럼 한꺼번에 늘어놓고 따라 쓰거나 보고 쓴다. 속담·한자성어·관용어는 각 학습 자료에서 뽑은 문구를 무작위로 하나씩 내고 뜻을 함께 보여 준다(`writing-texts.js`, `node scripts/build-handwriting-texts.cjs`로 다시 만든다. 다른 수업 메뉴가 잠겨도 쓸 수 있게 이 폴더에 둔다). 직접 넣기는 한글 48자까지이며 띄어쓰기는 칸 사이 간격으로만 보이고 채점하지 않는다. 숫자·문장 부호·옛한글은 채점하지 않는다.

- 기본은 펜 전용이다. `pointerType=pen`과 마우스만 기록하며 터치는 펜이 닿기 전부터 무시한다. 쓰기 칸의 스크롤·확대는 `touch-action:none`으로 막는다.
- 터치 모드는 한 접촉만 받으며 큰 접촉은 거른다. 접촉 크기만으로 손바닥을 완벽히 구분할 수 없으므로 손을 떼고 쓰도록 안내한다. 실제 펜 입력이 오면 임시 터치 획을 버리고 펜 전용으로 바꾼다. 펜을 올리거나 취소하기 전의 획은 확정하지 않는다.
- 기기의 모델명·브라우저 이름으로 펜 지원을 추정하지 않는다. 입력 확인 창에서 실제로 보고된 종류를 보여 준다. 물리적인 펜의 응답성과 운영체제의 손바닥 처리 성능은 실물 기기에서 별도로 확인해야 한다.
- 좌표는 100×100 칸을 기준으로 저장하여 화면 크기가 바뀌어도 유지한다. 로그인 계정은 `SiteStorage`에 자동 저장하고 게스트는 탭 안에서만 유지한다. 학생용 JSON 저장·불러오기 기능은 두지 않는다. 인쇄는 설정에서 열며 Canvas를 직접 사용한다.
- 첫 화면은 글자 선택·쓰기 단계와 연습장(본보기 칸 + 쓰기 칸)·되돌리기·이 칸 지우기·획순·확인으로 구성한다. 소개 제목, 홍보 문구, 장식 패널은 없다. 입력 방식·펜 굵기·보조선·인쇄와 저장 상태는 설정 안에 둔다.
- 연습장은 글자마다 본보기 칸을 위에, 같은 크기·같은 보조선의 쓰기 칸을 바로 아래에 붙인다. 낱말끼리 붙고 낱말 사이는 띄어쓰기만큼 벌어지며, 화면보다 긴 낱말은 줄을 바꾼다. 아무 칸이나 눌러 쓰면 그 칸이 지금 칸이 되고(초록 테두리, 획순·지우기·되돌리기의 대상), 한 글자의 획 수를 다 채우면 다음 빈 칸으로 넘어간다. 확인은 쓴 칸을 모두 채점해 칸마다 통과(초록)·다시(주황)를 표시하고 평균 모양 일치도와 획순 통과 수를 보여 준다.
- 칸 크기는 기본 64~104 CSS 픽셀(화면 폭에 맞춤)이며, 설정에서 작게(64)·보통(88)·크게(120)를 고를 수 있고 계정에 저장한다. CSS 픽셀로 모니터의 실제 인치를 알아낼 수는 없으므로 이 값은 물리적 길이를 보장하는 측정치가 아니다. 확대·회전 때 완료된 획의 100단위 좌표는 그대로 두고, 진행 중이던 획만 취소한다.

## 본보기와 점수

기본 `경필체 M`은 직접 설계한 **클래스제이 펜 M 1.300**을 사용한다. `를·어·푸`의 획 연결, 간격과 맺음을 다듬은 자체 M 서체이며 DX경필명조 정품 파일은 아니다. `받아쓰기체`도 선택할 수 있다.

`assets/fonts/classj-pen-m/source.js`가 기본 M의 자모 중심선·펜촉 윤곽·조합 배치 원본이다. `font-engine.js`가 선택한 모형을 본보기·따라쓰기·획순·채점이 공유하며 서버의 순위전 채점도 같은 M 모형을 쓴다. 받아쓰기체는 기존 `font-source.js`와 `style-badasseugi.js`의 모형을 사용한다. 아래 0.500~1.000은 M의 바탕이 된 기존 자체 서체의 제작 기록이다.

0.500에서는 펜의 시작을 곡선으로 돌리고 획 끝의 과도한 가늘어짐을 줄였다. 세로모음 옆 초성을 낮은 높이로 잡고, ㄴ·ㄷ·ㄹ·ㅌ의 발 부분은 다음 모음에 맞춰 연장한다. 왼쪽으로 뻗는 모음 앞의 둥근 초성에는 별도의 간격을 둔다. 받침은 ㄴ, ㅇ, ㄹ·ㅂ·ㅍ, ㅊ·ㅎ, 겹받침의 높이와 폭을 나눠 설계하며, 높은 받침이 있을 때 가로모음 위치도 올린다. 개별 글자 그림의 교체가 아니라 모든 조합에 적용하는 자모·펜촉·맥락 규칙의 수정이다.

0.600에서는 기울어진 타원형 펜촉으로 가로·세로와 양쪽 사선의 굵기 차이를 살렸다. 독립 세로획은 비스듬히 진입하고 아래에서 힘을 빼지만, 다른 획에 붙거나 윗획이 가까운 자리에는 머리를 덧붙이지 않는다. ㄷ의 바닥은 완만하게 올라가도록 펴고, ㅍ의 윗획과 안쪽 세로획 사이를 띄웠다. ㅇ은 좌우가 완전히 대칭인 원 대신 작은 기울기와 곡률 차이를 둔다. 문서 5판과 기존 연습은 유지한다.

0.700에서는 공식 페이지가 문구별로 제공하는 DX경필명조 L·M·B·ExB 미리보기 글꼴을 비교용으로 확보하고 M을 기준으로 같은 128px·같은 기준선에서 대조했다. 가로모음과 ㅍ을 넓히고, 받침 ㅇ은 좁혀 오른쪽에 배치하며, ㄴ은 가로모음 아래와 세로모음 아래를 나눠 배치한다. ㄹ의 층 높이와 폭을 키우고 세로모음은 받침 유무와 관계없이 같은 높이에서 시작한다. 짧은 획에는 작은 머리를 사용한다. TTF와 Canvas의 기준선을 함께 800/1000 em·80/100으로 맞췄다. 비교용 외부 글꼴은 생성기·배포 글꼴에 입력하지 않는다.

0.800에서는 공식 M 미리보기 133자로 조합을 대조하고, 109개 음절의 자모 위치·비례를 검토했다. 초성 배치는 모음의 방향과 받침 구조로 나누고, 받침은 오른쪽 모음·왼쪽 모음·ㅣ·가로모음·겹모음에 맞는 셀을 사용한다. 독립 자모의 연습 크기는 유지한다. 세로모음은 받침에 맞춰 길이를 정하며, 획을 고르게 만들고 긴 가로획만 조금 보강한다. ㄷ의 돌출과 둥근 꺾임, ㅈ·ㅊ의 긴 왼쪽 사선, 받침 ㄱ·ㅁ·ㄹ의 별도 형태를 다듬었다. 글자 간격은 920/1000 em이다. 화면·획순·채점은 같은 자체 중심선을 사용하며 외부 글꼴 윤곽을 배포 글꼴에 복사하지 않는다.

0.900에서는 `교·책·얘·워·웨·위` 등의 공식 M 견본과 실제 앱을 다시 대조했다. ㅐ·ㅒ·ㅔ·ㅖ의 두 세로획은 각각의 시작·끝 높이와 간격을 사용한다. 겹모음 7종은 모음 전체를 늘이던 방식 대신 긴 가로획·짧은 가로획·세로획을 따로 배치한다. 특히 ㅝ·ㅞ의 짧은 가로획은 긴 가로획 아래에 둔다. ㅛ의 두 세로획과 ㄱ 사이의 간격, ㅜ·ㅠ의 맺음, 쌍자음과 받침 위 초성도 수정했다. DX경필명조 원본과 동일한 서체라는 뜻은 아니며, 자체 중심선을 수정한 별도 글꼴이다.

1.000에서는 기본 연습 문구 전체와 `권·괄·귤·확·활·훤·뺨·찹·핥·팥` 등 구조가 다른 음절을 대조했다. 받침 27종의 공통 셀을 완성하고 가로모음·겹모음별 위치를 조정한다. ㅜ·ㅠ의 맺음은 받침 첫 가로획에서 멈추며 중간 층까지 관통하지 않는다. 초성과 받침은 전 음절에서 중심선 여백을 검사하며, 잘못 겹치는 초성만 높이를 줄인다. ㅁ의 진입획, 무·늘·믿의 비례와 받침 있는 ㄸ의 발도 다듬었다. 공식 미리보기 글꼴은 로컬 비교 자료로만 두며 배포물에는 자체 글꼴을 포함한다.

`scripts/compare-handwriting-font.py`는 공개 견본의 글자와 수정 전·후 TTF를 나란히 그린다. 글자 전체의 높이만 균일하게 맞추어 자모 비례를 유지하고 무손실 WebP로 저장한다. 견본은 https://www.sandollcloud.com/font/17065/DXKPM 에서 확인한 비교 자료이며 생성기에 입력하지 않는다. 실제 견본의 여러 굵기가 포함되어 있으므로 이 비교가 같은 웨이트의 수치적 일치율을 뜻하지는 않는다.

실제 글꼴을 비교할 때는 `--reference-font <DX경필명조 미리보기 TTF> --before <현재 TTF>`를 사용한다. 이 모드는 모든 글자에 동일한 em 크기와 기준선을 적용하며 글자별 확대·축소를 하지 않는다. `--after <수정 TTF>`로 세 열을 만들 수 있다. 미리보기 부분집합에 포함된 글자만 비교한다.

본보기와 따라쓰기 글자는 이 원본으로 만든 실제 WOFF2를 `fillText`로 그린다. 글자마다 모양을 강제로 확대하지 않고 같은 100단위 좌표와 기준선을 유지한다. 획순 시범은 같은 중심선을 따라 글꼴 안에서 색을 드러낸다. 획순은 획 개수·해당 순서의 경로·시작과 끝·진행 방향을 따로 검사한다. 필압과 속도는 점수에 넣지 않는다.

점수(2026-11-07):
- **모양**(`pen-reference.js`의 `measure`): 쓴 글자의 중심과 크기(제곱평균 반지름)를 본보기에 맞춰 놓은 뒤, 획 위 점들이 본보기 경로에서 얼마나 떨어졌는지(정밀도)와 본보기 경로를 얼마나 덮었는지(덮임)를 반반 본다. 획 굵기(2.8) 안은 만점, 8.8 넘게 떨어지면 0점이다. 여기에 **자리** 점수를 곱한다. 칸 안에서 8까지 비키거나 30%까지 크고 작은 것은 감점하지 않고, 그 뒤로 비킨 만큼·크기 차이만큼 줄어든다. 예전에는 자리를 그대로 비교해서, 모양이 바른 글자도 조금 작거나 비켜 쓰면 크게 깎였다.
- **글자 점수** = 모양 × 획 점수. 획 점수는 맞은 획 비율에 따라 40~100%이고, 획을 더 그었으면 그 비율만큼 더 깎는다. 획순 하나 틀렸다고 0점이 되지 않는다. 칸을 빽빽이 칠하면 모양 겹침은 나오지만 획 점수가 낮아 글자 점수가 낮다.
- **글 점수** = 글자 점수의 평균(안 쓴 글자는 0점). 연습의 '확인'과 순위전 순위가 같은 계산을 쓴다.

기본 자모의 획 개수와 방향은 국립국어원 세종한국어 1(2011), 예비편의 쓰는 순서 표를 대조했다. ㄹ 3획, ㅈ 2획, ㅊ 3획, ㅎ 3획과 ㅓ·ㅕ의 짧은 가로획을 먼저 쓰는 순서를 적용한다.

기본 M 글꼴은 `assets/fonts/classj-pen-m/`의 TTF·WOFF2이며 현대 한글 11,172음절과 호환 자모 51자를 지원한다. 재생성은 `python scripts/build-pen-m.py`로 한다(fonttools, brotli 필요). 외부 글꼴 파일을 입력으로 받지 않는다. manifest는 원본 소스의 SHA-256과 글자 수·파일 크기를 기록한다. 이 소스는 `.gitattributes`로 줄바꿈 변환을 막아 Windows와 서버에서 같은 해시를 유지한다.

저장 문서는 8판이다. 1~7판 연습은 `legacy-draft-v1`~`legacy-draft-v7`에 보관하고 새 자형용 연습장을 연다.

## 방번호 순위전

누구나 ‘순위전’에서 글(직접 넣기 또는 속담·한자성어·관용어 무작위, 한글 1~24글자)과 따라/혼자 쓰기 모드를 정해 방을 연다. 학생이 연 방은 방장도 함께 쓰고 시작·마치기를 맡는다. 교사가 연 방은 교사도 기본으로 함께 쓰며, '나는 참여하지 않고 관전하기'를 고르면 지켜만 본다. 학생은 메인 화면 `/room/`의 4자리 입구로 들어와 준비한다. 모두 준비하면 방장이 시작한다. 5분 동안 쓰고 각자 한 번 제출한다. 방장은 중간에 판을 마칠 수도 있다.

서버가 실제 획 좌표를 다시 채점하며 클라이언트 점수는 받지 않는다. 글 점수(모양 × 획순, 위 '점수' 참고)로 순위를 매기고 같은 점수는 공동 순위로 표시한다. 획순이 틀려도 순위에서 빠지지 않고 깎인 점수로 아래 순위가 된다. 미제출은 순위 없이 표시한다. 결과는 판 종료 후 함께 공개한다. 방 상태에는 다른 학생의 원본 획·토큰을 보내지 않는다.

기존 `roomCodes`의 공통 번호 공간을 사용하며 살아 있는 방은 번호를 재사용하지 않는다. 교사 제어는 방 토큰과 교사 로그인을 함께 확인한다. 종료·새 판·제한 시간 이후 제출과 중복 결과 교체를 막는다. 방은 리듬 활동처럼 서버 메모리에서 유지하며 2시간 미사용 또는 서버 재시작 시 끝난다. 방 입구는 학급 메뉴 잠금과 별개로 열리며 전체 사용 중지는 적용된다.

## 검증

`npm run test:handwriting` — 전 음절 구성과 초성·받침 여백, 내려오는 모음의 맺음, 역방향·획 순서 교환·누락, 서버 채점, 권한, 시간 제한, 공통 방번호, 메뉴.

`npm run test:handwriting:ui` — Playwright에서 펜·터치 우선순위와 취소, 단계별 획 분리, 실행 취소, 저장·복원, 인쇄, 모바일 크기, 방 입장·제출·순위. Windows에서는 Edge를 사용한다. Python/Pillow로 메모리 캡처를 무손실 WebP로 저장하며, 필요한 경우 `HANDWRITING_PYTHON`에 Python 경로를 지정한다. 결과는 `outputs/handwriting/`에 둔다.
