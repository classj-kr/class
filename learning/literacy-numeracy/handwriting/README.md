# 글씨 쓰기

문해·수리의 읽기 다음에서 여는 한글 연습장. 자음·모음·현대 한글 음절을 한 글자씩 따라 쓰거나 보고 쓴다. 직접 넣기는 한글 48자까지이며 띄어쓰기는 연습 칸에서 제외한다. 숫자·문장 부호·옛한글은 채점하지 않는다.

- 기본은 펜 전용이다. `pointerType=pen`과 마우스만 기록하며 터치는 펜이 닿기 전부터 무시한다. 쓰기 칸의 스크롤·확대는 `touch-action:none`으로 막는다.
- 터치 모드는 한 접촉만 받으며 큰 접촉은 거른다. 접촉 크기만으로 손바닥을 완벽히 구분할 수 없으므로 손을 떼고 쓰도록 안내한다. 실제 펜 입력이 오면 임시 터치 획을 버리고 펜 전용으로 바꾼다. 펜을 올리거나 취소하기 전의 획은 확정하지 않는다.
- 기기의 모델명·브라우저 이름으로 펜 지원을 추정하지 않는다. 입력 확인 창에서 실제로 보고된 종류를 보여 준다. 물리적인 펜의 응답성과 운영체제의 손바닥 처리 성능은 실물 기기에서 별도로 확인해야 한다.
- 좌표는 100×100 칸을 기준으로 저장하여 화면 크기가 바뀌어도 유지한다. 로그인 계정은 `SiteStorage`에 자동 저장하고 게스트는 탭 안에서만 유지한다. 학생용 JSON 저장·불러오기 기능은 두지 않는다. 인쇄는 설정에서 열며 Canvas를 직접 사용한다.
- 첫 화면은 글자 선택·쓰기 단계와 본보기·쓰기 칸·되돌리기·지우기·확인으로 구성한다. 소개 제목, 홍보 문구, 장식 패널은 없다. 입력 방식·펜 굵기·보조선·인쇄와 저장 상태는 설정 안에 둔다.

## 본보기와 점수

실제 교육용 글꼴인 **학교안심 받아쓰기 Light**를 사용한다. 원본 WOFF는 `assets/fonts/keris-badasseugi/`에 보관하고 OFL 이용 조건과 출처를 함께 제공한다. 자체 제작 시제품은 본보기에서 제외했다.

본보기와 따라쓰기 글자는 `fillText`로 실제 글꼴을 그린다. 글자별 원본 비례를 유지하여 80×80 영역에 맞추며, `reference-data.js`는 같은 글꼴에서 추출한 잉크 마스크와 배치 좌표를 담는다. 일치도는 필기선이 실제 글꼴에 얼마나 가까운지와 글꼴의 전체 획을 얼마나 덮었는지를 함께 비교한 참고 점수다. 임의로 조합한 자모 윤곽을 모양 채점에 사용하지 않는다.

`stroke-topology.js`는 획 개수·순서의 초기 위치 추정에만 사용한다. `reference.js`가 실제 글꼴 마스크의 잉크를 순서별로 나누고 중심선을 근사한다. 획순 시범은 이 경로를 따라 **실제 글꼴 안에서만** 색을 드러낸다. 획 개수·순서·방향 검사는 근사 방식이며 필압과 속도는 점수에 넣지 않는다.

기본 자모의 획 개수와 방향은 국립국어원 세종한국어 1(2011), 예비편 18~21쪽의 쓰는 순서 표를 대조했다. ㄹ 3획, ㅈ 2획, ㅊ 3획, ㅎ 3획과 ㅓ·ㅕ의 짧은 가로획을 먼저 쓰는 순서를 적용한다.

자료 재생성: `python scripts/build-handwriting-reference.py --font <공식 원본.woff>` (fonttools, brotli, Pillow, numpy 필요). 생성 도구는 한글 11,172음절과 호환 자모 51자의 마스크를 검증하고 글꼴을 변형 없이 복사한다. 이전 시제품용 저장 기록은 `legacy-draft-v1` 또는 `legacy-draft-v2`에 보관한다.

## 방번호 순위전

교사는 ‘순위전’에서 한글 1~12글자와 따라/혼자 쓰기 모드를 정해 방을 연다. 학생은 기존 `/room/`의 4자리 입구로 들어와 준비한다. 모두 준비하면 교사가 시작한다. 5분 동안 쓰고 각자 한 번 제출한다. 교사는 중간에 판을 마칠 수도 있다.

서버가 실제 획 좌표를 다시 채점하며 클라이언트 점수는 받지 않는다. 획순 통과 기록만 모양 일치도로 순위를 매기고 동점은 공동 순위로 표시한다. 미통과·미제출은 별도로 표시한다. 결과는 판 종료 후 함께 공개한다. 방 상태에는 다른 학생의 원본 획·토큰을 보내지 않는다.

기존 `roomCodes`의 공통 번호 공간을 사용하며 살아 있는 방은 번호를 재사용하지 않는다. 교사 제어는 방 토큰과 교사 로그인을 함께 확인한다. 종료·새 판·제한 시간 이후 제출과 중복 결과 교체를 막는다. 방은 리듬 활동처럼 서버 메모리에서 유지하며 2시간 미사용 또는 서버 재시작 시 끝난다. 방 입구는 학급 메뉴 잠금과 별개로 열리며 전체 사용 중지는 적용된다.

## 검증

`npm run test:handwriting` — 전 음절 구성, 역방향·획 순서 교환·누락, 서버 채점, 권한, 시간 제한, 공통 방번호, 메뉴.

`npm run test:handwriting:ui` — Playwright에서 펜·터치 우선순위와 취소, 단계별 획 분리, 실행 취소, 저장·복원, 인쇄, 모바일 크기, 방 입장·제출·순위. Windows에서는 Edge를 사용한다. Python/Pillow로 메모리 캡처를 무손실 WebP로 저장하며, 필요한 경우 `HANDWRITING_PYTHON`에 Python 경로를 지정한다. 결과는 `outputs/handwriting/`에 둔다.
