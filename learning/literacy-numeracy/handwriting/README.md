# 글씨 쓰기

문해·수리의 읽기 다음에서 여는 한글 연습장. 자음·모음·현대 한글 음절을 한 글자씩 따라 쓰거나 보고 쓴다. 직접 넣기는 한글 48자까지이며 띄어쓰기는 연습 칸에서 제외한다. 숫자·문장 부호·옛한글은 채점하지 않는다.

- 기본은 펜 전용이다. `pointerType=pen`과 마우스만 기록하며 터치는 펜이 닿기 전부터 무시한다. 쓰기 칸의 스크롤·확대는 `touch-action:none`으로 막는다.
- 터치 모드는 한 접촉만 받으며 큰 접촉은 거른다. 접촉 크기만으로 손바닥을 완벽히 구분할 수 없으므로 손을 떼고 쓰도록 안내한다. 실제 펜 입력이 오면 임시 터치 획을 버리고 펜 전용으로 바꾼다. 펜을 올리거나 취소하기 전의 획은 확정하지 않는다.
- 기기의 모델명·브라우저 이름으로 펜 지원을 추정하지 않는다. 입력 확인 창에서 실제로 보고된 종류를 보여 준다. 물리적인 펜의 응답성과 운영체제의 손바닥 처리 성능은 실물 기기에서 별도로 확인해야 한다.
- 좌표는 100×100 칸을 기준으로 저장하여 화면 크기가 바뀌어도 유지한다. 로그인 계정은 `SiteStorage`에 자동 저장하고 게스트는 탭 안에서만 유지한다. 학생용 JSON 저장·불러오기 기능은 두지 않는다. 인쇄는 설정에서 열며 Canvas를 직접 사용한다.
- 첫 화면은 글자 선택·쓰기 단계와 본보기·쓰기 칸·되돌리기·지우기·확인으로 구성한다. 소개 제목, 홍보 문구, 장식 패널은 없다. 입력 방식·펜 굵기·보조선·인쇄와 저장 상태는 설정 안에 둔다.
- 쓰기 칸과 본보기는 화면의 짧은 변을 반영한 72~88 CSS 픽셀의 작은 정사각형이다. 넓은 모니터에서도 이 상한을 넘겨 확대하지 않는다. 설정에서 작게·보통·크게를 고를 수 있고 계정에 저장한다. CSS 픽셀로 모니터의 실제 인치를 알아낼 수는 없으므로 이 값은 물리적 길이를 보장하는 측정치가 아니다. 확대·회전 때 완료된 획의 100단위 좌표는 그대로 두고, 진행 중이던 획만 취소한다.

## 본보기와 점수

직접 설계한 **클래스제이 경필명조**를 사용한다. 세로획의 작은 머리, 가로·세로 획의 굵기 차이와 곡선의 맺음을 펜글씨 방향으로 그렸다. 다른 서체로 대체하지 않는다.

`font-source.js`가 자모 중심선·펜촉 윤곽·조합 배치의 원본이다. 자모의 잉크 경계를 같은 사각형에 억지로 늘이지 않고, 세로모음·가로모음·겹모음·받침 유무에 따른 디자인 셀에 배치한다. ㄱ·ㅋ은 세로모음 앞, 가로모음 앞, 받침에서 다른 형태를 쓴다. 받침 높이를 확보하고 ㅊ·ㅎ의 윗획과 윗모음 사이에 별도 여백을 둔다. 겹받침은 두 자모를 분리해 배치한다.

0.500에서는 펜의 시작을 곡선으로 돌리고 획 끝의 과도한 가늘어짐을 줄였다. 세로모음 옆 초성을 낮은 높이로 잡고, ㄴ·ㄷ·ㄹ·ㅌ의 발 부분은 다음 모음에 맞춰 연장한다. 왼쪽으로 뻗는 모음 앞의 둥근 초성에는 별도의 간격을 둔다. 받침은 ㄴ, ㅇ, ㄹ·ㅂ·ㅍ, ㅊ·ㅎ, 겹받침의 높이와 폭을 나눠 설계하며, 높은 받침이 있을 때 가로모음 위치도 올린다. 개별 글자 그림의 교체가 아니라 모든 조합에 적용하는 자모·펜촉·맥락 규칙의 수정이다.

0.600에서는 기울어진 타원형 펜촉으로 가로·세로와 양쪽 사선의 굵기 차이를 살렸다. 독립 세로획은 비스듬히 진입하고 아래에서 힘을 빼지만, 다른 획에 붙거나 윗획이 가까운 자리에는 머리를 덧붙이지 않는다. ㄷ의 바닥은 완만하게 올라가도록 펴고, ㅍ의 윗획과 안쪽 세로획 사이를 띄웠다. ㅇ은 좌우가 완전히 대칭인 원 대신 작은 기울기와 곡률 차이를 둔다. 문서 5판과 기존 연습은 유지한다.

0.700에서는 공식 페이지가 문구별로 제공하는 DX경필명조 L·M·B·ExB 미리보기 글꼴을 비교용으로 확보하고 M을 기준으로 같은 128px·같은 기준선에서 대조했다. 가로모음과 ㅍ을 넓히고, 받침 ㅇ은 좁혀 오른쪽에 배치하며, ㄴ은 가로모음 아래와 세로모음 아래를 나눠 배치한다. ㄹ의 층 높이와 폭을 키우고 세로모음은 받침 유무와 관계없이 같은 높이에서 시작한다. 짧은 획에는 작은 머리를 사용한다. TTF와 Canvas의 기준선을 함께 800/1000 em·80/100으로 맞췄다. 비교용 외부 글꼴은 생성기·배포 글꼴에 입력하지 않는다.

0.800에서는 공식 M 미리보기 133자로 조합을 대조하고, 109개 음절의 자모 위치·비례를 검토했다. 초성 배치는 모음의 방향과 받침 구조로 나누고, 받침은 오른쪽 모음·왼쪽 모음·ㅣ·가로모음·겹모음에 맞는 셀을 사용한다. 독립 자모의 연습 크기는 유지한다. 세로모음은 받침에 맞춰 길이를 정하며, 획을 고르게 만들고 긴 가로획만 조금 보강한다. ㄷ의 돌출과 둥근 꺾임, ㅈ·ㅊ의 긴 왼쪽 사선, 받침 ㄱ·ㅁ·ㄹ의 별도 형태를 다듬었다. 글자 간격은 920/1000 em이다. 화면·획순·채점은 같은 자체 중심선을 사용하며 외부 글꼴 윤곽을 배포 글꼴에 복사하지 않는다.

`scripts/compare-handwriting-font.py`는 공개 견본의 글자와 수정 전·후 TTF를 나란히 그린다. 글자 전체의 높이만 균일하게 맞추어 자모 비례를 유지하고 무손실 WebP로 저장한다. 견본은 https://www.sandollcloud.com/font/17065/DXKPM 에서 확인한 비교 자료이며 생성기에 입력하지 않는다. 실제 견본의 여러 굵기가 포함되어 있으므로 이 비교가 같은 웨이트의 수치적 일치율을 뜻하지는 않는다.

실제 글꼴을 비교할 때는 `--reference-font <DX경필명조 미리보기 TTF> --before <현재 TTF>`를 사용한다. 이 모드는 모든 글자에 동일한 em 크기와 기준선을 적용하며 글자별 확대·축소를 하지 않는다. `--after <수정 TTF>`로 세 열을 만들 수 있다. 미리보기 부분집합에 포함된 글자만 비교한다.

본보기와 따라쓰기 글자는 이 원본으로 만든 실제 WOFF2를 `fillText`로 그린다. 글자마다 모양을 강제로 확대하지 않고 같은 100단위 좌표와 기준선을 유지한다. 획순 시범은 같은 중심선을 따라 글꼴 안에서 색을 드러낸다. `pen-reference.js`의 일치도는 실제 글꼴과 공유하는 필기 경로의 거리·전체 획의 덮임을 비교한 참고 수치다. 획순은 획 개수·해당 순서의 경로·시작과 끝·진행 방향을 따로 검사한다. 필압과 속도는 점수에 넣지 않는다.

기본 자모의 획 개수와 방향은 국립국어원 세종한국어 1(2011), 예비편의 쓰는 순서 표를 대조했다. ㄹ 3획, ㅈ 2획, ㅊ 3획, ㅎ 3획과 ㅓ·ㅕ의 짧은 가로획을 먼저 쓰는 순서를 적용한다.

글꼴은 `assets/fonts/classj-gyeongpil/`의 TTF·WOFF2이며 현대 한글 11,172음절과 호환 자모 51자를 지원한다. 재생성: `python scripts/build-handwriting-font.py --preview outputs/handwriting/gyeongpil-proof.webp` (fonttools, brotli, Pillow 필요). 외부 글꼴 파일을 입력으로 받지 않는다. `--specimen-only --output <임시 폴더>`로 문장 견본을 먼저 만들 수 있다. manifest는 원본 소스의 SHA-256과 글자 수·파일 크기를 기록한다.

저장 문서는 6판이다. 1~5판 연습은 `legacy-draft-v1`~`legacy-draft-v5`에 보관하고 새 자형용 연습장을 연다.

## 방번호 순위전

교사는 ‘순위전’에서 한글 1~12글자와 따라/혼자 쓰기 모드를 정해 방을 연다. 학생은 기존 `/room/`의 4자리 입구로 들어와 준비한다. 모두 준비하면 교사가 시작한다. 5분 동안 쓰고 각자 한 번 제출한다. 교사는 중간에 판을 마칠 수도 있다.

서버가 실제 획 좌표를 다시 채점하며 클라이언트 점수는 받지 않는다. 획순 통과 기록만 모양 일치도로 순위를 매기고 동점은 공동 순위로 표시한다. 미통과·미제출은 별도로 표시한다. 결과는 판 종료 후 함께 공개한다. 방 상태에는 다른 학생의 원본 획·토큰을 보내지 않는다.

기존 `roomCodes`의 공통 번호 공간을 사용하며 살아 있는 방은 번호를 재사용하지 않는다. 교사 제어는 방 토큰과 교사 로그인을 함께 확인한다. 종료·새 판·제한 시간 이후 제출과 중복 결과 교체를 막는다. 방은 리듬 활동처럼 서버 메모리에서 유지하며 2시간 미사용 또는 서버 재시작 시 끝난다. 방 입구는 학급 메뉴 잠금과 별개로 열리며 전체 사용 중지는 적용된다.

## 검증

`npm run test:handwriting` — 전 음절 구성, 역방향·획 순서 교환·누락, 서버 채점, 권한, 시간 제한, 공통 방번호, 메뉴.

`npm run test:handwriting:ui` — Playwright에서 펜·터치 우선순위와 취소, 단계별 획 분리, 실행 취소, 저장·복원, 인쇄, 모바일 크기, 방 입장·제출·순위. Windows에서는 Edge를 사용한다. Python/Pillow로 메모리 캡처를 무손실 WebP로 저장하며, 필요한 경우 `HANDWRITING_PYTHON`에 Python 경로를 지정한다. 결과는 `outputs/handwriting/`에 둔다.
