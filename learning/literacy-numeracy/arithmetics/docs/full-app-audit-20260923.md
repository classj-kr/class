## 검증 결과

- `npm test`: 통과. 타입 오류 0개, 단위 테스트 535개 통과, 프로덕션 빌드 성공, HTML 테스트 95개 통과.
- 중등 39장·고등 66장·이공계 기초 6장의 기존 반복도 검사를 통과했다.
- 브라우저: 176개 전부 정상 응답. 브라우저 예외, 수식 렌더링 오류, 검사 대상의 중복 선택지, 선택형 정답 채점 불일치, 새 문제 내용 불변, 모바일 가로 넘침, 인쇄 문항의 용지 이탈은 최종 검사에서 0건이었다.
- 직육면체: 실제 입력으로 `0/4 → 1/4 → 4/4` 및 오답 수정·초기화를 확인. 24번의 새 문제에서 각 회차 네 유형이 중복 없이 출제되고 전체 여덟 유형이 나타나는 것을 확인했다.
- 원: 두 값 중 하나만 맞히면 0문제, 두 값을 모두 맞히면 1문제로 채점하는 것을 확인했다.
- 소수 찾기: 빈 답 0점, 소수 25개만 선택하면 25점, 비소수 하나 추가 시 24점, 100개 모두 선택하면 0점으로 검증했다.
- 입체 8유형과 원 16유형을 실제 브라우저에서 모아 시각 검토했다. 입체 면적은 면 좌표의 넓이 합, 부피는 독립적인 공간 칸 개수로 교차 검증했다.
- 추가 회귀 검사는 생성된 소인수분해의 역산, 중등 수식 렌더링, 유리수 답의 유일성, 곡선 길이의 수치 적분, 삼각방정식 해의 대입을 포함한다.

## 재실행과 증거

연산앱 폴더에서 실행한다.

```text
npm test
npm run dev -- --host localhost --port 6180
npm run audit:browser
```

브라우저 검사는 이 저장소의 `game-hub-server/node_modules/playwright`와 Windows의 Microsoft Edge를 사용한다. 다른 로컬 포트는 `ARITHMETIC_AUDIT_URL`로 지정할 수 있다. 결과 JSON과 화면은 `tmp/browser-audit/`, 실행 로그는 `tmp/browser-audit.log`, 입력·채점 검증 로그는 `tmp/measurement-grading.log`에 있다. 타입 선언 재생성은 `npm run types:generate`로 실행한다. `wrangler.types.jsonc`는 타입 생성에 사용하는 별도 설정이다.

## 점검 범위

전체 176개 화면의 공통 동작과 기존·추가 테스트를 검증한 결과다. 모든 난수 조합의 수학적 정확성이나 모든 문항의 교육적 적합성을 전수 증명한 것은 아니다. 도형은 위의 24유형을 직접 확인했고, 나머지 생성기는 기존 테스트와 추가 표본 검사로 확인했다. 인쇄는 브라우저의 인쇄 모드에서 검사했으며 실제 프린터 출력과 여러 사용자가 동시에 참여하는 대회 운영은 이번 검사에 포함하지 않았다. 변경은 로컬에 반영했으며 외부 서비스에 배포하지 않았다.
