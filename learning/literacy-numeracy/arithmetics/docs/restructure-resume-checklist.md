# 중·고등 학습지 재구조화 재개 체크리스트

기준 커밋: `d6b2ca0d`

## 완료 판정 원칙

- 자동 테스트 통과만으로 완료 처리하지 않는다.
- 목차, 실제 생성기, 문제지 제목, 답안 입력 발문을 함께 확인한다.
- 중학교에는 초등 수준의 양수 산술·단순 대소 비교를 넣지 않는다.
- 쉬운 유형은 독립 반복 학습지로 만들지 않고 종합 페이지에 필요한 만큼만 둔다.
- 집중 훈련이 필요한 유형만 독립 학습지로 유지한다.
- 도형은 텍스트 설명이 아니라 화면·인쇄 공용 SVG를 사용한다.

## 1. 전체 목차 재분류

- [x] 중등·고등 목차에 `필수 통합`, `집중 훈련`, `도형 필수`, `심화·선행` 분류 저장
- [x] 버튼 제목·학년·과목·생성기 일치 검사
- [ ] `심화·선행`을 기본 필수 흐름에서 분리

## 2. 잘못 통합돼 사라진 유형

- [x] 제곱근과 근호 계산 종합 구성
- [x] 이차방정식 극기초를 기본·인수분해 페이지에 통합
- [x] 대푯값·도수·상대도수 통합
- [x] 각 통합 페이지의 유형별 문제 수 재검증

## 3. 중등 재구조화

- [x] 기본도형·작도·합동은 단순 개념 유형이므로 수학 OX로 분리
- [x] 도수분포·상대도수 그래프 보완
- [x] 중등 범위를 벗어난 세제곱 합차·3차식 묶기 이동
- [x] 정수·유리수의 초등 수준 양수 계산 제거
- [x] 훈련 가치가 낮은 정수 대소 비교 제거
- [x] 일차부등식과 연립방정식 혼합 페이지 해체
- [x] 일차부등식 활용 보완
- [x] 연립방정식 활용 보완
- [x] 해가 없거나 무수히 많은 연립방정식 보완
- [ ] 평면과 입체도형의 위치 관계 최종 확인
