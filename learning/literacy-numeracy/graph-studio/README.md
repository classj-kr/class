# 그래프 칠판

`/learning/literacy-numeracy/graph-studio/`에서 제공하는 정적 수업 도구입니다. 기존 교사용 메뉴의 “그래프 그리기” 링크를 그대로 사용합니다. 추가 서버나 외부 API가 필요하지 않습니다.

## 수업 흐름

1. 기본 이차함수에서 **지금 모양 남기기**를 누릅니다.
2. 큰 조절점을 끌어 꼭짓점을 이동하고, 작은 조절점으로 폭과 방향을 바꿉니다. 숫자로 정확한 계수를 입력할 수도 있습니다.
3. 점선으로 남은 원래 그래프와 비교합니다. 일차함수에서는 절편과 기울기를 조절합니다.
4. **좌표 탐색**으로 곡선 위의 값을 확인합니다. 빈 공간 드래그는 화면 이동, 휠이나 두 손가락은 확대·축소입니다.
5. **수업 보관함**에 이름을 붙여 저장하거나 수업 파일을 내보냅니다.

수업 모드는 입력 도구를 접고 수식과 계수를 크게 표시합니다. 실행 취소/다시 실행 버튼과 Ctrl+Z, Ctrl+Shift+Z를 지원합니다. 입력칸 안에서는 브라우저의 기본 텍스트 실행 취소를 사용합니다. 키보드로 그래프에 초점을 맞추면 방향키, +/-와 Home을 사용할 수 있습니다.

## 저장과 출력

- 현재 수식, 각 함수의 계수, 화면 범위, 비교 모양, 선택 좌표와 표시 설정을 브라우저에 자동 저장합니다.
- 이름 붙인 수업은 최대 40개, 현재 함수와 비교 모양은 각각 최대 8개입니다.
- 보관함은 이 브라우저에만 저장됩니다. 다른 기기에서는 `.graph.json` 파일로 옮깁니다.
- 저장이 제한되거나 공간이 부족하면 화면에 실패 상태를 표시합니다. 파일 내보내기는 계속 사용할 수 있습니다.
- PNG에는 현재 범위의 그래프·선택 좌표와 수식·계수를 함께 담습니다.
- 인쇄는 설명용 그래프와 학생용 빈 좌표평면을 지원합니다. 수식이 많거나 길면 페이지가 늘어날 수 있습니다.

## 그래프 분석

- **교점:** 선택한 함수와 다른 표시된 함수의 교점을 현재 x 범위 안에서 수치적으로 찾습니다. 부호가 바뀌는 교점과 접하는 교점을 탐색하고, 최대 64개까지 근삿값으로 표시합니다. 겹치는 구간은 별도 안내합니다. 유한한 표본 탐색이므로 모든 교점을 찾는다는 보장은 없습니다.
- **접선:** 접점의 x를 입력하거나 주황색 점을 끌어 움직입니다. 양쪽 변화율이 안정적으로 일치하는지 확인하고, 모서리·정의역 경계·불연속점에서는 접선을 표시하지 않습니다.
- **정적분·넓이:** 시작·끝 입력 또는 경계점 드래그로 구간을 변경합니다. x축 아래 부분은 주황색으로 구분하며, 부호 있는 정적분과 절댓값을 적분한 넓이를 따로 표시합니다. 구간을 뒤집으면 정적분의 부호만 바뀝니다.
- 특이점이나 수렴 확인 실패가 있으면 값을 표시하지 않습니다. 이상적분은 지원하지 않습니다. 계산 횟수와 탐색 깊이를 제한해 복잡한 식에서도 화면이 장시간 멈추지 않게 했습니다.
- 분석 표시와 요약은 PNG·설명용 인쇄에도 포함됩니다. 이전 버전의 수업 파일은 분석을 끈 상태로 호환됩니다.

## 코드 구성

- `graph-core.js`: 허용된 수학 연산만 해석하는 파서, 수식 조판, 좌표 변환, 적응형 곡선 표본 추출, 저장 자료 검증. 동적 JavaScript 실행을 사용하지 않습니다.
- `graph-analysis.js`: 교점 탐색, 양쪽 변화율 검증, 적응형 적분과 별도 구적법을 이용한 수렴 확인.
- `app.js`: 화면 상태, 독립적인 함수 계수, 마우스·터치 조작, 기록, 저장·복원과 출력.
- `index.html`, `styles.css`: 반응형 칠판과 수업/인쇄 화면.
- `vendor/`: 기존 로컬 KaTeX. 수학 본문 글꼴도 저장소의 로컬 파일을 사용합니다.
- `math-format.js`: 이전 버전의 독립 유틸리티이며 새 칠판에서는 로드하지 않습니다.

직접 조절점은 함수 목록의 일차함수 `ax+b`와 이차함수 `a(x-h)^2+k`에 제공됩니다. 다른 식은 수식 입력 또는 식에 포함된 a, b, c, h, k로 조절합니다. 삼각함수는 라디안입니다. 분석 버튼에서 교점, 움직이는 접선, 구간을 조절하는 정적분·넓이를 사용할 수 있습니다. 분석 설정도 수업에 함께 저장됩니다.

## 검증

저장소 루트에서 실행합니다.

```sh
npm run test:graph-board
npm run test:graph-board:ui
```

UI 검증은 `game-hub-server`의 기존 Playwright를 사용합니다. Windows에서는 설치된 Edge를 사용하고, 다른 환경은 Playwright Chromium을 사용합니다. `PLAYWRIGHT_CHANNEL`로 설치된 브라우저 채널을 지정할 수 있습니다. 테스트용 서버와 브라우저는 검증 후 종료합니다.

브라우저 검증에는 조절점 이동, 함수별 계수 독립성, 잘못된 수식의 격리, 화면 이동·확대·좌표 탐색, 새로고침 복원, 보관함, 수업 파일 왕복, PNG, 인쇄, 모바일 두 손가락 조작과 저장 실패, 교점·접선·적분 조작과 출력이 포함됩니다. 화면 및 출력 검수 자료는 Git에서 제외된 `outputs/graph-board/`에 생성됩니다.
