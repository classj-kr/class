# 학습 자기점검

답과 자신감을 함께 표시한 뒤, 이번 풀이에서 다시 볼 문제를 찾는 학습 활동이다.
학생의 능력·성향·상담 우선순위를 판정하지 않는다. 기존 URL과 저장 API는 유지한다.

## 화면 흐름

- 첫 화면에서 초3~중3 학년을 먼저 선택한다(각 16문항, 약 10분).
- 공통 문제(초5~중1 대상, 24문항)는 접힌 별도 선택지로 제공한다.
- 답 선택 단계에 ‘모르겠어요’를 별도로 둔다. 이를 고르면 자신감을 묻지 않고 다음 문제로 갈 수 있다.
- 실제 답을 고른 문제에서만 자신감 25·50·75·100%를 표시한다. 답을 바꾸면 자신감도 다시 고른다.
- 진행 중 정답은 보여 주지 않는다. 같은 기기에서 문제·선택지 순서와 응답을 복원한다.
- 결과는 전체 중 맞힌 비율, 고른 답이 틀린 문제 수, 모른다고 표시한 문제 수, 자신 있었던 오답 수를 보여 준다.
- ‘모르겠어요’는 오답과 구분한다. 자신감 평균·비교 그래프·bias·ECE·Brier에서는 제외한다. 모든 문항에 ‘모르겠어요’를 표시했으면 자신감 통계는 null로 남긴다.
- 모든 문항을 맞히거나 틀리면 그 사실을 안내한다. 비교할 정답/오답 묶음이 없으면 그래프에 문항 없음을 표시한다.
- 복습 화면은 실제 풀이 순서대로 문제, 내 답, 정답, 해설을 보여 준다. 오답, 자신 없었던 정답, ‘모르겠어요’를 따로 볼 수 있다.
- 후속 활동은 답의 근거 설명과 처음 보는 유사 문제 풀이이다. 같은 문항 재풀이 성적을 향상 근거로 삼지 않는다.

## 결과 해석

6개 유형 분류, 고정 기준에 따른 능력 판정, 위험도 색상, 시간에 따른 성향 추론,
자신감 횟수 제한과 유형별 2주 처방을 제거했다.
찍어서 맞힌 경우도 있으므로 낮은 자신감의 정답을 숨은 실력으로 단정하지 않는다.

원자료 호환을 위해 metrics.js의 정답률·평균 자신감·bias·discrimination·ECE·Brier 계산은 유지한다.
이 수치는 이번 문항의 기술 통계이며, 학년/학생 간 표준화된 능력 점수가 아니다.
accuracy는 모름을 포함한 전체 중 정답 비율이다. answeredAccuracy와 자신감 관련 통계는 실제 선택지를 고른 문항만 사용한다.
문항별 실제 난도와 이 통계의 해석 기준은 검증된 것으로 간주하지 않는다.

DB의 profile_key와 API의 profileKey는 이전 스키마 호환을 위해 남겨 두고,
신규 결과에는 모두 reflection-v1(리포트 형식)을 기록한다. 학생 분류값이 아니다.
교사 요약은 학번순이다. 과거 유형은 현재 학생 유형으로 노출하지 않고 legacy로 구분한다.
기존 원자료 CSV의 과거 기록은 보존한다.
응답 choice=-1, confidence=null은 명시적인 ‘모르겠어요’이다. choice=null인 미응답과 구분한다.
005-metacognition-unknown 마이그레이션은 unknown_count를 추가하고, 계산할 자신감 자료가 없을 때 null을 저장할 수 있게 한다.
CSV에는 unknown_count와 response_status를 덧붙이며 ‘모르겠어요’의 correct 칸은 비워 둔다.

## 파일

- index.html, grade3.html~grade9.html: 진입·풀이·복습 화면
- items.js, items-grade3.js~items-grade9.js: 문제, 선택지, 정답, 해설, 자신감 척도
- metrics.js: 응답 계산과 사실에 근거한 복습 안내(Node/브라우저 공용)
- app.js, styles.css: 문항 섞기, 이어 풀기, 복습 필터, 그래프, 결과 저장·내려받기
- game-hub-server/metacognition.js(저장소 루트 기준): 서버 채점·저장·조회

## 버전과 채점 호환

2026-09-30 수정본은 공통 metacog-v3, 학년별 metacog-g3-v2~metacog-g9-v2를 사용한다.
해설·표현·리포트 변경을 구분하기 위해 버전을 올렸다. 이전 진행 기록을 새 문항으로 이어 붙이지 않는다.
정답 인덱스, 문항 ID, kind, lure는 바뀌지 않아 서버는 기존 버전도 동일한 정답 키로 받는다.
향후 정답 인덱스나 문항 구성이 바뀌면 이전 버전용 채점 세트를 별도로 보존해야 한다.

학년별 문제는 이전 학년까지의 학습 내용을 바탕으로 작성했다.
kind/lure는 기존 원자료의 문항 태그이며, 학생의 사고 습관을 판정하는 근거로 쓰지 않는다.
문항 변경 시 정답 위치 분포와 선택지 길이 검사도 다시 실행한다.

## 검증

저장소 루트에서 실행한다.

```sh
node tests/metacognition-check.cjs
node tests/metacognition-browser.cjs
```

첫 명령은 결과 시나리오, 모든 학년 문항, 서버 계약, 기존 정답 키 호환성, 로컬 PostgreSQL의 마이그레이션과 저장을 검사한다.
두 번째는 로컬 서버와 브라우저로 모든 학년 풀이, 만점/전부 오답/찍기/전부 모름/일부 모름,
답 변경, 이어 풀기, 복습 필터, 모바일 가로 넘침, HTML·JSON 내려받기와 인쇄 가독성을 검사한다.
Windows는 설치된 Edge를 사용한다. 브라우저 검사 결과물은 output/metacognition-review-20260930에 저장한다.
기존 verify-shuffle.js와 verify-export.js 진입점도 같은 브라우저 검사를 호출한다.

## 저장과 내려받기

비로그인·오프라인에서는 기기에 결과를 저장하고 파일을 받을 수 있다.
로그인한 학생은 서버에 응답을 보내며, 서버가 요약 수치를 다시 계산한다.
HTML 파일에는 화면의 결과와 모든 문제·해설, JSON 원자료가 들어간다.
화면에서 필터를 적용하거나 접어 두었더라도 내려받는 파일에는 모든 문항을 펼쳐 담는다.

- POST /api/metacognition/attempts: 학생 결과 제출
- GET /api/metacognition/attempts/mine: 본인 기록
- GET /api/metacognition/teacher/class-summary: 교사 학급 요약
- GET /api/metacognition/teacher/export.csv: 이름·학번을 제외한 원자료

## 추가로 필요한 검토

실제 학생이 문항과 자신감 표현을 어떻게 이해하는지 관찰하고 문항을 검수한다.
학생/학부모에게 제공하는 안내에서도 이번 풀이와 학습 능력 전체를 구분한다.
교사 대시보드와 새 문항을 사용한 후속 활동 기록 화면은 별도 작업으로 남아 있다.
