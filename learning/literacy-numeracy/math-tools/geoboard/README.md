# 지오보드

문해·수리 → 수리 → 수학 교구 → 지오보드. 새 URL은 `/learning/literacy-numeracy/math-tools/geoboard/`.

SVG 핀판에 고무줄을 추가하거나 핀을 연결한다. 꼭짓점 이동, 변에 꼭짓점 추가, 도형 이동, 색과 채우기, 격자·넓이·둘레 표시, 되돌리기/다시 하기를 지원한다. 5×5와 9×9의 작업은 따로 유지한다. 고무줄 개수는 판마다 24개까지다.

넓이는 단순 다각형의 신발끈 공식, 둘레는 유클리드 거리의 합이다. 교차·중복 변은 확정하지 않으며 오목 다각형은 허용한다. 선분은 길이만 표시한다. 무리수 길이는 소수 둘째 자리까지 반올림하고 `≈`를 붙인다. 한 칸의 변 길이가 단위 1이다.

`SiteStorage.open('geoboard')`의 `board` 항목에 두 판과 표시 설정을 자동 저장한다. 게스트는 탭 메모리만 사용한다. 배경음악 없이 사이트 공통 음량 설정과 효과음을 사용한다.

검증: `node --test tests/geoboard.test.cjs tests/geoboard-browser.cjs`. 화면 검증 산출물은 `outputs/geoboard/*.webp`(무손실).
