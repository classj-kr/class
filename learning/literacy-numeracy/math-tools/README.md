# 수학 교구

초등학교 수학 수업의 조작 활동을 기준으로 구성한다. 모든 교구는 문해·수리 → 수리 → 수학 교구에서 연다. 제목·진행 안내 띠를 반복하지 않고, 조작 방법은 사이트 공통 설정 안에 둔다. 계정 저장, 공개 설정, 뒤로 가기, 음량 UI를 공통으로 사용한다.

## 기준 자료

- 교육부 고시 제2022-33호 별책 8 수학과 교육과정: [교육부 원문](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0). 저장소 원문 텍스트는 `references/moe/2022-revised-curriculum/extracted/08-mathematics.txt`.
- 미래엔 공개 수학 5-1 교과서: [전자책](https://download.mirae-n.com/elemteacher/ele_math_5-1/index.html).
- 미래엔 공개 수학 6-1 교과서: [각기둥의 구성 요소](https://download.mirae-n.com/elemteacher/ele_math_6-1/files/basic-html/page40.html). 공개 전자책은 2022년 검정본이므로 개정 교육과정과 구별해 참고한다.

## 수업 범위

| 교구 | 핵심 활동 |
| --- | --- |
| 자연수·소수 모형 | 자릿값, 묶기와 풀기 |
| 분수 모형 | 등분, 분수의 양과 크기 비교 |
| 수직선 | 자연수·분수·소수의 위치와 이동 |
| 네이피어 계산봉 | 배수·공배수·최소공배수 비교(커스텀 다자리 수 지원), 대각선 격자 곱셈 |
| 모형 시계 | 시각, 바늘 연동, 시간의 경과 |
| 자·각도기 | 가상 눈금으로 길이와 각도 재기 |
| 패턴블록·칠교 | 모양 만들기, 이동·뒤집기·회전, 대칭 |
| 지오보드 | 도형 구성, 넓이와 둘레 비교 |
| 넓이 변형 | 다각형·원의 넓이를 보존하는 조작 |
| 입체도형·전개도 | 구성 요소, 직육면체·각기둥·원기둥 전개 |
| 쌓기나무 | 공간 감각, 위·앞·옆 모습 |
| 저울·들이 | 무게 비교, 단위 관계, 들이의 합과 차 |
| 자료·그래프 | 표, 막대·꺾은선·띠·원그래프, 평균 |
| 가능성 실험 | 동전·주사위·회전판의 실험과 도수 |
| 그래프 그리기 | 함수와 좌표, 중등 이후 확장 |

각뿔·원뿔의 전개도는 2022 개정 초등 교육과정에서 제외하므로 입체 관찰만 제공한다. 화면의 자와 용기는 실제 물체의 길이나 들이를 재는 도구가 아니라 가상 단위 모형이다. 실험 도수와 이론적 가능성을 구분한다.

`assets/math.js`는 순수 계산, `assets/ui.js`는 계정 저장·되돌리기·터치·동작 연출, `assets/ui.css`는 교구 화면의 공통 스타일을 담당한다. 기존 교구는 기존 기능을 유지한다.

공통 자원은 `assets/`에 둬서 교구 하나만 공개한 학급에서도 같은 교구 묶음의 자원으로 허용된다. 수식 글꼴 STIX Two Math는 함께 둔 SIL OFL 조건으로 사용한다.

## 검증

- `npm run test:math-tools`: 수치·기하, 저장 자료 검증, 메뉴 연결.
- `npm run test:math-tools:ui`: 실제 드래그·접기·단위 변환·실험, 계정 복원, 모바일 터치, 교사의 공개/잠금.
- 검증 캡처는 `outputs/math-tools/`에 무손실 WebP로 저장한다.
