# 기출 자료 만드는 차례

평가원 문제지에서 공통 과목 문항을 뽑아 `../data/problems.js`에 채우는 데 쓰는 도구다.
문제지 PDF는 저장소에 넣지 않는다. 필요할 때 아래 차례로 다시 받는다.

## 1. 회차 목록 모으기

```
python list-papers.py
```

평가원 수능 게시판(boardID=1500234)과 모의평가 게시판(boardID=1500236)을 훑어
`board-rows.json`을 만든다. 회차마다 문제지와 정답표의 내려받기 번호가 들어 있다.

## 2. 문제지 받기

```
python fetch-papers.py
```

2022~2027학년도 수학 문제지와 정답표를 `papers/`에 받는다. 홀수형만 받는다.
2022학년도 수능처럼 이름만 `.pdf`이고 속은 압축 파일인 것이 있어, 받은 뒤
`PK\x03\x04`로 시작하면 풀어서 홀수형만 남겨야 한다.

## 3. 배점으로 후보 추리기

```
python find-top-score.py
```

쪽 머리글에 선택 과목 이름이 나오는 곳 앞까지를 공통 과목으로 보고(회차마다 8쪽),
문항 번호와 `[N점]` 표시를 읽어 `four-point-index.json`을 만든다.

배점은 후보를 추리는 그물일 뿐이다. 무엇을 실제로 실을지는 유형을 보고 사람이 고른다.

쪽을 자를 때 주의할 것: 공통 마지막 쪽 아래에 "이어서 선택과목(확률과 통계)" 안내문이
있어서, 쪽 전체에서 과목 이름을 찾으면 그 쪽이 통째로 잘려 21·22번이 빠진다.
그래서 머리글(맨 앞 90자)만 본다.

## 4. 정답표 읽기

```
python read-answers.py
```

정답표에서 공통 1~22번의 정답과 배점을 읽어 `answers.json`을 만들고,
문제지에서 읽은 배점과 맞대어 어긋난 곳을 알려 준다. 두 자료가 서로 검사가 된다.

2025학년도 수능 정답표는 글자가 없는 그림 파일이라 기계로 못 읽는다. 눈으로 읽어 넣는다.

## 5. 문항 옮기기

수식이 한글 수식 편집기 글꼴(HyhwpEQ)로 들어 있어 글자만 뽑으면 개인용 글자 영역
문자로 깨진다. 쪽을 그림으로 만들어 눈으로 읽고 옮겨야 한다.

```
python -c "import pymupdf; d=pymupdf.open('papers/2026-suneung-paper.pdf'); d[4].get_pixmap(dpi=150).save('p05.png')"
```

옮길 때 지킬 것

- 부등호 `<`는 `&lt;`로, 수식 안의 `&`는 `&amp;`로 쓴다. 그대로 두면 브라우저가
  태그로 읽어 문제 본문이 중간에 잘린다.
- 그림은 문제지에 그림 파일로 박혀 있다. `page.get_image_info()`로 자리를 찾아
  오려 내고 webp로 바꾼다. 모든 쪽에 있는 116×28 크기 그림은 "수학 영역" 머리글이니 거른다.
- 옮긴 뒤에는 반드시 원본 문제지와 다시 대조한다. 숫자 하나가 틀리면 답이 없는 문제가 된다.

## 6. 수식 검사

```
node check-math.mjs
```

모든 문항을 화면과 같은 차례(HTML로 읽고 → auto-render로 가르고 → KaTeX로 파싱)로 읽어
깨지는 곳을 찾는다. 문항을 더하거나 고친 뒤에는 이것이 0개를 낼 때까지 고친다.

- 그대로 쓴 `<`. `0<a<b`의 `<a`는 태그로 읽혀 그 뒤 문장이 통째로 사라진다.
- KaTeX가 파싱하지 못하는 수식. `\left(`만 있고 `\right)`가 없는 것, `\\)`처럼 백슬래시가 둘인 것 등.
- 닫는 기호를 잃어 수식 밖에 그대로 드러난 `\(`, `\dfrac`, `^{` 같은 TeX.
- 보기 개수와 답의 범위, 없는 그림 파일.

KaTeX는 같은 저장소의 `learning/literacy-numeracy/arithmetics/node_modules`에서 빌려 쓴다.
