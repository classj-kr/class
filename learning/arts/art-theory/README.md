# 색·조형 이론: 보고 바꾸고 표현하기

초등 미술 교과서의 관련 단원을 읽고, 기초 개념을 직접 써 보는 세 가지 활동과 오방색 감상으로 구성했습니다. 진입점은 `index.html`입니다. 2026-10-11 사용자 요청으로 공개 중단했습니다. 포털 메뉴에서 제거하고, 통합 서버의 `unpublished-lessons.js`에서 이 폴더 전체의 요청을 404로 응답합니다. 현재 소스는 공개 수업으로 사용하지 않습니다.

## 핵심 체험

| 체험 | 학습자가 하는 일 | 눈으로 확인할 관계 |
| --- | --- | --- |
| 색으로 숨바꼭질 | 10색상환으로 나비와 잎을 칠하고 나비를 옮기기 | 같은 색·이웃한 색·반대편 색, 배경에 따른 구별 |
| 선과 무늬 | 왼쪽 날개에 선을 그리거나 예시 무늬의 간격·색·굵기 바꾸기 | 선의 모양, 반복, 거울 대칭 |
| 그림의 주인공 | 다섯 꽃 중 하나를 골라 색·크기·여백을 바꾸고 모두 같을 때와 비교 | 주변과의 차이로 한 부분 강조하기 |
| 오방색과 사신 | 실제 의궤의 사신 그림을 확대하고 두 시기의 형태 비교 | 색·방위·오행 및 전통 그림의 특징 |

- 예상 답안, 필수 기록, 점수 판정 없이 조작부터 시작합니다. 느낌을 정답으로 채점하지 않습니다.
- 강조 예시는 색·크기·여백 중 하나만 바꿉니다. 직접 조절하면 여러 방법을 함께 쓸 수 있습니다. 비교 버튼을 눌러도 내 설정은 보존됩니다.
- 나비를 마우스·터치·방향키로 옮깁니다. 무늬는 마우스·터치로 직접 그리며, 키보드로도 예시 무늬·간격·굵기·색·대칭을 조절할 수 있습니다.
- 날개 밖의 선은 잘라서 표시합니다. 한 번 그은 선과 슬라이더 조작은 한 번에 되돌립니다. 무늬 비우기도 되돌릴 수 있습니다. 자유 선 200개, 선당 1,500개 좌표, 되돌리기 40단계로 제한합니다.
- 대칭을 끄면 오른쪽에 복제한 무늬를 숨겨 비교하고, 다시 켜면 왼쪽 전체를 거울처럼 복제합니다.
- 만든 나비는 가이드가 빠진 독립 SVG로 내려받습니다. 작품과 조작 상태는 페이지 실행 중 유지되며 새로고침 후 자동 복원하지 않습니다.
- 모바일에서는 조절하는 동안 그림이 화면 위에 남습니다. 화면 높이가 550px보다 작으면 일반 스크롤로 표시합니다.

색상환의 순서는 빨강·주황·노랑·연두·초록·청록·파랑·남색·보라·자주입니다. 표시색은 화면용 예시이고 물감 혼합, 정밀한 먼셀 색표나 측색 표준이 아닙니다. 나비 숨기기는 배경과의 구별을 관찰하는 그림 활동이며 생물의 보호색을 정량적으로 예측하는 모형은 아닙니다.

화면 탐색 이후 종이 접기, 색종이 무늬, 색연필·물감 표현으로 이어 갈 수 있습니다. 화면 체험이 재료를 직접 다루는 활동을 대신하지는 않습니다.

## 연결과 정리

- `color-mixing/` → `../#color`, `visual-elements/` → `../#pattern`, `design-principles/` → `../#emphasis`. 기존 주소를 열면 새 체험으로 연결됩니다.
- 예상·기록 중심의 색 혼합 화면과 자유 도형 작업실의 전용 앱·모델·스타일·검사는 제거했습니다. 공용 비교 스타일은 `comparison.css`로 옮겼습니다.
- 색의 밝기·선명함 비교(`color-properties/`)는 색 체험 아래 선택 활동으로 연결합니다. 기존 배색 비교(`color-harmony/`)의 독립 주소는 유지하되 핵심 메뉴에 늘어놓지 않습니다. 두 화면의 메뉴도 핵심 체험으로 돌아옵니다.
- 오방색 자료의 상세 출처·이용 조건은 [오방색 문서](obangsaek/README.md)를 참고합니다.

## 화면·파일 원칙

본문·조작 16px, 소제목 18px, 제목 22px. 출처와 교사 설명은 접힌 영역에 둡니다. 새 체험의 그림은 직접 작성한 SVG이며 원본 교과서의 그림을 가져오지 않았습니다. SVG는 코드 형식을 유지하고, 래스터 검증 캡처는 메모리에서 무손실 WebP로 변환한 뒤 크기·알파·디코딩 픽셀 일치를 검사합니다.

```powershell
node --test tests/art-experience-model.test.cjs tests/color-properties-model.test.cjs tests/color-harmony-model.test.cjs
$env:ART_EXPERIENCE_SCREENSHOTS='outputs/art-experience-20261011'
node tests/art-experience-browser-smoke.cjs
node tests/color-properties-browser-smoke.cjs
node tests/color-harmony-browser-smoke.cjs
node tests/obangsaek-browser-smoke.cjs
```

새 브라우저 검사는 1440·768·390·320px에서 실제 마우스/터치 그리기, 키보드 이동, 같은 색 비교, 대칭, 되돌리기, 반복 간격, 강조 전후 비교, SVG 다운로드 내용, 모바일 고정 그림, 옛 주소 연결을 확인합니다. Chrome 또는 Edge와 Pillow가 있는 Python을 사용합니다. `CHROME_PATH`, `PYTHON`으로 실행 파일을 지정할 수 있습니다. 검증 결과와 화면은 `outputs/art-experience-20261011/`에 둡니다.
