🔑 구글 API 키 설정 (최초 1회)

키는 이 컴퓨터의 브라우저에만 저장됩니다. 학교와 집에서 각각 한 번씩 넣으셔야 하고, 공용 컴퓨터에서 쓰셨다면 칸을 비우고 저장을 눌러 지워 주세요. 구글로는 활동 내용과 인원수만 가니 활동 칸에 학생 이름은 적지 마세요.

  1. aistudio.google.com/app/apikey에 구글 계정으로 로그인합니다. 학교 계정은 막혀 있을 수 있으니 개인 계정이 편합니다.
  2. API 키 만들기를 누릅니다. 결제 정보는 넣지 마세요.
  3. 만들어진 긴 글자(AQ.로 시작)를 복사해 아래 칸에 붙여 넣고 저장합니다.
