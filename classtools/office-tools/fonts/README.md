# Stamp fonts

Unmodified official TTF files from https://event.chosun.com/100/100font.html.
Usage and redistribution terms are recorded in CHOSUN-LICENSE.txt.

- ChosunGs.TTF — 조선궁서체
- ChosunKm.TTF — 조선굵은명조
- ChosunSm.TTF — 조선신명조

All stamp presets use these original font files. No procedural seal lettering is used.
