# 웹스토어 등록 메모

zip: `node classtools/neis-fill/pack.mjs` → 내려받기 폴더. page.js 를 고쳤으면 그 안 VERSION 과 manifest version 을 같이 올린다.

## 스토어 등록정보

설명 칸:

```
ClassJ(classj.kr) 생활기록부 도우미에서 만든 학생별 문장을 NEIS 화면의 학생 칸에 이름을 대조해 한 번에 넣어 주는 교사용 도구입니다.

1. 생활기록부 도우미에서 문장을 만들고 「전체 복사」를 누릅니다.
2. NEIS에서 넣을 화면을 열고 「조회」를 누릅니다.
3. 확장을 열어 붙여넣고 「화면 살펴보기」로 이름이 맞는지 봅니다.
4. 「채우기」를 누르면 이름과 번호를 대조해 각 칸에 넣습니다.
5. 화면을 훑어본 뒤 NEIS의 저장 단추를 직접 누릅니다.

- 순서가 아니라 이름과 번호로 대조하므로 전입생·결번이 있어도 밀리지 않습니다.
- 같은 이름이 둘인데 번호를 못 읽으면 넣지 않고 알립니다.
- 글의 학기·과목과 화면의 학기·과목이 다르면 넣지 않습니다.
- 「되돌리기」로 직전 값으로 돌릴 수 있고, 저장은 대신 누르지 않습니다.
- 붙여넣은 글은 브라우저 안에만 머물고 어디로도 보내지 않습니다.

교육부·NEIS의 공식 프로그램이 아닙니다.
```

- 카테고리 교육 · 언어 한국어 · 아이콘 icon128.png · 스크린샷 neis-shot-1.jpg
- 홈페이지 `https://classj.kr/classtools/neis-fill/` · 지원 `https://classj.kr/support`

## 개인정보 보호 관행

- 단일 목적: `ClassJ 생활기록부 도우미의 학생별 문장을 NEIS 학생 칸에 넣는 것 한 가지입니다.`
- activeTab: `확장 단추를 누른 NEIS 탭에만 접근합니다.`
- scripting: `NEIS 화면에서 학생 줄을 찾아 글 칸에 값을 넣습니다. 단추를 누를 때만 실행됩니다.`
- storage: `붙여넣은 글을 팝업이 닫혀도 유지합니다. 브라우저를 닫으면 지워집니다.`
- 호스트 권한: `NEIS 화면에 값을 넣기 위해 neis.go.kr 에서만 동작합니다.`
- 원격 코드 아니요 · 데이터 수집 모두 아니요 · 인증 세 개 체크
- 처리방침 `https://classj.kr/privacy#extension`
