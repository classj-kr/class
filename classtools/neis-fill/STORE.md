# 크롬 웹스토어 등록 메모

개발자 화면(https://chrome.google.com/webstore/devconsole)에 붙여넣을 글과 고를 값입니다. zip 은 `node classtools/neis-fill/pack.mjs` 로 만들며 내려받기 폴더에 `neis-paste-classj-<판>.zip` 으로 나옵니다.

## 계정

- 구글 계정에 2단계 인증을 켭니다(스토어가 요구).
- 개발자 등록비는 한 번만 냅니다. 해외 결제 카드가 필요합니다.
- 계정 설정의 「거래자/비거래자」 물음은 개인이 무료로 배포하니 「비거래자(Non-trader)」를 고릅니다.

## 항목 올리기 → 스토어 등록정보

- 이름: 스토어는 zip 안 manifest 의 name 을 씁니다. `NEIS 붙여넣기 - ClassJ`
- 요약(manifest description, 132자 이내): `생활기록부 도우미가 만든 학생별 문장을 나이스 학기말종합의견 화면에 이름을 대조해 한 번에 채웁니다. 저장은 나이스에서 직접 누릅니다.`
- 자세한 설명:

```
클래스제이(classj.kr) 생활기록부 도우미에서 만든 학생별 학기말 종합의견을 4세대 나이스(NEIS) 학기말종합의견 화면에 한 번에 넣어 주는 교사용 도구입니다.

쓰는 차례
1. 생활기록부 도우미에서 문장을 만들고 「전체 복사」를 누릅니다.
2. 나이스 학기말종합의견 화면에서 학년·반·교과를 고르고 「조회」를 누릅니다.
3. 이 확장을 열어 복사한 글을 붙여넣고 「화면 살펴보기」로 이름이 맞는지 확인합니다.
4. 「채우기」를 누르면 학생 이름과 번호를 대조해 각 칸에 넣습니다.
5. 화면을 훑어본 뒤 나이스의 저장 단추를 직접 누릅니다.

안전장치
- 학생 순서가 아니라 이름과 번호로 대조하므로 전입생·결번이 있어도 밀리지 않습니다.
- 같은 이름이 두 줄인데 번호를 못 읽으면 그 학생은 넣지 않고 알립니다.
- 복사한 글의 학기·과목과 나이스 화면의 학기·과목이 다르면 넣지 않습니다.
- 채우기는 두 번 눌러야 실행되고, 「되돌리기」로 직전 값으로 돌릴 수 있습니다.
- 저장은 절대 대신 누르지 않습니다.

개인정보
- 붙여넣은 학생 이름과 문장은 이 브라우저 안에만 머물고, 브라우저를 닫으면 지워집니다. 「지우기」로 바로 지울 수도 있습니다.
- 어떤 서버로도 보내지 않으며, 통계나 광고 도구를 쓰지 않습니다.
- 나이스(neis.go.kr) 화면에는 교사가 확장 단추를 눌렀을 때만 접근합니다.

이 확장은 교육부·나이스의 공식 프로그램이 아닙니다. 나이스 화면이 바뀌면 동작이 멈출 수 있으며, 그때는 아무것도 넣지 않고 알립니다.
```

- 카테고리: 생산성(Productivity) → 도구
- 언어: 한국어
- 스토어 아이콘: 폴더의 icon128.png
- 스크린샷: 1280×800 (또는 640×400) PNG 1~5장. 팝업을 연 나이스 화면이 가장 좋지만 학생 이름이 보이면 안 되므로, 모의 화면(mock.html?cpr=1)에서 찍은 것을 씁니다.
- 공식 URL/홈페이지: `https://classj.kr/classtools/neis-fill/`
- 지원 URL: `https://classj.kr/support`

## 개인정보 보호 관행 탭

- 단일 목적 설명: `교사가 클래스제이에서 만든 학생별 학기말 종합의견 문장을 나이스 학기말종합의견 화면의 학생 칸에 이름을 대조해 넣어 주는 것 한 가지입니다.`
- 권한 사유
  - activeTab: `교사가 확장 단추를 누른 그 탭(나이스 화면)에만 접근해 학생 칸을 찾고 값을 넣습니다.`
  - scripting: `나이스 화면 안에서 학생 이름·번호가 적힌 줄을 찾아 글 칸에 값을 넣는 스크립트를 실행합니다. 교사가 단추를 누를 때만 실행됩니다.`
  - storage: `교사가 붙여넣은 학생 문장을 팝업이 닫혀도 유지하려고 브라우저 세션 저장소에 둡니다. 브라우저를 닫으면 지워지며 「지우기」 단추로도 지웁니다.`
  - 호스트 권한 https://*.neis.go.kr/*: `나이스 학기말종합의견 화면에 값을 넣기 위해 나이스 도메인에서만 동작합니다. 다른 사이트에는 접근하지 않습니다.`
- 원격 코드 사용: 아니요.
- 데이터 사용: 수집 항목은 모두 「아니요」. 학생 이름·문장은 브라우저 안에서만 처리되고 개발자에게 전송되지 않습니다.
- 인증 세 가지 모두 체크: 승인된 용도 외 판매하지 않음, 단일 목적과 무관한 용도로 쓰지 않음, 신용도 판단·대출 목적으로 쓰지 않음.
- 개인정보 처리방침 URL: `https://classj.kr/privacy#extension`

## 배포

- 공개 범위: 미등록(Unlisted). 검색에 안 뜨고 링크로만 설치됩니다. 널리 알리려면 나중에 공개(Public)로 바꾸면 됩니다.
- 심사: 보통 며칠, 길면 몇 주. 3주가 넘으면 지원에 문의합니다.
- 통과하면: 스토어 주소(`https://chromewebstore.google.com/detail/<고유번호>`)를 `classtools/neis-fill/index.html` 의 설치 단추와 README 에 넣습니다.

## 새 판 올리기

1. page.js 를 고쳤으면 그 안의 VERSION 과 manifest.json 의 version 을 같이 올립니다. manifest 만 고쳤으면 version 만 올립니다.
2. `node classtools/neis-fill/pack.mjs` 로 zip 을 만듭니다.
3. 개발자 화면 → 해당 항목 → 패키지 → 새 패키지 업로드 → 제출. 심사 뒤 설치한 사람들에게 자동으로 갱신됩니다.
