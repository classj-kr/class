# 클래스제이 나이스 채우기 (크롬 확장)

생활기록부 도우미(`classtools/record-ai.html`)가 만든 학생별 문장을 나이스 학기말종합의견 화면에 **이름을 대조해** 한 번에 넣습니다. 저장은 하지 않으며, 나이스의 저장 단추는 교사가 직접 누릅니다.

## 설치 (압축 해제 방식)

1. 크롬(또는 엣지·웨일)에서 `chrome://extensions` 를 엽니다.
2. 오른쪽 위 「개발자 모드」를 켭니다.
3. 「압축해제된 확장 프로그램을 로드합니다」를 누르고 이 폴더(`classtools/neis-fill`)를 고릅니다.
4. 주소창 옆 퍼즐 단추에서 「나이스 채우기」를 고정해 두면 편합니다.

## 쓰는 차례

1. 생활기록부 도우미에서 문장을 만들고 「전체 복사」를 누릅니다.
2. 나이스 학기말종합의견 화면에서 학년·반·교과를 고르고 「조회」를 누릅니다.
3. 확장 단추를 누르고 「클립보드에서 가져오기」(또는 직접 붙여넣기)로 학생 목록을 넣습니다.
4. 「화면 살펴보기」로 화면의 이름과 목록이 맞는지 봅니다. 아무것도 바꾸지 않습니다.
5. 「채우기」를 두 번 누릅니다(두 번째는 확인). 덮어쓰기는 칸을 비우고 넣고, 이어쓰기는 있던 글 뒤에 붙입니다.
6. 화면을 훑어본 뒤 나이스에서 저장을 누릅니다.

## 줄을 찾고 값을 넣는 방법

- 화면 글 칸: 화면 구조(클래스 이름)에 기대지 않고, 학생 이름 글자와 글 칸이 같은 줄에 놓여 있는지로 짝을 짓습니다. 번호는 이름 왼쪽에서 가장 가까운 숫자 하나만 봅니다. 이름이 같고 번호가 보이면 번호까지 맞아야 넣고, 번호가 안 보이는데 같은 이름이 둘 이상이면 넣지 않습니다. 동명이인 판단은 붙여넣은 명단 전체로 하므로 「번호」 칸으로 한 명만 넣을 때도 보호가 유지됩니다. 값을 넣은 뒤 blur 를 흘립니다. 나이스 실행기(엑스빌더6)의 글 칸은 input 이 아니라 blur 때 화면 값을 받아들이기 때문입니다.
- 넣기 전 한 바퀴: 먼저 화면을 스크롤하며 훑어 같은 학생이 두 줄에 걸리면 그 학생은 넣지 않고 알립니다. 넣기 직전에 그 줄을 다시 읽어 아직 같은 학생인지 확인합니다.
- 실행기 자료: 나이스 실행기가 `window.cpr` 로 노출돼 있으면 목록(Grid)의 이름 열·번호 열·종합의견 열을 값으로 알아내, 화면으로 넣은 값이 자료에 들어갔는지 확인하고 안 들어갔으면 `setCellValue` 로 다시 넣습니다. 목록이 보이는 줄만 그려서 화면에 없는 학생도 이 길로 넣습니다. 번호 열은 줄마다 값이 다른 열만 후보로 삼습니다(학년·반처럼 늘 같은 값인 열에 속지 않게). 목록 자료에 같은 학생이 두 줄이면 건드리지 않고, 다 넣은 뒤 엉뚱한 줄에 목표 글이 들어 있지 않은지 훑어 알립니다. 실행기 이름은 공개된 것만 쓰고, 없으면 조용히 건너뜁니다.
- 화면 제목: 제목 후보에 「학기말종합의견」이 없으면 넣지 않습니다(아래 탭 줄의 이름표는 제외). 정말 그 화면이면 팝업의 「화면 제목 검사 건너뛰기」를 켭니다.
- 이어쓰기: 이미 같은 글이 들어 있으면 다시 붙이지 않습니다. 두 번 눌러도 두 번 붙지 않습니다.
- 되돌리기: 채우기 직전 값을 화면 쪽에 기억해 두었다가 「되돌리기」로 같은 길로 다시 씁니다. 팝업을 닫았다 열어도 마지막 결과와 되돌리기가 되살아납니다. 저장 전이면 나이스의 조회 단추로도 되돌아갑니다.
- 붙여넣은 글은 브라우저를 닫으면 지워지는 저장소에 두고, 「지우기」로 바로 지울 수 있습니다.

## 시험

`mock.html` 이 모의 나이스 화면입니다. 화면에서 `__classjNeis.run(학생목록, {mode:'inspect'|'overwrite'|'append', roster: 전체명단})` 를 부르면 확장 팝업과 같은 결과를 돌려줍니다. 주소 뒤에 붙이는 조건:

- `?virtual=1` 보이는 줄만 그리는 목록
- `?cpr=1` 실행기 흉내(공개 이름만, 학년·학기처럼 늘 같은 값인 열 포함)
- `?editonly=1` 편집 중인 첫 줄에만 글 칸이 있는 목록(나머지는 실행기로 넣어야 함)
- `?noblur=1` 화면 값을 실행기가 받아들이지 않는 경우(실행기로 다시 넣는지 확인)
- `?dup=1` 번호를 「3번」 꼴로 적어 못 읽게 함(동명이인 김지현 둘을 넣지 않아야 함)
- `?title=교과평가` 화면 제목을 바꿈(넣기가 막혀야 함)

실제 나이스에서 확인 못 한 것: 화면이 목록인지 낱개 글 칸인지, `cpr` 이 노출되는지, 종합의견 칸의 글자 수 한계, 제목 요소의 꼴. 처음 쓸 때 「화면 살펴보기」의 「화면 정보」에 이 답이 나옵니다.
