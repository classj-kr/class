# 학교안심 받아쓰기 Light

KERIS 교육저작권지원센터가 제공하는 실제 교육용 글꼴이다. 자체 제작 시제품은 본보기에서 제외했다.

- 공식 안내: https://copyright.keris.or.kr/wft/fntDwnldView?fntGrpId=GFT202408200000000000004
- 저작권자: KERIS. 제작사: 헤움디자인.
- 라이선스: SIL Open Font License 1.1. `OFL.txt`를 함께 배포한다.
- `HakgyoansimBadasseugi-Light.woff`는 공식 미리보기에서 제공하는 원본 파일을 수정 없이 보관한다. 실행 중 외부 CDN이나 만료 토큰에 의존하지 않는다.
- `reference-manifest.json`은 원본 글꼴의 SHA-256과 글자별 기준 데이터의 크기·범위를 기록한다.

글꼴 윤곽을 바꾸거나 별도 서체를 만들지 않는다. 본보기와 따라쓰기 칸은 이 글꼴을 직접 그린다. 채점은 `scripts/build-handwriting-reference.py`로 이 글꼴에서 만든 32×32 잉크 마스크를 사용한다. 마스크 자료에도 동일한 OFL을 적용한다.
