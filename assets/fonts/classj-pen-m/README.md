# 클래스제이 펜 M

DX경필명조 M의 공개 비교 견본을 참고해 기존 자체 펜글씨의 획 굵기, 곡률, 자모 배치와 연결을 다듬은 별도 서체 시안이다. DX경필명조 정품 파일이나 그 M 웨이트가 아니다. 원본 글꼴의 윤곽을 복사하거나 Bold 파일을 변환한 결과물이 아니다.

- `ClassJPenM-Regular.ttf`: 설치·문서용 글꼴. 내부 패밀리는 `ClassJ Pen M`, 무게 값은 500이다.
- `ClassJPenM-Regular.woff2`: 웹폰트.
- `preview.html`: 글자 크기를 바꾸고 문장을 직접 입력하는 로컬 견본.
- `source.js`: 모든 음절을 구성하는 자모 중심선, 맥락별 보정값과 펜 윤곽 생성기. 획순은 기존 자체 중심선의 순서를 유지한다.
- `font.css`: 웹 적용용 `@font-face` 선언.
- `font-manifest.json`: 소스 해시와 글자 수, 파일 크기.

현대 한글 11,172음절과 호환 자모 51자, 공백을 포함한다. 영문·숫자·문장부호는 지원 범위에 포함하지 않는다. 현재 글씨 쓰기 앱에는 적용하지 않은 독립 작업본이다.

## 제작과 확인

`python scripts/build-pen-m.py`로 전체 TTF·WOFF2를 생성한다. 빌드에는 외부 글꼴이 필요하지 않다. 기존 `scripts/build-handwriting-font.py`의 중심선 내보내기·곡선 생성 함수를 재사용하며 기존 배포 글꼴을 변경하지 않는다. Python의 fonttools, brotli와 Node.js가 필요하다.

`node scripts/check-pen-m.cjs`는 전 음절의 유효한 획 좌표, 디자인 셀 범위, 초성·받침 중심선 간격과 자모 지원을 검사한다. 빌드 과정에서는 두 형식의 글꼴을 다시 열어 cmap, 글리프와 경계를 검사한다.

`scripts/refine-pen-m.py`는 기존 로컬 M 미리보기 부분집합을 비교 이미지로 렌더링하고 자체 중심선에 적용할 공유 보정값을 조정하는 개발용 도구다. 외부 글꼴의 윤곽 데이터는 결과물에 포함하지 않는다. 한글로 매핑됐지만 그림이 비어 있는 견본 글자는 제외한다. 초기 분리 점검 후 최종 시안은 유효한 견본 217자를 모두 참고했다. `--holdout`은 고정된 일부 글자를 수치 보정에서 제외하는 점검 옵션이다.

`python scripts/refine-pen-m.py --review`는 원본 M·기존 자체 서체·새 시안을 같은 크기와 기준선으로 비교한 무손실 WebP와 잉크 마스크의 겹침 수치를 `outputs/handwriting/pen-m/`에 만든다. 이 수치는 해당 견본의 픽셀 겹침이며, 전체 한글의 재현 정확도나 사람의 시각적 평가 점수가 아니다. 드문 음절과 견본 밖 조합에는 기존 자모 설계가 더 많이 반영돼 있다.

## 두 번째 보정 · 1.200

초성·모음·받침에 공유되는 부드러운 변형으로 자폭과 곡률을 조정했다. ㅎ과 ㅕ가 함께 있는 글자의 가로획 높이, ㅍ과 ㅜ의 간격, ㅈ·ㅊ과 ㅛ의 연결, ㄱ·ㅋ과 ㅜ의 접점을 별도 구성 규칙으로 정리했다. 세로획은 가로획보다 조금 더 두껍게 유지하고 끝의 급한 가늘어짐을 줄였다.

`python scripts/polish-pen-m.py --font <현재 비교용 TTF>`는 같은 로컬 M 견본과 현재 시안을 렌더링한 영상에서 작은 변형을 계산하고, 자모 문맥별 3×3 제어 격자에 공유한다. 원본 글리프 윤곽을 옮기는 작업은 아니다. 이 도구는 개발용으로 NumPy, SciPy, scikit-image, Pillow가 추가로 필요하다. 다시 실행하면 `source.js`의 보정값이 갱신되므로 현재 TTF와 현재 소스가 일치할 때 실행해야 한다.

`python scripts/review-pen-m.py`는 이전 시안과 현재 시안의 비교 수치, 확대 점검표와 같은 크기·색상의 비교 견본을 만든다. 현재 기본 비교 대상은 1.2와 1.3이며 출력은 `outputs/handwriting/pen-m/revision-1300/`이다. 비교 입력인 원본 M 부분집합과 이전 버전은 이 배포 폴더에 포함하지 않는다. `--font`, `--before`, `--output`으로 비교 파일과 출력 위치를 지정할 수 있다.

웹에서는 `font.css`를 불러온 뒤 원하는 요소에 `font-family: "ClassJ Pen M", serif; font-weight: 500; font-synthesis: none;`을 지정한다. 영문과 숫자, 문장부호는 다음 글꼴로 표시된다.


## 세 번째 보정 · 1.300

사용자가 지적한 `를·어·푸`를 중심으로 보정했다. ㄹ의 윗부분과 받침을 다시 구성해 세로획이 비스듬하게 꺾이는 현상을 줄이고, 가운데 ㅡ의 높이와 각 가로획의 간격을 조정했다. `늘`과 `름`에서 받침 구조에 따라 높이가 달라지는 것도 반영했다. `어`의 ㅓ 가로획은 오른쪽으로 약간 올라가도록 바로잡았으며 `거`와 나머지 초성 문맥의 높이는 구분했다. `푸`의 짧은 기둥에는 직접 설계한 곡선을 사용하고, ㅜ의 기둥을 세운 뒤 마지막 여섯 단위에서 자연스럽게 가늘어지도록 했다.

해당 ㄹ·ㅍ·ㅡ의 가로획에는 위치에 따른 굵기 변화를 추가했다. `source.js`의 경로 배열에 붙는 `pen` 설정은 `model()`의 복사에서도 보존되며 글꼴 생성기의 윤곽 계산에 사용된다. 다른 글자의 펜 모형은 기존 보정을 유지한다.

`focus.webp`는 원본 M·이전 1.2·새 1.3의 세 글자를 같은 260px로 비교한다. `detail-metrics.json`의 수치는 이 세 견본을 800px로 렌더링한 잉크 겹침이다. 이 글자들은 제작에 참고한 표본이며, 수치를 전체 글꼴의 정확도나 독립 평가 결과로 해석하면 안 된다.
