# 고정 아바타 152종 · 제작 및 재검수 중

152종의 GLB 초안이 존재하지만 전체 외형 검수는 통과하지 못했습니다. 고양이·라멘 등 기존 6종과 개별 구조로 다시 만든 모델도 시제품입니다. 현재 49종에 개별 구조 코드가 있으며, 나머지 103종은 윤곽을 부풀린 초안으로 재제작 대상입니다. 이 숫자는 완성 또는 시각 검수 통과 수가 아닙니다.

원본 얼굴을 보존하며 최종 사용자는 고정 캐릭터를 고릅니다. 원본에 없는 옆·뒷모습은 새로 해석한 형상입니다.

## 열기

저장소 루트에서 `node scripts/preview_static.js 8766`을 실행합니다.

- 원본 비교 및 6종 산책: `http://127.0.0.1:8766/apps/avatar-lab/`
- 전체 152종 제작 검수: `http://127.0.0.1:8766/apps/avatar-lab/collection-review.html` — 미완성 모델 포함. 원본·정면·양옆·뒤·이동 동작을 나란히 표시합니다.
- 기존 6종 개별 보기: `http://127.0.0.1:8766/apps/avatar-lab/collection.html`
- 실제 미술관 시험: `http://127.0.0.1:8766/learning/arts/art-appreciation/museum/?avatars=preview`
- 독립 검토 파일: `outputs/avatar-lab/avatars-preview.html` (라이브러리·모델·원본 WebP 포함). 미술관 링크는 HTTP 서버가 필요합니다.

미리보기에서 앞·양옆·뒤·위, 드래그 회전과 확대, 서기·걷기·손 흔들기, GLB 저장을 지원합니다. 아래 산책 공간에서는 6종이 각자의 경로를 따라 이동하고 회전합니다. 미술관 시험에서는 6종 동시 보기 또는 한 종 보기를 고를 수 있습니다.

## 제작 방식

| 아바타 | 입체 구조 |
|---|---|
| 고양이 | 원본 윤곽을 따른 닫힌 후드·몸통·팔다리, 몸통 안에 연결한 꼬리 |
| 라멘 | 원형 회전체 그릇, 안쪽 벽·국물·면·달걀·고기·파·김, 곡면에 붙인 원본 얼굴 |
| 도넛 | 실제 도넛 고리, 흘러내린 초콜릿 표면, 스프링클, 얼굴 뒤를 막은 머리 |
| 바나나 | 긴 열매, 앞뒤로 벌어진 4개의 닫힌 껍질, 아래로 휜 껍질 |
| 헬리콥터 | 둥근 기체 후드, 곡선 조종석, 연결된 꼬리·꼬리 날개, 수평 회전날개 |
| 우산 | 두께가 있는 8개 곡면 천, 우산살, 기둥과 굽은 손잡이, 손잡이를 잡은 왼팔 |

`model-kit.cjs`는 재질·곡면·얼굴 투영·관절 애니메이션 도구를 공유합니다. 각 캐릭터의 머리·소품 형태는 개별 모델 파일에서 설계합니다. `ground-avatar.cjs`는 발을 딛는 구간과 들어서 돌려놓는 구간을 만들고 높이를 보정합니다. GLB의 `walkStride`와 `walkDuration`을 읽어 산책·미술관의 이동 속도에 재생 속도를 맞춥니다.

`illustration-materials.cjs`는 원본 얼굴과 입체 면의 색감이 조명에 따라 따로 보이지 않도록 중성 명암을 정점 색으로 저장합니다. 모든 재질은 `KHR_materials_unlit`으로 내보냅니다. 바나나 과육은 연한 크림 노랑, 껍질 안쪽은 더 밝은 아이보리로 분리했습니다.

원본 그림은 수정하지 않은 WebP로 GLB 안에 포함됩니다. 불투명한 실제 표면 위에 그림을 적용하므로 원본 투명도 때문에 몸체에 구멍이 나지 않습니다. 바나나·헬리콥터·우산 얼굴은 실제 머리 곡면을 따라 붙습니다.

## 재생성과 검증

각각 `node scripts/build-cat-avatar.cjs cat`, `ramen`, `donut`, `banana`, `helicopter`, `umbrella`로 모델을 만듭니다. 뒤의 이름만 바꾸어 여섯 번 실행합니다.

- `node scripts/package-cat-preview.cjs`: 독립 검토 파일 생성.
- `node tests/avatar-model-geometry.cjs`: 닫힌 표면, 정상 팔다리 수, 소품 구조, 얼굴 곡면 접촉, 동작별 바닥 접지, GLB에 실제 최신 동작이 포함되었는지 검사.
- `node tests/avatar-collection-geometry.cjs`: 나머지 146종의 실제 제작 경로와 내보낸 정점·법선·UV·색상 데이터를 대조하고 동작과 접지를 검사합니다. 일반 윤곽 메시의 닫힘만 검사하며, 모든 개별 소품의 위상·외형을 보증하지 않습니다.
- `node scripts/catalog-avatar-models.cjs`: 152종 목록 갱신. 검수 기록은 보존하고 원본 또는 GLB 파일이 바뀌면 재검토 상태로 되돌립니다.
- 실제 브라우저에서 각 모델의 방향과 이동 동작을 확인합니다. 최신 수정 캡처는 `outputs/qa/avatar-lab/repair-20261108/`, 이전 6종 기록은 `refined-six/`에 있습니다. 이전 캡처를 현재 모델의 합격 증거로 재사용하지 않습니다.

## 현재 범위와 한계

전체 외형 검수 완료 전입니다. 상세 변경·남은 결함은 `review.md`와 `catalog.json`에 기록합니다. 미술관에는 기존 6종을 불러오고 이동·회전시키는 시험 화면이 있습니다. `avatars=preview`일 때만 불러오며, 학급 접속 서비스에 연결하지 않습니다.

실사용 완료로 세지 않습니다. 기존 접속자의 아바타 선택·동기화, 크롬북 등 낮은 사양 기기, 학급 전체 인원 동시 표시 검증은 남아 있습니다. 일반 윤곽 초안의 얇은 측면, 임의의 뒷무늬, 소품 구조 누락은 기하 검사로 해결되거나 합격 처리되지 않습니다.

팔다리 노드를 이동·회전시키는 관절 애니메이션이며 스킨·본 리그, 얼굴 표정 교체, 회전 경로의 발 접점을 고정하는 IK는 없습니다. 직선 보행에서 딛는 발의 전후 이동을 보폭과 맞추며, 곡선에서 방향이 바뀔 때 발의 횡방향 미끄러짐까지 제어하지는 않습니다. GLB의 Walk는 제자리 동작이고 공간 내 이동은 앱이 처리합니다. 옆·뒤 형상과 무늬는 원본 한 장을 바탕으로 새로 설계했습니다.

## 여러 아바타 제작과 완료 기준

`catalog.json`은 전체 원본의 목록과 작업 상태입니다. 파일명에 있는 분류와 실제 3D 구조는 구분합니다. 구조 검토 없이 같은 타원형 메시를 모든 아바타에 복제하지 않습니다. 최종 사용자에게는 완성된 고정 아바타를 선택하는 방식으로 제공합니다.

1. 원본의 얼굴 표정, 색, 비율과 식별 가능한 특징을 먼저 확인합니다.
2. 정면·양쪽 옆면·뒷면·위에서 형태를 확인합니다. 그릇은 둥근 깊이와 열린 윗면, 바나나는 껍질의 곡면, 헬리콥터는 동체와 회전날개처럼 구조를 별도로 설계합니다.
3. 구멍, 떠 있는 부품, 중복 팔다리, 얼굴 늘어짐, 연결부 틈을 검사합니다. 의도된 구멍과 열린 그릇 입구는 결함으로 처리하지 않습니다.
4. 서기·걷기·회전을 실제 재생합니다. 머리 장식은 필요 없는 변형 없이 몸을 따라 움직여야 합니다.
5. GLB를 다시 로딩해 원본 텍스처와 동작을 확인하고, 실제 미술관 환경에서 용량·동시 표시 성능을 검증합니다.

기하 검사 통과만으로 시각적 완성도를 합격 처리하지 않습니다. 원본과 나란히 둔 캡처 및 동작 확인을 별도로 남깁니다. 기준 미달 모델은 수정 상태로 남기고, 미술관에서 검증되지 않은 시제품을 완성 모델로 세지 않습니다. 유형별 소수 시제품으로 스타일을 맞춘 뒤 묶음별로 진행하며, 개별 지적을 기다리는 방식으로 작업하지 않습니다.
