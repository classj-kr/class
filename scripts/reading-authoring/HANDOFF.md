# 비문학 자습 문항 작업 인수인계 (2026-09-17)

## 무엇을 바꿨나
- 문장 조각을 조합해 896문항을 만들던 `reading-self-study-v2.js`와 관련 데이터 파일을 지웠다.
- 문항은 `game-hub-server/data/reading-self-study-ko-v1.json` 한 파일에 한 세트씩(지문·문제·선지·해설) 들어 있다. 읽는 쪽은 `reading-self-study-v3.js`.
- 영어 비문학은 폐지했다. 시드 문항(reading-bank-seed-v1.json)도 학생 자습에서 뺐다.
- 학생 화면은 문항이 있는 급만 보여 준다.

## 출제 기준
`SPEC.md` 참고. 핵심:
- 1급은 지문·선지·해설 모두 습니다체, 2급 이상 선지·지문은 '-다'체.
- **지문 없이 선지만 보고 풀면 틀려야 한다.** 정답이 바른말·상식·합리적 선택이면 안 된다.
- 지문을 주고 풀면 답이 하나로 맞아야 한다.

## 검사 방법
1. `node scripts/reading-authoring/build.js check` → 형식 검사, 선지 순서 확정, `blindN.txt`(지문 없음)·`fullN.txt`(지문 있음)·`answer-key.json` 생성.
2. 에이전트 하나에 `blindN.txt`만 주고 찍게 한다(정답 파일은 열지 못하게). 확신도 40% 이상으로 맞힌 문항은 다시 쓴다.
3. 다른 에이전트에 `fullN.txt`를 주고 풀게 한다. 틀리거나 답이 둘로 읽힌다고 하면 고친다.
4. 통과한 문항만 싣는다.

## 현재 상태 (2026-09-17 개편)
- **1급**: 지식 글 28문항으로 전면 교체해 모두 실었다. 예전 1급은 가상 안내문·마을 이야기뿐이라
  "몇 시에 누가 무엇을 합니다" 글만 반복되고 읽어도 남는 지식이 없었다.
  - 선지 네 개가 모두 참인 지식이고, 문제는 "글에 나왔는가"를 묻는다(알 수 있는 것 / 설명하지 않은 것 / 답할 수 있는 질문 / 글쓴이가 알게 된 것).
  - 지문 없음 풀이: 1차 19/28 → 2차 14/28 → 3차 5/28(무작위 기댓값 7). 고친 문항은 따로 재검사.
  - 찍히는 원인은 "그 주제의 가장 유명한 사실"이 정답인 것. 유명한 사실은 글에서 빼고 오답에 둔다.
    "설명하지 않은 것"은 반대로 가장 전형적인 사실을 정답(글에서 뺀 것)으로 둔다.
    "답할 수 있는 질문"은 오답 질문도 어떻게·왜로 맞추고, 정답 질문에 글에서 빌린 낱말을 쓰지 않는다.
  - 화면에 제목(topicTitle)이 함께 뜬다. 제목이 오답 선지 내용을 말해 주면 안 된다.
  - 사실 확인 에이전트를 따로 돌려 오답 선지까지 사실인지 본다("모든 물고기", "모든 반딧불이" 같은 과한 일반화가 자주 걸린다).
- **2급**: 옛 기준(가상 설정·틀린 오답)으로 쓴 32문항. `excluded.json`으로 모두 뺐다. 새 기준으로 다시 써야 한다.
- **3급·4급**: 없음. 화면에서 숨겨져 있다.

## 남은 일
1. 2급을 새 SPEC 기준(지식 글, 참인 선지)으로 다시 쓰기 → 세 검사(지문 없음·지문 있음·사실 확인) → `excluded.json`에서 빼고 싣기.
2. 3·4급 작성(5지선다) → 같은 검사 → 추가.
3. `build.js publish`는 `excluded.json`(싣지 않을 id 배열)을 같은 폴더에 두고 실행한다. 없는 급 파일은 건너뛴다.
4. `blindN.txt`·`fullN.txt`·`answer-key.json`·`shuffled.json`은 검사할 때마다 새로 만드는 파일이라 커밋하지 않는다.
