# 비문학 자습 문항 출제 기준 (한국어)

한 문항 = 지문 1개 + 문제 1개 + 선지 + 해설. 지문마다 서로 다른 소재. 한 세트를 통째로 직접 쓴다.

## 급별 기준
| 급 | 대상 | 문체 | 지문 | 선지 수 | 요구 사고 |
|---|---|---|---|---|---|
| 1 | 초3~4 | **습니다체** (지문·문제·선지·해설 모두) | 4~6문장, 안내문·생활 설명문·쉬운 설명문, 쉬운 낱말 | 4 | 지문에 나온 사실 확인, 한 걸음 적용 |
| 2 | 초5~6 | '-다'체 (문제·해설은 '-요/-습니다' 가능하나 선지는 '-다'로 통일) | 5~7문장 설명문 | 4 | 원인과 결과, 간단한 추론 |
| 3 | 중1~2 | '-다'체 | 7~9문장 설명문·논설문 | 5 | 여러 정보 종합, 조건이 바뀔 때 결과 |
| 4 | 중3~고1 | '-다'체 | 8~10문장, 개념어가 있는 설명문·논설문 (400자 이내) | 5 | 원리를 새 상황에 적용, 적용 범위·한계 판단 |

## 반드시 지킬 것 (가장 중요)
1. **지문을 안 읽으면 못 풀어야 한다.** 검사에서 다른 AI가 지문 없이 선지만 보고 찍는다. 맞히면 불합격이다.
   - 상식·배경지식으로 풀리는 내용 금지. 누구나 아는 과학 사실(꿀은 안 상한다 등)을 묻지 마라.
   - 정답이 "바른말/착한 말/교훈/신중한 말"이면 안 된다. 규칙·공정·배려 같은 가치 주제는 쓰지 마라.
   - 지문 내용이 흔한 예상과 **다르게** 가는 지점을 정답으로 삼아라. (예: 보통은 저학년이 오전인데 이 안내문에서는 고학년이 오전)
   - 오답도 현실에서 충분히 그럴듯해야 한다. 억지·황당한 오답 금지.
   - 선지끼리 힌트를 주지 마라. (한 선지에만 나오는 소재가 다른 선지의 정답을 암시하면 안 됨. 서로 반대인 짝 선지를 만들지 마라.)
   - 선지는 길이·형식·어조를 맞춘다. 정답만 길거나, 정답만 '~수 있다' 같은 완곡 표현이면 안 된다. '항상, 절대, 전혀, 반드시, 오직, 무조건' 같은 극단어로 오답을 티 내지 마라.
2. **지문을 읽으면 답이 딱 하나여야 한다.** 오답은 지문의 구체적 문장과 어긋나야 하고, 해설에서 그 근거를 댈 수 있어야 한다. "지문에 안 나옴"만으로 틀린 오답은 최대 1개.
3. 정답 문장을 지문에서 그대로 베끼지 마라. 말을 바꾸거나 두 문장을 이어서 판단하게 하라.
4. 사실 오류 금지. 실제 세계에 대한 설명문은 정확한 사실만 쓴다. 상식과 다른 구체 내용이 필요하면 **가상의 대상**(어느 초등학교 안내문, 가상의 마을·섬·동아리, 한 학급의 실험 기록, 가상의 규칙이 있는 놀이·대회 등)을 써라. 가상의 대상을 실제 과학 사실처럼 꾸며 쓰지는 마라.
5. 자연스러운 한국어. 번역투·압축된 문장 금지. 해당 학년이 읽을 수 있는 낱말.
6. 해설에는 선지 번호를 쓰지 마라(선지 순서는 나중에 섞는다). "정답 문장이 왜 맞는지 + 헷갈리기 쉬운 오답이 지문 어디와 어긋나는지"를 1~3문장으로.
7. 문제(발문)는 다양하게: 내용 일치, 까닭 찾기, 적용 사례, 조건 변화, 추론 등. 급의 요구 사고에 맞게.

## 소재 폭
과학, 사회, 생활 안내, 역사·문화, 기술, 경제, 건강, 환경, 예술, 수학 활용 등을 고루. 가상 소재와 실제 사실 소재를 섞되, 실제 사실 소재는 **그 글만의 구체 정보**(순서, 조건, 수치, 비교 대상)를 묻는다.

## 출력 형식
JSON 배열. 각 원소:
```json
{
  "id": "K1-01",
  "topicTitle": "과학 축제 안내",
  "questionType": "content_match | cause | inference | application | condition | synthesis | scope",
  "passageText": "...",
  "promptText": "윗글의 내용과 맞는 것을 고르세요.",
  "choices": ["...", "...", "...", "..."],
  "correctIndex": 0,
  "explanation": "..."
}
```
correctIndex는 아무 값이어도 된다(나중에 섞는다).

## 합격 예시 (1급)
지문: 과학 축제는 5월 셋째 주 금요일에 운동장에서 열립니다. 4~6학년은 오전에, 1~3학년은 오후에 참여합니다. 비가 오면 축제는 다음 주 금요일로 미뤄집니다. 직접 실험을 해 보고 싶은 학생은 축제 전날까지 담임 선생님께 신청서를 내야 합니다. 실험은 한 사람이 한 가지만 신청할 수 있습니다.
문제: 윗글의 내용과 맞는 것을 고르세요.
선지: 한 학생이 실험을 두 개까지 신청할 수 있습니다. / 비가 오면 과학 축제는 다음 주 금요일로 미뤄집니다.(정답) / 실험 신청서는 축제 당일 아침까지 내면 됩니다. / 5학년 학생은 오후에 과학 축제에 참여합니다.
→ 지문 없이 푼 AI는 "고학년은 오후가 흔하다"며 오답을 골랐다. 합격.

## 불합격 예시
- 정답 "규칙을 지킬 때는 그 규칙을 만든 까닭도 생각해야 한다." → 교훈이라 지문 없이 찍힘.
- 오답 "밤사이에 낱말의 글자가 바뀌었기 때문입니다." → 황당해서 소거됨.
- 선지 "방학 동안에는 새로 들어온 책도…"가 다른 선지(정답)의 "책이 많아졌다"를 암시 → 선지끼리 힌트.
- 꿀이 물기를 빨아들이면 상한다 → 상식으로 풀림.
