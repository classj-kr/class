# 교과 단어 5-2 설명 줄이기 지침

대상은 문해력이 약한 초등 5학년이다. 지금 설명(explain)은 낱말마다 세 문단, 230자쯤이라 너무 길다.

## 만들 것

맡은 낱말마다 새 설명을 써서 덧붙임 파일에 넣는다. 원래 파일(extra/kor.json 등)은 고치지 않는다.

```json
{ "<단원 id>": { "<낱말>": { "explain": ["한자 뜻: …", "헷갈리는 말: …", "생활 속 예: …"] } } }
```

- 이 파일의 explain 이 원래 explain 을 통째로 덮어쓴다(build.mjs 가 -x/-y 같은 덧붙임 파일을 나중에 읽는다).
- 단원 id 와 낱말은 learning/literacy-numeracy/curriculum-vocabulary/words-5-2.js 그대로 쓴다. 맡은 낱말은 하나도 빠짐없이 넣는다.

## 분량

- 줄(배열 원소)은 많아야 셋. 둘이면 충분한 낱말이 많다.
- 한 줄에 한 문장. 이름표를 뺀 글이 45자 안쪽이다. 꼭 필요하면 짧은 문장 둘까지.
- 낱말 하나의 이름표를 뺀 글이 모두 합쳐 130자 안쪽이다.

## 이름표

줄마다 `이름표: 글` 꼴로 시작한다. 이름표는 아래 넷 가운데서만 고른다. 화면에서 색 이름표로 보인다.

- `한자 뜻:` 한자를 풀면 뜻이 바로 잡히는 낱말만 쓴다. 예: `合(합할 합)과 同(같을 동), 합쳐 보니 같다는 뜻입니다.` 한자 풀이가 뜻에 도움이 안 되면 넣지 않는다.
- `비교:` 단원에서 나란히 배우는 이웃 낱말과 무엇이 다른지 쓴다. 아이에게 헷갈린다고 말하지 않는다. 예: `초과는 기준 수가 빠지고, 이상은 들어갑니다.`
- `생활 속 예:` 아이 생활에서 바로 떠오르는 장면 하나. 예: `같은 틀로 찍은 쿠키는 서로 합동입니다.`
- `꼭 알기:` 교과서 시험에 나오는 핵심 사실 하나(사회의 때·사람·까닭, 과학의 원리 같은 것). 예: `세종이 1443년에 만들고 1446년에 널리 알렸습니다.`

## 좋은 설명의 조건

- 쉬운 낱말만 쓴다. 설명 속 낱말이 낱말 자신보다 어려우면 실패다. 한자말을 쓰면 쉬운 말로 바꾼다.
- ~습니다/~입니다 체.
- 원래 설명에서 가장 쓸모 있는 것만 남긴다. 새 사실을 지어내지 않는다. 숫자·연도·사람 이름은 원래 설명에 있던 것만 쓴다.
- 이미 화면에 있는 것을 되풀이하지 않는다: 뜻(mean), 예문(use), 다른 뜻(senses — 다의어·동형어), 유의어·반의어(rel)와 그 note.
- 수와 단위는 띄어 쓴다(8 cm, 25 °C 말고 25 ℃처럼 원래 표기 그대로).
- 강조 별표, 따옴표 남발 금지. 책 이름은 『』, 작품 이름은 「」를 원래대로.

## 확인

- `node tools/curriculum-vocabulary/build.mjs 5-2` 통과.
- 맡은 낱말 수와 넣은 수가 같은지, 줄 수·글자 수 기준을 넘는 낱말이 없는지 스크립트로 세어 본다.
- git add·커밋 하지 않는다. 다른 파일은 고치지 않는다(다른 도우미들이 동시에 다른 과목을 쓰는 중).
- 끝나면 낱말 수, 평균 글자 수, 기준을 지키느라 버린 내용 가운데 아까운 것이 있으면 그 목록을 짧게 보고한다.
