# 교과 단어 만들기 지침 (모든 학기 공통)

초등 3~6학년 「교과 단어」 앱(learning/literacy-numeracy/curriculum-vocabulary). 5학년 2학기(tools/curriculum-vocabulary/5-2)를 만들며 사용자에게 받은 지적을 모두 담았다. **대상은 문해력이 약한 아이**다. 이 지침과 5-2 원고를 본보기로 삼는다.

## 0. 파일과 흐름

학기 폴더 `tools/curriculum-vocabulary/<학기>/` (예: 6-2)

| 파일 | 내용 |
| --- | --- |
| `kor.json` `math.json` `soc.json` `sci.json` | 원고: 단원과 낱말(w, hanja, mean, use, blanks, evidence) |
| `extra/<과목>.json` | 낱말마다 en, explain, beats, img, imgKo, hanja(원고에 없을 때) |
| `extra/<과목>-g.json` | 코드로 그린 도식이 있는 낱말의 beats, fig |
| `extra/senses-<과목>.json` | 다른 뜻(다의어·동형어) |
| `extra/rel-<과목>.json` | 유의어·반의어·상위어·하위어·관련 단어 |
| `extra/foils-<과목>.json` | 연습 오답 후보 |

과목 코드: kor 국어, math 수학, soc 사회, sci 과학. `extra/` 의 덧붙임 파일은 `<코드>.json` 을 먼저, `<코드>-<글자 하나>.json` 을 나중에 읽어 칸마다 덮어쓴다. `senses-*`·`rel-*`·`foils-*` 는 이름 앞머리로 따로 읽는다(그 안의 과목 코드로 나눔).

만들기: `node tools/curriculum-vocabulary/build.mjs <학기>` → `learning/.../words-<학기>.js` (직접 고치지 말 것). build 가 검사하는 것을 통과해야 한다. 그림 프롬프트: `node tools/curriculum-vocabulary/make-prompts.mjs <학기>` → `<학기>/IMAGE-PROMPTS.md`.

## 1. 낱말 고르기 (원고)

- **수집한 교과서 본문에서만** 고른다. 과학·사회는 출판사 여러 곳에 공통으로 나오는 용어를 먼저. 국어는 국정 교과서. 수학은 여러 출판사 공통 용어.
- 그 단원을 공부하려면 꼭 알아야 하는 낱말: 교과서가 굵게 쓰거나 뜻을 풀어 주는 용어, 단원의 핵심 개념, 문해력이 약한 아이가 막힐 한자말.
- **구(句)는 낱말이 아니다.** 「인상적인 부분」 ✗ → 「인상적」, 「검토 기준」 ✗ → 「검토」. 교과서에서 한 덩어리로 쓰는 용어(선사 시대, 문장 성분, 재생 에너지)는 된다.
- **개수를 미리 정하지 않는다.** 단원 내용이 요구하는 만큼. (5-2는 국어 72·수학 40·사회 107·과학 52)
- 한 과목 안에서 같은 낱말을 두 단원에 넣지 않는다.
- 원고 꼴(5-2/soc.json 참고):
  ```json
  { "subject": "사회", "book": "미래엔 사회 6-2 외 두 종",
    "units": [ { "id": "1-1", "title": "1-1 ○○○", "words": [
      { "w": "유물", "hanja": [["遺", "남길 유"], ["物", "물건 물"]],
        "mean": "옛사람들이 만들어 쓰다가 남긴, 옮길 수 있는 물건.",
        "use": "…유물…입니다.",
        "blanks": ["…{}(이)라고 합니다.", "…{}을/를 …"],
        "evidence": "미래엔 9쪽 '…', 동아 10쪽 …" } ] } ] }
  ```
  - 단원 id: 국어 `reading`(독서 단원)·`1`…`6`·`media`(매체 단원), 수학·과학 `1`…, 사회 `1-1`처럼 교과서 차례. title 은 번호를 붙여 교과서 단원명 그대로.
  - **hanja**: 한자 풀이가 뜻을 잡아 주는 한자말만. 훈은 아이가 아는 쉬운 말(글월 문 ✗ → 글 문, 본디 소 ✗ → 바탕 소, 써 이 ✗ → 부터 이, 요긴할 ✗ → 중요할). 고유어·외래어·고유 이름은 null.
  - **mean**: 이 단원에서 쓰는 뜻 한 문장, 「~것.」「~일.」처럼 끝맺거나 「~습니다」. 뜻풀이 안에 낱말 자신을 쓰지 않는다.
  - **use**: 아이 생활이나 교과서 장면 예문 한 문장, ~습니다, 낱말 자신이 들어간다. **예문과 뜻풀이에 같은 알맹이 낱말(두 글자 이상)이 겹치면 안 된다**(「은행에서 대출」 ↔ 「은행 같은 곳에서 돈을…」 ✗).
  - **blanks**: 빈칸 문장 정확히 둘. `{}` 하나. 빈칸 뒤 조사는 `(이)라고` `(이)라는` `을/를` `이/가` `은/는` `와/과` `(으)로` 꼴이거나 받침과 상관없는 말(의, 에, 에서, 도, 만, 한, 하고, 했, 적인…). 정답 낱말·핵심 글자가 문장에 보이면 안 된다. **빈칸 옆 몇 글자만으로 답이 정해지면 안 된다**(「___을/를 틀어 놓고」 → 오디오 북 ✗). 문장 전체를 읽어야 이웃 낱말과 갈리게. 두 문장이 같은 장면이면 안 된다. 사실이 틀리면 안 된다.
  - **evidence**: 교과서·쪽 근거(화면엔 안 나옴).

## 2. 화면 글 공통 문체

- ~습니다/~입니다(존댓말). 따옴표 안 대사·인용만 원래 말.
- **쉬운 낱말만.** 설명 속 낱말이 낱말 자신보다 어려우면 실패. 어려운 말(처단, 토속신, 슴베찌르개, 외무 장관…) 금지.
- 수와 단위는 띄어 쓴다(8 cm, 25 ℃, 3 %). 우리말 단위(개·명)는 붙인다.
- 강조 별표 금지. 아이에게 「헷갈린다」고 말하지 않는다.
- 단원 밖 낯선 낱말을 끌어와 견주지 않는다.
- 사실은 교과서와 맞춘다. 교과서 표현이 따로 있으면 그것을 따른다(「지배자나 마을 사람들의 무덤」, 「지금 남아 있는 가장 오래된」, 「시대적 배경」).

## 3. 영어(en)

- **초등학생에게 쓸모 있는 실제 영어 낱말만.** 원어민 아이가 쓰는 말 + 영어로 알아 둘 만한 말.
- 넣지 않는다: 우리 고유 이름의 로마자(Gojoseon, yangban), 뜻을 영어로 풀어 쓴 말(bone-rank system, plain Korean word), 어려운 전문어(congruent, stanza, predicate, conduction, desalination, precipitation).
- 뜻이 딱 맞아야 한다(강수량 ≠ rainfall, 허위 정보 ≠ fake news).
- 한국어 풀이를 붙이지 않는다. 괄호 덧말은 꼭 필요할 때만(AR, UN).
- 5-2는 271개 가운데 77개만 넣었다. 없는 낱말이 많아도 된다.

## 4. 설명(explain) — 가장 중요

사용자 말: "설명 자체가 없고 국어사전처럼 뜻만 있잖아." / "꼭 알기라는 말은 도대체 왜 있는가?" / "영어 단어와 연계해서 쉽게 설명해 주면 되는데."

- 줄은 많아야 셋. 이름표는 `쉬운 뜻:` `한자 뜻:` `생활 속 예:` 셋뿐. 그 밖의 사실 줄은 이름표 없이 문장만.
- **첫 줄은 언제나 `쉬운 뜻:`** — 선생님이 아이에게 말로 풀어 주듯. 사전 말투 금지. 영어가 있으면 영어와 잇는다: `쉬운 뜻: 영어로 memorable, '기억할 만한'이라는 말입니다. 오래 기억에 남는 것이 인상적인 것입니다.` 비유도 좋다: `쉬운 뜻: 사탕 속에 초콜릿이 들어 있듯, 말 속에 다른 뜻이 숨어 있는 것입니다.` 60자 안쪽.
- `한자 뜻:` 한자 풀이가 뜻을 바로 잡아 줄 때만, 쉬운 훈으로: `印(도장 인)과 象(모양 상), 마음에 도장을 찍은 듯 모양이 남는다는 뜻입니다.`
- **낱말마다 구체적인 줄이 적어도 하나**: 아이가 본 적 있는 장면·물건·숫자. 국어·수학·과학은 `생활 속 예:`, 사회 역사 낱말은 그때 모습을 장면처럼(이름표 없이).
- 둘째·셋째 줄은 45자 안쪽, 이름표 뺀 합계 150자 안쪽(build 검사).
- 낱말 둘을 견주기만 하는 줄은 쓰지 않는다 — 견주는 짝은 '관련 단어'(rel see)로 간다.
- 화면에 이미 있는 것(뜻, 예문, 다른 뜻, 관련 단어 note)을 되풀이하지 않는다.
- 흔한 잘못 알기는 장면으로 살리면 좋다(주전자 하얀 김은 수증기가 아니라 물방울).

## 5. 다른 뜻 (senses)

- 이 단원 뜻 말고 아이가 생활에서 마주치는 다른 뜻. 있는 낱말만.
- 꼴: `{ "<과목 코드>": { "<단원>": { "<낱말>": { "senses": [ { "mean": "", "use": "", "hanja": "異常", "kind": "동형어" } ] } } } }`
- **kind**: `다의어`(같은 낱말의 다른 뜻, 한자도 같거나 뜻이 넓어진 것) / `동형어`(소리만 같은 다른 낱말, 한자가 다르거나 사전에 따로 올림말). 한자가 다르면 hanja 에 그 한자를 적는다.
- 연습에서 예문을 보여 주고 뜻을 고르게 하므로 **예문과 그 뜻풀이에 같은 알맹이 낱말이 겹치면 안 되고**, 다른 뜻으로도 읽히는 예문이면 안 된다.
- 설명(explain)에 다른 뜻 이야기를 되풀이하지 않는다.

## 6. 관련 단어 (rel)

- 꼴: `{ "<과목 코드>": { "<단원>": { "<낱말>": { "syn": [{ "w": "", "note": "" }], "ant": [...], "up": [...], "down": [...], "see": [...] } } } }`
- 화면 이름표: 유의어(syn), 반의어(ant), 관련 단어(up·down·see 묶음). 이름표 옆 덧말 없음.
- **확실한 것만**: 사전·교과서 짝. 아이가 아는 쉬운 말. 이 단원 뜻에 대한 관계만. 없으면 비운다.
- 반의어는 진짜 반대인 짝만(대출↔반납, 이상↔이하, 고기압↔저기압). 갈래·자리만 다른 것은 반의어가 아니다(진분수·가분수·대분수, 곱해지는 수·곱하는 수 → see).
- see: 견주어 볼 이웃 낱말과 다른 점 한 줄(note, 40자 안쪽, ~습니다). 토의 → 토론 「토론은 편을 나누어 따지고, 토의는 편 없이 함께 방법을 찾습니다.」
- 같은 단원 낱말이면 눌러서 그 낱말로 간다(낱말 이름 그대로).

## 7. 연습 오답 (foils)

사용자 말: "문제가 유치원 수준이긴 하네, 선지 수준이." / "네 개 중에 '틀어 놓고'에 해당하는 게 오디오 북밖에 없잖아."

- 꼴: `{ "<과목 코드>": { "<단원>": { "<낱말>": ["후보1", "후보2", "후보3"] } } }` — 낱말마다 3~4개.
- **같은 과목 같은 학기 낱말 목록 안에서**(다른 단원 가능), **같은 갈래**로. 빈칸 앞뒤 말에 들어갈 듯 보이고 문장 전체를 읽어야 틀린 것이 드러나야 한다.
- 빈칸에 넣어 문장 전체가 맞는 말이 되면(두 번째 정답) 버린다.

## 8. 그림과 도식

- **사람·장면 그림은 사용자가 만든다.** extra/<과목>.json 의 `img`(영어 프롬프트 2~4문장)와 `imgKo`(우리말 한두 문장)만 쓴다. 그림 속 글자·숫자·말풍선 글 금지. 한 그림에 한 생각. 등장인물 HARIN(소녀, 노란 머리띠, 민트 카디건), DOYUN(소년, 둥근 안경, 남색 후드), TEACHER(30대 여선생님, 베이지 재킷). 역사는 시대에 맞게, 전쟁·식민 통치는 피·무기·다친 사람 없이 간접적으로. 실존 인물 얼굴을 그대로 그리지 않는다.
- `beats`: 그림 아래 차례로 뜨는 칸 글 2~4개(~습니다, 쉬운 말, 그림에 보이는 것만, 마지막 칸은 낱말 뜻으로 묶음).
- **움직임으로 보여야 하는 낱말은 코드로 그린 도식**(그림 프롬프트를 만들지 않는다):
  - 수학 낱말 전부(figures/<학기>/math-N.js — 5-2 math-1~6.js 본보기)
  - 국어 문법·글 갈래 낱말(문장 성분, 호응, 생략, 극본 등 — 5-2 kor.js 본보기)
  - 과학 원리·과정 낱말(증발, 대류, 해풍 등 — 5-2 sci.js 본보기)
  - 도식 낱말은 `extra/<과목>-g.json` 에 beats 와 fig(칸마다 도식 메모)를 넣는다. fig 가 있으면 그림 프롬프트에서 빠진다.
  - figures/kit.js 의 약속(viewBox 640×360, b1~b5·h2~h5, on1~onN 누적, 장면 고유 클래스 아래 CSS, transform 속성 있는 <g> 에 CSS transform 금지). 글씨 18px 이상, 그림 안에 문장 금지(짧은 이름표만), 색은 kit 의 C, 칸마다 움직임, 마지막 칸은 뜻 정리. 지도는 국내 지도 앱의 실제 경계 자료에서 뽑는다(손으로 그린 지도 금지).
  - 찍어 보기: `node tools/curriculum-vocabulary/shoot-figures.cjs <학기> <과목> <단원> E:/webprojects/curriculum-shots/<폴더>` → 칸별 PNG를 직접 열어 겹침·잘림·과학 오류를 고친다.
