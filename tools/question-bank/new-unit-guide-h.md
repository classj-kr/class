# 고등학교 2·3학년 단원 짓기 — 공용 기호·그래프 도구(`B.kit.hs`)

먼저 `fill-guide.md`, `new-unit-guide.md`, `new-unit-guide-m.md`를 읽는다. 이 글은 대수·미적분Ⅰ·확률과 통계·기하·미적분Ⅱ 단원이 함께 쓰는 도구만 적는다. 도구는 `middle.js` 끝의 `B.kit.hs`에 있고, 모양은 `styles.css`의 「고등학교 2·3학년 공용 기호」에 있다.

```js
const { ms, fn, sub, lim, sum, intg, evl, pw, rtn, lg, nC, pr, vec, plot, space, jh, qAns, piAns, coordAns } = B.kit.hs;
```

같은 일을 하는 함수를 단원 파일에 다시 짓지 않는다. 모자라면 단원 파일 안에 덧붙이고 보고에 적는다(공용 파일은 고치지 않는다).

## 1. 글자 모양
- 문자(변수)는 지금처럼 기울인 글자 `V('x')`. 점 이름(A, B, P)·사건(A, B)은 세운 글자 그대로 적는다.
- `fn(name)` — 함수 이름·기호를 세운 수식 글자(KaTeX_Main)로. sin, cos, tan, log, ln, lim, max, min, P, C, H, Π, E, V, N, B. 예: `fn('max')`.
- `ms(글, caps)` — 수식 글을 짧게 적는다. 소문자·그리스 문자(π 빼고)는 기울인 글자, sin·cos·tan·log·ln·lim·max·min은 세운 글자, `-`는 −, `*`는 ×, `<=` `>=` `!=` `->`는 ≤ ≥ ≠ →, `'`는 ′, `^`·`_`는 위·아래 첨자(두 글자 넘으면 `{ }`: `x^{n+1}`, `a_{n+1}`). 대문자는 세운 글자이고 caps의 글자(기본 `'XYZ'` — 확률변수)만 기울인다.
  - 예: `` `함수 ${ms('f(x) = x^3 - 2x^2 + 5')}에 대하여` ``, 적분상수: `ms('x^2 + C', 'C')`.
  - `<` `>`는 앞뒤를 띄어 쓴다(`x < 3`). 붙여 쓰면 태그로 읽힐 수 있다.
  - σ는 KaTeX_Main에 없어 수식 글꼴의 기울인 σ로 나온다(`sd`, `ms('σ')`). π는 지금 단원들처럼 손대지 않는다.
- 그 밖에 내보낸 것: `signed(n)`(음수는 −), `plainOf(h)`(HTML → 글, 숨은 글 포함), `readOf(h)`(단원 검사가 토씨를 볼 때 읽는 글), `hide(t)`(화면에 안 보이는 글), `vis(h)`(보이는 글자만 — 글로 옮기면 사라진다), `proj(p)`(공간의 점 → 화면의 점).
- 다른 도구의 인자는 `mt`를 거친다: 수는 −를 붙인 글, 태그나 글자 참조(`&lt;`)가 든 글은 그대로, 글자만 있는 글은 `ms`로 바꾼다. 그래서 `lim('x→2', 'f(x)')`처럼 글만 줘도 된다. 이미 그린 HTML(`frac(…)`, `V('a')`)에 글을 붙여 넘길 때는 글 쪽을 먼저 `ms`로 바꾼다: `evl(ms('x^2 - ') + frac(ms('x^3'), 3), 0, 2)`.

## 2. 첨자·지수·로그·삼각함수·미분
- `sub(h)` — 아래 첨자. `V('a') + sub(V('n'))` → aₙ, `ms('a_{n+1}')`. 기록 글은 `a_n`, `a_(n+1)`.
- `pw(밑, 지수)` — `pw(2, 3)` → 2³, `pw(9, [3, 2])` → 9의 3/2제곱(위첨자 안의 작은 세로 분수), `pw(2, -1)`. 분수 지수만 따로 쓰려면 `sup(sfrac(3, 2))`.
- `rtn(n, 안)` — 거듭제곱근. `rtn(3, 8)` → ∛8 꼴(근호는 공용 `rt`와 같고 왼쪽 위에 작은 3). 기록 글 `³√8`, `ⁿ√a`.
- `lg(밑, 진수)` → log₂ 8(`lg(null, 100)` 상용로그), `ln('x')`, `trig('sin', 'x')` → sin x, `trig('cos', '2x', 2)` → cos² 2x. 진수가 `(`로 시작하면 띄우지 않는다(`lg(2, '(x+1)')`). 한 덩이로 묶여 줄이 갈리지 않는다.
- `df('f')` → f′, `df('f', 2, 'x')` → f″(x)(′ U+2032 두 개), `prime(n)`, `ms("f'(x)")`. `dd('y', 'x')` → dy/dx(세로 분수).

## 3. 쌓은 기호(Σ·lim·∫·[ ]ₐᵇ)
화면에는 교과서처럼 쌓아 보이고, 기록 글·검사·화면 읽기에는 한 줄 글이 남는다(보이는 글자는 CSS로 그리고, 숨은 글을 따로 넣었다).
- `lim(아래, 몸)` — `lim('x→2', 'f(x)')`. `'x→2+'`·`'x→2-'`는 한쪽 극한(위첨자 +, −), `'x→∞'`, `'n→∞'`, `'x→-1'`. `->`도 된다. 몸을 함께 주면 기호와 한 덩어리가 된다(줄이 갈리지 않는다). 예: `` `${lim('x→1', '(x^2 + 3x)')}의 값은?` ``
- `sum(아래, 위, 몸)` — `sum('k=1', 'n', 'a_k')`, `sum('k=1', 10, '(2k - 1)')`.
- `intg(a, b, 몸, 변수)` — 정적분 `intg(0, 2, '(3x^2 + 1)', 'x')`(∫ 오른쪽 위 2, 아래 0, 끝에 dx). 부정적분 `intg(null, null, '(2x + 1)', 'x')`.
- `evl(F, a, b)` — 끝값 대입 [F(x)]ₐᵇ. 괄호는 안의 글 높이에 맞춘다. 예: `` `${intg(0, b, '(3x^2 + 1)', 'x')} = ${evl('x^3 + x', 0, b)} = ${b ** 3 + b}` ``
- 쌓은 기호는 글줄을 조금 높인다. 글에는 기호 하나·짧은 몸만 넣고, 분수가 든 긴 식은 그림 칸에 `hx(식)`으로 따로 놓는다(`hx`는 공용 `ex`처럼 휴대폰 너비에 맞춰 글씨를 줄이되 쌓은 기호의 너비를 바르게 센다).
- 한계 글에 「수 + m·g·t·L」(`'2m'`)을 쓰지 않는다. 숨은 글 「Σ(k=1~2m)」을 단원 검사가 수와 단위를 붙여 쓴 것으로 잡는다.

## 4. 순열·조합
- `nP(5, 2)` → ₅P₂, `nC(5, 2)` → ₅C₂, `nPi(3, 2)` → ₃Π₂(중복순열), `nH(3, 2)` → ₃H₂(중복조합). 문자도 된다: `nC('n', 'r')`. 기록 글 `5C2`, `nCr`.

## 5. 확률·통계
- `pr('A')` → P(A), `pr('B', 'A')` → P(B∣A)(세로 막대 U+2223), `pr('X = 2')`(X는 기울인 글자), `pr('A^C')` → P(Aᶜ), `pr('A∩B')`. 몸에 HTML을 섞으려면 `pr(ms('49 <= ') + bar('X') + ms(' <= 52'))`.
- `ev('X')` → E(X), `vr('X')` → V(X), `sd('X')` → σ(X), `bin(10, frac(1, 3))` → B(10, 1/3), `nrm(50, pw(4, 2))` → N(50, 4²)(둘째 인자는 분산을 적은 글 그대로 — N(0, 1)은 `nrm(0, 1)`).
- `bar('X')` → X̄(표본평균, 줄은 글자 너비에 맞추고 띄운다), `hat('p')` → p̂(표본비율).
- `dist(값들, 확률들, { v: 'X', x: 'x', total: true })` — 확률분포표. 첫 줄 X, 값…, 「합계」 / 둘째 줄 P(X = x), 확률…, 1. 값·확률은 수나 HTML(`frac(1, 4)`, `V('a')`). `total: false`면 합계 열을 뺀다. 표 설명(aria-label)에 값과 확률이 적힌다. 360px에 들어가려면 값은 다섯 개쯤까지.
- `ztab([[1, 0.3413], [1.5, 0.4332], [2, 0.4772]])` — 표준정규분포표 조각(z는 소수 첫째 자리, 확률은 넷째 자리로 적는다).

## 6. 벡터·공간좌표
- `vec('a')` → a⃗(기울인 소문자 위 화살표, b·d·k처럼 위로 솟은 글자는 화살표를 더 띄운다), `vec('AB')` → AB⃗(세운 두 글자, 화살표를 글자 너비에 맞춘다).
- 크기 `'|' + vec('a') + '|'`, 내적 `vec('a') + ' · ' + vec('b')`, 성분 `cmps('a', 2)` → (a₁, a₂), 공간의 점 `ms('(x, y, z)')`, `ms('P(1, 2, 3)')`.
- 기록 글은 `a⃗`, `AB⃗`(결합 문자 U+20D7)이다. 「두 벡터 a⃗, b⃗」가 「벡터 벡터 a」로 읽히지 않게 낱말을 덧붙이지 않았다.

## 7. 토씨
- `jh(글, '은/는')` — 단원 검사(`tight`)와 같은 방법으로 글을 읽어 끝소리로 토씨를 붙인다(`'을/를'`, `'이/가'`, `'과/와'`, `'으로/로'`, `'이라/라'` — 앞이 받침 있는 쪽). 예: `` `${jh(nC(n, 2), '과/와')} ${nC(n, 3)}의 합은?` ``
- 무엇을 읽는가:
  - ₙCᵣ·₅P₂ → 오른쪽 아래 r(₅C₂ → 「이」 → 는, ₅C₃ → 「삼」 → 은, ₙCᵣ → 「알」 → 은). 검사도 숨은 글 「5C2」의 끝 숫자로 본다.
  - aₙ·log₂ 8 → 끝 숫자나 문자(a₃ → 삼, aₙ → 엔).
  - 거듭제곱(위첨자, 분수 지수 포함) → 「제곱」(받침 있음). 근호·거듭제곱근 → 안의 수(∛8 → 팔).
  - 분수 → 분자(사분의 삼 → 삼). dy/dx → y.
  - Σ·lim·∫ → 몸의 끝(f(x) → x, dx → x). 닫는 괄호는 건너뛴다: P(A) → A, E(X) → X, B(18, 1/3) → 일.
  - 영문자는 이름으로: L·M·N·R은 받침(R·L은 ㄹ — 「으로」가 아니라 「로」), 나머지는 받침 없음. 그리스 문자·π·∞(무한대)는 받침 없음.
  - X̄ → 「바」(받침 없음), p̂ → 「햇」(받침 있음: p̂은, p̂을), a⃗ → 글자 이름(a⃗와, b⃗를).
- 검사는 숫자 뒤 토씨만 본다. 문자·기호 뒤 토씨는 검사가 잡지 못하니 `jh`로 붙인다.

## 8. 답 칸 고르기
- 정수·분수 하나: `qAns(text, 값, o)` — 값은 정수, 유리수 `Q(p, q)`, `[분자, 분모]`. 정수는 수 칸, 분수는 분자·분모 칸(크기가 같은 분수도 맞게 친다). `o.signed`: 부호 단추(답이 음수면 저절로 붙는다 — 음수가 나올 수 있는 유형은 늘 `signed: true`), `o.lowest`: 기약분수만 받는다(문제 글에 「기약분수로」를 적는다). 확률처럼 늘 양수인 값은 단추 없이.
- π가 든 값(호도법): `piAns(text, p, q, o)` → 「[±][분자/분모] π」(계수가 정수면 「[±][ ] π」). 칸 모양이 「π가 든 값」을 알려 주므로 묻는 글이 이미 π 꼴을 말할 때만 쓴다: 「210°를 호도법으로 나타내면 □π이다. □ 안에 알맞은 수는?」. 「θ의 값은?」처럼 꼴을 말하지 않은 물음은 고르기(C)로 낸다. 한 유형 안에서는 계수가 늘 분수이거나 늘 정수이게 수를 고른다(칸 모양이 바뀌면 답을 흘린다).
- 근호: a√b는 공용 `radAns`. a + b√c, (a ± √b)/c는 `B.kit.inline`에 `rt('{1}')`, `frac('{0} ± ' + rt('{1}'), '{2}')`을 넣고 `shown`을 준다(`new-unit-guide-m.md` 중3).
- 좌표·성분: `coordAns(text, [x, y, z], o)` → 「( [±][ ], [±][ ], [±][ ] )」. 두 성분이면 점의 좌표·벡터의 성분. 정수만 — 분수 성분이면 고르기로. `facts.calc`는 칸마다 `[[식, 0], [식, 1], [식, 2]]`.
- 식 속 칸: ``B.kit.inline(text, `${lim('x→1-', 'f(x)')} = {0}, ${lim('x→1+', 'f(x)')} = {1}`, [{ answer, signed: true }, …], { shown, facts })`` — 쌓은 기호를 틀에 넣어도 된다.
- 소수: 엔진의 소수 칸(`D`)은 셋째 자리까지 받고, 단원 검사는 `FINE_DECIMAL_UNITS`에 든 단원만 둘째 자리 이상을 허락한다(나머지는 첫째 자리까지). 표준정규분포표로 구한 넷째 자리 확률(0.8185)은 칸으로 받지 못하므로 고르기로 낸다. 0.25 같은 답이 필요한 단원은 보고에 적는다(받는 쪽이 검사에 넣는다).
- 큰 수: 답이 9999를 넘는 단원(₁₀P₅ = 30240 따위)은 검사의 `BIG_NUMBER_UNITS`에 들어 있어야 한다. 넘어야 하면 보고에 적는다.
- 답이 식·집합·구간이고 칸으로 받으면 모양이 답을 흘리는 것, 무리수·π가 섞인 값, 부등호 방향이 뜻인 것은 고르기(C). 보기에 이 도구의 기호가 있으면 화면의 답 줄(정답 공개)에도 기호 그대로 보인다(`app.js`의 `choiceShown`).

## 9. 그래프 `plot(o)`
공용 `plane`은 그대로 두고 고등학교 함수용으로 따로 지었다(축·화살촉·O·글씨는 같은 모양).
- `x`, `y`: [작은 끝, 큰 끝](실수, 0을 품어야 한다 — 두 축이 그림 안에). 가로 한 칸은 너비 `w`(기본 270)에 맞춘다(`u`로 직접). 세로가 너무 길거나 짧으면 `ys`(세로 배율).
- 눈금 `xt`, `yt`: 수의 배열이나 `{ v: 자리, t: '적을 글' }`. `'/'`가 든 글은 세로 분수로 적는다. π 눈금은 `piTicks(0, 2, 2)` → π/2, π, 3π/2, 2π. 문자 눈금은 `{ v: 2, t: 'a' }`. 곡선이 눈금 글 자리를 지나면 글이 옆으로 비킨다. `grid: true`(정수 자리)·`'ticks'`(눈금 자리)면 옅은 모눈.
- `curves: [{ f, from, to, dash, name, at, side, breaks, said }]` — y = f(x). 상자 밖으로 나가는 곳은 상자 변에서 끊고 값이 튀는 곳(점근선, 가우스 함수 같은 끊긴 곳)도 저절로 끊는다. 구간마다 식이 다른 함수는 `breaks: [1]`로 그 자리를 꼭 끊는다(값이 이어지는 곳은 끊지 않아도 된다).
- `params: [{ x: (t) => …, y: (t) => …, from, to, name, at }]` — 원·타원·쌍곡선(t 는 기본 0~2π, `at`은 이름을 적을 t). 쌍곡선 x = 2/cos t, y = 1.5 tan t 처럼 값이 무한히 커지는 식도 그대로 주면 상자 밖에서 끊긴다.
- `lines: [{ a, b } | { x } | { y } | { p, q }]` — 직선. `dash: true`면 회색 점선(점근선·보조선). x = π/2처럼 수로 적으면 어색한 자리는 `said`로 그림 설명을 준다.
- `segs: [{ p, q, dash }]` 선분, `fill: [{ f, g, from, to }]` 두 곡선 사이(g를 빼면 x축과의 사이)를 칠한다.
- `dots: [{ x, y, open, name, guide, xl, yl, said }]` — `open: true`면 속이 빈 점(극한·연속의 끝점), `guide`면 두 축으로 점선, `xl`·`yl`은 그 발에 적을 글(`'a'`, `'f(a)'`).
- `texts: [{ x, y, t, side }]` 그림 속 글(넓이 S, 점 이름 따위).
- 이름 자리: `side`('ur'·'ul'·'dr'·'dl'·'u'·'d'·'r'·'l')를 주면 그 자리에 둔다. 주지 않으면 선·다른 글에 닿지 않는 자리를 찾아 놓는다(곡선 이름은 `at` — 기본은 오른쪽 끝). 원점 O도 곡선을 피해 자리를 옮긴다.
- 그림 속 글은 HTML 기호를 쓸 수 없다(svg). 이름·눈금은 `svgm` 글로 준다: `'y=f(x)'`, `'y=2^x'`, `'y=log_2 x'`, `'S_1'`, `'y=3 sin x'`(문자는 기울인 글자, sin·log는 세운 글자, `^`·`_`는 첨자).
- 그림 설명(aria-label)에는 눈금 글, 곡선·직선 이름(점선인가), 점의 좌표(소수 둘째 자리)가 저절로 들어간다. 검사가 다시 셈하는 식의 수는 글·그림 설명에 보여야 하므로, 그림에서만 읽는 수는 눈금(`xt`·`yt`)으로 적거나 `say`로 덧붙인다. 좌표를 읽는 것이 문제인 점은 `said`로 좌표를 감춘다.
- **곡선·점 이름이 답을 흘리면 안 된다.** 상수를 묻는 그래프(「y = a sin x의 그래프이다. a의 값은?」)에 `'y=3 sin x'`처럼 답이 든 이름을 붙이지 않는다 — 문제 글의 꼴(`'y=a sin x'`)이나 `'y=f(x)'`로 적고, 그림 설명(aria-label)에도 답이 든 식을 적지 않는다(`said`로 감춘다). 눈금·점 좌표도 묻는 값이면 감춘다.
- 휴대폰 카드 너비는 288px이다. 그림 너비는 280px 안팎으로 두고(기본이 그렇다), 다 짓고 360px 화면 사진으로 눈금 글·이름이 겹치지 않는지 본다.

## 10. 공간 그림 `space(o)`
x축은 왼쪽 아래(앞으로 나오는 쪽, 길이를 0.55배), y축은 오른쪽, z축은 위(`o.u` 한 칸 px — 기본 26, `o.k` x축 비율, `o.ang` x축 방향). 좌표는 [x, y, z]. 함수를 이어 쓴다.
```js
const figure = space().axes({ x: a + 1.5, y: b + 1.2, z: c + 1.2 }, null, { x: a, y: b, z: c })
  .box([0, 0, 0], [a, b, c], ['', 'A', 'B', 'C', 'D', 'E', 'F', 'G'])
  .svg('공간 그림: 원점에 한 꼭짓점이 있는 직육면체 OABC-DEFG. 모서리 OA는 x축, OC는 y축, OD는 z축 위에 있다.');
```
- `axes(len, neg, inside)` — 세 축과 화살촉, x·y·z, O. `inside`: 원점에서 물체 뒤로 숨는 길이 — 그 부분은 긋지 않고 물체의 점선 모서리에 맡긴다(원점에 놓인 직육면체의 세 모서리). 주지 않으면 실선 축이 점선 모서리를 덮는다.
- `box(p, q, 이름 8개)` — 직육면체. 뒤·왼쪽·아래 꼭짓점에 모인 세 모서리는 점선. 이름 차례: 아래 넷(뒤 왼쪽 → 앞 왼쪽 → 앞 오른쪽 → 뒤 오른쪽) → 위 넷(같은 차례). 원점 쪽 이름을 `''`로 두면 axes의 O와 겹치지 않는다.
- `solid({ A: [x, y, z], … }, 'AB BC CA AD BD CD', 'AC')` — 사면체·뿔(셋째 인자의 모서리는 점선, 이름은 가운데에서 먼 쪽에 저절로).
- `seg(p, q, 'dash')`, `dot(p, 이름, 각)`, `name(p, 글, 각)`, `text(p, 글)`, `face(점들, 색)`(칠한 면), `guide(p)`(점의 좌표를 읽는 점선: xy평면에 내린 발과 두 축, z축).
- 숨은 모서리는 보는 쪽에 따라 달라 `box` 말고는 손으로 정한다. 그림 설명(`svg`의 인자)에 모서리 길이·점의 좌표처럼 그림에서 읽어야 하는 것을 적는다.

## 11. 기록 글(학습 기록에 남는 글)
앱은 문항을 태그를 걷은 글로 남긴다. 이 도구의 기호는 이렇게 남는다:

## 12. 화면에서 볼 것
- 쌓은 기호·₅C₂·벡터는 바로 뒤 토씨와 함께 줄이 갈리지 않는다(`app.js`의 `tie`가 `.mb-hs`를 묶는다). 글 속의 「OC = 4」처럼 기호와 수 사이는 `nb(…)`로 묶는다.
- 사이트는 문항 글에 공용 읽기 글꼴(바탕체)을 입힌다. 기호는 저마다 수식 글꼴을 따로 적어 두어 바탕체로 바뀌지 않는다. 새 기호를 단원 파일에서 만들면 공용 읽기 글꼴을 끼운 화면에서도 본다.
- 위첨자 안에 위첨자(`<sup>` 겹치기)를 넣지 않는다(기록 글의 거듭제곱 표시가 깨진다). 분수 지수는 `pw(밑, [p, q])`.
- 그림이 있는 유형은 360px 화면 사진을 찍어 눈금 글·이름·점이 겹치지 않는지 본다(자리 피하기는 어림이라 빈틈없지 않다).
