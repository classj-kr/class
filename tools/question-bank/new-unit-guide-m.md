# 중학교 단원 짓기 — 덧붙임

먼저 `tools/question-bank/fill-guide.md`와 `tools/question-bank/new-unit-guide.md`를 처음부터 끝까지 읽고 그대로 따른다. 중학교 단원은 아래가 더 붙는다.

## 단원 번호와 파일
- 중학교 1·2·3학년은 7·8·9로 적는다. `B.addUnit({ id: '7-1-2', grade: 7, semester: 1, no: 2, title, version: 1, groups })` — id는 글자 그대로 적는다. 화면에는 「중 1학년 1학기」로 나온다(초등은 「초 3학년 1학기」).
- 단원 파일은 번호 차례로 읽히므로 중학교 단원은 초등 단원 뒤에 읽힌다. 그래도 다른 단원이 내보낸 도구(`B.kit.g…`, `B.kit.m712`)에 기대지 않는다. 중학교 단원이 함께 쓰는 도구는 공용 파일 `middle.js`의 `B.kit.mid`에 있다(아래 「공용 도구」). 거기 없는, 그 단원에만 필요한 그림 함수는 단원 파일 안에 적는다. 같은 단원의 b·c 파일이 a 파일의 도구를 쓰려면 `B.kit.m712`처럼 단원 번호를 넣은 이름으로 내보낸다.
- 꼴 목록은 `references/textbooks/수학/_분석/<단원>/기본꼴_N.md`, `심화꼴.md`. 대조표 번호는 ①n·②n(기본꼴_1·2의 n번), 심n.

## 공용 도구 (`middle.js` — `const { Q, tx, V, ex, plane, … } = B.kit.mid;`)
7-1-2 「정수와 유리수」를 지으며 만든 도구를 옮겨 둔 것이다. 쓰는 본보기는 `units/7-1-2a.js`·`7-1-2b.js`·`7-1-2c.js`. **같은 일을 하는 함수를 단원 파일에 다시 짓지 않는다.** 모자라면 단원 파일 안에 덧붙여 짓고 보고에 적는다(공용 파일은 고치지 않는다).
- 유리수 `{ p, q }`(늘 기약분수): `Q(p, q)`, 소수로 적을 수 `dc(십분의 몇)`·`dc2(백분의 몇)`, 셈 `qadd`·`qsub`·`qmul`·`qdiv`·`qneg`·`qabs`·`qpow`·`qcmp`, `isInt`, `fl`(실수 값), `gcd`·`lcm`, `range(lo, hi)`.
- 수를 적는 글: `tx` −3·3, `sx` −3·+3, `px` (−3)·(+3), `mag` 크기만, 토씨를 붙인 `tj(x, '을/를')`·`sj`·`pj`, 정수 뒤 토씨만 `tail(n, '을/를')`, 줄이 바뀌면 안 되는 덩이 `nb(글)`, 그림 설명에 적는 `plain(x)`, 검사 식에 적는 `js(x)`(음수는 `(-3)`, 분수는 `(3/4)`).
- 문자와 식의 글: `V('x')`(수식 글꼴의 기울인 글자), `sup(2)`, 항 `mono(계수, 문자 글)`, 다항식 `poly([[계수, 문자 글], …])`(계수 1 생략, 0인 항 생략, 부호 이어 붙이기 — `poly([[-1, V('x') + sup(2)], [4, V('x')], [-7, '']])` → −x² + 4x − 7), 일차식 `lin(a, b, 문자 글)`. 계수는 수나 유리수.
- 수로 된 식(조각의 배열): 항 `P(x)` (+3)·(−3), `U(x)` 3·−3, `S(x)` 음수만 괄호, `G(식, '(' | '{' | '[')` 묶음, `W(x, n)` 거듭제곱, `WN(x, n)` −3², `MN(항)` 앞에 −, `A(식)` 절댓값. 기호는 `'+'` `'-'` `'*'` `'/'`. 값 `val(식)`, 화면 글 `html(식)`(식 글꼴)·`inl(식)`(풀이 글), 검사 식 `jsx(식)`, 한 단계씩 계산한 줄 `chainOf(식)`, 중간에 분수가 안 나오는가 `intsOnly(식)`.
- 식을 그리기: `ex(글)`(긴 식은 휴대폰 너비에 맞게 글씨를 줄인다), `show(식)`, 이름표를 붙인 여러 줄 `taggedEx([글, …])`, 계산 과정 `proc([{ h, mark }, …])`, 차례로 계산하는 칸 `flow([...])`.
- 답: 값 하나 `ansV(text, 유리수, 'int' | 'frac' | 'dec', { figure, unit, explain, facts })`(부호 단추가 붙는다), 식 하나를 계산하는 문항 `calcQ(식, kind, { rule, explain, text })`, 조건에 맞는 식 뽑기 `pickEx(d, make, kind, ok)`, 검사 근거 `valueFacts(식, { rule })`.
- **답이 일차식인 문항** `linAns(text, a, b, 문자 글, { figure, explain, facts })`: 「[±][ ]x [±][ ]」 두 칸으로 받고, 틀리면 식 그대로(3x − 2) 보인다. a, b는 0이 아닌 정수. `facts.calc: [[계수를 셈하는 식, 0], [상수항을 셈하는 식, 1]]`. 계수가 분수이거나 항이 하나·셋인 답은 고르기로 바꾸거나 `M(…, { shown: 식 글 })`으로 칸을 직접 짠다(`shown`은 틀렸을 때 답 줄에 보일 글).
- **답이 점의 좌표인 문항** `pointAns(text, x, y, { figure, explain, facts })`: 「( [±][ ] , [±][ ] )」 두 칸으로 받는다(정수 좌표). `facts.calc`로 두 칸을 따로 근거 댄다.
- 수 고르기: `nz(d, lo, hi)` 0이 아닌 정수, `pm(d)` ±1, `co(d, q, lo, hi)` q와 서로소인 수, `fr(d, [분모들], 최대 크기)` 정수가 아닌 양의 기약분수, `distinct(유리수들)`.
- 풀이 글: `addTold(x, y)`·`subTold`·`mulTold`·`divTold`·`commonTold(식)`(두 수의 셈을 규칙대로 풀어 적은 글), 참·거짓 문장 고르기 `claimQ(d, text, 옳은 문장들, [[틀린 문장, 바로잡은 말, 함께 싣지 않을 옳은 문장], …], 옳은 것을 묻는가)`.
- 그림
  - `nline(lo, hi, { parts, labels, points: [{ at: 유리수, name }], moves: [{ from, to, label }] })` — 수직선.
  - `plane({ x: [-5, 5], y: [-5, 5], points: [{ x, y, name, side: 'ur' | 'ul' | 'dr' | 'dl', guide }], poly: [[x, y], …], segs: [[x1, y1, x2, y2], …], lines: [{ a, name }], curves: [{ a, name }], ticks: 'all' | 'none' | [수, …], grid, say })` — 좌표평면. `lines`는 정비례 관계 y = ax, `curves`는 반비례 관계 y = a/x 의 그래프. 그림 설명은 점을 「원점에서 오른쪽으로 3칸, 위쪽으로 2칸 간 곳」으로 적는다(좌표를 읽는 문제의 답을 흘리지 않게).
  - `graph({ xname: '시간(분)', yname: '거리(km)', xmax, ymax, xstep, ystep, paths: [{ pts: [[x, y], …], name, smooth }], marks: [[x, y]], plain, w })` — 상황을 나타낸 그래프(꺾은선, `smooth`면 곡선). 보기 그림은 `{ plain: true, w: 132 }`로 작게 그려 고르기 단추에 넣는다.

## 중2에서 더한 공용 도구 (`B.kit.mid`, `B.kit.mgeo`, 엔진 `B.kit.inline`)
- 중학교 2학년 단원은 `grade: 8`이고 화면에는 「중 2학년 1학기」로 나온다.
- **순환소수** `rep('0.', '3')`(0.3 위에 점), `rep('1.2', '45')`(4와 5 위에 점 — 순환마디의 첫 숫자와 끝 숫자). 값은 `repQ('1.2', '45')`(유리수), 소수점 아래 n번째 자리의 숫자는 `repDigit(head, cycle, n)`. 점을 글자(결합 문자)로 찍지 않는다 — 읽기 글꼴에서 자리가 어긋난다.
- **연립방정식** `sys([식 글, 식 글])` — 왼쪽에 중괄호, 식은 위아래로. 문제 글 안에 그대로 넣는다(`연립방정식 ${sys([…])}의 해는?`).
- **식 속에 끼워 넣는 답 칸** `B.kit.inline(text, template, inputs, { shown, explain, facts, figure })`: `template`의 `{0}`, `{1}`, … 자리에 `inputs`의 칸이 그 번호대로 들어간다. 지수 칸은 `x<sup>{1}</sup>`처럼 적는다. 칸은 `{ answer, signed }`(수) 또는 `{ rel: true, answer: '<' | '<=' | '>' | '>=' }`(부등호를 고르는 칸). 틀렸을 때 보일 답 글 `shown`을 꼭 준다. 아래 셋은 이것으로 지은 것이다.
  - `ineqAns(text, '>=', -3, V('x'), o)` — 「x [부등호] [±][ ]」로 받는다(경계는 정수). 경계가 분수이면 고르기로 낸다.
  - `monoAns(text, 계수, [['x', 3], ['y', 2]], o)` — 「[±][ ] x^[ ] y^[ ]」. 계수는 0이 아닌 정수, 지수는 자연수. 문제 글 끝에 「(단, 지수가 1이면 1을 적는다.)」가 저절로 붙는다.
  - `polyAns(text, [[3, V('x')], [-2, V('y')], [5, '']], o)` — 항마다 「[±][ ] 문자」. 이차식은 문자 글에 `V('x') + sup(2)`.
  - **칸의 모양이 답을 흘리면 안 된다.** 문자가 약분되어 사라지거나(답 −6y³에 x 칸을 주면 x가 있다고 알려 준다) 항의 수가 달라지는 꼴, 계수가 분수인 꼴은 칸으로 받지 않고 고르기(C)로 낸다. 한 유형 안에서는 차례·씨앗이 바뀌어도 칸의 모양이 같아야 한다.
  - 근거: 수 칸은 `facts.calc: [[식, 칸 번호], …]`로 칸마다 적는다. 부등호 칸은 검사가 다시 셈하지 못하므로 풀이 글(`explain`)에 방향이 바뀌는 까닭을 적는다.
- **수직선 위의 해** `nline(lo, hi, { rays: [{ at: -2, dir: 1, closed: true }] })` — 경계에 ●(포함)·○(포함하지 않음), 그쪽으로 굵은 선과 화살표.
- **좌표평면의 직선** `plane({ lines: [{ a: 2, b: -3, name: '㉠' }, { x: 3, dash: true }, { a: 0, b: 2 }] })` — y = ax + b(`b`를 빼면 원점을 지난다), `{ x: p }`는 y축에 평행한 직선 x = p, `dash: true`는 점선. 원점 이름 O의 자리는 `oSide: 'l' | 'r'`로 옮긴다. 기울기·절편은 `Q(…)`(유리수)로 줄 수 있다. 직선의 이름표가 서로 닿거나 눈금 수에 걸리지 않게 수를 고르고, 그림을 그려 보고 고친다.
- **직선·반직선·선분의 기호** `LN('AB')`·`RY('AB')`·`SG('AB')` — 글자 위에 ↔·→·―를 얹는다. `text-decoration: overline`은 쓰지 않는다(읽기 글꼴에서 줄이 윗줄 글자 밑에 붙는다).
  - 기호 바로 뒤의 토씨가 다음 줄 머리로 혼자 떨어지지 않게 묶는 일(「EF」 / 「의 길이는?」)은 화면(app.js의 `tie`)이 한다. 단원 파일에서 따로 묶지 않는다.
- **분수 꼴의 식** 엔진의 `frac(분자 글, 분모 글)`은 글을 그대로 받으므로 `frac('6' + V('x') + sup(2), '2' + V('x'))`처럼 쓴다.
- **도형 그림 판** `B.kit.mgeo` — 7-2-3 「평면도형의 성질」에서 지은 판을 옮겨 둔 것이다. 쓰는 본보기는 `units/7-2-3a.js`(다각형)·`7-2-3b.js`(원)·`7-2-3c.js`. 삼각형·사각형·원·닮음·피타고라스 그림은 이 판으로 짓는다(판을 새로 짓지 않는다).
  - `Board()` — 화면 좌표에 그리고 그린 것의 크기에 맞춰 그림 틀을 잡는다. 그리기 `seg`·`poly`·`disk`·`shape`·`fan`·`arc`·`dot`, 표시 `tick`(같은 길이)·`arrow`(평행)·`corner`(직각)·`sym`(같은 각 ●·×), 글 `text`·`name`(점 이름)·`nameFree`(선이 성긴 쪽에 이름)·`beside`(선분 옆 글)·`dim`(치수선)·`arcDim`·`angle`(각의 크기 — 글 상자가 두 변에서 떨어질 때까지 밀어 놓는다), `clash`(글끼리 겹치는가 — `d.until`에서 수를 다시 고르는 데 쓴다), `svg(그림 설명)`.
  - 짓기 `polyOf(내각들, 크기)`, `triOf(a, b, c, 크기)`, `regPts(n, s)`·`regOn(p, q, n)`(정다각형), `vnames(pts)`, 셈 `at(c, r, 각)`·`dirOf`·`dist`·`mid`·`meet`(두 직선의 교점)·`awayFrom`.
  - 모자라는 것(같은 각 표시의 다른 꼴, 넓이 칠하기 등)은 단원 파일 안에서 판의 함수를 써서 덧붙이고 보고에 적는다.
- **단위** 수와 단위 기호 사이는 띄어 쓴다(`3 cm`). 줄 끝에서 수와 단위가 갈리지 않게 하는 일과 `cm²`·`cm³`의 작은 숫자를 위첨자로 바꾸는 일은 화면이 한다(단원 파일은 `cm²` 글자를 그대로 써도 된다).

## 중3에서 더한 공용 도구 (`B.kit.mid`, 엔진 `inline`)
- 중학교 3학년 단원은 `grade: 9`이고 화면에는 「중 3학년 1학기」로 나온다. 중3 자료는 미래엔 2015(황선욱) 한 종뿐이라, 2022 교육과정 원문(`references/moe/2022-revised-curriculum/extracted/08-mathematics.txt` 1416줄·1506줄 부근)과 맞지 않는 것을 거른다.
- **근호** `rt(inner)` — `rt(12)` → √12, `rt(V('a') + ' + 1')`. √ 기호는 안의 글 높이에 맞춘 작은 그림이고 안의 글 위에 줄이 그어진다. 글로 옮기면 「√12」(보이지 않는 √ 글자가 들어 있다). 안에 답 칸 자리(`rt('{1}')`)를 넣을 수 있다. **그림(svg) 속 글에는 쓸 수 없다** — 그림에 근호가 든 길이를 적어야 하면 문제 글로 알려 주거나, 단원 파일 안에서 svg 글자 「√」와 그 위의 가는 선으로 그리고 figshow로 겹침을 본다.
  - 근호 바로 뒤의 토씨는 화면(app.js `tie`)이 근호와 한 덩어리로 묶는다. 토씨는 근호 안 수의 끝소리로 정한다(√2는, √3은 — `josa(n, '은/는')`처럼 근호 안의 수로 구한다).
- `sqParts(n)` → `[a, b]`(n = a² × b, b는 제곱인 수를 인수로 갖지 않는다). `radText(coef, n)` → 「−2√3」「√5」 글(n = 1이면 수만).
- **답이 a√b** `radAns(text, a, b, o)` — 「[±][ ]√[ ]」(a = 1이면 「√[ ]」 한 칸). a = −1(답 −√b)은 받지 않는다 — 고르기나 다른 꼴로. b는 2 이상이고 제곱인 수를 인수로 갖지 않는 자연수. 근거는 `facts.calc: [[a를 셈하는 식, 0], [b를 셈하는 식, 1]]`.
- 근호가 든 다른 답은 엔진 `inline`으로 짓는다(틀렸을 때 보일 답 글 `shown`을 꼭 준다):
  - a + b√c: 틀 `'{0} {1}' + rt('{2}')`, 칸 `[{ answer: a, signed: true }, { answer: b, signed: true }, { answer: c }]` — 둘째 칸의 부호 단추가 더하기·빼기 기호 노릇을 한다(`polyAns`와 같은 꼴).
  - 이차방정식의 해 x = p ± √q: 틀 `` `${X} = {0} ± ${rt('{1}')}` ``. 분수 꼴 x = (p ± √q)/r 는 엔진 `frac('{0} ± ' + rt('{1}'), '{2}')`을 틀에 넣는다(360px에서 넘치지 않는지 꼭 본다). 두 해가 유리수이면 「x = [±][ ] 또는 x = [±][ ]」 두 칸에 `unordered: true`.
- **인수분해 답** 괄호 하나를 `grp(…)`로 묶는다(좁은 화면에서 괄호 가운데서 줄이 갈리지 않는다).
  - (x + a)(x + b): 틀 `` grp(`(${X} {0})`) + grp(`(${X} {1})`) ``, 두 칸 모두 `signed: true`, `unordered: true`.
  - (ax + b)(cx + d): 칸 넷, `blocks: [[0, 1], [2, 3]]`(엔진: 괄호째 차례를 바꾸어 적어도 맞다. 묶음 안의 차례와 묶음 밖의 칸은 그대로 견준다). 앞에 공통인수가 있으면 그 칸은 묶음 밖에 둔다(`blocks: [[1, 2], [3, 4]]`).
  - (2x − 1)(3x + 2)를 (−2x + 1)(−3x − 2)로도 적을 수 있듯 답이 하나로 정해지지 않으면, 「x의 계수는 자연수」처럼 정하는 말을 문제 글에 붙이거나 고르기로 낸다.
- **포물선** `plane({ x: [lo, hi], y: [lo, hi], parabolas: [{ a, p, q, name, dash }] })` — 이차함수 y = a(x − p)² + q 의 그래프. 상자 안에 드는 부분만 그리고, 그림 설명에 꼭짓점·볼록한 쪽·지나는 모눈 점을 적는다. 꼭짓점이나 읽을 점을 보이려면 `points`(guide 점선)를 함께 쓴다. 눈금이 모자라면 상자를 키우기보다 `ticks`로 적을 수를 고른다(상자가 크면 그림이 세로로 길어진다).
- 고르기 보기에 근호가 있으면 화면의 답 줄도 근호 그대로 보인다.

## 그림은 겹침까지 본다
- 넘침 검사는 그림 속 글이 선이나 다른 글과 겹치는 것을 잡지 못한다. 그림이 있는 단원은 다 짓고 나서 사본을 가리켜 겹침 후보를 뽑고, 걸린 꼴은 그려서 눈으로 본다.
  - `UNIT=8-2-1 MATH_BANK_DIR=<사본 math-bank 폴더> node tools/question-bank/figoverlap.cjs 12` — 씨앗 12개씩. 색만 칠한 도형의 테두리도 선으로 세므로 헛짚음이 있다.
  - `UNIT=8-2-1 MATH_BANK_DIR=<사본> SEEDS=3 node tools/question-bank/figshow.cjs <제 작업 폴더의 png> <꼴 이름 앞부분> …` — 꼴 몇 개를 씨앗을 달리해 한 장에 그린다. png는 보고 나서 지운다.
- 좁은 자리에 글을 넣어야 하면 그림 밖에 적고 가는 선으로 가리키거나, 글자 둘레에 바탕색 테두리(`paint-order: stroke`)를 둘러 밑의 선이 글자를 긋지 않게 한다(`units/7-2-4a.js`의 `on-face`).

## 실력에 두는 문항의 잣대 (중1을 받으며 굳힌 것)
- 실력은 ① 문제의 그림·상황에 함정이 있어 뜻을 정확히 대야 풀리는 것, ② 세 단계 넘게 이어 생각해야 풀리는 것뿐이다. 「어려운 문제만 실력으로, 웬만한 것은 다 기본으로」가 원칙이다.
- **기본에 두는 것**: 두 단계를 잇는 것(다각형을 찾아 → 다른 것 구하기, 한 점으로 a를 구해 → 다른 점, 반지름을 구해 → 넓이), 거꾸로 한 번 구하는 것(부피 → 높이), 교과서가 사실로 가르치는 문장의 참·거짓, 수집본 기본 문서에 여러 번 나오는 꼴, 기본에서 하는 일을 고르기로만 바꾼 것, 그림에서 답이 한눈에 보이는 것.
- 꼴 목록에 없는 꼴을 지어내지 않는다. 과제 글이 든 보기를 꼴 목록에서 찾지 못하면 싣지 않고 보고에 적는다.

## 일할 때 지킬 것
- 제 작업 폴더(과제 글이 정해 준 사본 폴더와 그 옆의 제 폴더) 밖의 파일을 만들거나 고치거나 지우지 않는다. 임시 폴더(scratchpad)의 다른 폴더·다른 파일은 남의 것이다.
- 프로세스를 죽이는 명령(`taskkill`, `pkill` 등)을 쓰지 않는다. 띄운 브라우저는 스크립트 안에서 닫는다.

## 답 — 부호가 있는 수
- 수 답 칸 앞에 부호 단추(+/−)를 붙일 수 있다. 휴대폰 숫자 자판에는 −가 없어서 단추를 눌러 부호를 바꾼다.
  - 정수: `N(text, -5, { signed: true, … })`
  - 소수: `D(text, -1.5, { signed: true, … })`
  - 분수: `F(text, 분자, 분모, { negative: true, … })`. 분자·분모·자연수 칸의 수는 늘 양수로 적고, 음수이면 `negative: true`, 양수이지만 부호 단추를 보여야 하면 `signed: true`. 대분수는 `whole`을 준다. 기약분수가 아닌 답도 받으려면 `anyForm: true`(문제에 「기약분수로」가 없을 때).
  - 여러 칸: `M(text, [{ answer: -2, signed: true, label: '㉠' }, { answer: 3, signed: true, label: '㉡' }], …)`
- **부호가 있는 수를 다루는 단원에서는 수 답 칸에 모두 부호 단추를 단다.** 단추가 있고 없음이 「답이 음수다」를 알려 주면 안 된다. 개수·횟수처럼 음수일 수 없는 답(「모두 몇 개인가」)만 단추 없이 받는다.
- 양수 답은 +를 고르든 그대로 두든 맞는다. 0은 부호가 없다.
- 답이 식·부등식인 꼴은 끼워 넣는 답 칸(`linAns`·`polyAns`·`monoAns`·`ineqAns`)으로 받거나 고르기(C)·수 빈칸(계수, ㉠·㉡)으로 바꾼다. 답이 문장인 꼴(「계산 과정을 쓰시오」)은 고르기로 바꾼다. 「모두 구하시오」로 답이 여럿인 꼴은 「모두 고른 것」 고르기, 개수, 가장 큰(작은) 수로 바꾼다. 바꿀 수 없으면 싣지 않는다.

## 검사 — 답을 다시 셈하는 근거
- 답이 하나인 계산 문항(정수·소수·분수)은 `facts: { value: '식' }`으로 적는다. 검사가 식을 따로 셈해 답의 값(분수는 부호와 대분수까지 합친 값)과 맞춰 본다.
  - 식은 자바스크립트 셈 글이다: 음수는 괄호에 넣고 `(-3)+(+5)`, 분수는 `(3/4)`, 대분수는 `(1+2/3)`, 거듭제곱은 `(-2)**3`, 절댓값은 미리 풀어 적는다.
  - 식에 든 수는 문제 글(그림 설명 포함)에 숫자로 보여야 한다. 글에 없는 수는 `facts.unseen`에 밝힌다.
  - `-2**2`는 자바스크립트에서 오류다. 괄호 없는 거듭제곱의 음수는 `-(2**2)`로 적는다.
- 답이 여러 칸이면 칸마다 `calc: [[식, 칸 번호], …]`를 쓴다(부호가 있는 칸은 0 이하도 된다). 고르기는 `truth`·`choose` 등 있는 근거를 쓴다.
- 검사는 부호를 뒤집은 답이 틀리는지도 본다. 분수 답이 음수인데 부호 단추가 없으면 떨어진다.

## 글과 식의 표기
- 음수의 빼기표는 `−`(U+2212)로 적는다. 화면에 보이는 글에 `-`(하이픈)을 음수 부호로 쓰지 않는다. 수를 글로 바꾸는 일은 공용 도구를 거친다(`tx(Q(-3))` → `−3`, `px(Q(-3))` → `(−3)`, `px(Q(3))` → `(+3)`, `sx(Q(3))` → `+3`).
- 토씨는 수의 크기에 맞춘다: `josa(Math.abs(n), '을/를')`로 토씨만 구해 붙인다(음수를 그대로 넘기지 않는다). 분수 뒤 토씨는 분모가 아니라 읽는 끝소리(「사분의 삼」의 「삼」 = 분자)에 맞춘다.
- 곱셈은 `×`, 나눗셈은 `÷`, 분수는 엔진 `frac(k, n)`, 거듭제곱은 `<sup>`, 절댓값은 `|−3|`, 부등호는 `&lt;` `&gt;` `≤` `≥`, 수를 나타내는 문자는 `<i class="mb-var">a</i>`(수식 글꼴의 기울인 글자로 나온다. 사이트 공용 읽기 글꼴에는 기울인 글자가 없어 `<i>`나 `font-style`만으로는 실제 사이트에서 곧게 나온다). 점 이름(A, B)과 단위(cm)는 곧은 글자 그대로 둔다.
- 온도의 단위는 초등 단원처럼 `°C`로 적고 수와 띄어 쓴다(`−7 °C`, 답 칸 `unit: '°C'`). `℃` 한 글자는 쓰지 않는다.
- 문체는 초등 단원과 같다(「~을 구하시오.」「~은?」「~이다.」, 「~세요/~습니다」 금지). 풀이는 계산의 차례를 한 줄씩 보이되 건조하게 쓴다.

## 교육과정의 금(중학교 1~3학년, `references/moe/2022-revised-curriculum/extracted/08-mathematics.txt` 1396줄부터)

## 실력
- 잣대는 fill-guide와 같다: ① 상황·그림의 장치 때문에 배운 뜻을 정확히 대야 풀리는 문제 ② 두 번 넘게 생각해야 풀리는 문제. 기본에서 하는 일을 고르기로 바꾼 것, 수만 키운 계산은 실력이 아니다.
- 수집본 기본 문서에 나오고 기본에서 하는 일을 다시 묻는 꼴은 고르기·견주기로 바뀌어 있어도 기본 묶음에 싣는다(거듭제곱 값 견주기, 역수·절댓값에 대한 설명 가리기, 계산 과정에서 틀린 줄 찾기, 한쪽 끝만 있는 범위의 정수 세기, 변화량을 이어 더하는 문장제 — 7-1-2에서 실력으로 왔다가 기본으로 내린 것들).
- 기본과 실력에 같은 일을 묻는 꼴을 따로 싣지 않는다(「부호가 정해진 두 문자의 식 가운데 항상 음수인 것」과 「항상 옳은 것」).
- 조건 여럿을 풀어 수를 찾는 것, 퍼즐(마방진), 요령을 알아야 하는 긴 합(부분분수로 지워 가기, 1부터 100까지), 뒤 학년 내용(지수법칙, 방정식 풀이)은 싣지 않는다.
