# 중학교 단원 짓기 — 덧붙임

먼저 `tools/question-bank/fill-guide.md`와 `tools/question-bank/new-unit-guide.md`를 처음부터 끝까지 읽고 그대로 따른다. 중학교 단원은 아래가 더 붙는다.

## 단원 번호와 파일
- 중학교 1·2·3학년은 7·8·9로 적는다. `B.addUnit({ id: '7-1-2', grade: 7, semester: 1, no: 2, title, version: 1, groups })` — id는 글자 그대로 적는다. 화면에는 「중 1학년 1학기」로 나온다(초등은 「초 3학년 1학기」).
- 단원 파일은 번호 차례로 읽히므로 중학교 단원은 초등 단원 뒤에 읽힌다. 그래도 다른 단원이 내보낸 도구(`B.kit.g…`, `B.kit.m712`)에 기대지 않는다. 중학교 단원이 함께 쓰는 도구는 공용 파일 `middle.js`의 `B.kit.mid`에 있다(아래 「공용 도구」). 거기 없는, 그 단원에만 필요한 그림 함수는 단원 파일 안에 적는다. 같은 단원의 b·c 파일이 a 파일의 도구를 쓰려면 `B.kit.m712`처럼 단원 번호를 넣은 이름으로 내보낸다.
- 꼴 목록은 `references/textbooks/수학/_분석/<단원>/기본꼴_N.md`, `심화꼴.md`. 대조표 번호는 ①n·②n(기본꼴_1·2의 n번), 심n.

## 공용 도구 (`middle.js` — `const { Q, tx, V, ex, plane, … } = B.kit.mid;`)
7-1-2 「정수와 유리수」를 지으며 만든 도구를 옮겨 둔 것이다. 쓰는 본보기는 `units/7-1-2a.js`·`7-1-2b.js`·`7-1-2c.js`. **같은 일을 하는 함수를 단원 파일에 다시 짓지 않는다.** 모자라면 단원 파일 안에 덧붙여 짓고 보고에 적는다(공용 파일은 고치지 않는다).
- 유리수 `{ p, q }`(늘 기약분수): `Q(p, q)`, 소수로 적을 수 `dc(십분의 몇)`·`dc2(백분의 몇)`, 셈 `qadd`·`qsub`·`qmul`·`qdiv`·`qneg`·`qabs`·`qpow`·`qcmp`, `isInt`, `fl`(실수 값), `gcd`·`lcm`, `range(lo, hi)`.
- 수를 적는 글: `tx` −3·3, `sx` −3·+3, `px` (−3)·(+3), `mag` 크기만, 토씨를 붙인 `tj(x, '을/를')`·`sj`·`pj`, 정수 뒤 토씨만 `tail(n, '을/를')`, 줄이 바뀌면 안 되는 덩이 `nb(글)`, 그림 설명에 적는 `plain(x)`, 검사 식에 적는 `js(x)`(음수는 `(-3)`, 분수는 `(3/4)`).
- 문자와 식의 글: `V('x')`(수식 글꼴의 기울인 글자), `sup(2)`, 항 `mono(계수, 문자 글)`, 다항식 `poly([[계수, 문자 글], …])`(계수 1 생략, 0인 항 생략, 부호 이어 붙이기 — `poly([[-1, V('x') + sup(2)], [4, V('x')], [-7, '']])` → −x² + 4x − 7), 일차식 `lin(a, b, 문자 글)`. 계수는 수나 유리수.
- 수로 된 식(조각의 배열): 항 `P(x)` (+3)·(−3), `U(x)` 3·−3, `S(x)` 음수만 괄호, `G(식, '(' | '{' | '[')` 묶음, `W(x, n)` 거듭제곱, `WN(x, n)` −3², `MN(항)` 앞에 −, `A(식)` 절댓값. 기호는 `'+'` `'-'` `'*'` `'/'`. 값 `val(식)`, 화면 글 `html(식)`(식 글꼴)·`inl(식)`(풀이 글), 검사 식 `jsx(식)`, 한 단계씩 계산한 줄 `chainOf(식)`, 중간에 분수가 안 나오는가 `intsOnly(식)`.
- 식을 그리기: `ex(글)`(긴 식은 휴대폰 너비에 맞게 글씨를 줄인다), `show(식)`, 이름표를 붙인 여러 줄 `taggedEx([글, …])`, 계산 과정 `proc([{ h, mark }, …])`, 차례로 계산하는 칸 `flow([...])`.
- 답: 값 하나 `ansV(text, 유리수, 'int' | 'frac' | 'dec', { figure, unit, explain, facts })`(부호 단추가 붙는다), 식 하나를 계산하는 문항 `calcQ(식, kind, { rule, explain, text })`, 조건에 맞는 식 뽑기 `pickEx(d, make, kind, ok)`, 검사 근거 `valueFacts(식, { rule })`.
- **답이 일차식인 문항** `linAns(text, a, b, 문자 글, { figure, explain, facts })`: 「[±][ ]x [±][ ]」 두 칸으로 받고, 틀리면 식 그대로(3x − 2) 보인다. a, b는 0이 아닌 정수. `facts.calc: [[계수를 셈하는 식, 0], [상수항을 셈하는 식, 1]]`. 계수가 분수이거나 항이 하나·셋인 답은 고르기로 바꾸거나 `M(…, { shown: 식 글 })`으로 칸을 직접 짠다(`shown`은 틀렸을 때 답 줄에 보일 글).
- **답이 점의 좌표인 문항** `pointAns(text, x, y, { figure, explain, facts })`: 「( [±][ ] , [±][ ] )」 두 칸으로 받는다(정수 좌표). `facts.calc`로 두 칸을 따로 근거 댄다.
- 수 고르기: `nz(d, lo, hi)` 0이 아닌 정수, `pm(d)` ±1, `co(d, q, lo, hi)` q와 서로소인 수, `fr(d, [분모들], 최대 크기)` 정수가 아닌 양의 기약분수, `distinct(유리수들)`.
- 풀이 글: `addTold(x, y)`·`subTold`·`mulTold`·`divTold`·`commonTold(식)`(두 수의 셈을 규칙대로 풀어 적은 글), 참·거짓 문장 고르기 `claimQ(d, text, 옳은 문장들, [[틀린 문장, 바로잡은 말, 함께 싣지 않을 옳은 문장], …], 옳은 것을 묻는가)`.
- 그림
  - `nline(lo, hi, { parts, labels, points: [{ at: 유리수, name }], moves: [{ from, to, label }] })` — 수직선.
  - `plane({ x: [-5, 5], y: [-5, 5], points: [{ x, y, name, side: 'ur' | 'ul' | 'dr' | 'dl', guide }], poly: [[x, y], …], segs: [[x1, y1, x2, y2], …], lines: [{ a, name }], curves: [{ a, name }], ticks: 'all' | 'none' | [수, …], grid, say })` — 좌표평면. `lines`는 정비례 관계 y = ax, `curves`는 반비례 관계 y = a/x 의 그래프. 그림 설명은 점을 「원점에서 오른쪽으로 3칸, 위쪽으로 2칸 간 곳」으로 적는다(좌표를 읽는 문제의 답을 흘리지 않게).
  - `graph({ xname: '시간(분)', yname: '거리(km)', xmax, ymax, xstep, ystep, paths: [{ pts: [[x, y], …], name, smooth }], marks: [[x, y]], plain, w })` — 상황을 나타낸 그래프(꺾은선, `smooth`면 곡선). 보기 그림은 `{ plain: true, w: 132 }`로 작게 그려 고르기 단추에 넣는다.

## 답 — 부호가 있는 수
- 수 답 칸 앞에 부호 단추(+/−)를 붙일 수 있다. 휴대폰 숫자 자판에는 −가 없어서 단추를 눌러 부호를 바꾼다.
  - 정수: `N(text, -5, { signed: true, … })`
  - 소수: `D(text, -1.5, { signed: true, … })`
  - 분수: `F(text, 분자, 분모, { negative: true, … })`. 분자·분모·자연수 칸의 수는 늘 양수로 적고, 음수이면 `negative: true`, 양수이지만 부호 단추를 보여야 하면 `signed: true`. 대분수는 `whole`을 준다. 기약분수가 아닌 답도 받으려면 `anyForm: true`(문제에 「기약분수로」가 없을 때).
  - 여러 칸: `M(text, [{ answer: -2, signed: true, label: '㉠' }, { answer: 3, signed: true, label: '㉡' }], …)`
- **부호가 있는 수를 다루는 단원에서는 수 답 칸에 모두 부호 단추를 단다.** 단추가 있고 없음이 「답이 음수다」를 알려 주면 안 된다. 개수·횟수처럼 음수일 수 없는 답(「모두 몇 개인가」)만 단추 없이 받는다.
- 양수 답은 +를 고르든 그대로 두든 맞는다. 0은 부호가 없다.
- 답이 식·부등식·문장인 꼴(「부등호를 사용하여 나타내시오」「계산 과정을 쓰시오」)은 고르기(C)나 수 빈칸(계수, ㉠·㉡)으로 바꾼다. 「모두 구하시오」로 답이 여럿인 꼴은 「모두 고른 것」 고르기, 개수, 가장 큰(작은) 수로 바꾼다. 바꿀 수 없으면 싣지 않는다.

## 검사 — 답을 다시 셈하는 근거
- 답이 하나인 계산 문항(정수·소수·분수)은 `facts: { value: '식' }`으로 적는다. 검사가 식을 따로 셈해 답의 값(분수는 부호와 대분수까지 합친 값)과 맞춰 본다.
  - 식은 자바스크립트 셈 글이다: 음수는 괄호에 넣고 `(-3)+(+5)`, 분수는 `(3/4)`, 대분수는 `(1+2/3)`, 거듭제곱은 `(-2)**3`, 절댓값은 미리 풀어 적는다.
  - 식에 든 수는 문제 글(그림 설명 포함)에 숫자로 보여야 한다. 글에 없는 수는 `facts.unseen`에 밝힌다.
  - `-2**2`는 자바스크립트에서 오류다. 괄호 없는 거듭제곱의 음수는 `-(2**2)`로 적는다.
- 답이 여러 칸이면 칸마다 `calc: [[식, 칸 번호], …]`를 쓴다(부호가 있는 칸은 0 이하도 된다). 고르기는 `truth`·`choose` 등 있는 근거를 쓴다.
- 검사는 부호를 뒤집은 답이 틀리는지도 본다. 분수 답이 음수인데 부호 단추가 없으면 떨어진다.

## 글과 식의 표기
- 음수의 빼기표는 `−`(U+2212)로 적는다. 화면에 보이는 글에 `-`(하이픈)을 음수 부호로 쓰지 않는다. 수를 글로 바꾸는 일은 공용 도구를 거친다(`tx(Q(-3))` → `−3`, `px(Q(-3))` → `(−3)`, `px(Q(3))` → `(+3)`, `sx(Q(3))` → `+3`).
- 토씨는 수의 크기에 맞춘다: `josa(Math.abs(n), '을/를')`로 토씨만 구해 붙인다(음수를 그대로 넘기지 않는다). 분수 뒤 토씨는 분모가 아니라 읽는 끝소리(「사분의 삼」의 「삼」 = 분자)에 맞춘다.
- 곱셈은 `×`, 나눗셈은 `÷`, 분수는 엔진 `frac(k, n)`, 거듭제곱은 `<sup>`, 절댓값은 `|−3|`, 부등호는 `&lt;` `&gt;` `≤` `≥`, 수를 나타내는 문자는 `<i class="mb-var">a</i>`(수식 글꼴의 기울인 글자로 나온다. 사이트 공용 읽기 글꼴에는 기울인 글자가 없어 `<i>`나 `font-style`만으로는 실제 사이트에서 곧게 나온다). 점 이름(A, B)과 단위(cm)는 곧은 글자 그대로 둔다.
- 온도의 단위는 초등 단원처럼 `°C`로 적고 수와 띄어 쓴다(`−7 °C`, 답 칸 `unit: '°C'`). `℃` 한 글자는 쓰지 않는다.
- 문체는 초등 단원과 같다(「~을 구하시오.」「~은?」「~이다.」, 「~세요/~습니다」 금지). 풀이는 계산의 차례를 한 줄씩 보이되 건조하게 쓴다.

## 교육과정의 금(중학교 1~3학년, `references/moe/2022-revised-curriculum/extracted/08-mathematics.txt` 1396줄부터)
- 그 단원의 성취기준·해설·고려 사항을 원문에서 직접 읽는다. 금 문장은 적힌 만큼만 읽는다(「A와 같이 간단한 경우는 다루고 B와 같이 복잡한 경우는 다루지 않는다」에서 막힌 것은 B의 종류뿐이다).
- 수집본 기본 문서에 여러 번 나오는 꼴을 금으로 빼려 할 때는 원문의 낱말이 정말 그것을 가리키는지 다시 본다.

## 실력
- 잣대는 fill-guide와 같다: ① 상황·그림의 장치 때문에 배운 뜻을 정확히 대야 풀리는 문제 ② 두 번 넘게 생각해야 풀리는 문제. 기본에서 하는 일을 고르기로 바꾼 것, 수만 키운 계산은 실력이 아니다.
- 수집본 기본 문서에 나오고 기본에서 하는 일을 다시 묻는 꼴은 고르기·견주기로 바뀌어 있어도 기본 묶음에 싣는다(거듭제곱 값 견주기, 역수·절댓값에 대한 설명 가리기, 계산 과정에서 틀린 줄 찾기, 한쪽 끝만 있는 범위의 정수 세기, 변화량을 이어 더하는 문장제 — 7-1-2에서 실력으로 왔다가 기본으로 내린 것들).
- 기본과 실력에 같은 일을 묻는 꼴을 따로 싣지 않는다(「부호가 정해진 두 문자의 식 가운데 항상 음수인 것」과 「항상 옳은 것」).
- 조건 여럿을 풀어 수를 찾는 것, 퍼즐(마방진), 요령을 알아야 하는 긴 합(부분분수로 지워 가기, 1부터 100까지), 뒤 학년 내용(지수법칙, 방정식 풀이)은 싣지 않는다.

## 그림
- 수직선은 공용 도구 `nline`(음수 쪽까지), 좌표평면은 `plane`, 두 양 사이의 관계 그래프는 `graph`를 쓴다. 새 그림을 지을 때는 눈금 숫자를 `−3`처럼 빼기표로 적고, 그림 설명 `aria-label`에 그림에서 읽어야 하는 것을 말로 적는다.
- 단원 파일 안에 만든 그림 함수는 `figure_preview.cjs`로 그려 볼 수 없다. 화면 검사(`node tests/math-bank-browser.cjs --shots`)의 사진으로 본다.
- 휴대폰 너비(360px)를 넘지 않게 하고, svg·표는 너비 60px·높이 20px 아래로 내려가지 않게 한다. 글줄 속 작은 아이콘은 `class="mb-inline"`.
