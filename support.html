문의·권리 요청

처리 절차

1. 로그인 또는 학교 연락 확인
2. 요청 접수
3. 학생·법정대리인 관계 확인
4. 처리 결과 확인

학생은 보호자 또는 담임교사와 함께 요청해도 됩니다. 확인 전에는 선택 정보 공개를 켜지 않습니다.

새 요청

로그인 상태를 확인하고 있습니다.

학생 Google 로그인이 “관리자가 차단함”으로 막힌다면 학교 Google Workspace 설정이 필요합니다. 학교 도입 안내를 학교 관리자에게 전달해 주세요.

내 요청 내역

로그인하면 최근 요청과 처리 상태가 표시됩니다.

법정대리인 요청

로그인한 학생이나 교사는 요청 종류에서 ‘법정대리인 동의 확인·철회’를 선택할 수 있습니다. 로그인하기 어려운 법정대리인은 학교에서 사용하는 기존 연락 수단으로 담임교사에게 요청해 주세요. 학교가 학생과의 관계 및 요청자 본인을 확인한 뒤 서비스 담당자가 처리 상태를 기록합니다.
