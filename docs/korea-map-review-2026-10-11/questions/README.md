# 고등 역사 지도 문항 개편 검토

검토일: 2026-10-11. 실행 환경: 로컬 `127.0.0.1:8876`. 운영 사이트 배포는 이 검토에 포함하지 않았다.

## 변경 범위

- 고등 역사 37개 장면의 74문항을 `history-map-questions.js`로 교체했다. 초·중 문항은 유지했다.
- 원본 출판사 문항의 전사가 아니라 보관된 교과서의 장소·사건·정책 및 평가 유형을 참고한 재구성 문항이다.
- 5지선다, 정답, 해설, 문제별 지도 좌표를 포함한다. 표시 지점은 기존 학습 지도의 좌표를 사용한다.
- 기존 문항 ID는 유지하고 revision을 2로 올렸다. 첫 응답 정오와 선택지의 고정 ID를 구분하는 기존 기록 이벤트를 유지했다.
- 문제 옆에 해당 지점과 경로를 표시한다. 다음 문제에서 지도도 교체한다. 좁은 화면에서는 지도 위·문항 아래로 배치하고 배경 페이지 스크롤을 막는다.
- 오답에는 재시도 안내만 표시하고 정답·해설을 공개하지 않는다. 정답을 선택한 뒤 해설을 표시하며, 결과는 첫 응답 기준이다.

## 검증 결과

`node --test tests/history-map-questions.test.cjs tests/model-scope-history.test.cjs tests/objective-school-practice.test.cjs tests/space-school-practice.test.cjs`: 13개 통과.

- 고등 74문항: ID 중복 없음, revision 2, 선택지 5개 중복 없음, 정답 인덱스 유효, 지도 좌표는 기존 지점과 일치, 범위 안에 포함, 문항의 표지 참조가 지도에 존재함.
- 발해 교통로 2개와 4개 지점, 천도 문제의 정답 연결을 검사했다.
- 기존 초·중과 과학·우주 문항 소비 코드의 데이터 검사도 통과했다.
- 관련 JS 구문 검사와 변경 파일 공백 오류 검사 통과.

실제 브라우저:

- 발해: 오답 선택 시 정답 미노출, 재시도 후 해설 표시, 다음 문제에서 지도·지점 교체, 첫 응답 기준 2문제 중 1개 정답 결과 확인.
- 병자호란: 인접한 지점 표지의 겹침 회피와 연결선 확인.
- 한양: 북쪽 표시와 경복궁·종묘·사직의 상대 위치 확인.
- 1280×720: 지도와 다섯 보기를 함께 확인. 콘솔 오류 없음.
- 390×844: 지도와 문항 수직 배치, 가로 넘침 없음, 배경 스크롤 잠금 확인. 임시 화면 크기 설정은 검증 후 복원했다.
- 캡처: `desktop.webp`, `mobile.webp`. 무손실 저장 및 원 캡처 픽셀 일치 검사 완료.

자동 검사는 역사적 정확성이나 난이도 교정을 보장하지 않는다. 학생 반응을 이용한 문항 난이도·변별도 분석이나 외부 검토를 완료했다고 주장하지 않는다.
