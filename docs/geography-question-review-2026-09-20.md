# 지리 문제 구성 재검토

기존 주제별 2문제는 시험 대비 범위를 확인하기에 부족했다. 이후의 일괄 최소 개수 방침도 폐기했다. **주제별 문제 개수는 조건이 아니다.** 개념, 자료 판독, 계산, 비교, 적용 가운데 해당 주제에서 실제로 확인해야 하는 학습 요소를 기준으로 문제를 검토한다.

## 중복 처리

초안에서 기존 문항과 같은 개념을 되풀이하거나 숫자만 바꾼 44개 항목을 제외했다. 예를 들어 동일한 인구밀도 나눗셈, 같은 방향의 바람 명명, ‘모든 대륙이 동일하지 않다’는 결론만 반복하는 문항을 제외했다. 대신 경위도 모형 판독, 축척 역산, 날짜가 바뀌는 시차, 최대 종교 집단과 과반의 차이, 통계 범례와 공간 단위처럼 빠진 판단 요소를 보강했다.

일부 핵심 개념은 개념 구별과 실제 자료 적용을 각각 확인한다. 이것은 같은 목표의 단순 문장·숫자 치환과 구별한다. 향후에도 오개념·내용 중복과 해설을 검토하며 추가·삭제할 수 있고, 정해진 개수에 맞추기 위한 항목은 넣지 않는다.

## 출제 동작

- 주제를 선택하면 해당 주제의 미확인 문항과 오답을 출제한다. 두 개 또는 여덟 개로 자르지 않는다.
- 오답을 먼저 제시하고, 이미 정답 처리된 문항은 미확인 항목이 남아 있는 동안 제외한다.
- 모두 확인한 주제는 전체 문항을 다시 풀 수 있다.
- 오답 다시 풀기에도 임의의 개수 제한을 두지 않는다.
- 문항별 해설은 답을 선택한 뒤 표시한다. 가상 표·경위도 모형과 실제 자료를 구분하며, 그래프에서 계산해야 할 정답을 미리 표시하지 않는다.
- 중간에 닫아도 이미 답한 결과는 남는다. 다시 시작하면 남은 문항과 오답으로 이어진다.

기출문제를 복제한 문제은행이 아니라 성취기준에 연결된 자체 제작 문항이다. 전체 교육과정이나 학교별 모든 시험 유형이 완성되었다는 뜻은 아니다.
