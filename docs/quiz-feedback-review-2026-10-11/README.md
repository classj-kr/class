# 오답 피드백 수정 검증 — 2026-10-11

## 적용 동작

- 오답 선택: 고른 오답만 막고 다른 보기를 선택할 수 있다. 정답 강조, 정답 문구, 해설은 공개하지 않는다.
- 정답 선택: 정답과 해설을 공개한다. 순차 풀이 화면에서는 이때 다음 문제/결과 버튼을 연다.
- 최초 응답 기반 점수·이벤트는 고쳐 맞혀도 변경하지 않는다. 실험실은 기존 세션 기록에 재시도를 함께 저장한다.

## 수정 경로

공통 학교급 문제(`school-level.js`), 우주 문제(`quiz-board.js/css`), 인체 공통 문제(`engine-core.js`), 청동기 유물 문제(`history-bronze.js`), 전쟁 지도 순서 문제(`history-order.js`), 실험실 채점 및 문제은행(`science-assessment.js`, `exam-review.js`). 연결된 HTML 및 로더의 캐시 버전을 갱신했다.

## 실행 확인

- 첨부된 고등 중화 이온 문항을 로컬 물질 모형에서 재현했다. H⁺와 OH⁻를 고른 뒤 정답 강조 0개, 선택 가능한 보기 3개, 결과 버튼 숨김을 확인했다. Na⁺와 Cl⁻를 다시 고른 뒤 해설이 열렸고 결과는 최초 응답 기준 2문제 중 1문제였다.
- 브라우저 검증용 `tests/inquiry-feedback-review.html`에서 공통 문항의 연속 오답, 우주 문항의 정답 보기 배경색 비공개, 인체의 완료 콜백, 유물 문항의 다음 버튼 차단을 확인했다.
- 공통·우주 최초 오답 이벤트가 교정 후에도 각각 한 번만 발생하고 `correct:false`인 것을 확인했다. 인체 완료 콜백도 최초 오답을 전달했다(`first-response-events.json`).
- 지도 순서 문제는 오답에서 날짜 0개/정답 강조 0개/선택 가능한 보기 4개였으며 정답 뒤에만 날짜와 순서 해설을 공개했다.
- 실험실 중화 문제에서 오답→정답→새로고침 후 최초 정답 0/교정 정답 1을 확인했다. ‘새로 풀기’ 후 보기와 채점 버튼이 다시 활성화되었다.
- 과학 문제은행에서도 오답에는 재선택 안내만, 정답 뒤에는 해설을 보여 주고 초기화가 동작하는 것을 확인했다.
- `node --test --test-name-pattern='first answer|missing/corrupt|fresh transfer|all supplied' tests/science-assessment.test.cjs`: 4개 통과. 657개 문항 정의의 피드백을 검사했으며, 모든 문항 화면을 개별 방문한 검증은 아니다.
- `node tests/periodic-table-quiz.js`: 100개 원소/유형 조합의 기존 재시도 동작 통과.
- 수정 JS 구문 검사 및 과학실험실 자산 해시 동기화 완료.
