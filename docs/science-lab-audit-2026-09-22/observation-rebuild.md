# 관찰 화면 8곳 수정 — 2026-09-22

이번 작업은 앞서 현재 화면에서 확인한 8개 문제 영역의 수정이다.
104개 앱 전체의 시각적 완성이나 교육과정 전수조사 완료를 뜻하지 않는다.
실제 아이패드·크롬북 기기는 사용하지 않았으며 아래 검증은 브라우저 자동화 환경이다.
커밋·푸시·운영 배포는 수행하지 않았다.

## 수정 내용

| 대상 | 기존 문제 | 수정 |
| --- | --- | --- |
| 암석 생성·순환 | 이름을 쓴 단색 사각형 | 처음→변화 과정→결과. 결정 생성, 퇴적물 다져짐, 녹지 않는 변성, 녹음을 구별 |
| 곰팡이 | 한 점에서 뻗은 막대들 | 얽힌 실 구조와 둥근 끝 부분의 실제 현미경 사진 2장 |
| 해캄 | 사각형과 U자 선 | 나선 모양 엽록체와 마디 경계가 보이는 실제 현미경 사진·부분 확대 |
| 버섯 | 단순 갓·자루 도형, 뭉친 주름 선 | 갓 아래에서 자루 둘레로 뻗는 주름의 실제 사진·부분 확대 |
| 소금·모래 분리 | 거르는 단계에 비커만 있음 | 혼합물→용해→거름종이·깔때기·유리 막대·거른 소금물→증발 접시와 남은 소금 |
| 줄기 물 이동 | 줄기 전체가 붉게 변함 | 초록색 줄기는 유지하고 일부 통로만 붉게 표시, 가로 단면을 함께 비교 |
| 화석 | 부채·나뭇잎 아이콘 | 실제 바다 조개·나뭇잎 화석 사진, 굴곡·잎맥 부분 확대 |
| 이슬 | 잎 위 공중에 배열된 파란 점 | 잎 표면 내부에만 물방울을 배치하고 반사광·접촉 그림자로 표면에 맺힘을 표현 |

버섯·곰팡이·해캄 등 선택 표본에 맞춰 확인 문제도 바뀐다.
사진별 저작자·원본·라이선스·축소 및 확대 표시를 사진 정보에서 확인할 수 있다.
기존 현무암·화강암 사진과 교육과정 원문은 변경하지 않았다.
HTML 105개의 변경은 공통 로더의 새 캐시 해시 반영이다.

## 검증 결과

- 새 화면: 21개 상태 × Chromium 1366×912 / WebKit 1024×768 / WebKit 820×1180.
- 두 WebKit 크기에서는 새 관찰 선택·초기화를 합성 터치(tap)로 추가 검사해 통과.
- 사진 로드·확대·출처 표시, 그림 내 글자 겹침/잘림, 가로 넘침, 초기화 검사.
- 여과 후 소금 결정이 그려지지 않고 거름종이·모래·거른 소금물이 구분됨을 검사.
- 줄기 물 이동 전후 통로 표시, 이슬의 잎 표면 내부 배치를 검사.
- 실제 렌더링을 `rebuilt/`에 캡처하고 8개 대표 장면 및 나머지 세부 상태를 직접 확인.
- `science-required-core.test.cjs`: 613개 관찰 상태, 1,839개 답안 검사 통과.
- `science-specimen-viewer.test.cjs`: 기존 암석 사진 비교·확대·오답 재시도·초기화 통과.
- `science-supplement-models.test.cjs`: 모든 36개 보충 관찰 모델 상태 검사 통과.
- `science-scope-metadata.test.cjs`: 캐시·학년/성취기준 연결 및 JS 128개 구문 검사 통과.
- `science-school-devices.test.cjs`: WebKit 터치 104개 앱/104개 정답 상호작용, 키보드·회전·초기화 검사 통과.
- `science-all-apps.test.cjs`: 분리 재실행에서 104개 앱/416개 문제 통과.

### 재현되지 않은 첫 회귀 검사 실패

다른 브라우저 검사와 함께 실행한 첫 전체 검사에서 `immune`의 4개 정답 피드백이
빈 문자열인 실패가 한 번 발생했다. 해당 앱은 새 비주얼 8곳에 포함되지 않으며
이 작업에서는 원인 추정으로 코드를 수정하지 않았다.
같은 147개 조작 후 오답→정답 재시도를 단독으로 3회 반복해 모두 통과했고,
전체 104개 검사의 분리 재실행도 통과했다. 첫 실패의 원인은 확정하지 못했다.
