# 암석 관찰 패널과 공통 관찰 UI 수정

## 확인한 문제와 반영

- `volcano-model` 추가 관찰은 타원 위에 점과 둥근 사각형을 배치했다. ‘알갱이와 표면’ 선택은 사각형 크기만 바꾸므로 실제 암석을 관찰하는 자료로 부적합했다. 해당 도형을 삭제하고 GeoDIL 현무암·화강암 원본 사진으로 교체했다.
- 기본 화면에서 두 표본을 나란히 비교한다. 각 표본만 볼 수 있고, ‘표면 확대’는 같은 사진의 중앙 부분을 확대한다. 실제 확대 배율이나 두 표본의 크기 비율로 오해하지 않도록 설명했다. 출처는 접힌 ‘사진 정보’에서 볼 수 있다.
- 확인 문제의 ‘이름만’, ‘무조건 구멍의 개수만’ 선택지를 실제 사진의 알갱이·색을 비교하는 관찰 기록으로 바꿨다.
- 공통 `supplement-labs` 렌더러의 세로 배치를 그림·설명 두 열로 조정했다. 좁은 화면에서는 한 열로 전환한다. 이 렌더러를 쓰는 36개 활동에 적용되며 다른 렌더러까지 변경한 것은 아니다.
- 공통 확인 문제에서 오답을 선택해도 해설이 노출되던 동작을 수정했다. 선택한 오답만 비활성화하고 계속 응답할 수 있다. 정답에 도달한 뒤에만 해설과 정답 표시를 제공한다. 조건 변경과 초기화 때는 새 관찰에 맞춰 문제 상태도 초기화한다.
- 공유 로더와 이를 참조하는 104개 페이지의 캐시 URL을 갱신했다. 이 페이지들의 개별 학습 내용을 모두 수정했다는 뜻은 아니다.

## 검증

- `science-required-core.test.cjs`: 3개 검사 통과. 23개 활동의 613개 상태, 브라우저 답안 1,839회 확인. 두 오답 → 정답 순서로 재시도와 해설 공개 시점을 검사한다.
- `science-supplement-models.test.cjs`: 3개 검사 통과. 36개 활동의 상태·교육과정 연결 및 기존 과학적 불변 조건을 확인했다.
- `science-specimen-viewer.test.cjs`: 1개 검사 통과. 1366px·390px에서 두 사진의 실제 로딩과 2000px 이상 원본 해상도, 표본 변경, 확대, 초기화, 출처 링크, 오답 재시도, 정답 후 잠금, 가로 넘침을 확인했다.
- 실제 Chrome 화면을 데스크톱·모바일 크기로 캡처하여 읽기 순서와 사진 표시를 확인했다. 실물 모바일 기기 검사는 아니다.

## 남은 시각 자료 검토 대상

이번 수정으로 모든 과학 도해가 충분한 품질이라고 판정하지 않는다. `supplement-core.js`의 미생물·세포 관찰은 여전히 설명용 도형이다. 미생물은 실제 표본의 생김새·움직임, 세포는 현미경 사진과 구조 설명의 차이를 구분할 수 있는 자료가 후속 검토 대상이다. 현상·입자·광선처럼 보이지 않는 관계를 설명하는 모형은 단순하다는 이유만으로 사진으로 대체하지 않는다.

이 작업에서 커밋·푸시·운영 배포는 수행하지 않았다.

## 학생 화면 문구 후속 정리

공통 관찰 패널 36개에서 성취기준 코드 출력을 제거했다. 58개 보충 문구를 검토하여 제작·평가 안내와 반복 문장은 없애고, 관찰 조건·과학 개념·안전 안내를 짧게 고쳤다. 빈 안내는 렌더링하지 않는다. 남은 안내는 설명 본문에 배치하고 암석 사진의 크기·표본 관리 표시는 기존 사진 정보 안으로 옮겼다. 관련 검사 7개가 모두 통과했으며 데스크톱·모바일의 불필요 문구 부재도 검사한다. 운영 배포는 아직 수행하지 않았다.
