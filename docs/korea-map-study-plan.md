# 국내지도 시각 학습 개편

목표: 핵심 그림을 읽고 기본·필수 문제를 풀며, 같은 그림에서 정답 근거를 확인한다.

## 구현 순서
1. 기존 139문제를 7개 지리 영역의 세부 개념에 명시적으로 연결한다. 기존 문제 ID와 학습 기록 키는 유지한다.
2. 지형·기후에 단면·비교·과정 도식을 만들고 실제 지도 지점과 연결한다.
3. 같은 도식을 국토·인구·산업·교통·권역까지 확장한다. 모형과 관측 자료를 구분한다.
4. 개념별 기본 확인 → 기존 연결 문제 → 오답 복습 흐름을 제공한다. 학습 그림의 개념명은 문제에서 A/B로 바꾸고 정답 뒤 복원한다.
5. 기존 지도 탐색·유물·관광 기능을 보존하고 데스크톱·모바일 브라우저로 검증한다.

## 완료 기준
- 모든 기존 지리 문제가 적어도 한 개의 학습 개념에 연결된다.
- 모든 세부 개념에 지도 비교 지점, 시각 자료, 읽는 순서, 오개념, 그림 확인 문제가 있다.
- 기본/필수/확장 필터는 실제 문제 선택에 반영된다. 필수는 이 서비스의 핵심 학습 순서이며 기출 빈도 등급을 뜻하지 않는다.
- 문제의 A/B, 학습 그림의 A/B, 지도 표식의 A/B가 일치한다.
- 정답 전 개념명 노출, 그래프 축 왜곡, 빈 세션, 기록 중복, 모바일 가로 넘침이 없다.

## 범위
시험·학년이 특정되지 않았으므로 공통 한국지리 개념 중심으로 구성한다. 특정 시험의 전체 범위를 보장하지 않는다. 사진·3D 장식보다 단면, 분포, 비교, 흐름의 가독성을 우선한다.
