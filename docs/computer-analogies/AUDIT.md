# 36차시 생활 사례·비유 그림 검수

대상: 초등 고학년 입문자. 차시 제목·순서는 유지한다. 정의를 읽기 전에 관찰할 수 있는 물건·동작을 제시하고, 대응 관계와 비유의 한계를 함께 적는다. 조작 자체가 개념인 차시는 실제 화면·동작을 그린다. 모든 차시에 억지 비유를 넣지는 않는다.

## 작업과 검증

- 기존 A01·B01·E04 그림을 포함한 36차시의 본문·실습 지시·문항 주제를 전부 검수했다.
- 나머지 33차시에 생활 비교 그림을 추가했다. 비교 상태를 바꾸면 그림과 설명이 함께 바뀐다.
- A04는 시계·피아노·온도계로 본문과 두 확인 문항을 다시 작성했다. 슬라이더는 같은 실제 값의 변화를 두 표현 방식에 함께 적용한다.
- KoPubWorld 바탕체, 필수 용어 영어 병기, 압축된 기존 상단 구성을 유지한다.
- 생활 그림의 관찰은 문제 정오 소리를 발생시키지 않고 학습 완료로 기록하지 않는다.
- 브라우저 검증 결과는 같은 폴더의 verification-all-life.json 및 기존 3그림 verification.json에 기록한다.

## 아날로그·디지털 설명의 근거

- [Yamaha: Acoustic or Digital?](https://www.yamaha.com/en/musical_instrument_guide/piano/selection/selection002.html): 어쿠스틱 피아노의 해머·현·울림판, 디지털 피아노의 센서·음원·스피커, 터치에 따른 음량과 음색을 확인했다.
- [Kawai: KDP120 keyboard action](https://www.kawai-global.com/news/kawai-announces-new-kdp120-digital-piano/): 많은 모델은 건반의 빠르기를, 해당 모델은 해머의 빠르기를 감지한다. 모든 전자피아노를 힘 센서 또는 단순 음량 선택기로 설명하지 않았다.
- [Analog Devices: Quantization](https://www.analog.com/en/resources/glossary/quantization.html), [Sampling and ADC](https://www.analog.com/en/resources/analog-dialogue/studentzone/studentzone-february-2022.html): 시간 간격에 따른 측정과 구분된 숫자 단계에 대응시키는 과정을 구별했다.

시계 그림은 연속적으로 움직이는 초침과 초 단위 숫자 표시를 비교한 모형이다. 전자 회로의 유무로 아날로그·디지털 전체를 분류하지 않는다. 피아노 그림의 네 단계는 양자화를 관찰하기 위해 크게 줄인 교육용 모형이다. 실제 기기 성능의 수치로 제시하지 않는다.

## 남은 검증 범위

그림의 대응·한계와 브라우저 동작을 검수한 것이며, 학생 대상 수업에서 이해도와 소요 시간을 검증한 것은 아니다.
