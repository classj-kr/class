# 2026-10-18 움직임·선택 조작 개선 검증

반복되는 드롭다운을 선택 버튼으로 바꾸고, 긴 목록에는 검색을 붙였다. A·U·G·C 같은 짧은 선택지는 44px 터치 영역을 유지하는 작은 격자로 배치했다. 선택값·비활성화·초기화·키보드 방향키를 원래 실험 상태와 연결했다.

연속 운동에 쓰이던 45~100ms 갱신 제한과 장면 전체 재생성을 줄였다. 73개 기존 앱의 그림·그래프와 공유 실험 렌더러는 노드를 유지하며 바뀐 부분을 갱신한다. 놀이기구 6종을 다시 그리고, 수조·비커·스피커의 형태와 재질 표현을 보강했다. WebKit에서 큰 패널 그림자가 발생시키던 재생 지연도 줄였다. 전체 그림을 새로 그렸다는 뜻은 아니다.

- 현재 196개 앱 실행과 기본 과목 경로의 객관식 786문항 오답→정답 채점 통과. 문항의 내용·출처 재심사와 구분한다.
- Chrome·WebKit 각각 201개 과목 경로, 6개 화면 크기(1,206상태), 219개 실제 선택 조작 통과. 터치 영역·선택값 동기화·검색·키보드·가로 넘침 검사에서 오류 없음.
- 변경된 110개 앱·112개 과목 경로의 확장 가독성 검사: 각 엔진 2,735상태, 오류 없음. 1366×768, 1180×820, 1024×768, 820×1180, 768×1024에서 실제 웹폰트와 모드·추가 탐구·측정 후 도표를 검사했다.
- 연속 움직임 15종을 각 엔진에서 측정했다. 실제 SVG 속성 변화, 노드 유지, 정지 후 시간 고정과 화면 크기를 검사했다. 상세 측정값은 motion 보고서에 있다. 별도 브라우저 검사들이 끝난 뒤 측정했다.
- 조작·계산 회귀 34개 테스트 통과.
- 무손실 WebP 261개를 디코딩하고 크기·투명도·해시를 확인했다. 이 중 9개를 직접 열어 검토했다.
- 사용자 미리보기 주소의 HTML·JS·CSS·WebP 944개가 로컬 파일과 동일하다. 자산 버전 검사도 통과했다.

가독성 검사는 동일한 소스를 실험별 독립 배치로 나누어 진행했으며, 각 과목 경로가 정확히 한 번 포함되는지 대조해 합산했다. 원시 배치 보고서는 readability 폴더에 보존했다. 움직임 측정은 병렬 검사 없이 실행했다.

Windows의 Chrome과 iPad 설정을 적용한 WebKit 검사다. 실제 크롬북·iPad를 연결한 검사가 아니다. 이 작업은 교과서 전수 대조나 필수실험 총수 확정을 완료한 것으로 기록하지 않는다.

재현: 로컬 미리보기 서버를 실행한 뒤 `node --test tests/science-motion-controls.test.cjs`, `node --test tests/science-visible-choices.test.cjs`, `node --test tests/science-all-apps.test.cjs`. 경로는 `SCIENCE_BASE_URL`, 출력은 `SCIENCE_TEST_ARTIFACTS`로 지정할 수 있다. 가독성은 `scripts/audit-science-readability.cjs --extended`와 `--webkit`에 실제 웹폰트 설정을 적용한다.
