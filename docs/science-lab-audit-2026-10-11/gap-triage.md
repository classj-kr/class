# 누락 활동의 구현 검토

이전 미연결 68개 중 23개 활동에 조작 가능한 실험을 추가했다. 남은 45개를 아래에 모두 보존한다. 이 분류는 내부 작업 방식이며 교육과정의 공식 영역 분류를 바꾸지 않는다. 조사·설계·관측도 교육과정에서 제외하지 않는다.

현재 앱 145개는 독립 필수실험의 확정 총수가 아니다. 이번에 확인한 원문 쪽과 실제 수행을 지원하는 범위는 [복원 실험](restored-experiments.md)에 적었다. 아래 기존 출처 후보는 이전 색인의 연결이며 이번에 모든 원문 절차를 다시 읽었다는 뜻이 아니다.
