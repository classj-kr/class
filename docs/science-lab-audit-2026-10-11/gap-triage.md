# 실험 범위 정리와 남은 검토 후보

2022 교과서의 실험·직접 관찰·측정과 그 결과 해석을 대상으로 한다. 진로·사례 조사, 토의, 홍보·콘텐츠 제작, 일반 계획서와 아이디어 제안은 독립 실험으로 만들거나 미구현 필수실험에 합산하지 않는다. 관측 자료 분석·모형·장치 설계는 실제 탐구 절차를 확인한 뒤 판단하며 제목만으로 일괄 제외하지 않는다.

**교육과정에 있는 모든 탐구활동을 실험으로 구현하지 않는다. 아래 제외 항목은 교육과정에서 삭제한 것이 아니라 사용자가 요청한 실험실의 범위 밖으로 분리한 것이다.**

첫 정리에서 미연결 비실험 과제 24개를 뺐고, 남은 21개 원문 절차 대조에서 5개를 추가 제외했다. 전체 제외 기록은 32개다. 남은 6개는 실험·측정·관찰 0개, 관측 자료 해석 5개, 해당 교과서 절차 미확인 1개로 구분한다. 필수실험 확정 수가 아니다. [21개 후보의 원문 쪽·절차·판정](remaining-procedure-review.md).

**미연결 6개를 신규 실험 목록으로 사용하지 않는다.** 실험·측정·관찰 0개 활동은 공통 절차를 묶은 0개 검토 묶음으로 정리했다. 자료 해석 5개는 참고 목록, 원문 미확인 1개는 근거 확인 목록으로 분리했다. 검토 묶음의 수는 새 앱 수나 필수실험 수가 아니다.

생활 기록 계산인 ‘하루 에너지 섭취·소비 비교’ 앱(energy-budget)을 학생용 경로·목록·문항에서 철회했다. 미래엔 세포와 물질대사 PDF 60~61쪽(인쇄 58~59쪽)은 조사·자료 분석으로 명시한다. 이전 HTML은 retired-non-experiments/energy-budget/index.html에 보존한다. 원본 교과서·평가자료는 유지한다.

## 직접 실험·관측·측정의 공통 절차 검토

과목별 학습 범위는 보존하되 같은 장치·절차마다 페이지를 복제하지 않는다. 기존 앱 연결은 재사용 검토 근거이며 해당 활동의 구현 완료 판정이 아니다. 과학마술은 특정 반응을 의무 지정한 활동이 아니므로 별도 앱을 만들지 않는다.
