# 과학실험 앱 검증 — 2026-10-11

목록 분류를 **초·중·고(공통)·고(선택)**으로 수정했다. 초·중은 공식 **5개 영역·18개 범주**, 고등은 **공통 4과목·10영역, 선택 15과목·47영역**을 모두 표시한다. 실험이 없는 범주도 숨기지 않고 등록된 실험이 없다고 표시한다. 물리학·화학·생명과학·지구과학은 고등 일반 선택의 과목명이다. [121개 앱 분류 및 원문 대조](catalog-classification.md), [빈 범주·전체 공식 분류·필터·반응형 검사](official-categories-tests.log), [이전 앱 접근·채점 회귀 검사](catalog-classification-tests.log).

현재 121개 앱과 복원 실험 17개 경로의 [원문 근거](restored-experiments.md), [문항 363개와 추가 확인 33개 재작성](question-quality-review.md), [전체 앱 재검사](question-quality-runtime.log), [최종 보완 재검사](question-quality-final.log)를 우선 확인한다. 기존 앱 수를 실험의 목표·상한으로 세지 않는다. 필수실험 총수는 미확정이다. 아래 기존 실행·화면 로그는 해당 시점의 증거다.

**필수실험 전체 포함 상태가 아니다. 앱 수와 실험 수는 다르며, 교육과정 탐구 261개 중 68개에는 대응 구현이 확인되지 않았다.** 기존 활동지 시안 60개는 학생용 실험 수에서 제외했다. 연결된 193개는 활동 전체 완료 수가 아니다. [누락 활동과 집계 기준](<E:/webprojects/class/docs/science-lab-audit-2026-10-11/activity-coverage.md>).

104개 앱·182개 모드·1,414개 조작 사례와 보충·추가 탐구를 검토하여 24개 앱의 확인 결함을 수정했다. 남겨 두었던 연소 검출·단열·소리·우리은하 관찰 표현 4건도 보강했다. [앱별 문제·수정·검증 결과](<E:/webprojects/class/docs/science-lab-audit-2026-10-11/whole-review.md>).

경로·수집 기록으로 2022를 확인한 4,008개 경로에서 중복을 제외한 3,582개 문서를 색인화했다. 3,581개 텍스트를 추출했고 1개는 오류로 남겼다. 이전에 누락했던 연도 없는 파일도 수집 기록 근거로 포함했다. 121개 앱에 대한 133건 발췌 대조와 새 도구 60개의 근거를 기록했다. 657문항을 모두 읽어 76개를 수정했다. 발췌 대조가 문서 전체의 검토 완료를 뜻하지는 않는다. [원문 위치와 검토 범위](<E:/webprojects/class/docs/science-lab-audit-2026-10-11/source-comparison.md>).
