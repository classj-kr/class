# 과학실험 앱 검증 — 2026-10-11

현재 변경: 백조목 플라스크·뉴턴의 프리즘·분무/접촉/손 씻기를 실험과 객관식 문항으로 복원했다. [현재 추가 구현과 원문 근거](restored-experiments.md), [현재 검사 로그](restored-final-tests.log)를 우선 확인한다. 기존 앱 수를 실험의 목표·상한으로 세지 않는다. 필수실험 총수는 미확정이다. 아래 기존 실행·화면 로그는 해당 시점의 증거다.

**필수실험 전체 포함 상태가 아니다. 앱 수와 실험 수는 다르며, 교육과정 탐구 261개 중 82개에는 대응 구현이 확인되지 않았다.** 기존 활동지 시안 60개는 학생용 실험 수에서 제외했다. 연결된 179개는 활동 전체 완료 수가 아니다. [누락 활동과 집계 기준](<E:/webprojects/class/docs/science-lab-audit-2026-10-11/activity-coverage.md>).

104개 앱·182개 모드·1,414개 조작 사례와 보충·추가 탐구를 검토하여 24개 앱의 확인 결함을 수정했다. 남겨 두었던 연소 검출·단열·소리·우리은하 관찰 표현 4건도 보강했다. [앱별 문제·수정·검증 결과](<E:/webprojects/class/docs/science-lab-audit-2026-10-11/whole-review.md>).

경로·수집 기록으로 2022를 확인한 4,008개 경로에서 중복을 제외한 3,582개 문서를 색인화했다. 3,581개 텍스트를 추출했고 1개는 오류로 남겼다. 이전에 누락했던 연도 없는 파일도 수집 기록 근거로 포함했다. 104개 앱에 대한 115건 발췌 대조와 새 도구 60개의 근거를 기록했다. 657문항을 모두 읽어 76개를 수정했다. 발췌 대조가 문서 전체의 검토 완료를 뜻하지는 않는다. [원문 위치와 검토 범위](<E:/webprojects/class/docs/science-lab-audit-2026-10-11/source-comparison.md>).

최종 전체 테스트: 65개 중 65개 통과·0개 실패. [실행 로그](<E:/webprojects/class/docs/science-lab-audit-2026-10-11/content-tests.log>). 기존 중간 로그는 당시 결과이며 최종 결과와 구별한다.
