# 원문에 대조하여 복원한 실험과 문항

2022 교과서의 해당 절차를 확인하여 학생용 실험 17경로를 추가했다. 기존 104개 앱을 목표·상한으로 삼지 않는다. 전체 교과서 필수실험의 전수 대조와 출판사별 중복 판정은 계속 미완료이며, 전체 실험 수는 미확정이다.

수동 실험 목록 24개는 앱 수와 다른 단위다. 백조목의 절단·기울임 조건은 같은 실험의 조건으로 묶었다. 프리즘의 분산·단색광 재통과·재합성과 감염 단원의 분무·접촉·손 씻기는 각각 별도의 조작과 관찰을 기록했다.
