# 원문에 대조하여 복원한 실험과 문항

2022 교과서의 해당 절차를 확인하여 학생용 실험 네 경로를 추가했다. 기존 104개 앱을 목표·상한으로 삼지 않는다. 전체 교과서 필수실험의 전수 대조와 출판사별 중복 판정은 계속 미완료이며, 전체 실험 수는 미확정이다.

수동 실험 목록 8개는 앱 수와 다른 단위다. 백조목의 절단·기울임 조건은 같은 실험의 조건으로 묶었다. 프리즘의 분산·단색광 재통과·재합성과 감염 단원의 분무·접촉·손 씻기는 각각 별도의 조작과 관찰을 기록했다.

## 객관식 확인

새 기본 문항 16개는 각각 개념과 오답 해석을 연결했다. 조건을 바꾼 추가 문항 9개로 같은 문항을 다시 맞힌 경우와 새 조건에서 처음부터 맞힌 경우를 구별한다. 오답 직후 정답·해설을 공개하지 않는다. 재도전해 맞힌 뒤에만 해설과 첫 선택의 의미를 보여 준다. 단일 문항으로 학생의 전체 능력을 진단했다고 주장하지 않는다.

고교 카드 배열·백조목·프리즘의 문항은 위 교과서 절차·관찰에 맞춰 새로 작성했다. 초등 감염 단원은 함께 수집한 형성평가의 접촉 경로와 30초 물/비누 비교 해설도 대조했다. 프리즘 광원 비교는 미래엔 교과서의 평가 07번과 해설을 대조했다. 모든 문항을 기존 객관식 원문에서 그대로 가져온 것은 아니다.

## 검증

- `tests/science-restored-experiments.test.cjs`: 끓임·공기·오염의 독립 조건, 프리즘 두 경계의 스넬 법칙·교점·색별 굴절 순서, 접촉 경로와 동시 차례, 형광의 관찰 조건, 원소 카드의 이동·교환·원자량 순서와 화학식 분류 조건.
- 같은 검사에서 Chromium·WebKit의 조작·초기화·문항 채점·첫 응답 보존·새 조건 문항·390/1100px 배치와 WebP 캡처를 확인한다.
- 전체 앱 재검사는 `restored-four-tests.log`, 카드 화학식 표시 보완 뒤 최종 재검사는 `restored-four-final.log`에 기록한다. 이전 세 앱의 전체 재검사는 `restored-final-recheck.log`, 프리즘 도구 변형의 재검사는 `prism-variants-recheck.log`에 있다. `restored-final-tests.log`의 캡처 파일 쓰기 오류와 `prism-variants-tests.log`의 option 비활성 판독 오류는 실패 이력으로 보존하며 통과 증거로 사용하지 않는다. 원문 대조 기록은 `source-review-restored.cjs`, 문항 내용 해시는 `restored-question-review.json`이다.
- 새로운 앱 수를 교육과정 완료 수로 환산하지 않는다. 활동 연결은 부분 모형을 포함한다. 실물 배양·도구 제작·현장 측정·다른 출판사 변형 절차는 별도다.

## 측정 화면의 동선 정리

measurement·wave-transfer의 별도 기록표와 기록·내려받기 버튼도 제거했다. 현재 측정값·파형을 관찰하고 기존 객관식으로 이어진다. 길이 보정, 시간 측정, 합성 신호의 RMS·주파수, 가상 마이크 중지·권한 거부 처리는 `digital-direct-tests.log`에서 검사했다. 전체 앱의 활동지·우회 링크 부재와 첫 응답 보존은 `direct-flow-final.log`에 기록한다.
