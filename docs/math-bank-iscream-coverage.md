# 아이스크림 「생각을 더하다」 반영 대조표

2022 개정 3-1~6-2의 48개 단원, 본 활동과 후속 활동을 모두 확인했다. 기존 문항과는 소재가 아닌 주는 조건·묻는 것·풀이 구조로 비교했다. 자유 제작·그리기·의견 쓰기는 수학적 핵심을 답이 정해지는 질문으로 바꾸거나 이미 있는 동일 유형에 연결했다. 원문 문장과 그림은 복제하지 않았다.

새 문항은 기존 단원의 **종합**에 들어간다. 출판사와 앱의 단원 순서가 다른 경우 내용에 따라 연결한다. 수치·조건·도형은 새로 작성했다.

48개 단원 중 31개 단원에서 빠진 37유형을 추가했고, 17개 단원은 이미 있던 동일한 풀이 구조에 연결했다. 새 유형마다 원문제 하나와 검증된 수치 변형 세 개를 제공한다.

검증은 유형마다 60개 씨앗(2,220개 조건)에서 별도의 계산·조합 탐색으로 답과 유일성을 확인했다. 360px·1100px 화면에서 37문항씩 총 74번 실제 입력·채점을 확인했고, 새 유사 문항 111개도 로딩과 검증값을 확인했다. 분수 계산은 크기가 같은 분수 답을 허용한다.

회귀 검사 중 기존 학기 종합의 사다리꼴·최소공배수 넓이 문항에서 정수 답 조건을, 물 옮기기 문항에서 L 단위와 자연수 답 처리를 수정했다. 풀이의 조사 오류도 고쳤다. 바뀐 단원은 기록 버전과 캐시 주소를 갱신했다.

재검증 명령: `node --test tests/math-bank-iscream.test.cjs tests/math-bank-twins.test.cjs`, `node tests/math-bank-iscream-browser.cjs`. 전체 문항의 기존 검사는 `node --test tests/math-bank-units.test.cjs`를 사용한다.
