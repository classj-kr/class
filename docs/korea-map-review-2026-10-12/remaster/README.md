## 문항 구성

지도 위치 판별, 지형 형성 과정, 같은 눈금의 기후 그래프, 연교차·강수 집중률, 인구밀도·노령화 지수, 주간 인구, 산업 총량과 비율, 운송비, 통근·순이동, 재정착률 등을 다룬다. 계산 자료는 `학습용 가상 자료`라고 표시한다. 실제 기상청 그래프에는 관측 지점·기간을 표시한다.

틀렸을 때는 정답 표시나 정답 해설을 노출하지 않고 재시도할 수 있다. 보기 순서를 바꾸어도 정답 문구로 채점한다. 고등용 새 문항은 기존 낮은 학년용 문항과 별도로 선택된다.

## 바다 수심과 기후 자료

- 수심: NOAA ETOPO1 Ice Surface, 1분 격자. `data/bathymetry.json`에 원본 해시·출처·구간·검증 수치를 기록했다.
- 육지의 기존 지형 음영을 유지하고 바다만 200m 미만 / 200~2,000m / 2,000m 이상 세 구간으로 칠했다. 수심 색은 깊이를 나타내며 조차·수온을 나타내지 않는다.
- 기존 해안선 마스크와 Web Mercator 위치 변환을 사용했다. 2,756개 무손실 RGBA WebP 타일의 크기와 디코딩 픽셀 일치를 생성 시 확인했다. 수심 래스터는 1분 격자 원자료의 표현이므로 확대할 때 해상도가 새로 높아지지는 않는다.
- 단면도도 바다를 0m로 평탄화하던 처리를 제거했다. 바다 구간에서는 같은 ETOPO1 원본으로 만든 2,701×1,801 무손실 WebP 높이 자료를 쌍선형 보간한다. 육지에는 기존의 더 세밀한 DEM을 유지한다. 0m 해수면 선을 기준으로 해저의 음수 높이와 물층을 표시한다. 자료가 없으면 가짜 0m를 그리지 않고 재시도 안내를 표시한다. 지역 래스터의 모든 픽셀 복호화 일치와 브라우저 횡단면(양의 육지 높이·음의 해저 높이)을 확인했다.
- 남북한 18개 기후 그래프를 기상청 1991–2020 평년값으로 바꿨다. `climate-normals.json`에 조회 방식, 지점 코드, 월별 기온·강수, 공식 연 통계와 원응답 해시를 보관했다. 연평균 기온은 월 평균을 단순 평균해 만들지 않고 공식 연 값을 사용했다.

출처: [NOAA ETOPO](https://www.ncei.noaa.gov/products/etopo-global-relief-model), [기상청 기후평년값](https://data.kma.go.kr/normals/table.do), [기상청 북한 기후평년값](https://www.weather.go.kr/w/climate/statistics/nk-average.do).

## 화면과 검증

- 지도를 넓히고 옆에는 개념 선택·작은 그림·핵심 확인 항목·지점만 둔다. 그림이나 `설명`을 누르면 넓은 읽기 창이 열린다.
- 읽기 창은 밝은 바탕과 KoPubWorld 바탕체를 사용한다. 모바일 자료 표는 줄을 바꾸어 불필요한 가로 스크롤을 없앴다.
- `browser-verification.json`: 39개 개념의 78문항을 실제 브라우저에서 오답→재시도→정답→다음 문제→결과까지 확인했다.
- 1280px 데스크톱과 390px 휴대전화 크기에서 지도·설명·문항을 확인했다. 고등 수심 개념에서 초등 전환, 설명창의 키보드 열기·Escape 닫기, 한양의 산·성곽·개천 바탕과 역사 설명창도 확인했다.
- 자동 검증 25개 통과: 지리 자료·수치 계산·학년별 범위, 기존 역사 문항·지점·시점별 임진왜란·한양 배치, 공유 문항 경로.
- 캡처는 WebP로 저장했다. 교과서 원문 페이지 이미지는 배포용 파일에 포함하지 않았다.

## 수심 색상 간소화

사용자 피드백에 따라 5단계를 3색으로 줄였다. 200m와 2,000m는 대륙붕과 깊은 분지의 대비를 읽기 위한 화면 표시 경계이며, 수능에서 이 세 구간 자체를 외워야 한다는 뜻이 아니다. 실제 수심과 해저 단면은 유지한다. 지도 타일·범례·문항의 수심 안내를 함께 바꿨고, 2,756개 타일의 무손실 픽셀 일치와 기존 자동 검증 5개를 확인했다. 관련 교과서의 해안 지형(PDF 40~41쪽), 지리 부도의 빙기·후빙기 해안선(PDF 42쪽)을 다시 대조했다. 최신 3색 검증 화면은 `depth-three-bands.webp`이며, 앞의 공개 서비스 캡처는 최초 5단계 배포 당시 기록이다.
