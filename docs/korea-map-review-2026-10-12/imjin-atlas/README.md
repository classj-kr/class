## 발견한 결함과 수정

- 기존 지도는 부산–한성–평양을 직선 하나로 연결했다. 화살표의 주체·시기 범례가 없었고, 1592년 진격의 종점에 `평양성 탈환(1593)`이 놓여 있었다.
- 기존 설명에 의병과 명군 참전이 있었지만 지도에는 의병 활동지와 명군의 반격 방향이 없었다.
- 1592년 침입·저항, 1593년 반격·협상, 1597~1598년 정유재란으로 시점을 나누었다. 기존 시점 선택 UI를 사용하며 지도 위에 새 제목 행을 만들지 않았다.
- 1592년에는 평양 함락과 함경도 방면을 구분하고, 의령 곽재우·금산 조헌/영규·길주 정문부의 활동을 추가했다. 1593년에는 의주→평양→개성→벽제관 방면의 명군 진격을 표시했다.
- 진주 대첩(1592)과 진주성 함락(1593), 평양 함락(1592)과 탈환(1593)을 각각의 시점·설명으로 분리했다.
- 초등은 시점별 대표 지점 6·3·2개를 표시한다. 초등에도 의병과 조명 연합군을 포함한다. 중·고등은 9·6·5개 지점이다. 지도 범위·설명도 학교급과 시점에 맞춘다.
- 모든 새 지점에 클릭 설명을 연결했다. 기존 객관식 문항이 참조하는 기본 지점 8개의 순서와 좌표는 유지했다.
- 모바일에서 범례가 한산도 이름표를 가리는 현상을 발견했다. 실제 글 높이를 측정하고 범례·지도 안내 상자·조작 버튼을 피하도록 배치 후보를 보완했다.

## 표현 범위

- 경로는 부도에 나타난 주요 도시를 기준으로 방향을 재구성한 개략선이다. 원본 도판의 모든 지선, 실제 도로, 부대별 세부 행군로를 복원한 지도가 아니다.
- 1597~1598년 화면은 주요 전투의 위치·시기를 비교한다. 실제 항해로로 오인할 수 있는 명량→노량 직선은 추가하지 않았다. 각 수군 출전 차수의 항로와 모든 의병장은 이번 범위에 포함하지 않았다.
- 국가 영역 색상은 앞서 수정한 1592년 무렵의 배경 영역을 재사용한다. 시기별 일본군 점령 전선을 나타내지 않는다. 명 영역의 검증은 상위 `ming/README.md`를 참조한다. 이번 작업으로 모든 주변국의 세부 경계까지 검증했다고 주장하지 않는다.

## 검증

- 자동 검사 20개 통과: 시점별 연도·주체, 좌표 범위, 초등 필터, 모든 지점 설명, 기존 74개 고등 문항의 지도 참조, 기타 역사·공통 문제 기능.
- 브라우저에서 초·중·고 × 3개 시점의 캡션·지점 수·범례·설명을 직접 전환하여 확인했다(`review.json`).
- 의령 이름표 클릭 → 곽재우 의병 설명, 진주성 함락 클릭 → 1593년 사건 설명 확인.
- 데스크톱 1440×900과 모바일 실제 캡처 375×812 확인. 모바일 첫 화면에서 이름표와 범례·안내 상자의 겹침 0건을 DOM 사각형으로 확인했다. 임의의 모든 확대·이동 위치에서 무겹침을 보증하는 검사는 아니다.
- 캡처는 모두 무손실 WebP이며 변환 전후 크기·RGBA 픽셀 동일성을 확인했다. 데스크톱 캡처는 시점 구성 확인, 최종 배포 캡처는 최신 이름표 배치와 공통 제목 확인용이다.
