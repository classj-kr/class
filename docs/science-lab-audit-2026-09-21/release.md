# 과학 실험 후속 배포 — 2026-09-21

## 완료한 작업

- 검증된 과학 실험 수정만 격리 체크아웃에서 커밋했다. 한국 지도·동화·산수의 미커밋 변경을 포함하거나 원본 작업 폴더를 되돌리지 않았다.
- 배포 커밋: `972365b1fbbadef42123a7a7b8c94676112e501d`.
- `origin/main`에 일반 fast-forward push 성공. 다른 작업의 선행 push로 첫 시도가 거절됐으나, 격리 커밋을 최신 원격 위로 rebase하고 강제 push 없이 해결했다.
- 격리본에서 새 관찰 검사와 범위 메타데이터 검사 5개가 모두 통과했다. 이전 전체 회귀 검사는 51개 통과했다.
- 배포본의 과학 소스 564개 해시가 검증된 manifest와 모두 일치했다.
- 감사 문서의 전체 문자열 비교는 절대경로가 원래 작업 폴더를 가리키므로 격리 경로에서 실패한다. 문서 경로를 대량 변경하지 않고, 소스 해시 전수 대조와 메타데이터 검사를 별도로 사용했다.

## 아직 확인되지 않은 항목

- GitHub Pages 작업은 별도로 실행되지만 classj.kr의 Render 운영 배포와 같은 것으로 취급하지 않는다.
- classj.kr의 `/health`는 정상 응답했다. 과학 앱과 해당 정적 스크립트는 인증 없는 GET에서 `302 → /?access=required`로 이동했다. 따라서 이 응답만으로 수정 버전이 운영 서버에 반영됐다고 판정하지 않았다.
- 컴퓨터 사용 스킬의 브라우저 연결이 초기화 단계에서 실패했다. 재초기화 후에도 실패했으며 세션·쿠키를 추출하거나 접근 통제를 우회하지 않았다.
- 실제 아이패드·크롬북 조작 확인은 사용자 기기에서 필요하다. 두 브라우저 엔진을 이용한 화면 크기·터치 모사 검사를 실물 검증으로 표시하지 않았다.

## 사용자 기기에서 확인할 화면

1. 로그인 후 `/learning/inquiry/science-lab/microbes/`: 곰팡이·해캄·짚신벌레 표본을 선택해 새 도해가 나오는지 확인한다. 세균은 냉장고·2시간에서 1마리이며 아직 분열하지 않았다는 설명이어야 한다.
2. `/learning/inquiry/science-lab/microscope/`: 대물렌즈를 4→10→40배로 바꿀 때 선택 렌즈가 가운데에 위치하고, 두 표본 버튼과 그래프 아래 설명이 겹치지 않아야 한다.
3. 아이패드는 가로·세로 회전, 크롬북은 100% 배율에서 선택·초기화·정답 확인을 눌러 본다. 실제와 다른 화면은 스크린샷으로 남긴다.
