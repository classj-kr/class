# 학습 활동 보고서 연결 점검 (2026-11-14)

## 확인한 누락 원인

- 운영 보고서의 활동 목록은 기존 문해·수리 18종만 포함했다. 계정 저장 공간에 있는 다른 활동은 보고서에 연결되지 않았다.
- 전체 기간은 나눠 조회했지만, 날짜를 지정하면 1,000개 세션을 넘을 때 조회 자체를 거절했다. 모든 기간에 200개 단위로 마지막 페이지까지 읽도록 통일했다.
- 최고기록만 저장하는 퍼즐은 저장 공간 연결만으로 새 최고기록이 아닌 플레이를 확인할 수 없다. 실제 조작과 판별 완료 이벤트를 추가했다.

게임의 숨은 카드, 투표 내용, 다른 참가자 명단은 보고서에 넣지 않는다. 게임 결과와 누적 저장값을 첫 풀이 정답률에 넣지 않는다. 페이지 디자인에 기록 표시줄을 추가하지 않는다.

## 이전 기록의 한계

계정 저장 공간의 학습 증거를 해당 학년도 내 마지막 저장 시점으로 복원한다. 기기나 표시 이름으로 계정을 추측하지 않는다. 같은 내용의 복원과 설정 변경은 중복 활동을 만들지 않는다. 기존 누적값은 상세에서 `이전 누적 기록 · 마지막 저장 시점 기준`으로 표시한다. 저장되지 않은 과거 플레이, 개별 풀이 시각, 과거 최초 정오답은 복원할 수 없다. 이름만 있는 공개 완주 명단을 학생 기록으로 가져오지 않는다.

## 아직 연결 대상으로 삼지 않은 메뉴

- 순위전 전용 방(타자·국어·쌓기나무·리듬), 브라우저 호스트가 상태를 중계하는 나머지 보드게임, 과학 실험·몸 탐험·미술 제작 등의 별도 결과는 이번 연결 범위에 포함하지 않는다. 이 화면들도 수업 활동으로 포함할 후보이나, 방 입장이나 화면 조작 횟수로 대신 집계하지 않는다. 각 메뉴의 실제 응답·결과 제출 경로를 별도로 연결해야 한다.
- 세계사·지도·작품·음악을 단순 열람하거나 재생한 것만으로 이해·완료를 추정하지 않는다.
- 프로필·환경 설정·교사 도구·채팅은 학생의 학습 활동으로 집계하지 않는다.

## 검증

- `learning-report-sources.cjs`: 저장 API→보고서, 기존 누적값 복원, 날짜 보존, 중복 방지, 빈 값·설정 제외, 학급 권한, 게임 참여·완료·시간 종료, 첫 답·재풀이.
- `learning-activity-browser.cjs`: 실제 교과 어휘 읽기·오답·재풀이·단원 완료, 실제 퍼즐 이동, 반복 완료, 별도 브라우저의 교사 보고서.
- `learning-records-platform.cjs`: 실제 플랫폼 스키마와 로그인 쿠키로 23명 OX·3종 스토리북 읽기 및 교사 상세 조회.
- 기존 날짜·기간·현재 학급·참여 판정·가독성·체스 서버 검증. 지정 날짜의 1,001건도 끝까지 조회.
- 광범위한 `learning-records-storage.cjs`는 기존 음악 설정/임시 입장 정보 및 주석 속 저장소 문자열까지 금지하여 실패한다. 이번 활동 기록은 브라우저 저장소를 사용하지 않으며, 이 별도 정리 문제를 테스트 통과로 보고하지 않는다.
