# 한국지도 대개편 3차 — 물길·해안·생활 연결

## 구현

- 지형에서 강을 선택하면 유역 범위와 물길 추적을 표시한다. `상류에서 하구까지` 개념은 남한강을 먼저 선택한다. 기존 세계지도 하천 프레임·색·굵기·50ms 갱신은 유지하며 재생/일시정지 버튼은 없다.
- HydroBASINS Asia level 6 v1.c에서 MAIN_BAS별 10개 내륙 유역을 추출했다. 12개 하천 이름에 대응하며 남한강·북한강은 한강 유역으로 연결한다. 임진강은 자료상 별도다. 원본의 잘못된 링 복구, 0.001도 단순화, 좌표 반올림 외에 경계를 그려 넣거나 국경으로 자르지 않았다.
- 한강·영산강 하구 등 원본이 바다로 처리하는 부분은 그대로 빠져 있다. 유역과 OSM 하천이 완전히 일치하지 않음을 화면에 알린다. 실제 강 이름은 중류 좌표와 원본 폴리곤의 교차로 부여했으며, 공식 유역 고시가 아니다.
- 슬라이더는 확인된 하천 선의 길이 비율이다. 남한강/북한강 끝점과 한강 시작점의 일치를 확인한 뒤 두물머리에서 잇는다. 압록강의 분리된 선 두 개는 연결선을 만들어 붙이지 않는다. 땅에서 강까지의 강우 유출 경로·유속·도착 시간 계산은 구현하지 않았고, 그런 것처럼 표시하지 않는다.
- 주변 생활·답사는 기존 도시/산업/항만/관광/유적 좌표에서 물길 표본점까지 직선 약 25km 이내의 지점을 고른다. 유형당 1개(답사 2개), 지도 번호·위치 이동·기존 사진/설명 창으로 연결한다. 같은 유역이나 실제 도로 접근성을 뜻하지 않는다고 표시한다. 관광 308곳 데이터를 다시 복사하거나 바꾸지 않는다.
- 해안 개념에는 별도 `해류`/`조석` 장면을 추가했다. 해류 세 경로는 세계지도 자료와 동일하며 난류·한류 색과 방향을 구분한다. 폭·속도·위치는 대표적인 모형이지 관측값이 아니다.
- 조석은 같은 가상 해안에서 해면 높이만 변화시킨다. 간조→만조→간조, 드러난 갯벌 폭을 비교한다. 조석과 수평 방향의 조류를 구분하고 실제 조위·시각·침수·갯벌 안전 예측을 하지 않는다.
- 해류는 자동 이동하며 줄어든 동작 설정·화면 밖·비활성 탭·대화상자에서 멈춘다. 해안 장면은 전국 하천 흐름 조작부를 숨기며, 역사/다른 주제로 이동하면 새 레이어를 정리한다. 설명은 KoPubWorld Batang을 따른다.

## 출처와 재현

- [HydroBASINS 배포 및 이용조건](https://www.hydrosheds.org/products/hydrobasins). 원본은 `https://data.hydrosheds.org/file/hydrobasins/standard/hybas_as_lev06_v1c.zip`. 원본 ZIP은 앱에 포함하지 않는다. 재현: `scripts/build-korea-watersheds.py <ZIP>` (pyshp, shapely 필요). 결과 약 197KB, 원본 SHA-256/수정 사항/원본 ID를 결과에 포함한다.
- HydroSHEDS 자체 이용조건이지 CC BY가 아니다. `data/watershed-notice.html`에 요구된 저작권 문구와 제한·수정 내용을 표시하고 원 기술문서/Appendix A 전문을 `data/watershed-license.pdf`로 함께 둔다. 앱과 통합된 파생 자료이며 독립 유역 상품으로 재배포하는 용도가 아니다.
- 하천 중심선은 기존 OpenStreetMap 기여자(ODbL) 자료다. 약 1.5km 완충 범위 안의 표본 점 비율은 대부분 98% 이상이지만 한강 55.3%, 영산강 75.7%다. 하구가 빠지는 원본 특성 때문에 낮으며, 이를 맞추려고 유역을 임의 확장하지 않았다. 최종 10개 지오메트리는 모두 유효하다.
- [JMA 쓰시마 난류 해설](https://www.data.jma.go.jp/kaiyou/data/db/maizuru/knowledge/tsushima_current.html): 대표 해류와 실제 변동을 구분하는 참고. 세계지도 경로가 실제 관측 자료라는 뜻은 아니다.
- [NOAA 조석/해류 구분](https://oceanservice.noaa.gov/facts/tidescurrents.html): 조석의 수직 변화와 물의 수평 이동을 구분하는 참고. 조석 단면은 직접 만든 설명용 모형이다.

## 검증

- 신규 `tests/korea-map-water.cjs`: 10개 유역·12개 이름 대응, 합류 점과 경로 끝, 분리 구간 유지, 세계지도 해류 좌표 완전 일치, 조석 높이/해안선 변화, 슬라이더 지도 위치, 답사 상세창, 동작 줄이기·대화상자 정지, 역사 전환 정리, 자료 실패/재시도.
- 390/820/1440px에서 물길과 해안 모두 가로 넘침 0. 새 설명 글꼴 확인. 390px·DPR 3·CPU 4배 감속 모의 환경에서 1.5초 동안 하천 28프레임 갱신. 실제 휴대폰 측정은 아니다.
- 회귀: flow, mountain, study(28개 개념·195문항), layout(5개 화면 폭), reading(308곳·616문단), heritage(630회 클릭·최대 확대 68곳), history(28개 장면), war(6개 시점), territories(39개 기준 시점) 통과.
- 화면 및 측정 결과: `outputs/korea-map-water/` (배포에서 제외).

## 한계

실제 저사양 휴대폰 실측, 정밀 강우 유출 계산, 공식 고시급 유역 정밀도는 완료 항목이 아니다. 운영 환경은 로그인 없이 학습 화면 검증이 제한되므로 저장소 업로드와 실제 로그인 화면 검증을 구분해서 보고한다. 역사 데이터·렌더러와 다른 작업의 파일은 이 변경에 포함하지 않는다.
