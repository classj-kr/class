# 우주 학습 전체 내용 검토

검토일: 2026-09-20
대상: https://classj.kr/learning/inquiry/space/

## 검토 범위와 한계

공개 URL과 하위 페이지·스크립트 요청은 모두 `302 /?access=required`로 돌아왔다. 연결 브라우저 도구도 Windows 실행 오류로 작동하지 않았다. 따라서 로그인한 배포 사이트를 직접 순회했다고 볼 수 없다. 이번 검토는 사용자가 제공한 화면과 작업 폴더의 해당 사이트 원본을 기준으로 한다. 배포본과 원본의 일치 여부, 화면 조작 시 실제 렌더링은 미확인이다.

다음 내용을 읽었다.

- 허브와 세 하위 영역의 HTML 화면 문구 전체
- 태양계 천체 데이터 14종의 설명·주요 특징·비교 수치
- 별자리 12종의 설명, 계절별 별자리·신화·항성 비교표, 별의 일생 두 경로의 설명
- 천구와 북쪽 하늘, 일주·연주 운동의 설명·조작 구성
- 달의 위상·지구와 달 비교표, 계절별 태양 경로의 화면과 관련 계산
- 퀴즈 132개의 문항·선택지·정답·해설과 주제 분류
- 공통 퀴즈 화면의 답 확인·해설·더 보기 동작 코드

문항의 정답 참조와 주제 매핑에는 형식상 누락이 없었다. 이는 과학 내용 전체가 정확하다는 뜻은 아니다.

## 우선 해결할 내용

### 1. 황도 화면의 생일 날짜와 관측 기준이 혼재함

별자리 원에는 `양자리 3/21~4/19` 같은 전통적인 생일 별자리 날짜가 표시되지만, 설명과 월별 배열은 한밤중 관측 별자리와 태양 배경 별자리를 다룬다. 개념 화면에는 생일에 태양이 그 별자리 앞에 있다는 설명과 세차 때문에 날짜가 어긋난다는 설명이 함께 있다. 어떤 기준의 날짜인지 학생이 구분하기 어렵다.

제안: 주 화면은 지구 공전에 따른 태양 방향·밤하늘 방향에 집중한다. 생일 날짜는 제거하거나 전통적인 황도궁 날짜임을 명시해 별도 읽을거리로 둔다. 실제 관측 날짜로 사용하려면 현대 별자리 경계와 기준일을 사용하는 자료로 다시 구성한다. 황도궁의 12등분과 실제 크기가 다른 별자리 구역을 구분해야 한다.

근거: `constellations/app.js:67`, `constellations/index.html:535`. [NASA 황도 별자리 교육 자료](https://nightsky.jpl.nasa.gov/media/documents/resources/0SolSysManual.pdf)는 세차로 인해 전통적인 점성술 날짜와 태양의 실제 배경 별자리가 일치하지 않음을 설명한다.

### 2. 별의 진화 단계 막대가 실제 시간 비율처럼 보임

주계열성 설명에는 일생의 약 90%라고 쓰지만, 같은 단계의 표시에는 `진화 10% ~ 70%`라고 나온다. 실제 코드의 단계 선택 경계는 20%씩이다. 학습 단계 위치, 설명상의 비율, 실제 수명 비율이 서로 다르다.

제안: 현재 막대는 '진화 단계'로만 표시하고 각 단계에 이름을 보여준다. 실제 수명 비교를 원하면 별의 질량과 단계별 지속 시간을 별도의 근거 있는 자료로 다룬다.

근거: `constellations/app.js:1039`, `:1051`, `:1139`. 문구 정리로 조작기 이름은 바꾸었지만 백분율 데이터와 단계 계산은 아직 수정하지 않았다.

### 3. 질량이 큰 별의 일생 경로가 오해를 줌

표시 경로는 성운 → 청색 초거성 → 적색 초거성 → 초신성 → 블랙홀이다. 주계열 단계가 빠져 있고 마지막 제목은 블랙홀 하나지만 상세 설명과 문제에는 중성자별 또는 블랙홀이라고 나온다. 마지막 정보의 '밀도: 무한대'도 두 종류의 천체를 구분하지 않는다.

제안: 질량이 큰 별의 주계열 단계를 포함하고, 마지막 잔해는 중성자별 또는 블랙홀로 일관되게 표시한다. 질량에 따라 경로가 달라지는 개념도임을 설명한다. '밀도 무한대'처럼 두 대상을 한 수치로 설명하는 문장은 재작성한다.

근거: `constellations/app.js:1082`, `:1117`, `:1154`. [NASA 별의 일생](https://science.nasa.gov/universe/stars/) 참조.

### 4. 계절과 태양 고도를 설명할 개념 내용이 부족함

관찰에는 계절별 경로가 있고 퀴즈에는 자전·공전, 계절, 낮의 길이, 태양 고도, 그림자가 총 23문항 있다. 그러나 개념 화면은 달의 위상과 지구·달 비교표가 중심이다.

제안: '지구의 운동과 계절' 개념 구역에 자전과 낮·밤, 자전축과 공전, 고도와 단위 면적당 햇빛, 낮의 길이, 남중 고도·그림자를 연결해 설명한다. 설명을 본 뒤 같은 주제 문제로 이동할 수 있어야 한다.

근거: `earth-moon/index.html:218`, `earth-moon/app.js:2832`.

### 5. 일식·월식은 문제만 별도 주제로 있음

일식·월식과 매달 식이 생기지 않는 이유를 묻는 3문항이 있다. 이를 가르치는 독립된 개념 설명이나 명시적인 관찰 모드는 없다. 삭·망 설명의 '일직선'만 읽으면 매달 식이 생긴다고 이해할 수 있다.

제안: 달의 위상 설명에 위상 변화와 식 현상의 차이, 궤도면 기울기를 먼저 보충한다. 현 단계에서 일식·월식을 허브 독립 카드로 만들 만큼의 내용은 없다.

근거: `earth-moon/index.html:226`, `earth-moon/app.js:2807`.

### 6. 천구 설명과 문제의 정확도 수준이 다름

천구 화면은 북극성 고도가 위도와 '정확히' 같다고 설명하지만, 문제 해설은 '거의' 같다고 한다. 북극성은 천구의 북극 가까이에 있는 별이고 두 위치가 완전히 같지는 않다.

제안: 천구의 북극 고도와 위도의 관계를 기준으로 설명하고, 북극성은 가까운 근삿값이라는 문구를 사용한다. 모형에서 두 위치를 일치시켰다면 그 단순화를 짧게 알린다.

근거: `constellations/app.js:1245`, `:1958`. [NASA 북극성 설명](https://science.nasa.gov/solar-system/what-is-the-north-star-and-how-do-you-find-it/) 참조.

### 7. 겨울철 대육각형의 구성 별 수정 필요

현재 개념 표에는 베텔게우스가 포함되고 폴룩스가 빠져 있다. 일반적으로 사용하는 겨울철 대육각형은 리겔·알데바란·카펠라·폴룩스·프로키온·시리우스다. 베텔게우스는 겨울철 대삼각형에 들어간다.

근거: `constellations/index.html:528`. [NASA 계절별 별무리 설명](https://science.nasa.gov/solar-system/skywatching/night-sky-network/connecting-the-dots-with-asterisms/) 참조. 이번에는 학습 자료 자체를 교정하지 않고 검토 항목으로 남겼다.

### 8. '음력 기준'은 실제 음력 달력처럼 보이지만 계산은 단순화된 월령 모형임

음력 월은 경과 일수를 평균 삭망월로 나눈 값이며 12개월로 순환한다. 특정 연도의 합삭 시각, 음력 월 시작, 윤달을 반영한 달력 변환은 아니다. 그런데 화면은 구체적인 '음력 1월 6일 9시' 형식이다.

제안: 메뉴는 '달의 위상'으로, 날짜는 '삭 이후 약 N일' 또는 모형의 날짜임을 드러내는 표현으로 바꾸는 편이 학습 목적에 맞다. '양력 기준'은 '계절과 태양 고도'가 내용을 더 잘 설명한다. 메뉴 명칭 변경은 아직 적용하지 않았다.

근거: `earth-moon/app.js:994`.

### 9. 태양 경로 그림의 가로 위치는 실제 방위각이 아님

고도와 방위각 계산은 있지만, 경로를 그릴 때 가로 위치는 방위각 대신 낮의 길이와 타원식으로 정한다. 따라서 그림을 실제 지평선 방위로 읽으면 계절별 일출·일몰 방향을 정확히 설명하기 어렵다. 적도에서 계절에 따라 태양이 북쪽 또는 남쪽으로 지나는 문제도 별도 확인이 필요하다.

제안: 실제 방위각을 사용한 지평선 그림으로 바꾸거나, 고도·낮 길이 비교를 위한 개념 그림임을 명확히 한다. 북동·정동·남동처럼 계절별 방향을 읽게 할 계획이라면 실제 방위각 표현이 필요하다.

근거: `earth-moon/app.js:1754`, `:2155`, `:2204`. 소스에서 확인한 표현상의 한계이며 배포 화면의 각 관측 위치를 직접 조작해 재현한 것은 아니다.

### 10. 태양계 세부 설명과 수치도 점검 대상임

- 타이탄 설명의 '메탄 대기/바다'는 대기의 주성분까지 메탄으로 읽힐 수 있다. 질소가 주성분인 대기와 메탄·에테인 호수를 구분해야 한다. [NASA 타이탄](https://science.nasa.gov/saturn/moons/titan/facts/)
- 토성 위성 수는 원본에 274로 고정되어 있으나 NASA 토성 위성 페이지는 2026년 8월 기준 293으로 표기한다. 이런 수치는 기준일과 출처가 필요하다. [NASA 토성 위성](https://science.nasa.gov/saturn/moons/)
- 혜성과 소행성은 천체의 종류인데 반지름·밀도 등을 단일 천체 수치처럼 보여준다. 예시값이라면 대상으로 삼은 천체를 명시해야 한다.
- 유성은 빛나는 현상으로 설명하면서 분류와 물리량은 작은 천체처럼 취급한다. 유성체·유성·운석의 구분을 도감에서도 유지해야 한다.
- 혜성 꼬리 문제에는 '항상 태양 반대 방향'과 '대체로 태양 반대쪽, 먼지 꼬리는 휨'이 혼재한다. 같은 학습 영역에서 단순화 수준을 맞출 필요가 있다.

근거: `solar-system/solar-data.js:218`, `:367`, `:387`, `:405`, `solar-system/app.js:3625`, `:3646`.

| 합계 | 16개 학습 주제 | 132 | 문항 중복 배정 없음 |

큰 영역은 선택 화면의 구획 제목으로 활용하고, 학생은 그 아래 세부 주제로 직접 들어간다. 기존 세 개의 큰 카드 속에 모두 숨기는 방식은 유지하지 않는다. 16개의 주제를 한 줄에 늘어놓는 것이 아니라 영역별 카드 묶음으로 보여준다.

각 주제의 기본 흐름은 관찰 → 개념 → 해당 주제의 문제다. 관찰 콘텐츠가 없는 주제는 빈 관찰 화면을 만들지 말고 설명·그림과 문제부터 제공한다. 기존 관찰 모형을 공유하더라도 진입한 주제에 맞는 설명과 조작을 먼저 보여준다.

문제도 한 단계 더 나눈다.

- 행성: 순서 / 지구형·목성형 / 행성별 특징 / 고리와 위성
- 행성의 운동과 관측: 궤도·주기 / 내행성 관측 / 외행성 관측·역행
- 위성과 작은 천체: 위성 / 왜소행성·소행성 / 혜성 / 유성체·유성·운석
- 황도 12궁: 황도의 뜻 / 태양 방향과 밤하늘 방향 / 지구 공전
- 북쪽 하늘과 방향 찾기: 북극성의 위치 / 북극성 찾기 / 남반구 방향 찾기
- 일주 운동과 연주 운동: 일주 / 연주 / 비교
- 천구: 기준점과 기준선 / 위도와 고도 / 관측 위치에 따른 차이
- 별의 밝기와 색: 겉보기·절대 등급 / 광도와 거리 / 색과 온도
- 별의 일생: 태양과 비슷한 질량 / 큰 질량 / 마지막에 남는 천체
- 지구의 자전과 공전: 자전과 낮·밤 / 공전과 일 년
- 계절의 변화: 자전축과 공전 / 남북반구 / 낮 길이와 햇빛
- 태양의 고도와 일주 경로: 남중 고도 / 일출·일몰 / 그림자 / 위도
- 달의 위상과 관측: 위상 변화 / 뜨고 지는 시각 / 방향 / 달의 주기
- 일식과 월식: 일식 / 월식 / 매달 생기지 않는 이유

세부 구분은 문제의 학습 목표 기준이며, 현재 모든 작은 구분에 충분한 문항이 있는 것은 아니다. 태양·별의 밝기·별의 일생·일식과 월식 등은 분리 후 수량만 채우는 반복 문제가 아니라 관찰·판단·적용 문제를 보강해야 한다. 신화는 해당 별자리의 읽을거리로 두며 과학 개념 문제와 섞지 않는다.

문항 배정 원칙:

- 북극성이 거의 움직이지 않는 이유와 방향 찾기는 북쪽 하늘에, 위도·고도 관련 여섯 문항은 천구에 배정한다.
- 계절별로 보이는 별자리가 달라지는 문항은 계절별 별자리에, 같은 시각에서 이동량을 비교하는 문항은 일주·연주 운동에 배정한다.
- 지구 자전·공전의 원인 설명과 별의 겉보기 운동은 서로 연결하되, 같은 문제를 양쪽에 복제하지 않는다.
- 분리 시 관찰 버튼뿐 아니라 개념·문제·돌아가기 경로까지 함께 정리한다.

## 이번에 적용한 문구 정리

사용자가 따로 요청한 문구 수정만 적용했다. 메뉴 이동·분리와 과학 모형 변경은 하지 않았다.

- 허브의 '태양과 8대 행성 3D 공전 궤도 시뮬레이션' → '태양과 행성, 위성과 작은 천체'
- 세 영역 공통 'Simulation / Knowledge / Quiz' → '관찰 / 개념 / 문제'
- 페이지 소개의 3D·2D·인터랙티브 등 구현 방식 나열 → 학습 내용 소개
- 'Simulation Mode', 'Log Scale', 'My View', 'Timeline Knob' 등 → 거리 표시·관측자 시점·진화 단계처럼 이해하기 쉬운 표현
- '핵심 출제 지식', '중학교 시험 필수 출제 개념' 등 제목 → 주요 특징·관측 원리
- '폭발 임박', '우주 최강 대폭발', '초강력 광도' 등 과장 수식어 삭제

모형의 거리·크기가 실제 비율과 다르다는 안내, 관측 위치와 방향, 시간 조절에 필요한 정보는 보존했다. 본문의 과학 설명과 수치 교정은 위 검토 결과를 기준으로 후속 작업이 필요하다.

- 수정은 로컬 작업 폴더에만 반영. 커밋·배포하지 않음.
