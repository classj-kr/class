# 별의 일생 연속 모형 검토

2026-09-20. 로컬 구현이며 배포하지 않음.

## 구현

기존 사진 다섯 장과 단계별 이미지 교체 코드를 제거했다. Canvas에서 가스 입자, 불규칙한 성운, 별의 구면 표면 질감, 바깥층, 충격파와 방출 물질을 직접 그린다. 진행 값에 따라 입자의 위치와 크기, 별 반지름과 표면 표현이 연속적으로 변한다.

- 성운 → 원시별 → 주계열성 → 적색거성 → 행성상 성운 → 백색왜성.
- 큰 질량의 대표 경로: 성운 → 원시별 → 주계열성 → 적색 초거성 → 초신성 → 중성자별 또는 블랙홀.
- 마지막 잔해는 비교를 위해 확대한다. 표시 크기와 재생 시간은 실제 크기와 수명 비율이 아니다.
- 재생·일시정지·처음부터·구간 이동·속도 변경을 지원한다. 질량을 바꾸면 같은 진화 구간에서 두 경로를 비교한다.
- 숨겨진 탭이나 비활성 문서에서는 재생 시간을 진행시키지 않는다. 동작 줄이기 설정에서는 자동 재생을 하지 않는다.
- 모바일에서는 관찰 화면 바로 다음에 재생 조작을 둔다.

## 과학적 범위

별의 구조 방정식이나 실제 질량별 진화 궤적을 적분하는 수치 모형이 아니라, 대표적인 진화 과정을 관찰하는 교육용 애니메이션이다. 모든 큰 질량 별이 같은 초거성·초신성 경로를 거치는 것은 아니다. 잔해는 처음 질량 외에 질량 손실 등에도 영향을 받으므로 임의의 정확한 질량 경계값을 표시하지 않았다. 백색왜성은 사라지는 것으로 표현하지 않고 장기간 냉각하는 잔해로 남긴다.

근거: [NASA Stars](https://science.nasa.gov/universe/stars/), [NASA의 태양형·큰 질량 별 진화 경로](https://science.nasa.gov/asset/webb/life-cycles-of-sun-like-and-massive-stars/).

## 검증

- 두 질량 경로, 세 종류의 잔해, 각 단계 사이의 반지름 연속성과 유한한 수치 상태 확인.
- 브라우저에서 전체 단계 이동, 재생 중 Canvas 프레임 변화, 일시정지 후 진행 정지, 분기 변경, 재시작, 모바일 넘침과 조작 위치 확인.
- 기존 우주 10개 경로의 개념·문제·해설·새로고침 확인. 별의 밝기 비교표 유지.
