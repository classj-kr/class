# 수학 문제은행 오답 쌍둥이 복습

초·중학교 전 학기와 고1 1학기의 원문제 14,010개에 쌍둥이를 3개씩 연결했다. 총 42,030개이며, 고1 2학기와 평가원·수능 기출은 대상에서 제외했다. 원래 단원 문항 파일은 수정하지 않았다.

## 문항 준비와 검증

- 기존 유형의 생성기를 사용한 수치·조건·그림 변형 40,670개를 준비했다. 수나 정의가 고정되어 변형이 부족한 경우에는 제시한 답을 판단하는 개념 확인형 1,360개를 별도로 표시한다.
- 19개 학기별 JSON에 검증된 씨앗·변형 조건·지문 및 정답의 검증값을 저장한다. 학생 화면은 이 세 변형만 복원한다. 원문제나 생성 결과가 달라지면 복습을 중단하고 재검증 안내를 표시한다.
- 보기 순서와 라벨의 여백 변경은 새 문제로 세지 않는다. 라벨 보정 전의 문항 내용으로 원문제 및 쌍둥이 세 개의 중복을 검사한다.
- 기존 `tests/math-bank-units.test.cjs`를 수정하지 않고 여섯 문항별 검사 함수를 재사용했다. 문항 형식·분수·부호·답의 유일성, 독립 계산, 가린 숫자의 모든 경우, 선택지·조건, 도형 좌표, 큰 수의 읽기와 표현을 검사한다. 기존 검사의 씨앗 표본 수 집계는 이 문항별 검사에서 제외하고, 실제 제공되는 42,030개 변형을 전부 검사한다.
- 도형의 선·면·수치를 보존한 채 복습용 335개 문항의 라벨 여백과 겹침을 보정했다. 원래 그림의 자르기 영역은 유지하며, 보정 전후의 수학적 근거와 그림의 문자·숫자가 같음을 검사한다.
- 원문제와 쌍둥이를 360px·1280px에서 총 112,080회 배치했다. 최종 쌍둥이의 글자 잘림·겹침·화면 넘침은 0건이었다. 원문제에서 나온 기존 배치 경고 212건은 비교 정보이며, 원문제의 그림을 수정한 것은 아니다.
- 도형·원그래프·좌표 그림 등 보정 사례 여섯 종류의 전후 화면을 직접 확인했다. 전체 문항을 사람의 눈으로 하나씩 검수했다는 의미는 아니다.

## 학습 흐름과 기록

오답에서는 정답·전체 해설 대신 힌트를 표시하며 다시 답할 수 있다. 해당 문항에서 바로 쌍둥이 세 개로 연습하거나, 회차 완료 뒤 최초 오답만 골라 복습할 수 있다. 정답·해설은 학생이 버튼으로 요청한 뒤에만 공개한다.

힌트 후 맞혀도 최초 오답 기록을 유지한다. 원래 풀이와 쌍둥이 복습은 서로 다른 학습 기록으로 저장하며, 복습 문항에 원문제 키·변형 번호·원래 풀이 기록 ID를 연결한다. 복습을 풀어도 원래 점수를 올리지 않는다. 새로고침 뒤 문제와 답, 힌트 사용 여부를 복원한다.

