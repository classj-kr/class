# 학생용 문구 정리 — 2026-10-12

사용자 요청에 따라 학생 화면에서 출처·원문 대조·구현 범위·검증 현황을 설명하는 문구를 제거했다. 실험 조작·관찰·해석에 필요한 안내와 안전 지침만 유지한다.

- 탐구·증거·구조·센서 생성기 4개는 감사용 `current`/`boundary`를 학생 문구로 출력하지 않는다. 23개 실험의 짧은 안내를 별도로 작성하고, 안내가 빠지면 생성 과정에서 확인할 수 있게 했다.
- 망원경·회전 수조의 긴 구현 범위 설명, 원소 카드의 원문 설명, 전기장·지질 연대표·확산·해수의 작업성 문구를 정리했다.
- 흑점과 단백질 상호작용에는 출처·검증 패널을 추가하지 않았다. 원본 자료와 해시는 데이터 메타데이터와 개별 검토 문서에 보존한다.
- 과학실험실 AGENTS.md에 같은 기준을 기록했다.

현재 로컬 미리보기의 148앱·150과목 경로를 Chrome으로 열어 화면 텍스트와 JS 오류를 검사했다. [최종 검사 결과](learner-copy-review.json). 문구 검사는 표시된 화면과 정적 텍스트를 대상으로 하며, 전체 교과서 검토나 모든 실험의 과학적 검증 완료를 뜻하지 않는다.

[관련 회귀 검사 29개](combined-tests.log)는 통과했다. 두 엔진 각각 기본 600문항의 첫 오답·수정·새로고침 보존, 기존 탐구 294조건·882답, 망원경·회전 수조·흑점·도킹의 조작·자료·진단을 포함한다. 별도 핵심 회귀 6개도 613조건·1,839답과 JS 179개 구문·교육과정/자산 메타데이터를 확인했다. 마지막 안내 문장 수정은 생성 일치·자산 해시·현재 화면 텍스트 검사를 다시 수행했다.
