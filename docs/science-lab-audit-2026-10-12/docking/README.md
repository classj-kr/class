# 단백질·화합물 상호작용 — 2026-10-12

천재 생물의 유전 PDF 111쪽, 자료 ID `7bad326c8e3be2fd`의 표적 기능 확인·후보 화합물 비교·도킹 에너지 분석 절차를 대조했다. 해당 쪽이 지정한 [KISTI VlabON](https://vlabon.re.kr/contents/protein_interaction)의 공개 자료를 사용했다. 다른 출판사 전수 대조는 미완료다.

표적 3종(AChE, KIT, DPP-4) × 화합물 6종 × 배치 20개, 총 360개 배치의 원자·결합 좌표와 점수를 원본과 대응했다. 구조는 RCSB PDB의 [4EY7](https://www.rcsb.org/structure/4EY7), [1T46](https://www.rcsb.org/structure/1T46), [4J3J](https://www.rcsb.org/structure/4J3J)의 Cα 골격을 사용한다. 원래 결정화 리간드와 물은 표시하지 않는다. 원본 프로그램 코드를 복사하지 않고 사실 데이터와 좌표를 별도 추출했다.

[출처·해시 기록](../../../learning/inquiry/science-lab/protein-interaction/data/provenance.json)과 [추출 스크립트](../../../scripts/prepare-science-docking-data.py)를 보존했다. 화면에는 출처·구현·검증 문구를 추가하지 않는다.

느린 자동 회전, 드래그/키보드 회전, 결합 부위 확대, 표적·후보 선택, 20개 배치와 상대 에너지 비교, 후보별 최저값 표를 제공한다. 표적별 시험 기록을 분리하며 초기화와 비동기 표적 전환을 처리한다. 동작 줄이기 설정과 숨겨진 탭에서의 회전 정지도 반영했다.

**사전 계산 자료의 재생·비교이며 새 도킹 계산을 실행하지 않는다.** 원본 10종·102종 중 3종·6종을 제공한다. 원본 UI의 점수는 단위 없는 상대 에너지이므로 kcal/mol이나 실측 자유 에너지로 표시하지 않는다. 배치 번호는 시간·최적화 궤적이 아니다. 낮은 점수만으로 세포 효과·치료 효과·선택성·안전성을 판단할 수 없다.

기본 4문항과 추가 2문항은 음수 비교, 표적에 따른 후보 순위 변화, 최저 배치와 평균의 구별, 계산 결과의 해석 범위를 평가한다. 360개 배치의 좌표·결합·최저값·해시 검사와 Chrome·WebKit의 18개 표적/후보 조합, 회전·배치 변경·초기화·6문항 첫 오답 보존·재방문, 320/390/820/1280px 넘침 검사를 통과했다. [데스크톱](comparison-1280.webp)과 [모바일](comparison-390.webp)을 직접 확인했다.
