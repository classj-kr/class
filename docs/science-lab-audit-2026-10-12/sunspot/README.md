# 흑점 관측 자료 측정 — 2026-10-12

동아 행성우주과학 Ⅱ단원 PDF 6–7쪽(인쇄 54–55쪽), 자료 ID `83a281f014c6a235`의 위성 영상 분석 절차를 대조했다. 2일 간격의 세 영상을 비교하고, 4일 간격 두 영상에서 같은 흑점 3–5개를 찾아 위도·경도·각거리와 자전 주기를 구한다. PDF 5쪽의 직접 망원경 관측·필터 설치·촬영은 이 분석으로 완료 판정하지 않는다. 다른 출판사 전수 대조는 미완료다.

NASA SDO/HMI의 2024-05-05·07·09 00:00 UTC 영상을 사용했다. 관측 영상은 디코딩한 픽셀을 보존하는 무손실 WebP로 변환했다. 원본 날짜·URL·SHA-256, 각 영상의 원반 중심·반지름, 관측자 위도와 거리는 [데이터 기록](../../../learning/inquiry/science-lab/sunspot-observation/data/provenance.json)에 있다. [준비 스크립트](../../../scripts/prepare-science-sunspot-data.py)로 재생성할 수 있다.

원반 중심과 반지름은 각각 영상에서 직접 맞추고, 같은 장비의 11초 이내 관측 헤더로 B0와 관측자 거리를 반영한다. 북쪽이 위인 방향, 유한 거리 투영과 구면 좌표 역변환을 사용한다. 밝은 광구·원반 밖·극단적 가장자리·위도 불일치 선택은 측정에 넣지 않는다. 3배 확대창은 실제 픽셀을 확대한다. 관측 영상의 시간 순서 재생과 정렬 겹침 비교를 제공한다.

**Browse 영상에서의 교육용 어림 측정이다.** 지구 부근 관측자의 겉보기 주기이며 항성 자전 주기가 아니다. 좁은 위도의 세 흑점만으로 전 위도의 차등 자전을 확정하지 않는다. 흑점의 형태 변화·생성·소멸과 가장자리 투영 오차가 있다.

기본 4문항과 추가 2문항은 동일 흑점 대응, 동서 경도의 각거리, 주기 계산, 투영, 관측 범위와 일반화 여부를 평가한다. 첫 오답을 고쳐도 기록을 덮어쓰지 않는다.

검사: 좌표 왕복 변환·입력 거부·날짜/해시/무손실 형식, Chrome·WebKit의 실제 영상 조작·재생·겹침·5개 측정·초기화·6문항 재방문 보존, 320/390/820/1280px 넘침 검사를 통과했다. 같은 흑점의 예시 측정은 약 52.2°/4일, 겉보기 약 27.6일이다. [데스크톱](observation-1280.webp)과 [모바일](observation-390.webp)을 직접 확인했다.
