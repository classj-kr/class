# 망원경 관측 절차·문항 보완 — 2026-10-12

삼각대·가대·균형추·경통·광학 부품의 설치, 균형추 조절, 파인더와 접안렌즈의 중심 맞추기, 대상 찾기, 초점과 배율 비교를 실제 조작으로 추가했다. 구름·건물·지평선 아래 조건에서는 관측 대상이 보이지 않는다.

중학교는 달과 행성, 고교 선택과목은 행성을 관측한다. 하나의 장치를 두 과목에 연결하며 각각 기본 4문항·추가 2문항과 응답 기록을 분리했다. 공식 분류는 중학교 **지구와 우주 / 천체**, 고(선택) **행성우주과학 / 우주탐사와 행성계**다.

교과서는 천재 과학1(임성숙) PDF 234–237쪽, 동아 행성우주과학 Ⅰ단원 PDF 28–29쪽을 대조했다. 천재 과학1(임성숙) 지도서 515–517쪽과 과학1(정대홍) 지도서 북2 411·415·426쪽의 역할·배율·집광력·정렬 오개념을 문항에 반영했다. 문항은 새로 작성했다. 모든 원문 경로·해시·평가 근거는 [review.json](review.json)에 기록했다.

배율과 근사 실제 시야는 [Celestron 제조사 설명서](https://celestron-site-support-files.s3.us-east-1.amazonaws.com/support_files/22028-CGL_Royal-Observatory_Travel%20Scope70_Manual-F.pdf)의 계산 관계를 사용한다. 600 mm 경통과 겉보기 시야 50°는 이 실습의 고정 조건이다. 천체 위치·위상은 가상 사례이고 실시간 예보가 아니다. 특징 확대 그림은 실제 시야와 분리하며, 현장 관측·사진 촬영·실제 분해능과 대기 효과까지 재현한 것으로 판정하지 않는다.
