# 인체 앱 전체 화면·동작 점검 — 2026-09-20

8개 앱의 25개 장면을 모두 브라우저에서 열어 그림, 이름표, 애니메이션, 조작, 확인 문제를 점검했다. 1440×960, 1024×768, 390×844 화면을 촬영했다.

## 점검한 장면

| 앱 | 장면 |
|---|---|
| 순환계 | 혈액의 구성, 심장과 순환 경로 |
| 소화계 | 전신 소화관, 위, 소장 융털, 효소 관련 실험 |
| 호흡계 | 폐포 기체 교환, 폐와 조직의 기체 교환, 호흡 운동 |
| 배설계 | 전신 배설계, 오줌이 만들어져 나가는 길, 네프론 |
| 신경계 | 뇌, 반응과 중추, 자율신경, 반사궁, 눈, 귀, 동공 반사 |
| 항상성 | 피부와 체온 조절, 혈당 조절 |
| 면역계 | 몸의 방어 작용, 1차·2차 반응 그래프 |
| 골격계 | 관절과 길항근, 근절 활주설 |

## 수정한 문제

- **이름표:** 공통 배치 함수를 도입해 화면 크기와 움직이는 기관의 좌표를 따라가도록 했다. 혈액·심장·네프론·혈당·면역 도식 등의 겹침을 해소하고 실제 대상까지 연결선을 표시한다. 이름표는 키보드로도 선택할 수 있다.
- **호흡:** 인체와 유리종 모형을 같은 호흡 상태에 연결했다. 횡격막·고무막·폐·풍선·흉강의 이름표를 해당 구조에 연결하고, 기도 안을 따라 움직이는 공기 입자를 사용한다. 고무막의 가장자리를 고정하고 드래그, 키보드 조작, 자동 호흡, 일시정지를 연결했다.
- **심장:** 판막의 투명도를 바꾸던 표현을 판막엽의 실제 개폐로 바꿨다. 폐순환과 체순환 입자는 각각 받는 심방에서 경로를 마치며 심실 사이막을 가로지르지 않는다.
- **배설:** 콩팥 형태와 양쪽 오줌관을 다시 그렸다. 두 관이 각각 방광으로 연결되고 입자는 실제 관의 곡선을 따라간다. 그림의 방광 저장량·오줌색·배뇨 상태와 사이드바 수치를 같은 상태로 연결했다.
- **체온:** 땀샘 관을 피부 표면까지 연결했다. 땀은 피부 표면에서 나타나 증발하고, 열 방출은 변화하는 곡선으로 표현한다.
- **동공:** 밝기에 따라 동공이 부드럽게 변하며 일시정지가 적용된다. 축동의 부교감신경 경로와 산동의 교감신경 경로를 구별했다. 경로 설명은 [NIH의 동공 반사 설명](https://www.ncbi.nlm.nih.gov/books/NBK537180/)과 [동공의 교감·부교감 조절 경로 문헌](https://pmc.ncbi.nlm.nih.gov/articles/PMC6305320/)을 참고했다.
- **조작:** 신경계에서 장면에 해당하는 조작 탭을 자동으로 연다. 골격계 이름표에 설명 선택을 연결하고 근절 화면에도 일시정지를 표시한다.
- **배치:** 장면 메뉴의 폭을 실제 상단 버튼 위치로 계산해 클릭을 가리던 문제를 해결했다. 긴 실험 설명과 그래프 축 이름을 재배치했다. 휴대폰에서 복잡한 그림은 최소 크기를 유지하며 그림 영역을 좌우·상하로 스크롤할 수 있다.
- **문구:** 화면의 ‘개념 문제’를 ‘확인 문제’, ‘가상 실험실’을 ‘관련 실험’으로 정리했다.

## 검증 결과

- 25개 장면을 실제 메뉴 클릭으로 전환: JavaScript 오류와 실패한 자산 요청 없음.
- 모든 사이드바 탭, 노출되는 슬라이더의 최솟값·최댓값, 조작 버튼, 확인 문제의 정답·오답 설명 및 다음 문제 동작을 확인.
- 일시정지 버튼이 있는 20개 장면: SVG 형상 좌표와 캔버스 화면이 정지 후 유지되는 것을 비교해 통과.
- 데스크톱·1024px·390px 이름표 겹침 검사 통과. 휴대폰의 큰 도식은 스크롤 영역 안에 배치했으며 소화·배설·면역·귀 장면에서 끝쪽 이름표까지 스크롤한 뒤 실제 클릭해 설명 표시를 확인.
- 방광 그림/사이드바 저장량 일치와 배뇨 후 감소, 판막엽의 모양 변화, 혈류 경로의 심방 도착, 밝기에 따른 동공 크기·경로 문구 변화를 별도로 검증.
- Node 회귀 검사 6개 통과: 혼잡한 이름표 배치와 경계, 호흡 흐름의 반전·멈춤, 고무막 기하, 횡격막·풍선 변화.

## 재실행

~~~powershell
node --test tests/body-diagram-labels.test.cjs tests/respiration-motion.test.cjs
node tests/human-body-browser-audit.cjs
~~~

브라우저 검사는 Playwright와 Chromium이 필요하다. 기본 설치 외의 경로를 사용하는 경우 PLAYWRIGHT_MODULE, BROWSER_EXECUTABLE 환경 변수로 지정한다. 결과와 화면 캡처는 기본적으로 OS 임시 폴더의 human-body-browser-audit에 저장하며 AUDIT_OUTPUT으로 변경할 수 있다.

이번 검사는 화면과 동작 중심이며 모든 확인 문항을 교과서·출제기준에 대조하는 별도 문항 감수는 포함하지 않는다.
