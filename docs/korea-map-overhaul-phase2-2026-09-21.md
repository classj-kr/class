# 한국지도 대개편 2차 — 산을 넘는 바람

2026-09-21. 역사 메뉴 완료 후 재개한 로컬 구현. 전체 대개편 완료나 운영 배포를 의미하지 않는다.

## 구현

- 기존 기후 `foehn` 개념의 학습 그림을 진부–강릉 실제 지도 단면으로 연결했다. 그림 문제에는 기존 원리 모형을 유지해 문항 A/B와 정답을 보존한다.
- A 진부(37.635, 128.553)와 B 강릉(37.755, 128.896) 사이 직선 약 33.0km를 241점으로 표본화한다. 기존 단면 도구와 같은 저장된 Copernicus DEM을 해독한다. 도로 경로나 대관령 고개 자체를 따라가는 선이 아니다.
- 검사 시 끝점 표본은 529m/18m, 최고 표본은 1,048m였다. 이를 산봉우리의 공식 높이로 표시하지 않는다. 세로 과장은 화면의 실제 가로·세로 눈금에서 계산한다.
- 동쪽/서쪽에서 오는 바람을 선택하면 지도 경로, 단면의 이동 방향, 풍상·풍하 색과 설명이 함께 바뀐다. 지형과 A/B 위치는 반전하지 않는다.
- 응결·강수 조건을 켜고 끈다. 끈 경우 상승 냉각·하강 가열만으로 같은 높이에서의 순가열을 설명하지 않는다.
- 바람은 표본 지형 위의 단조 포락선을 이용한 설명용 모형이다. 관측된 바람 궤적이나 대기 수치모형이 아니며 실제 풍속·기온·강수량을 계산하지 않는다.
- 해당 개념에서는 전국 계절풍과 계절 평년값 카드를 숨겨 다른 장면을 섞지 않는다. 개념을 바꾸면 기존 기후 화면을 복원한다.
- 이름 가리기, 문제 풀이, 학습 기록을 유지한다. 재생·일시정지 버튼은 없다. 대화상자·비활성 탭·화면 밖·동작 줄이기 설정에서는 해당 움직임을 멈춘다.
- 고도 자료 실패 시 오류와 실제 재시도를 제공하며, 0m나 가짜 산 모양으로 채우지 않는다. 요청 제한 시간과 실패 캐시 해제를 추가했다.
- 진입: `learning/inquiry/korea-map/index.html?lesson=foehn#climate`. 유효하지 않거나 주제가 다른 `lesson` 값은 무시한다.

## 근거와 한계

지형 생성·저작권은 기존 `tools/build_dem.py`, `tools/build_relief.py`, `data/README.md`의 Copernicus DEM / Mapzen 설명을 따른다.

[기상청 기후 설명](https://www.kma.go.kr/kma/servlet/NeoboardProcess?bid=press2&callback=&fno=1&k=ATC201106131057091_4cf0da9b-36da-4070-b5c8-fc957642c29d.pdf&mode=download&num=1416&ses=USER_SESSION)에서 동풍·영서 푄·높새바람 사례를 확인했다. 그 관측값을 이 단면의 기온 값으로 전재하지 않았다.

[Met Office — Foehn effect](https://weather.metoffice.gov.uk/learn-about/weather/types-of-weather/wind/foehn-effect)를 대조하여, 응결·강수 외의 발생 과정도 있으므로 강수 없는 푄이 불가능하다는 설명을 피했다. 이 장면은 실제 푄의 모든 과정을 계산하지 않으며, 모든 산 넘는 바람이 푄이라는 뜻도 아니다. 예보가 아니다.
