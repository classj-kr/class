# 지리 탐구 개편 검증

## 결과

기존 지리앱의 화면 구조와 92문제는 재사용하지 않았다. 지구본 렌더러 위에 8분류·32주제·64문제의 새로운 학습 경로를 만들었다. 학습 목록 검색, 초등 기초/중학 핵심/고교 확장 필터, 대표 지점 비교, 출처 확인, 주제별 문제·섞어 풀기·오답 다시 풀기를 지원한다.

홈 메뉴는 지리 탐구로 합쳤다. 지구본과 평면지도는 같은 지도 인스턴스를 사용하며 자료·선택 상태를 공유한다. 옛 지리 주소는 같은 앱을 평면으로 연다. 기존 학급 공개 경로는 유지했다. 이전 앱의 학습 기록은 삭제하지 않으며 새 문제에 옛 정답 기록을 적용하지 않는다.

## 교육 내용 대조

## 새 자료 검증

- 인구밀도: World Bank EN.POP.DNST **2023년**만 사용. 지도 도형 177개 가운데 값이 있는 169개에 연결. 미확인 8개는 null. 이전 앱의 불명확한 인구/면적 수치는 폐기했다.
- 기후: Peel 외(2007)의 논문 부록을 다시 받아 0.1° 원본 래스터를 직접 읽고 0.25° 격자 및 5대 기후로 재생성. 원본 결측 보존, 다운로드 SHA-256 기록. 전체 셀 수·방향과 사하라/콩고/시베리아/이탈리아/남극 표본을 확인했다.
- 판: USGS ArcGIS의 1,000개 반환 제한을 확인하고 두 페이지 1,175개 선을 수집. Other를 다른 경계로 임의 분류하지 않았다.
- 지형·국경·바탕 그림은 기존 지구본 지도 기능을 유지했다. 국가 밀도 도형만 기존 지도에서 가져오되 통계·문화 속성을 제거했다. 이 도형은 작은 국가/섬 표현과 정밀한 경계 판정에 한계가 있다.
- 상세 URL·가공·라이선스·재생성 방법: `learning/inquiry/globe/data/ATLAS-SOURCES.md`.

## 화면과 동작 확인

- 데스크톱 1440×950, 모바일 390×844에서 학습 목록, 검색·필터, 기후·밀도·판, 학습 카드 접기/열기, 모형 전환을 확인했다.
- 지구본↔평면 전환, 옛 지리 주소의 평면 시작, 해시 주제 선택을 확인했다.
- 확인 문제의 정오답 처리, 중복 답 방지, 오답만 재시도, localStorage 기록을 확인했다.
- 의미 있는 단위 검증: 성취기준 연결/좌표/레이어, 문제 식별자와 정답 범위, 통계 결측, 기후 원본/방향, 판 경계 페이지 수, 저장소 오류 대응, 메뉴 통합.
- 기존 지구본 자료 계약, 흐름 방향·날짜 변경선 테스트, 국내 지도와 홈 메뉴 계약을 유지했다.

## 구현상의 구분

전환 중에는 임시 WebGL 표면이 뒷경선을 따라 열리고 곡률을 줄이며 펼쳐진다. 완료 후에는 실제 메르카토르 지도/지구본으로 복귀한다. 전환 표면은 지형 텍스처를 사용하며 주제별 색상·이름표는 완료 후 원래 지도에서 다시 보인다. 도법을 엄밀하게 유도하는 교육 모형은 아니다. 동작 줄이기 설정에서는 전환과 판 모형 움직임을 생략하고 바람·해류도 처음에 정지한다.

## 후속 확장 범위

이 32주제는 핵심 학습 경로이며 지리·지구과학 전체 교육과정의 누락 없는 구현은 아니다. 다음은 별도 자료와 상호작용으로 확장할 대상이다: 북한 및 우리나라 지역별 산업의 세부 비교, 지정학적 분쟁과 평화, 실제 연령별 인구 통계, 여러 기후 관측소의 공인 평년값, 지진·화산의 시계열 관측 분포, 심층 해양 순환, 기단·전선·온대 저기압, 지구 공전과 태양 고도의 정량 모형. 현재 화면을 이런 기능이 구현된 것처럼 표시하지 않는다.
