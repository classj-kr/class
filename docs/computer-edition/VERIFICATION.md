검증일: 2026-09-20. 환경: Windows, 로컬 Chrome의 headless 브라우저.

- 기존 제목과 순서 36개 유지. 실제 `lessons/?lesson=...` 주소와 목차에서 개편본 사용.
- A01: 실제 그림 변환, 저장 전·후 작업 닫기, 저장본 다시 열기, 숫자 독립 과제, 확인 문항, 기록 복원·초기화 검사 통과. 1440·1024·768·390·320px의 네 화면 검사 통과.
- A02–J03: 35차시의 대표 실습 조작과 175개 문항의 오답·정답·재시도·기록 복원 검사 통과.
- 35차시 × 네 학습 화면 × 네 너비(1440·1024·768·390px), 560개 배치 검사 통과.
- 설명·문항·선지·해설에서 실제 KoPubWorld 웹폰트 사용을 140회 확인.

최종 기계 판독 기록: [verification-final.json](verification-final.json).

## 검증 중 수정한 문제

1. D02: 제스처 화면 안의 메뉴 클릭이 새 탭 동작으로 감지되어 메뉴가 닫히는 오류. 메뉴의 포인터·키보드 이벤트를 제스처 감지에서 제외했다. 이름 바꾸기 클릭과 공유·이름 바꾸기 키보드 실행을 검사했다.
2. J02: 작은 화면에서 실습 영역이 넘치고 분기 문장 전체가 회전하는 문제. 그리드 최소 너비와 분기 문장 변환을 수정하고, 실제 이미지로 겹침이 사라진 것을 확인했다.
3. G02: 최종 전체 실행에서 캡처 파일 쓰기가 일시적으로 실패했다. 화면 저장 재시도를 추가하고 G02의 모든 검사와 목차·초기화를 다시 통과했다. 이전 실패 기록을 삭제하지 않고 재검증 기록과 함께 보존했다.
4. A03: 동적으로 나타나는 설명에서도 API·펌웨어 세부를 제거해 이번 차시의 역할 구별 범위에 맞췄다.
5. 실제 제공되지 않는 조작을 요구하던 실습 지시를 수정하고 G01은 새로운 조합 기록 실습으로 교체했다.

원 실행: [verification.json](verification.json). 추가 실행: [G02](verification-g02.json), [J02](verification-j02.json). 대표 캡처는 같은 폴더의 차시별 PNG에 있다.

## 기존 검사

`node --test tests/computer-fundamentals-contract.test.mjs tests/computer-a01-model.test.cjs`: 32건 중 31건 통과, 1건 실패.

남아 있는 실패는 타자 연습 페이지의 스크립트 버전 문자열 검사다. 검사 기대값은 `20260910-fix-back-navigation`, 현재 타자 페이지 값은 `20260917-reading-words`다. 이번 교재 개편에서 타자 페이지나 해당 검사의 기대값은 수정하지 않았다. 기존 내용에 대한 계약 검사와 새 화면 브라우저 검사는 범위가 다르며, 실제 새 화면의 동작은 위 전용 검사로 확인했다.

## 확인 범위의 한계

브라우저 검사는 모든 기종의 모든 조작 조합을 증명하지 않는다. 실제 학생을 대상으로 한 독해 난도, 차시 소요 시간, 오개념 감소 효과는 아직 수업으로 검증하지 않았다. 이 결과는 구현과 콘텐츠 검토, 명시된 브라우저 검사 범위의 완료 기록이다.
