# 설명·활동·평가 재집필

2026-10-09. 목차, 36차시의 순서, 필수 용어는 유지한다. 사용자가 지적한 문제는 외관이 아니라 설명과 가르치는 방식, 실습의 질이다.

## 발견한 문제

- 정의 2–3문단으로 관계와 작동 과정을 건너뛰는 설명.
- 답을 미리 알려 주고 미리 정한 결과 화면을 바꾸는 실습.
- 본문과 실습의 과제가 연결되지 않는 차시(J01의 최댓값/파일 이동).
- 실제 오개념을 구별하지 못하는 자명한 오답 선택지.
- 아무 조작 한 번으로 `labUsed`를 인정하는 완료 기준.
- 모든 차시 앞에 비유 그림을 배치해 실제 사례의 설명보다 비유가 먼저 나오는 구성.

## 집필 기준

1. 차시마다 학생이 설명하거나 수행해야 할 결과를 한 문장으로 정한다.
2. 하나의 구체적인 사례를 시작 상태, 변화, 결과 순서로 충분히 설명한다.
3. 용어는 그 사례에서 하는 역할과 연결한다. 선행 학습하지 않은 내부 기술을 갑자기 늘리지 않는다.
4. 구조 관찰, 비교 실험, 조작 연습, 자료 판단, 절차 설계를 내용에 맞게 구분한다.
5. 실습은 학생이 비교할 조건과 확인할 증거가 있어야 한다. 단추 방문 횟수를 수행 증거로 삼지 않는다.
6. 문항은 학생이 혼동할 만한 원인·순서·판단을 구별하며 선택지별로 구체적인 근거를 설명한다.
7. 기술 검증과 실제 학생의 학습 효과 검증을 구별한다. 자동 검사 통과를 수업 효과의 증명으로 보고하지 않는다.

## 반영한 내용

- A01의 입력·처리·출력·저장 설명을 실제 그림 처리 과정으로 확장했다. 실제 사례를 먼저 보여 주고 공방 비유는 선택해서 펼치게 했다.
- A02–J03의 35개 본문에 학습 목표, 단계별 설명, 조건과 결과를 비교하는 풀이 사례를 집필했다. 목차·차시명·필수 용어 목록은 유지했다.
- 35차시마다 구조 관찰·조작 연습·비교 실험·원인 찾기·자료 판단·절차 설계 중 내용에 맞는 과제를 붙였다. 관찰 전 예상과 관찰 후 설명은 선택적으로 기록할 수 있다. 이 서술 내용의 타당성을 자동 채점한다고 표시하지 않는다.
- 서로 다른 모형 결과를 직접 기록해야 실습 확인 문제를 제출할 수 있다. 실행이 필요한 모형은 준비 화면을 기록하지 못하게 했으며 중복 관찰을 다시 세지 않는다. 단순 비교 모형은 기록 두 개와 확인 문항으로 판단한다. 모든 모형의 과제별 수행을 자동으로 완전히 판별하는 것은 아니다.
- A02는 같은 입력 화면에서 그림/피아노 프로그램의 다른 반응과 출력 음소거를 비교한다. 실제 기기의 스피커 연결을 바꾼다고 주장하지 않는다.
- E03은 파일 선택·편집·저장·다른 이름으로 저장·복사·이동·휴지통 모형으로 교체했다. 원본 내용과 위치, 수정본 내용과 위치, 파일 수를 확인해야 통과한다.
- J01은 최댓값의 초기값·비교 규칙·빈 입력 처리를 바꾸어 실행하는 모형으로 교체했다. 잘못된 규칙도 실제로 실행하고 양수·음수·같은 수·한 수·빈 입력에서 검증한다.
- G01은 한 자리의 두 조합과 두 자리의 네 조합을 모두 기록해야 통과한다.
- 실습 확인 35문항, 새 모형의 확인 6문항, A02 적용 2문항을 개정했다. 나머지 문항과 신규 문항을 합한 기존 175문항의 채점·재시도 동작을 검사했다.
- 개정 문항은 새 답을 받되 이전 판의 전체 학습 기록을 계정 저장 공간의 `:before-teaching-20261009` 항목에 한 번 보관한다. 모형 자체는 재방문하면 초기 상태이며 관찰 기록과 답 기록은 계정에서 복원한다.
