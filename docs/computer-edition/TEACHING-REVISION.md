# 설명·활동·평가 재집필

2026-10-09. 목차, 36차시의 순서, 필수 용어는 유지한다. 사용자가 지적한 문제는 외관이 아니라 설명과 가르치는 방식, 실습의 질이다.

## 발견한 문제

- 정의 2–3문단으로 관계와 작동 과정을 건너뛰는 설명.
- 답을 미리 알려 주고 미리 정한 결과 화면을 바꾸는 실습.
- 본문과 실습의 과제가 연결되지 않는 차시(J01의 최댓값/파일 이동).
- 실제 오개념을 구별하지 못하는 자명한 오답 선택지.
- 아무 조작 한 번으로 `labUsed`를 인정하는 완료 기준.
- 모든 차시 앞에 비유 그림을 배치해 실제 사례의 설명보다 비유가 먼저 나오는 구성.

## 집필 기준

1. 차시마다 학생이 설명하거나 수행해야 할 결과를 한 문장으로 정한다.
2. 하나의 구체적인 사례를 시작 상태, 변화, 결과 순서로 충분히 설명한다.
3. 용어는 그 사례에서 하는 역할과 연결한다. 선행 학습하지 않은 내부 기술을 갑자기 늘리지 않는다.
4. 구조 관찰, 비교 실험, 조작 연습, 자료 판단, 절차 설계를 내용에 맞게 구분한다.
5. 실습은 학생이 비교할 조건과 확인할 증거가 있어야 한다. 단추 방문 횟수를 수행 증거로 삼지 않는다.
6. 문항은 학생이 혼동할 만한 원인·순서·판단을 구별하며 선택지별로 구체적인 근거를 설명한다.
7. 기술 검증과 실제 학생의 학습 효과 검증을 구별한다. 자동 검사 통과를 수업 효과의 증명으로 보고하지 않는다.
8. 본문 제목과 소제목은 배우는 개념·관계를 직접 쓴다. 질문은 실제로 관찰하거나 판단해야 하는 과제에 사용한다.
9. 비유가 필요한 추상적 관계에는 입문자가 아는 상황과의 대응을 설명한다. 모든 차시에 비유를 채우지 않는다. 실제 동작보다 설명이 길어지는 도장 공방·학교 행사·택배 이야기 등은 사용하지 않는다.

## 2026-10-10 전체 검토와 수정

36차시의 본문·실습·평가를 읽고 연결을 재검토했다. 1차시의 실제 그림 처리와 숫자 과제는 유지하고 제목을 수정했다. 나머지 35차시에서는 제목·소제목·풀이 사례 제목을 개념 중심으로 정리하고 다음 사항을 고쳤다.

- **설명:** 호환성, 인터페이스, 드라이버, 플래시 메모리, FPS, 부호화, 전송 속도 등을 본문에서 설명한 뒤 문제에 쓰도록 보완했다. 소리의 비트 깊이, 영상의 FPS, 비트/바이트 속도에는 수치 예를 넣었다.
- **비유:** 15차시에 조리 도구/조리법, 작업대/보관함, 작업실 관리자, 악보/연주, 서류함, 표지/본문, 책갈피, 동기화/날짜별 사본, 모눈, 색칠표/작도, 스위치, 연결 도로, 연락처, 도서관 권한, 조리법을 선별했다. 비유 설명·대응표·실제 개념에 연결할 때의 주의점을 본문에 펼쳐 놓았다. 예전의 인물·문·열쇠 등을 그린 공통 SVG와 강제로 붙인 차시별 생활 비유는 실행 경로에서 제외했다. 나머지 21차시는 실제 자료·풀이 사례·조작으로 설명한다.
- **문항:** 65문항의 질문·선택지 또는 해설을 개정했다. 사라진 피아노 그림을 묻는 문항, 설치 파일 이름을 바꾸는 식의 지나치게 허술한 선지, 관찰하지 않은 사실을 정답 근거로 삼는 표현을 정리했다. 수정한 문항에는 revision 3을 붙였다.
- **B01 실습:** 부품 설명 클릭과 별도로 RAM/SSD 상태를 실제로 바꾸는 문서 모형을 추가했다. 미저장 수정의 소실과 저장한 수정의 재열기를 모두 수행해야 한다. 실제 부품 사진은 실습 아래에서 필요할 때 펼친다.
- **A04·A05 실습:** A04는 서로 다른 입력이 같은 숫자로 기록되는 쌍을 찾아야 한다. A05는 샘플링 레이트만 바꾼 비교와 비트 깊이만 바꾼 비교가 모두 필요하다.
- **H03 실습:** 같은 도서관의 과거 안내와 현재 특별 공지를 비교한다. 가상 자료임을 화면에 명시한다. 검색 화면·탭 조작을 원문 관찰로 기록하지 않으며, 두 원문의 날짜와 적용 범위를 읽어야 한다.
- **I01 실습:** 같은 계정·같은 발표 자료에서 읽기와 수정 권한을 비교한다. 로그인만 끝내거나 다른 파일 하나를 눌러서는 완료되지 않는다.
- **J03 실습:** 원래 오류를 고친 뒤 다른 정상 파일과 존재하지 않는 파일까지 확인해야 한다.
- **기록:** 변경 전 문항·관찰 기록은 계정 저장 공간의 `:before-review-20261010`에 한 번 보관한다. 바뀐 과제는 관찰 revision 3으로 구별한다. 학생의 자유 서술을 자동으로 이해·채점한다고 표시하지 않는다.

비유 선정은 보편적인 관계와 본 차시의 설명 필요성을 기준으로 한 편집 판단이다. 특정 학원의 공통 교육과정을 확인했다는 뜻은 아니다. 책상과 보관함의 관계는 [Crucial의 메모리 설명](https://test.crucial.com/articles/about-memory/support-what-does-computer-memory-do), 이름과 통신 주소의 관계는 [Cloudflare의 DNS 설명](https://developers.cloudflare.com/learning-paths/cybersafe/concepts/what-is-dns/), 두 상태의 표현은 [CS Unplugged의 이진수 활동](https://classic.csunplugged.org/documents/activities/binary-numbers/unplugged-01-binary_numbers.pdf)과 대조했다. 학생에게 보이는 설명과 예시는 별도로 집필했다.
