# 실험 동작·채점 수정 기록

## 확인하고 고친 결함

- 전기 회로: ‘전지 1개에서 2개로 늘리면?’이라는 질문을 현재 전지 1개의 밝기로 채점하여 ‘같다’를 정답으로 인정했다. 이제 전지 1개는 비교 기준으로만 안내하고, 2개로 바꾼 후에는 ‘밝아짐’만 맞는 예상으로 판정한다. 끊어진 회로는 기준 회로와 비교하는 별도 질문으로 전환한다.
- 전기 회로: 조건을 바꿔도 이전 관찰 설명이 남았다. 그림, 설명, 결과 표시를 현재 조건에 맞게 갱신한다.
- 예상 변경: 회로 외 99개 앱의 선택 이벤트에 기존 결과 무효화를 추가했다. 연속 렌더링 앱은 `checked` 상태도 해제하여 옛 판정을 되살리지 않는다.
- 질문 재생성: 46개 앱에서 선택 버튼만 지우고 내부 예상값은 남기는 코드를 수정했다. 새 질문은 선택되지 않은 상태로 시작한다.
- 기존 확인 문제: 다른 보기를 고른 뒤 이전 정답 판정·해설이 남지 않도록 공통 변경 처리를 추가했다.
- 생물 다양성: 100개체 중 20개체가 사라진 결과를 ‘80% 넘게 남음’으로 표시하던 오류를 ‘80% 남음’으로 수정했다. 식물 개체 단위를 ‘마리’에서 ‘개체’로 바꿨다.
- 회로·전자석 그림: 같은 방향의 전지를 직렬로 연결하고, 철심 앞뒤로 이어지는 코일과 스위치를 표현했다. 극성 반전, 전원 차단, 영구자석 비교를 구분했다. 전원을 껐을 때 떨어진 클립 수를 켰을 때의 수와 일치시켰다.

## 검증

- `science-circuit-behavior.test.cjs`: Chrome / Windows WebKit. 전지 1개에서 오채점하지 않음, 2개에서 세 예상의 판정, 끊어진 회로, 전자석 세기 변화·극 반전·전원 차단·영구자석 비교, 태블릿/노트북 화면 범위.
- `science-prediction-lifecycle.test.cjs`: Chrome / Windows WebKit 각각 104개 앱. 예상 입력 100개, 기존 문제 416개에서 답 변경 후 판정 초기화. 질문 재생성은 초기 화면에서 해당 경로가 있는 30개 앱을 실행 검사했다. 소스 수정 대상 46개 전체 모드의 과학적 정답을 검증했다는 뜻은 아니다. 예상 초기화 검사는 과거 결과를 주입하여 재현하는 상태 회귀검사다.
- `science-physical-invariants.test.cjs`: 전류·전압 54조건, 마찰 72조건, 충돌 81조건, 생존 비율 4조건. 앱의 정답 키가 아닌 별도 계산식·보존 조건과 비교했다.
- 기존 전체 앱 검사: 104개 앱 / 416문항, 조건 조작·실행·초기화 회귀검사 통과.
- 기존 핵심 보충 경로: 611상태 / 1,833응답 검사 통과. 대표 15개 앱의 노트북·태블릿 레이아웃 검사 통과.
- 교육과정 자료 목록과 앱 매핑 계약 검사 통과. 레퍼런스 파일을 수정하거나 삭제하지 않았다.

## 검증 한계 / 남은 범위

이 수정은 확인된 회로 오류와 공통 채점 상태 결함을 해결한 것이다. 104개 실험의 모든 과학적 모델·상황별 그림·문제 정답을 독립적으로 전수 검증한 것은 아니다. 필수 실험의 최종 누락 여부도 이번 검사만으로 새롭게 확정하지 않는다.

Windows Chrome/WebKit과 화면 크기·터치 입력을 사용했다. 실제 iPad Safari 및 ChromeOS 기기에서의 검사와 동일하지 않다. 다른 실험의 장치 표현과 조건별 설명·채점 일치 여부는 개별 검토가 남아 있다.
