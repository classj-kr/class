# 성취기준 473개 역방향 대조

정적 교육과정 대조표입니다. 관련 기능/모의활동 존재는 성취기준 완전 충족, 실제 실험 대체, 브라우저 동작·수치 정확성 보증을 뜻하지 않습니다. 타학년 앱은 그대로 수업에 사용 가능하다는 판정이 아닙니다.

‘직접 대응 미확인’은 이 실험실 안의 기능 판정이며 사이트 전체에 콘텐츠가 없다는 뜻이 아닙니다. 조사·토론·설계 성취기준은 앱 추가보다 활동지·협업/기록 기능이 적합할 수 있습니다.
