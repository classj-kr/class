각 패널은 조건 선택 → 관찰 결과 → 관찰 기록 표 → 확인 문제 → 초기화로 작동한다. 맹점 화면은 점을 자동으로 숨기지 않으며 학생이 관찰한 결과를 별도로 선택한다. 수치가 있는 나머지 모형은 실제 실측 자료가 아니라는 점을 명시했다. 기록은 현재 페이지 메모리에만 남고 새로고침하면 사라진다.

원문 활동 19개에 대응하지만, 실물 제작·소리굽쇠 실물 관찰·실측 전체를 완료한 것으로 세지 않는다. 태양 고도 측정기 제작, DNA 입체 모형 제작, 발열 조리장치 제작은 대조표에 `부분`으로 남겼다. 진로·자료 조사·토론·홍보물 제작과 기기 센서 실측·실시간 외부 데이터 활동을 모형 하나로 완료했다고 표시하지 않았다. 전체 교육과정의 모든 활동이 완료됐다는 보고가 아니다.

## 근거와 검증

- 성취기준·활동은 `references/moe/2022-revised-curriculum/extracted/09-science.txt`와 대조했다. 원문은 수정하지 않았다.
- 정확한 앱·성취기준·원문 행·부분 구현 경계는 `required-gap-review.cjs`에 있으며 현재 앱·활동·단원·성취기준 역방향표에 반영했다.
- `tests/science-required-experiments.test.cjs`: 18개 실험, 153개 조건, 459개 정답·오답 선택 검사 통과. 기록·초기화·화면 표시 검사 포함.
- 크롬북 1366×768, 아이패드 가로 1024×768 및 세로 820×1024·768×1024를 Chrome에서 재현하여 점검했다. 실제 iPad Safari 기기 검증은 아니다.
- 대표 렌더링: `required-gap-screenshots/`. 용수철과 생성물 검출 화면은 육안으로도 확인했다.
- 해수면 모형은 [NASA JPL의 육지 얼음·떠 있는 얼음 비교](https://www.jpl.nasa.gov/edu/resources/lesson-plan/whats-causing-sea-level-rise-land-ice-vs-sea-ice/), 맹점 관찰은 [Exploratorium 실험](https://www.exploratorium.edu/snacks/blind-spot)으로 교차 확인했다. 연소 생성물 검출과 안전 범위는 교육과정 원문 1769–1781행을 따랐다.
