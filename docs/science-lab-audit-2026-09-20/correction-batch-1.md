- `npm run test:curriculum`: 교육과정 파일 목록 및 기존 전기 회로 계약 검사 통과.
- [science-grade-scope.test.cjs](<E:/webprojects/class/tests/science-grade-scope.test.cjs>): 6개 앱의 실제 브라우저 실행, 총 24문항의 미선택/오답/재선택/정답 처리, 두 재구성 앱의 초기화 검사.
- 용해: 0/20/100℃와 소금량 경계값, 전후 무게, 조건 변경 후 오래된 애니메이션 취소.
- 산·염기: 4종 용액의 두 리트머스 변화, 용액 변경 후 이전 결과 취소.
- 전기: 직렬/병렬의 정성적 저항 표시, 전압·저항 경계값의 전류, 설명 갱신.
- 계절: 여름/겨울 남중고도·낮 길이·정오 그림자 비교, 오후 약 10° 고도의 긴 그림자, 지평선 아래 표시, 0°/23.44° 공전 비교.
- 모든 앱의 1365px/390px 화면 캡처와 390px 가로 넘침 검사. 페이지 자바스크립트 오류 없음.

Codex의 브라우저 조작 도구는 로컬 ACL 오류로 실행되지 않아, 기존 설치된 Playwright와 별도 임시 프로필의 헤드리스 Chrome으로 검증했다. 사용자 브라우저 세션은 사용하지 않았다. 테스트는 외부 리소스 요청을 막고 로컬 앱만 연다.

이 컴퓨터에서 재실행:

```powershell
$env:NODE_PATH = 'C:\Users\A\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\node_modules'
$env:SCIENCE_BROWSER = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
npm run test:science-scope
```

다른 환경에서는 설치된 Playwright를 사용하고, 필요할 경우 `SCIENCE_BROWSER`를 해당 브라우저 실행 파일로 지정한다. `SCIENCE_SCREENSHOT_DIR`를 지정하면 화면 캡처도 저장한다.

## 남은 범위와 기존 조사표의 관계

이번 교정은 전체 102개 중 우선순위 6개다. 나머지 96개 앱을 교정 완료했다고 볼 수 없다. 이번 6개도 해당 성취기준 전체를 대체하는 완성형 수업 도구라는 뜻은 아니다. 용질 종류·진하기 비교, 산·염기 혼합과 물질 반응, 시간별 고도·그림자·기온 기록, 전력과 에너지 전환 등 기존 전수조사에서 지적한 나머지 기능은 별도다.

`apps.md`, `standards.md`, `activities.md`, `audit.json`, `inventory.json`은 **교정 전 전수조사 스냅샷**으로 보존했다. 이 6개 앱의 현재 상태는 이 문서를 우선한다. 원래 표의 범위 초과·오류 건수를 현재 미해결 건수로 인용하면 안 된다. 원본 감사 생성기의 `--check`는 소스 해시 변경을 감지하도록 설계되어 있으므로, 교정 후에는 현재 소스와 일치하지 않는다고 보고한다. 최신 전수표로 갱신하려면 변경된 기능·연결 기준을 재판정한 뒤 인벤토리와 표를 함께 재생성해야 한다.
