# 탐구활동 261개 역방향 대조

정적 교육과정 대조표입니다. 관련 기능/모의활동 존재는 성취기준 완전 충족, 실제 실험 대체, 브라우저 동작·수치 정확성 보증을 뜻하지 않습니다. 타학년 앱은 그대로 수업에 사용 가능하다는 판정이 아닙니다.

모의활동: 해당 관찰·조작의 핵심 모형 존재. 부분: 소재/일부 단계만. 타학년: 다른 학년·과목 앱에 관련 기능만 존재. 미확인: 직접 수행 기능 미확인. 원문의 탐구활동 제시는 앱 제작 의무 목록이나 별도 성취기준으로 계산하지 않습니다.
