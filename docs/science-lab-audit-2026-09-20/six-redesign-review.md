# 전수검사 후 남은 여섯 화면 개선

2026-09-20. 기존 104개 앱 전수검사에서 시각 재설계가 필요하다고 남긴 여섯 항목을 수정했다. 전체 앱을 새로 제작하거나 모든 과학 수식을 독립 검증한 작업은 아니다.

## 반영 내용

| 대상 | 개선 및 검증 |
|---|---|
| 증류 | 전열기, 플라스크, 온도계, 냉각관, 냉각수 입출구, 받는 용기를 연결했다. 냉각수는 낮은 쪽으로 들어가 높은 쪽으로 나온다. 기화·냉각 이후에 액체가 모인다. 가열 후에도 원래 용기에 액체가 남도록 표현했다. 에탄올 혼합물의 완전 분리나 정량 수율을 주장하지 않는다. |
| 날씨 | 밝은 낮/어두운 밤에 맞춘 배경과 글씨. 구름과 헤더를 분리하고, 상승·하강 및 해풍·육풍의 방향을 현재 조건에 연결했다. 두 온도는 밝은 카드에서 같은 크기로 읽는다. |
| 암석 | 마지막 테두리의 CSS 채움이 결정을 가리던 오류를 없앴다. 결정들이 빈 영역 없이 시야를 채운다. 큰 결정은 관찰 폭을 50/100 mm로 바꾸고 눈금도 함께 바꾼다. 자동 관찰 폭 변경을 안내하며, 시간 수치와 단위가 갈라지지 않게 했다. |
| 지구계 | 선택한 두 권을 그림으로 분리하고 영향 방향을 강조했다. 작은 표의 겹친 현상 이름들은 점 기록으로 바꾸고, 설명은 HTML에 남겼다. 이 활동과 관계없는 물 저장소의 체류 시간 주의문은 제거했다. |
| 열기관 | 열원, 피스톤, 열펌프와 에너지 전달 방향을 표시한다. 온도에 따른 모형 값으로 열/일의 배분 막대를 그린다. 막대는 에너지 100 기준이며 순간 유량이 아니다. 불가능한 100% 순환 기관은 피스톤을 움직이지 않는다. |
| 핵융합 | 반응 전의 수소 4개/헬륨 3개와 반응 후의 헬륨/탄소를 비교한다. 양성자와 중성자를 구분하고 핵자 수 보존 및 에너지 방출을 표시했다. 여러 반응 단계와 양전자·중성미자의 생략을 명시했다. |

원래의 선택·예상·채점 구조는 유지했다. 질문/설명용 명조 글꼴 설정은 변경하지 않았다. 교육과정 레퍼런스 원본은 수정하거나 삭제하지 않았다.

## 실제 실행한 검사

- Chrome와 WebKit 각각 6개 앱·15개 모드·106개 범주/범위 조건. 실행 오류, 잘못된 도형 좌표, 명시적 도형 스타일 누락 없음. 기존 수치 verdict/개념 질문 차이 경고 20건씩은 실제 채점을 별도 검사했다.
- 새 회귀검사: 엔진별 133개 상태, 총 266개. 증류 12, 날씨 18, 암석 15, 지구계 10, 열기관 70, 핵융합 8.
- 새 상태의 1366/1024/820/768 px 검사: 엔진별 32개 레이아웃, 총 64개. 별도 Chrome 모드별 60개 조합의 글자 겹침/잘림 검사도 통과.
- 전지 직렬 연결의 밝기 판정, 전자석 제어/장치, 실시간 결과/채점 회귀 재검사.
- 물리 불변량 검사: 회로 54, 마찰 72, 충돌 81, 생존 비율 4개 조건.
- 필수 보충 실험 611개 상태와 1,833개 선택지 판정 검사.
- 앱 목록·로컬 스크립트 캐시·교육과정 원본 참조 계약 검사.

원시 자료: [Chrome 모드 검사](six-redesign/summary-chromium.json), [WebKit 모드 검사](six-redesign/summary-webkit.json), [Chrome 추가 회귀](six-redesign/regression-chromium.json), [WebKit 추가 회귀](six-redesign/regression-webkit.json).

## 한계

Chrome는 Windows에 설치된 Chrome, WebKit은 Windows에서 실행한 엔진이다. 터치와 화면 폭을 모사했지만 실제 ChromeOS/iPadOS 기기 검사는 아니다. 외부 웹폰트 요청을 차단한 회귀검사에서는 로컬 대체 글꼴이 사용된다. 기기 고유 글꼴·Safari 버전에서 생기는 차이까지 확인했다는 의미는 아니다.

그림은 개념 모형이다. 증류의 실제 온도/수율, 날씨 예보, 실제 암석 결정 분포, 실제 열펌프 성능이나 핵반응량을 재현하는 도구는 아니다. 관찰 폭과 에너지 정규화처럼 정량 의미가 있는 표현은 화면에 기준을 함께 표시했다.
