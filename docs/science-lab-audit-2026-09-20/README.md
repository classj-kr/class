## 조사 범위와 판정법

기준은 복구된 [09-science.txt](<E:/webprojects/class/references/moe/2022-revised-curriculum/extracted/09-science.txt>)이다. 초3~6, 중학교, 고교 공통·일반선택·진로선택·융합선택을 포함한다. 별책 20 과학계열 전문 교과, 국수사영, 실험실 밖의 사이트 콘텐츠는 이번 범위가 아니다. 고교 선택과목 전부를 모든 학생이 이수한다는 뜻도 아니다.

1. 카탈로그 102개와 실제 앱 폴더 102개를 일치 확인했다. 각 앱의 HTML·JS 총 204개를 수집했다.
2. 제목/메타데이터에만 의존하지 않고, 조작 버튼·동적 선택항목·모형 결과·설명/퀴즈를 읽었다. 2차 버튼/모드 대조로 제목에 드러나지 않는 기능도 반영했다.
3. 성취기준 본문, 탐구활동, 성취기준 해설과 적용 시 고려사항을 비교했다. 내부 계산용 수식이 있다는 이유만으로 학생 학습범위 초과라고 판정하지 않았다. 화면·설명·평가에 제시되는 내용은 구분했다.
4. 관련 앱이 있어도 실측, 대조실험, 설계, 자료해석, 발표, 실천 등 요구 행동이 없으면 완전 충족으로 판정하지 않았다.
5. 초3과 초4처럼 같은 학년군 안의 배치는 원문만으로 오배치라고 하지 않았다. 앱의 특정 학년/학기 표시는 학교·교과서 운영에 따라 추가 검토해야 한다.

‘직접 대응 미확인’은 **이 102개 앱에서 확인하지 못했다는 뜻**이다. 사이트 전체에 없다는 확정이나 새 앱을 하나씩 만들어야 한다는 뜻이 아니다. 조사·토론·진로·윤리·실천 기준은 활동지, 기록·공유 기능 등으로 지원하는 편이 적절할 수 있다. 제시된 탐구활동 역시 별개의 필수 앱 제작 목록으로 해석하지 않는다.

### 1. 과학 설명·수치 표시 오류

**동공 빛반사의 중추를 연수로 표시한다.** [반사 앱의 모형](<E:/webprojects/class/learning/inquiry/science-lab/reflex-nerve/app.js:34>)과 [선택 버튼](<E:/webprojects/class/learning/inquiry/science-lab/reflex-nerve/index.html:40>)이 모두 ‘연수’라고 한다. 중뇌의 덮개앞핵 및 에딩거-베스트팔핵 경로로 수정해야 한다. 무조건반사를 척수/연수만으로 설명한 문구도 함께 검토한다. 근거: 중뇌의 동공 빛반사 중계를 연구한 [원저 논문](https://pubmed.ncbi.nlm.nih.gov/10938320/), [신경해부학 경로 해설](https://www.ncbi.nlm.nih.gov/books/NBK553169/).

**계절 앱에서 그림자 숫자가 화면 잘림 길이에 영향을 받는다.** [seasons/app.js](<E:/webprojects/class/learning/inquiry/science-lab/seasons/app.js:152>)는 화면 경계로 제한한 `shadowLen`을 막대 높이로 나눠 ‘그림자 ○배’로 표시한다. 코드 식을 대입하면 오후 태양고도 10°에서 실제 기하학적 비율은 약 5.67배인데 표시값은 약 3.13배로 잘린다. 그림용 길이와 측정값을 분리해야 한다. 이 값은 소스 식 재현 결과이며 브라우저 캡처 검증은 하지 않았다.

## 이미 있는 기능 — ‘없다’고 세면 안 되는 것

- 전자석: `circuit-bulbs`에 전원·극 방향·코일/전지 조건·영구자석 비교가 있다.
- 계절: `seasons`가 있고, 태양의 남중고도와 낮길이 및 축 기울기를 다룬다.
- 화석: `rock-layers`에 ‘화석 함께 넣기’와 매몰 표시가 있다. 부족한 것은 화석 특징/환경 추론 활동이다.
- 짚신벌레: `microscope` 표본에 있다. 해캄과 버섯까지 모두 있다는 뜻은 아니다.
- 시금치 색소 분리: `separation-methods`의 크로마토그래피에 있다. 고교 활동으로 연결하고 추출 절차를 보완할 수 있다.
- 젖산발효: `energy-metabolism`에 산소 없음 모드가 있다. 실제 발효 실험 설계/생성물 측정과는 다르다.
- 물 전기분해: `redox`에 물(묽은 황산) 선택과 수소/산소량 모형이 있다.
- 전구 직렬·병렬: 초등 2022 원문에서는 제외한다. 초등은 전지 직렬연결·전자석, 중학교는 저항 직렬·병렬의 특징을 다룬다. 중등용 전구 관찰 예시는 별도 구현 여부로 구분해야 한다.

## 실행 순서 제안

1. 설명 오류(동공반사), 측정 표시 오류(그림자), 원문에 명시된 범위초과 설명/평가를 먼저 바로잡는다.
2. 앱별 `학년군·과목·성취기준·탐구활동·지원 단계·심화 내용` 등록부를 만든다. 같은 기능이 다른 학년에 숨어 있는 문제를 해결한다. 코드만 태깅하고 ‘충족’으로 표시하면 안 된다.
3. 초등의 직접 관찰/기초실험 공백부터 기존 앱에 추가한다. 식물·열·기체무게·초등 빛·태양 측정 기록을 우선한다.
4. 중등 공백과 고교 지원 과목을 나누어 보완한다. 진로/융합선택의 조사·토론·설계는 활동지/기록·공유 형태도 고려한다.
5. 수정된 앱을 실제 브라우저에서 기본값·경곗값·모드 전환·초기화·퀴즈 일치까지 검증한다. 실제 측정치/모형 가정/단위/유효숫자도 별도 검증한다.

이번에는 조사와 보고서 작성만 수행했다. 수정 우선순위 제안은 구현 완료를 뜻하지 않는다.

현재 교정본은 워크스페이스 루트에서 검사한다:

```powershell
npm run test:science-audit
```

추후 소스 변경 시 현재 수작업 판정 파일을 먼저 검토하고 현재 생성물만 갱신한다:

```powershell
node scripts/sync-science-catalog.cjs --apply
node scripts/build-current-science-audit.cjs --refresh
npm run test:science-audit
```

당시 조사에서는 원문과 앱을 변경하지 않았다. 이후 교정에서는 앱을 수정했으며, 교육부 원문 파일은 변경·삭제하지 않았다. 현재 변경과 검증 범위는 문서 상단의 현재 결과 링크를 따른다.
