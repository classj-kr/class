# 초3~중3·고1 시험 대비 점검 결과

## 범위와 판정

대상은 초3~초6, 중1~중3, 고1 통합과학1·2다. 고2·고3 선택과목 및 과학탐구실험 전체는 이번 범위에 포함하지 않는다. 학년은 앱 편성이며 실제 학교의 단원 배치와 시험 범위는 다를 수 있다.

로컬 교육부 2022 개정 과학 교육과정의 공통 범위 220개 성취기준, 61개 단원을 대조하여 **기준별 핵심 확인 문항의 빈 항목을 없앴다**. 기존 실험의 조건·관찰 결과에 더해 분류·생물다양성, 태양 활동, 빛의 합성, 유전 정보 발현, 산화·환원 등 빠져 있던 개념을 확인 문제로 보완했다. 모든 기준에 문제가 있다는 사실을 모든 교과서 세부 내용이나 모든 학교 시험 유형을 망라했다는 뜻으로 해석하지 않는다.

## 추가한 시험 대비 기능

- 기본·심화 구분 없이 8개 학년과 61개 단원으로 선택한다.
- 새 문항 241개: 기준별 220개와 자료 해석 보강 21개. 모든 선택지에 정오 판정과 해설을 제공한다.
- 8개 자료 표와 3개 그래프: 가열·냉각 곡선, 태양 고도·그림자, 계절, 광합성, 반응의 온도 변화, 속력–시간, 중화 등을 다룬다. 자료는 학습용 모형 값이다.
- 실험 목록의 ‘개념·실험 해석 문제 풀기’에서 접근한다. 관련 앱의 ‘핵심 개념·실험 해석 문제’는 필요할 때 펼친다.
- 답안 상태는 현재 페이지의 메모리에만 유지한다. 제출·계정·성적 서버 저장 기능은 추가하지 않았다.
- 기존 104개 앱과 416개 문항은 유지하며, 별도 확인 문제 페이지를 새 실험으로 세지 않는다.

학년별 새 문항 수: 초3 26, 초4 27, 초5 26, 초6 28, 중1 28, 중2 36, 중3 35, 고1 35.

## 후속 문항·서체 개선

- 새 241문항 전체의 선택지를 다시 읽고, 194문항에서 질문 또는 오답을 수정했다. 엉뚱한 속성·도덕적으로 나쁜 행동만 고르면 되는 오답을 실제 오개념·변인 혼동·수치 비교로 바꿨다. 유지한 47문항은 순서·계산·개념 구별형이었다. 이는 실측 난이도나 변별도 검증을 뜻하지 않는다.
- 정답 위치가 3문항마다 반복되던 순서를 문항 ID에 따른 섞기로 바꿨다. 새로고침해도 같은 문항의 선택지 순서는 유지된다.
- 교육과정 코드와 문항 수는 유지했다. 편집 내역은 `scripts/science-exam-choice-review.cjs`, 일치·화면 검사는 `tests/science-exam-editorial.test.cjs`로 확인한다.
- 별도 문제 페이지의 보이는 제목과 반복 단원 이름, 문제·선택지 외곽선을 제거하고 선택지를 ①②③으로 표시했다. 화면 낭독기용 제목은 남겼다.
- 104개 실험 앱과 문제 페이지의 설명·문제·선택지에 Noto Serif KR 명조체를 적용했다. 조작 버튼·학년 탭·수치 표시는 기존 서체로 유지한다. 웹폰트가 실제 로딩되는지 Chrome에서 확인했다. 네트워크로 글꼴을 받지 못하면 바탕·AppleMyungjo·기본 serif 순으로 대체된다.

## 기존 문항 정정

21개 앱의 기존 문항 30개를 수정했다. 정확한 문항·선택지·정답·해설은 [정정 목록](exam-question-corrections.cjs)에 보존했다.

| 범위 | 주요 정정 |
|---|---|
| 초등 | 모든 나무가 뜬다는 단정 제거, 어는점·끓는점의 순수한 물/기압 조건, 그림자의 투영 조건, 음판 비교 조건, 한살이 단원의 범위를 벗어난 먹이 단계 문항 교체 |
| 초등 지구·환경 | 최고 기온을 자료로 판단, 물과 모래의 온도 변화 조건, 바닷물 잔류물을 소금만으로 설명하지 않음, 계절의 같은 지역 조건, 뒤집히지 않은 지층 조건, 물의 순환 모형의 경계 |
| 중학교 | 입사각의 법선 기준, 일정 속력과 일정 속도의 구별, 연소 전 질량에 소비된 산소 포함, 기관계 협력, 재흡수의 조건, 선 스펙트럼 원리, 주요 염류 비율의 적용 범위, 판 경계 유형 차이 |
| 고1 | 발전기의 전자기 유도 원리, 태양 전지판 각도의 조건, 대멸종 가설의 증거 판단, 화산 황산염 에어로졸, 지구 권역 물질 이동, 확산의 같은 부피·막 투과 조건 |

문항과 연결된 기존 안내도 함께 맞췄다. 날씨 시각을 고정된 법칙으로 단정하지 않고, 힘의 평형에서는 방향도 일정함을 명시했다. 물 순환 탱크는 평균 체류 시간을 완전 교체 시간으로 표현하던 오류를 수정하여 완전 혼합 예시에서는 처음 물의 약 37%가 남게 했다. 평균 체류 시간의 해석은 [USGS 물 수지 자료](https://water.usgs.gov/watercensus/AdHocComm/Background/WaterBudgets-FoundationsforEffectiveWater-ResourcesandEnvironmentalManagement.pdf)와 대조했다.

## 크롬북·아이패드 우선 후속 검사

터치 영역을 보완하고 Windows WebKit 터치 입력 및 Chrome 키보드 검사를 추가했다. [기기 우선 검사 범위](school-device-check.md)에서 실제 기기 검사와의 차이를 확인한다.

## 검증 방법과 경계

- `tests/science-exam-review.test.cjs`: 220개 기준과 정확히 대응하는지 확인, 241문항의 723개 선택지 판정, 61개 단원 필터, 답안 유지·초기화, 6개 앱 통합 및 목록 연결 검사.
- `tests/science-exam-corrections.test.cjs`: 기존 정정 30개 문항의 실제 HTML·정답·해설 및 과학적 조건 검사.
- 기존 104개 앱·416개 문항과 필수 실험 패널의 회귀 검사도 별도로 유지한다.
- 화면은 로컬 Chrome에서 1366×768, 1024×768, 820×1024, 768×1024를 재현한다. 실제 Chromebook 하드웨어 및 iPad Safari에서의 검증은 아니다.
- 실제 실험 설계·장치 제작·현장 관찰을 구현하지 않았다는 이유로 시험 대비 작업을 계속 확장하지 않는다. 모형은 실제 수행평가를 대신한다는 뜻이 아니다.
- 이 결과는 로컬 작업물이다. 배포 또는 실제 사용자 환경의 반영 여부는 별개다.

## 근거와 재현

- 교육과정 원문: [09-science.txt](../../references/moe/2022-revised-curriculum/extracted/09-science.txt). 원문 파일을 수정하거나 삭제하지 않았다.
- [단원·성취기준·원문 행 번호](../../learning/inquiry/science-lab/exam-bank-meta.js), [문항 연결 코드](../../learning/inquiry/science-lab/exam-bank.js). 각 기본 문항 ID는 성취기준 코드이며 보강 문항은 `@` 접미사를 쓴다. 실제 실험이 없는 개념은 별도 문제 페이지에서 제공하며 실험 구현으로 오인 집계하지 않는다.
- `node scripts/build-science-exam-meta.cjs --check`로 원문 메타데이터와의 일치를 확인한다.
- `node --test tests/science-exam-review.test.cjs tests/science-exam-corrections.test.cjs`로 문항과 브라우저 동작을 확인한다. Playwright 및 로컬 Chrome 실행 경로가 필요하다.
- 바닷물의 여러 이온: [NOAA](https://oceanservice.noaa.gov/facts/whysalty.html). 화산 에어로졸: [NASA](https://science.nasa.gov/science-research/earth-science/climate-science/aerosols-small-particles-with-big-climate-effects/).
- 전체 과목의 실제 탐구활동 연결 여부는 [별도 활동 대조](common-experiment-census.md)에 남긴다. 그 표의 미구현 현장 활동을 이번 시험 대비의 누락과 혼동하지 않는다.
