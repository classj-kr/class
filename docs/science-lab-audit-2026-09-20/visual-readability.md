# 과학 실험실 시각 개선 검증

2026-09-20. 우선 대상은 크롬북과 아이패드이며, 휴대전화는 기존 기능의 깨짐 여부만 확인했다.

## 반영 내용

- 104개 실험에 공통 읽기 규칙 적용: 본문 15px, 보조 글자 13–14px, 소제목·결과값 18px, 페이지 제목 21px.
- 결과 숫자와 단위의 불필요한 줄바꿈을 줄이고 조작 버튼·선택 상자는 최소 높이 44px로 조정.
- 긴 설명 및 가로축 제목은 도식 아래의 문서 흐름으로 분리. 그래프 없이 설명만 있는 SVG의 빈 공간 축소.
- 44개 앱의 기존 라벨 이동 코드가 폰트 여백을 실제 겹침으로 판단하던 문제 수정. 항목명과 결과값이 분리될 때는 함께 표기.
- 계절 태양 경로의 좌표 투영·범례·시간 표시, 자석과 나침반 간격, 소리 결과 표시 수정.
- 추가 발견된 교배표, 이동하는 자 눈금, 인체 기관 이름, 풍력 비교, 연소·화산·생애 주기·해류·별의 밝기 설명 수정.
- 교육과정 원본 파일은 수정하지 않았다. 이전에 제거한 목록의 안내 문구와 성취기준 배너도 복원하지 않았다.

## 검증 결과

Chrome의 독립된 로컬 테스트 세션에서 1366×768, 1024×768, 820×1024, 768×1024 화면을 사용했다. 사용자 브라우저 프로필이나 외부 사이트는 사용하지 않았다.

- `node scripts/audit-science-layout.cjs --check`: 104개 앱, 728개 화면·모드 조합 통과.
- 검사 항목: 문서 가로 넘침, 공통 도식 내부 가로 넘침, 검사 대상 HTML 글자 크기, 관찰·그래프 SVG 글자 잘림 및 실제 글자 획의 겹침. 최종 검출 0건.
- `node --test tests/science-visual-layout.test.cjs tests/science-all-apps.test.cjs tests/science-grade-scope.test.cjs`: 4개 테스트 통과. 104개 앱의 기존 문제 416개 작동 확인.
- 필수 실험 회귀 검사: 611개 상태·1833개 답안 검사 통과. 보충 모형 불변 조건 검사 통과.
- `npm run test:curriculum`, `npm run test:science-audit`, 작업 범위의 `git diff --check`: 통과.
- 대표 화면은 `visual-refresh/`에 저장하고 계절·자석·소리·빛과 그림자·인체·교배표를 육안 확인했다. 폴더에는 수정 과정의 중간 화면도 포함된다.

## 검증 한계

실제 아이패드 Safari 및 ChromeOS 기기로 실행한 결과는 아니다. 설치된 WebKit 테스트 런타임이 없어 Chrome의 해당 화면 크기로 검사했다. 728개 검사는 각 기본 조작 조건에서 모드별 화면을 확인한 것이며, 모든 슬라이더 값·애니메이션 프레임·모든 보충 도식의 시각적 완전성을 보증하지 않는다. 배포나 커밋은 수행하지 않았다.
