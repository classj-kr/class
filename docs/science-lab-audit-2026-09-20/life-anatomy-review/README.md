# 한살이 그림·움직임 정정 — 2026-09-21

사용자가 지적한 알, 애벌레, 나비, 사마귀, 개구리, 사마귀 알집의 표시 문제를 수정했다. 이전의 실행·배치 검사 통과만으로 생물 그림의 정확성을 보증할 수 없었으며, 이번에는 구조 검사와 실제 렌더링 검토를 구분했다.

## 수정 내용

- 배추흰나비 알: 화면 경계에 잘린 것이 아니라 도형의 뾰족한 끝과 단조로운 바닥선이 잘린 모양처럼 보였다. 닫힌 외곽선, 둥근 끝, 잎에 붙은 밑면과 세로 융기를 다시 그렸다. 닭 알처럼 둥근 타원형으로 바꾸지는 않았다.
- 애벌레: 몸보다 큰 얼굴과 눈 하나를 없애고 작은 머리, 작은 눈 무리와 턱으로 바꿨다. 몸 13마디, 가슴다리 세 쌍, 배다리 다섯 쌍을 구별했다. 통째로 좌우 왕복하던 애니메이션을 마디별 전진 파동으로 바꿨다. 두 걸음 전진 후 잎 가장자리에서 먹이 활동을 하며 뒤로 미끄러지거나 시작점으로 튀지 않는다.
- 나비: 머리·가슴·배, 여섯 다리, 앞날개·뒷날개를 별도 도형으로 그렸다. 날개와 다리의 시작점은 가슴에 있다. 관찰용 날갯짓은 폭 82% 이상을 유지한다. 기존 28% 축소로 날개가 가느다란 선처럼 보이던 문제를 없앴다.
- 사마귀: 길쭉한 앞가슴과 나머지 가슴, 배를 구분하고 여섯 다리를 가슴에 연결했다. 어른벌레 날개는 가슴의 연결점이 보이게 조금 벌린 관찰 자세다. 애벌레 단계에는 날개가 없다. 앞다리는 관절을 중심으로 접힌다.
- 개구리: 화살표 모양의 꺾인 선을 관절이 있는 앞·뒷다리, 앞발 네 발가락과 뒷발 다섯 발가락 및 물갈퀴로 바꿨다.
- 사마귀 알집: 막대 위의 단색 타원 대신 나뭇가지에 부착된 굳은 거품 덩어리의 불규칙한 외곽·음영·표면 결·중앙 이음 부분을 표현했다. 알집 내부의 알을 외부로 드러내지는 않았다.

## 확인 방법

`tests/science-life-anatomy.test.cjs`는 Chrome와 WebKit에서 각각 다음을 확인한다.

- 수정된 7단계(사마귀 애벌레 포함), 1366·1024·820·768px, 움직임 네 시점의 잘림과 가로 넘침.
- 나비·사마귀 여섯 다리와 두 쌍의 날개. 실제 SVG 경로 시작점을 화면 좌표로 바꾸어 가슴과 만나는지 확인.
- 애벌레의 마디·다리 배치. 0~10.4초를 0.2초 간격으로 비교해 어떤 마디도 후진하지 않는지 확인.
- 개구리 앞·뒷다리와 발가락 수, 알의 닫힌 외곽선, 큰 그림과 썸네일의 독립적인 음영 참조.
- 렌더링 오류 및 날개가 가장 접힌 순간의 폭.

`tests/science-observation-motion.test.cjs`로 기존 14단계, 일시정지·재생, 동작 줄이기, 단계 전환과 다른 관찰 실험의 회귀를 함께 확인한다. 화면 캡처는 자동 검사 결과와 별개로 직접 검토한다.

검수 그림: [Chrome](review-chromium.jpg), [WebKit](review-webkit.jpg). 같은 폴더의 개별 PNG는 설명 영역 포함 화면, 생물 도형, 애벌레 이동 종료 상태와 나비의 최소 날개 폭 상태다.

## 근거와 한계

- [UF/IFAS 배추흰나비](https://ask.ifas.ufl.edu/publication/IN283): 알의 부착점과 둥근 끝, 애벌레 형태·배다리, 어른벌레 무늬.
- [Butterfly Conservation 몸의 구조](https://butterfly-conservation.org/discover-and-learn/activities-and-resources/butterfly-body-parts): 머리·가슴·배, 가슴에 붙은 다리·날개.
- [University of Maryland 사마귀](https://extension.umd.edu/resource/praying-mantid-mantis): 굳은 거품 알집, 날개 없는 애벌레와 성충의 모습.
- [AES 곤충 날개](https://www.amentsoc.org/insects/fact-files/wings.html): 가슴과 날개의 연결.
- [호주 정부 양서류 형태 자료](https://www.dcceew.gov.au/sites/default/files/env/pages/dc11235d-8b3b-43f7-b991-8429f477a1d4/files/04-fauna-2a-amphibia-morphology.pdf): 앞발 네 발가락·뒷발 다섯 발가락.

이 그림들은 확대·단순화한 학습용 도해이며 개체의 실측 크기, 이동 속도, 모든 종의 형태를 재현하지 않는다. 관찰하기 쉽게 날개 움직임을 제한했다. WebKit 검사는 실물 iPad Safari 검사와 다르며, 실제 iPad·크롬북 기기 검수와 운영 사이트 배포 확인은 이 검사에 포함하지 않는다. 앱 전체의 완전성이나 무오류를 판정하는 문서가 아니다.
