# 국내 지도 화면·학교급 분리 작업 — 2026-10-11

## 이번 변경

- 지리 개념 아래의 큰 문제 카드와 `필수 그림 / 기본 / 전체` 범위 선택을 제거했다. 개념 선택 바로 아래에서 현재 학교급의 전체 문항을 한 버튼으로 시작한다.
- 현재 개념에서 마지막 응답이 오답인 문항이 있을 때만 오답 복습 버튼을 표시한다. 시도 전에는 진행률도 숨긴다.
- 첫 오답을 선택하고 문제 창을 닫을 때 복습 버튼이 즉시 갱신되지 않던 문제를 수정했다. 첫 응답을 기록하는 기존 동작은 유지한다.
- 학교급 선택을 주제 메뉴와 같은 줄에 배치했다. 별도의 상단 줄을 추가하지 않았다.
- 역사 주제에서도 `초 / 중 / 고`를 사용할 수 있다. 학교급에 따라 지도 목록, 설명, 일부 대표 지점이 바뀐다. 지원하지 않는 지도에서 초로 전환하면 연대순 다음 지원 지도로 이동하고 URL도 갱신한다.
- 역사 지도 29개에 3개를 추가했다. 초 목록 28개, 중·고 목록 각각 32개이다.
- 역사 설명에 출판사·저자 이름을 표시하지 않는다. 과목명은 기존 지도 제목 옆에 짧게 표시한다.
- 모바일에서 역사 지도와 학교급 버튼이 화면을 가로로 넘는 문제를 수정했다.

## 1차 검증 결과 (32개 지도 기준)

- Node 구문 검사: 변경한 JS 5개 통과.
- 데이터 검사: 역사 ID 32개 중복 없음, 연대순 정렬, 표시 좌표 형식, 지원 학교급 설명 누락 없음.
- 실제 브라우저: 초 28개 + 중 32개 + 고 32개 = **92개 선택 조합**을 순회했다. 설명이 표시되고, 지도 마커 수와 지점 목록 수가 일치했다. 역사 사실 92건을 검증했다는 뜻은 아니다.
- 같은 고구려 지도에서 초 4개 지점 / 중·고 5개 지점과 서로 다른 설명을 확인했다.
- `여러 나라의 성장`에서 초로 바꿀 때 가야 지도로 이동하고 URL이 갱신됨을 확인했다.
- 문제 시작 → 첫 오답 → 창 닫기 → 오답 1문제 복습 → 정답 → 복습 버튼 숨김을 확인했다.
- 1280×720, 모바일 390×844에서 배치를 확인했다. 모바일 역사 화면의 `scrollWidth == clientWidth == 375`로 가로 넘침이 해소됐다(스크롤바 제외).
- 로컬 정적 서버는 저장 API가 없어 기록이 탭 메모리에만 남는다. 이번 검사로 서버 저장·학생 계정 연동을 검증한 것은 아니다.
- 배포·커밋하지 않았다.
