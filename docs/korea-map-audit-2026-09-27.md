## 실제 검사 범위

- 지리 7개 주제, 28개 수업, 195개 문항(기존 139 + 그림 56).
- 모든 문항을 각 수업의 ‘전체’ 경로로 열고, 섞인 보기에서 정답을 선택해 결과 화면까지 완료. 잘못된 첫 답·재시도·학습 기록 유지도 검사.
- SVG 글자 영역, 기후 그래프·표·지도 자료 표시, 문제 화면 넘침 확인.
- 전체 10개 탭을 390·820·1440px 폭에서 검사. 화면 너비 초과 없음. 실제 휴대폰 기기 시험은 아님.
- 29개 역사 지도: 시대 이동, 표지·이름·범위·출처·옆 탭 전환. 영토 지도 28개 장면의 39개 시기별 SVG 영역 해독·범례·전환 검사. 6·25 전쟁 6단계 문제·키보드·피드백 검사.
- 유물·유적 68개: PC·모바일에서 군집을 풀어 각각 접근 가능. 체험·관광 308개: 기존 본문·글꼴·화면 배치 검사.
- 하천 이동 방향·합류점·실제 클릭·팬/줌 정렬·계절 전환·애니메이션 정지 조건·자료 로딩 실패 처리 검사.

주요 화면을 직접 확인해 기능 검사만으로 놓칠 수 있는 배경 대비와 수업별 보조 자료 혼합도 수정했다.

## 자동 검사 결과

19개 스크립트 중 **16개 통과, 3개 실패**. 실패를 통과로 간주하지 않았다.

통과: `study`, `reading`, `region-labels`, `layout`, `flow`, `navigation`, `history`, `heritage`, `war`, `history-cleanup`, `territories`, `bronze`, `fill`, 앱 계약, 메뉴 계약, 새 `theme-integrity`.

- `tests/korea-map-theme-integrity.cjs`: 이번 오류의 핵심인 지연 응답·28개 수업 주제 정보·범례·화면 폭·순수비 사진 연결을 검사한다.
- `tests/korea-map-study.cjs`: 일부 대표 수업만 풀던 검사를 28개 수업 전체 풀이로 확대했고, 중복 보기·인구 비율 합계 검사도 추가했다.
- 앱 계약 검사는 역사 탭을 누락한 과거 9개 탭 기대값과 캐시 버전 형식을 현재 앱에 맞췄다.
- 역사 검사 3개는 기존 고정 포트가 열려 있지 않아 초기 실패했다. SVG MIME을 제공하는 로컬 서버 주소로 다시 실행해 통과했다.
- 실패한 `water`, `mountain`, `transition`은 현재 `index.html`에서 불러오지 않는 별도 유역·산악 단면 모듈을 기대한다. 현재 제공 화면과 검사 대상이 불일치한다. 기존 파일·검사를 삭제하거나 대규모 기능을 임의로 복원하지 않았다.

검사 산출물: `outputs/korea-map-audit/final-results.json`, `theme-regression.json`, 각 스크립트 로그, 주제별 화면 JPG. 이 폴더는 임시 산출물이며 저장소 추적 대상이 아닐 수 있다.

## 정확성 확인이 남은 항목

1. **도시 인구 원의 기준연도·원자료 부재.** `geo-data.js`에 남북한 도시 37개의 인구 수치가 있으나 기준연도와 집계 기준이 기록되어 있지 않다. 표시 동작은 확인했지만 최신 인구 통계로 인증할 수 없다. 원자료를 확보해 동일 기준으로 교체하거나, 기준이 다른 남북 자료를 분리해야 한다. 임의로 최신 연도를 붙이지 않았다.
2. **다른 순수비의 사진 연결.** 창녕·황초령·마운령 등은 북한산 사진 연결과 별개로 각각의 실제 사진·소장 정보·이용 조건을 확보해야 한다.
3. **동적 현실 정보의 최신성.** 체험·관광 308개 장소의 영업·예약·휴관, 전체 교통 노선의 최신 개통 여부를 기관별로 전수 대조하지 않았다. 학습 화면 동작 검사와 현실 운영 정보 확인을 구분한다.
4. **사실 인증의 범위.** 문항 설명의 오류·모호성은 점검했지만, 모든 역사 경계 좌표·유물 설명·산업 통계를 원전과 한 항목씩 대조한 학술 감수는 아니다. 앱이 실행된다는 이유로 모든 사실이 검증됐다고 판단해서는 안 된다.
