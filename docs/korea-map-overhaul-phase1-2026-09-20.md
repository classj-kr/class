# 한국지도 대개편 1차 구현 기록

2026-09-20 · 로컬 코드 반영 및 Chrome 검증. 운영 사이트 배포 여부는 검증하지 않았다.

후속 변경(2026-09-21): 아래는 1차 당시 기록이다. 현재 하천은 세계지도의 14개 흐름 프레임·색·굵기·50ms 갱신 방식을 Canvas에 연결하며 캡슐·화살표 입자를 사용하지 않는다. 수동 재생·일시정지 버튼과 상태는 사용자 요청으로 삭제했다. 자동 재생과 접근성·비활성 화면 자동 정지는 유지한다. 실제 지도 단면과 산 넘는 바람의 후속 구현은 [2차 기록](korea-map-overhaul-phase2-2026-09-21.md)을 따른다.

## 구현한 장면

- 지형 탭에 들어가면 주요 하천 12개, 선형 13개에 하류 방향으로 움직이는 물빛과 화살표가 즉시 표시된다. 강 이름 선택 또는 실제 강 선 클릭으로 해당 강을 따라간다.
- 한강을 선택하면 남한강·북한강·임진강을 함께 표시하고 두물머리와 하류를 연결한다. 지류만 선택해도 연결되는 한강 본류가 남는다.
- 기후 탭의 여름·겨울 전환은 바람 방향, 비교 카드, 지도 위 A/B의 기온을 함께 바꾼다. 춘천–강릉, 대관령–강릉 두 쌍을 비교한다.
- 일시정지·재생을 제공한다. 동작 줄이기 설정에서는 정지된 방향 표시를 유지한다. 비활성 탭, 화면 밖 지도, 문제·상세 대화상자, 단면도 점 찍기 중에는 애니메이션이 멈춘다. 문제 지도에는 새 레이어를 추가하지 않는다.
- Canvas 레이어는 클릭을 받지 않는다. 새 합류점·비교 지점의 Canvas도 표시 전용 pane에 넣었다. 기존 유물·여행 표식의 이벤트를 변경하지 않았다.
- 하천을 작은 선 조각으로 그릴 때 흰 테두리가 이웃 조각을 덮던 순서를 고쳐 점선처럼 보이는 이음새를 줄였다.
- 늦게 도착하는 하천 자료가 기후 탭 직접 진입에도 반영되며, 자료 수신 때문에 학습 개념이나 지도 위치를 초기화하지 않는다. 자료 실패는 조작부에 표시한다.
- 큰 중복 제목·불필요한 위쪽 빈 공간·전체 문제은행 실행 버튼을 다시 추가하지 않았다. 비교 설명은 KoPubWorld 바탕체다.

## 자료의 의미와 한계

하천은 저장소의 `data/major-rivers.geojson`을 사용한다. 원본 출처는 OpenStreetMap 기여자/Nominatim이다. `data/flow-data.js`에 강별 방향과 하류 끝점·합류 관계를 별도로 기록했다. 한강·금강·섬진강의 원본 배열을 역순으로 읽으며, 원본 파일 자체는 변경하지 않는다. 강 이름이 있는 12개만 대상으로 하고 방향 정보가 없는 선형은 움직이지 않는다.

현재 선형에는 강의 일부 구간만 포함된 사례가 있다. 시작점을 발원지로 표시하지 않으며, 이동 속도·선의 굵기는 실제 유속·유량을 의미하지 않는다. 한강 합류점은 남한강·북한강 끝점과 한강 시작점이 동일한 좌표인지 검사했다. 본류와 지류를 임의의 유역 다각형으로 포장하지 않았다.

바람 경로는 [기상청의 우리나라 기후 설명](https://www.weather.go.kr/w/climate/statistics/korea.do)을 바탕으로 만든 대표적인 계절풍 모형이다. 여름 남서풍·겨울 북서풍을 구별하되, 현재 관측·예보·지역별 바람장·실제 풍속으로 표시하지 않는다. 지형을 넘으며 변하는 국지적 바람은 이번 애니메이션의 계산 대상이 아니다.

비교 수치는 [기상청 지역별 기후특성 — 강원](https://www.weather.go.kr/w/climate/statistics/region.do?area=2)의 1991–2020 평년값을 사용한다. 여름은 6–8월, 겨울은 12–2월이다. 기온은 계절 평균, 강수량은 계절 합계다. 두 지역과 두 계절에 공통 눈금을 적용했고 음의 기온은 영점 왼쪽에 그린다. 카드에는 출처와 평년 기간을 표시한다. 기존 월별 학습 모형 그래프·문항은 변경하지 않았다.

## 검증

- `node tests/korea-map-flow.cjs`: 12개 강/13개 선의 방향 끝점, 한강 합류, 원본 불변, 실제 Canvas 픽셀 이동, 강 선 클릭, 선택 변경, 확대·이동 정렬, 재생·정지, 동작 줄이기, 백그라운드 탭, 문제 격리, 계절과 수치 동시 변경, 자료 실패, 직접 기후 진입, 390/820/1051/1440px 화면. JavaScript 오류 0.
- `node tests/korea-map-study.cjs`: 28개 개념·195개 기존 지리 문항, 첫 응답 기록 저장·복원 및 문제 풀이.
- `node tests/korea-map-reading.cjs`: 308곳·616문단 유지, 실제 KoPubWorld 글꼴 로드, 설명·선지·문항 글꼴, 모바일 상세창.
- `node tests/korea-map-layout.cjs`: 390/820/1051/1440/1920px, 전체 28개 개념의 SVG 글자 범위·위쪽 여백·지도 크기.
- `node tests/korea-map-heritage.cjs`: PC/모바일 각각 유물 상세창 315회 실제 클릭, 합계 630회. 최대 확대에서 68곳 접근, 묶음/필터/키보드/동일 좌표 사례.
- `node tests/korea-map-navigation.cjs`: 지도 주변 국가 탐색, 경계·확대 축소·창 크기·숨겨진 문제 지도.

검증 산출물은 `outputs/korea-map-flow/`와 기존 검사별 출력 폴더에 있다. 움직임은 스크린샷만으로 판정하지 않고 시간이 다른 두 Canvas의 위상·픽셀 해시가 달라지는지 확인했다. 입자는 작은 지도에서 최대 180개, 큰 지도에서 최대 420개로 제한하며 일반 재생은 최대 약 20Hz로 그린다. 실제 저사양 휴대폰 성능 측정은 아직 하지 않았다.

## 후속 범위 — 완료로 표시하지 않음

1. 출처와 경계가 검증된 유역 자료, 빗물이 합류하는 지점 추적.
2. 실제 산지 위치·단면과 연결된 풍상/풍하·푄 실험.
3. 해류와 조석을 분리한 해안 장면.
4. 유역·도시·산업·교통의 겹쳐 보기와 여행/유물 관찰 활동 연결.
5. 운영 배포 확인 및 실제 휴대폰 성능 측정.
