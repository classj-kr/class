학교 도입 안내

학교 Google Workspace 관리자용 · 최초 1회 · 약 3분

학생 계정, 특히 18세 미만으로 지정된 계정은 학교 관리자가 허용하지 않은 외부 앱에 Google로 로그인할 수 없습니다. 학생이 클래스제이에서 Google 로그인을 누를 때 “관리자가 차단함” 같은 메시지가 뜬다면 아래 설정이 필요합니다.

등록할 앱
서비스: 클래스제이 (https://joyclass.kr)
OAuth 클라이언트 ID:
40207792836-p4khj60t06rmcbaalh585fr2jvh84685.apps.googleusercontent.com

관리 콘솔 화면은 업데이트에 따라 메뉴 이름이 조금 다를 수 있습니다. 괄호 안 영문을 함께 참고해 주세요.

설정 방법

  1. Google 관리 콘솔 접속

    admin.google.com에 학교 최고 관리자 계정으로 로그인합니다.

  2. API 관리 메뉴로 이동

    왼쪽 메뉴에서 보안 (Security) → 액세스 및 데이터 제어(또는 액세스 및 데이터 관리) → API 관리 (또는 API 제어 / API controls)를 누릅니다.

  3. 서드 파티 앱 관리 화면 열기

    앱 액세스 제어 (App access control) 항목에서 서드 파티 앱 액세스 관리 (Manage Third-Party App Access)를 누릅니다.

  4. 앱 추가

    구성된 앱 (Configured apps) 목록 위의 앱 추가 (Add app)를 누르고, OAuth 앱 이름 또는 클라이언트 ID (OAuth App Name Or Client ID)를 선택합니다.

  5. 클라이언트 ID로 검색 후 선택

    • 검색창에 위 클라이언트 ID 전체를 붙여넣고 검색 (Search)을 누릅니다. 이름으로 검색하면 비슷한 앱이 섞일 수 있으니 ID로 검색해 주세요.
    • 결과에 클래스제이(ClassJ) 앱이 나오면 선택 (Select)을 누릅니다.
    • 클라이언트 ID 목록에서 40207792836-p4kh…로 시작하는 ID에 체크하고 선택을 누릅니다.

  6. 적용 대상(조직 단위) 지정

    • 모든 학생 허용: 최상위 조직(학교 도메인 전체) 또는 학생 조직 단위를 선택합니다.
    • 특정 학년·반만 허용: 해당 조직 단위(예: 학생/6학년)를 선택합니다.

    선택 후 계속 (Continue)을 누릅니다.

  7. ⭐ 액세스 권한: ‘신뢰할 수 있음’ 선택

    신뢰할 수 있음 (Trusted)을 선택합니다.

    ⚠️ 제한됨 (Limited)으로 두면 18세 미만 학생 계정은 로그인이 막힐 수 있습니다.

    화면 하단의 구성 (Configure) 또는 저장을 눌러 설정을 완료합니다.

확인

  • 구성된 앱 목록에 클래스제이가 추가되고 액세스 권한이 ‘신뢰할 수 있음’으로 표시되는지 확인합니다.
  • 설정이 반영되기까지 보통 몇 분, 길게는 최대 24시간이 걸릴 수 있습니다.
  • 학생 계정으로 joyclass.kr에 접속해 Google 로그인이 되는지 확인합니다.

문제 해결

증상확인할 점
클라이언트 ID로 검색해도 앱이 안 나옴ID를 앞뒤 공백 없이 .apps.googleusercontent.com까지 전부 붙여넣었는지 확인
설정했는데도 “관리자가 차단함” 메시지가 뜸① 학생 계정이 선택한 조직 단위에 속해 있는지 ② 권한이 ‘신뢰할 수 있음’인지 확인한 뒤 잠시 후 다시 시도
일부 학생만 로그인이 안 됨그 학생이 다른 조직 단위에 있을 가능성이 큽니다. 해당 조직 단위에도 같은 설정을 추가하거나 상위 조직에 적용

그래도 해결되지 않으면 문의·권리 요청(로그인 필요)으로 알려 주세요.
