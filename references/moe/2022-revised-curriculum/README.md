# 2022 개정 초·중등학교 교육과정

교육부 고시 제2022-33호에 따른 초·중등학교 교육과정 원문 참고자료를 보관하는 곳입니다.

## 출처

- 기관: 교육부
- 제목: `[교육부 고시 제2022-33호] 초중등학교 교육과정 총론 및 각론 고시`
- 등록일: 2022-12-22
- 원문: <https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0>

## 폴더 구성

- `extracted/`: 사이트 제작과 검색에 바로 사용할 수 있도록 HWP 내용을 변환한 UTF-8 텍스트 자료
- `scripts/restore_2022_curriculum.py`: 교육부 공식 첨부 파일에서 이 자료를 다시 만드는 복원 스크립트

## 보관 자료

1. 별책 1~4: 총론 및 초·중·고 학교급별 교육과정
2. 별책 5~14: 국어, 도덕, 수학, 사회, 과학, 실과·기술가정·정보, 체육, 음악, 미술, 영어
3. 별책 15~22: 바른 생활·슬기로운 생활·즐거운 생활, 제2외국어, 한문, 중학교 선택, 고등학교 교양 및 계열 선택 과목
4. 별책 40: 창의적 체험활동 교육과정

직업계고 전문교과인 별책 23~39와 2017년 고시에 따른 한국어 교육과정인 별책 41은 현재 사이트 범위에서 제외했습니다.

## 사용 원칙

- 자료는 UTF-8 텍스트로 보관하여 코드 검색과 콘텐츠 가공에 사용합니다.
- 실제 방문자에게 제공할 내용만 검토·요약하여 사이트 데이터 파일로 옮깁니다.
- 내용을 인용할 때는 교육부 고시 번호와 원문 URL을 함께 표시합니다.
- 원본을 잃었을 때는 저장소 루트에서 `python -m pip install olefile`을 한 번 실행한 뒤 `python scripts/restore_2022_curriculum.py`를 실행합니다.
